## Rules

- If <DirectoryListing> is used → **warning**: add `import { DirectoryListing } from "~/components"`.
- Use on `navigation` and `overview` pages to auto-generate a listing of child pages.

## Example

```mdx
import { DirectoryListing } from "~/components";

<DirectoryListing />
```

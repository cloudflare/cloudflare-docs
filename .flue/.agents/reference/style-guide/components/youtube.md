## Rules

- If <YouTube> is used → **warning**: add `import { YouTube } from "~/components"`.
- If `<YouTube>` is missing the `id` prop → **warning**: `id` is required.

## Example

```mdx
import { YouTube } from "~/components";

<YouTube id="XHvmX3FhTwU" />
```

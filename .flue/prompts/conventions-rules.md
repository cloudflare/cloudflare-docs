Report only these issues:

- For docs-content changes, the title does not identify the affected product, feature, or content area.
- The description is empty, only an empty template, or so minimal that it provides no meaningful explanation of the work. A brief but clear description passes.
- The description omits a core change evident from the changed files, such as a new page, removed or moved page, substantial rewrite, or distinct product-area change. Do not require minor incidental edits or extra detail.

A changed file with status `added` is a new file and `removed` is a deleted file, whatever the line counts. A new or removed docs page is a core change.

Do not second-guess author intent, enforce a template, or report an ambiguous omission.

Create a `preset.json` file for the role you are configuring, using the [Create Preset API schema](/api/resources/realtime_kit/subresources/presets/methods/create/). Include a distinct preset name and all required `config`, `permissions`, and `ui` fields.

Apply these webinar settings:

- Set `config.view_type` to `WEBINAR`.
- Set `permissions.stage_enabled` to `true` for both presets.
- Set `permissions.can_accept_production_requests` to `true` for presenters who moderate stage requests and `false` for viewers.

Set the following permissions to the same value for that role:

- `permissions.stage_access`
- `permissions.media.audio.can_produce`
- `permissions.media.video.can_produce`
- `permissions.media.screenshare.can_produce`

Choose the value based on the stage behavior you want:

| Stage behavior        | Applies to                                | Value         |
| --------------------- | ----------------------------------------- | ------------- |
| _Allowed to join_     | Presenters                                | `ALLOWED`     |
| _Can request to join_ | Viewers who can request to join the stage | `CAN_REQUEST` |
| _Can only view_       | View-only viewers                         | `NOT_ALLOWED` |

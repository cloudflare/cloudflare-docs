Durable Objects may shut down at any time due to deployments, inactivity, or runtime decisions. Design your application to write state incrementally rather than relying only on a shutdown notification.

Use the best-effort [`[shutdown]()`](/durable-objects/api/base/#shutdown) hook for clean shutdown logic. The hook runs before idle eviction and code-update resets, but it is not guaranteed to run.

Persist important changes during normal request processing. SQLite storage operations such as `sql.exec()` are synchronous, while key-value storage operations are strongly consistent and complete asynchronously.

For example, persist each event as it arrives rather than buffering events in memory until shutdown:

<TypeScriptExample filename="index.ts">
```ts
import { DurableObject, shutdown } from "cloudflare:workers";

export class EventRecorder extends DurableObject<Env> {
	async recordEvent(eventId: string, payload: string) {
		await this.ctx.storage.put(`event:${eventId}`, payload);
	}

	async [shutdown](info) {
		// Record shutdown metadata, but do not rely on this write for progress.
		await this.ctx.storage.put("lastShutdownReason", info.reason);
	}
}
```
</TypeScriptExample>

This approach ensures that recorded events survive an unexpected shutdown. Refer to [`[shutdown]()`](/durable-objects/api/base/#shutdown) for hook details.

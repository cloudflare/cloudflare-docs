:::caution[Do not use `prepare: false` with Postgres.js]

[`prepare: false`](https://github.com/porsager/postgres?tab=readme-ov-file#prepared-statements) disables prepared statements. Postgres.js then sends additional protocol messages to discover parameter types before each query. Hyperdrive's [transaction pooling mode](/hyperdrive/concepts/how-hyperdrive-works/#pooling-mode) does not reliably support this behavior. This can cause queries to hang or fail intermittently.

:::

import { PackageManagers } from "~/components";

Use the Nimbus {props.type} recipe to generate this page. Your coding agent pulls the full page skeleton and self-review checklist, then adapts them to your product:

<PackageManagers type="exec" pkg="@cloudflare/nimbus-docs" args={`add ${props.recipe}`} />

Adapt the frontmatter the recipe emits to Cloudflare's schema: set [`pcx_content_type`](/style-guide/frontmatter/custom-properties/#pcx_content_type) and `products` instead of the generic fields the recipe emits, such as `type`.

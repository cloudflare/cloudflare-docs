A bucket stores your objects in R2. To create a new R2 bucket:

<Tabs>
<TabItem label="Wrangler CLI">

1. Log in to your Cloudflare account:

```sh
npx wrangler login
```

2. Create a bucket named `my-bucket`:

```sh
npx wrangler r2 bucket create my-bucket
```

If prompted, select the account you want to create the bucket in.

3. Verify the bucket was created:

```sh
npx wrangler r2 bucket list
```

</TabItem>
<TabItem label="Dashboard">

<Steps>
1. In the [Cloudflare Dashboard](https://dash.cloudflare.com/?to=/:account/r2/overview), go to **R2 > Overview**.
2. Select **Create bucket**.
3. Enter a name for your bucket.
4. Select a [location](/r2/reference/data-location) for your bucket and a [default storage class](/r2/buckets/storage-classes/).
5. Select **Create bucket**.
</Steps>

</TabItem>
</Tabs>

Browser Rendering offers multiple integration methods depending on your use case:

- **[Quick Actions](/browser-rendering/quick-actions/)**: Simple HTTP endpoints for stateless tasks like screenshots, PDFs, and scraping.
- **[Puppeteer](/browser-rendering/puppeteer/)**, **[Playwright](/browser-rendering/playwright/)**, and **[Stagehand](/browser-rendering/stagehand/)**: Direct browser control within Cloudflare Workers.
- **[CDP](/browser-rendering/cdp/)**: Connect from any environment using Chrome DevTools Protocol for session management and browser control.

| Use case | Recommended | Why |
| --- | --- | --- |
| Simple screenshot, PDF, or scrape | [Quick Actions](/browser-rendering/quick-actions/) | No code deployment; single HTTP request |
| Browser automation | [Playwright](/browser-rendering/playwright/), [Puppeteer](/browser-rendering/puppeteer/), or [CDP](/browser-rendering/cdp/) | Full browser control with scripting |
| Porting existing scripts | [Puppeteer](/browser-rendering/puppeteer/), [Playwright](/browser-rendering/playwright/), or [CDP](/browser-rendering/cdp/) | Minimal code changes from standard libraries |
| AI-powered data extraction | [JSON endpoint](/browser-rendering/quick-actions/json-endpoint/) | Structured data via natural language prompts |
| Site-wide crawling | [Crawl endpoint](/browser-rendering/quick-actions/crawl-endpoint/) | Multi-page content extraction with async results |
| AI agent browsing | [CDP with MCP clients](/browser-rendering/cdp/mcp-clients/) | LLMs control browsers via MCP |
| Resilient scraping | [Stagehand](/browser-rendering/stagehand/) | AI finds elements by intent, not selectors |

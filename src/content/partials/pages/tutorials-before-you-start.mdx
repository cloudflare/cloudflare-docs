## Before you continue

This guide assumes you already have a fundamental understanding of [Git](https://git-scm.com/). If you are new to Git, refer to the [GitHub guide to Git](https://docs.github.com/en/get-started/using-git/about-git) on how to set up Git on your local machine.

If you clone with SSH, you must [generate SSH keys](https://docs.github.com/en/authentication/connecting-to-github-with-ssh/generating-a-new-ssh-key-and-adding-it-to-the-ssh-agent) on each computer you use to push or pull from GitHub.

Refer to the [GitHub documentation](https://docs.github.com/en/get-started/using-git/about-git) and [Git documentation](https://git-scm.com/book/en/v2) for more information.

For new static sites and full-stack applications, start with [Cloudflare Workers](/workers/static-assets/get-started/). Workers supports [static assets](/workers/static-assets/), [framework guides](/workers/framework-guides/), [automatic configuration](/workers/framework-guides/automatic-configuration/) for existing projects, and [Git-connected builds](/workers/ci-cd/builds/). If you already run a Pages project and want to move to Workers, refer to the [Pages to Workers migration guide](/workers/static-assets/migration-guides/migrate-from-pages/).

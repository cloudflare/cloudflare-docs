Artifacts is only available on the [Workers Paid plan](/workers/platform/pricing/).

| Unit                          | Workers Free | Workers Paid                                                            |
| ----------------------------- | ------------ | ----------------------------------------------------------------------- |
| Operations (1,000 operations) | Unavailable  | First 10,000 per month included + $0.15 per additional 1,000 operations |
| Storage (GB-mo)               | Unavailable  | First 1 GB per month included + $0.50 per additional GB-mo              |
| Repositories per account      | Unavailable  | First 100,000 included + $0.01 per additional repository per month      |

The repository allowance applies across all namespaces in your account. Namespaces group repositories and do not incur an additional resource charge. Repository charges apply alongside operations and storage charges.

Refer to [Artifacts limits](/artifacts/platform/limits/) for repository and storage limits.

Use Trace when you need to test what would happen with a simulated request:

- Understanding why a rule did not trigger as expected
- Testing how your rules handle different request scenarios
- Seeing the evaluation order of your rules
- Simulating requests from different geolocations or conditions
- Verifying that a specific path is not blocked or modified by existing WAF, cache, or firewall rules before enabling a new feature — for example, confirming your [Google tag gateway for advertisers](/google-tag-gateway/) measurement path will not be intercepted by a WAF custom rule or rate limiting rule

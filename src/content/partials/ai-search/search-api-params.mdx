`messages` <Type text="array" /> <MetaInfo text="required" />

An array of message objects. Each message has:

- `content` <Type text="string" /> - The search query content.
- `role` <Type text="string" /> - The role: `user`, `system`, or `assistant`.

`filters` <Type text="object" /> <MetaInfo text="optional" />

Narrow down search results based on metadata. Refer to [Metadata filtering](/ai-search/configuration/metadata/) for syntax and examples.

For the full list of optional parameters, refer to the [Search API reference](/api/resources/ai_search/subresources/instances/methods/search/).

To edit member permissions using the dashboard:

1. In the Cloudflare dashboard, go to the **Members** page.

		<DashButton url="/?to=/:account/members" />

3. On the member's row, select **...** > **View & Edit permission policies**.

4. On the **Permission policies** tab, make your changes:

   - To add a policy, select **Create a policy**, choose the [scope](/fundamentals/manage-members/scope/) and [roles](/fundamentals/manage-members/roles/), then select **Create policy**.
   - To change an existing policy, select **...** > **Edit policy** on its row, adjust the scope and roles, then save your changes.
   - To remove a policy, select **...** > **Delete policy** on its row.

To edit member permissions using the API, first get the permission group ID you want to assign from the [Permission Groups API](/api/resources/iam/subresources/permission_groups/).

Then send a [`PUT` request](/api/resources/accounts/subresources/members/methods/update/) with the member's full `policies` array.

:::note
This request replaces the member's existing policies. Include any current policies you want to keep along with the changes you are making.
:::


```bash title="Request"
export PERMISSION_GROUP_ID='...' # id from the permission_groups API response

curl --request PUT \
  --url https://api.cloudflare.com/client/v4/accounts/{account_id}/members/{member_id} \
  --header 'Authorization: Bearer <API_TOKEN>' \
  --header 'Content-Type: application/json' \
  --data '{
    "policies": [
      {
        "access": "allow",
        "permission_groups": [
          {
            "id": "'"$PERMISSION_GROUP_ID"'"
          }
        ],
        "resource_groups": [
          {
            "scope": {
              "key": "com.cloudflare.api.account.{account_id}",
              "objects": [
                {
                  "key": "*"
                }
              ]
            }
          }
        ]
      }
    ]
  }'
```

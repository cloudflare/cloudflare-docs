:::note
**Important Update:** Cloudflare User Groups replace the older Virtual Groups model that mapped IdP groups directly to Cloudflare roles (identified by the pattern `CF-<accountID> - <Role Name>`). Virtual Groups are deprecated. Migrate to SCIM User Groups to keep group-based provisioning support in the Cloudflare dashboard. For migration steps, refer to [SCIM v1 to v2 Migration](/fundamentals/reference/migration-guides/scim-virtual-groups-migration/).
:::

To request a DCV recheck for a Universal SSL certificate pack, use the [Update SSL Certificate Pack Validation Method endpoint](/api/resources/ssl/subresources/verification/methods/edit/). Omit `validation_method` or specify the current method.

For an advanced certificate, use the [Certificate Pack PATCH endpoint](/api/resources/ssl/subresources/certificate_packs/methods/edit/). This endpoint keeps the current validation method.

Cloudflare may queue the recheck rather than complete validation before returning the response. The certificate pack can still show `pending_validation` while the recheck is queued or validation remains incomplete.

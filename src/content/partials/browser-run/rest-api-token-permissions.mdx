To use this endpoint via the REST API, [create a custom API Token](/fundamentals/api/get-started/create-token/) with `Browser Rendering - Edit` permission. To use it from a Worker with a [browser binding](/browser-run/reference/wrangler/#bindings), no API token is needed. For more information, refer to [Quick Actions — Before you begin](/browser-run/quick-actions/#before-you-begin).

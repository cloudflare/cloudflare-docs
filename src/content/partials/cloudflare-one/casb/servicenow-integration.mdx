## Integration prerequisites

- `admin` access to a {props.environmentName}
- Ability to [configure an OAuth authorization code grant for an inbound integration](https://www.servicenow.com/docs/r/platform-security/authentication/configure-an-oauth-authorization-code-grant.html)

### Create an inbound integration

1. In ServiceNow, go to **Machine Identity Console** > **Inbound integrations**.
2. Select **New integration** > **OAuth - Authorization code grant**.
3. For **Provider name**, enter `Auth0`.
4. Set **Redirect URL** to the URL shown in Cloudflare.
5. Leave **This is a public client** turned off.
6. [Configure a REST API Auth Scope](https://www.servicenow.com/docs/r/platform-security/authentication/configure-rest-api-auth-scope.html) that grants `GET` access to the **Table API**.
7. In **Scope validation settings**, turn on **Allow access only to APIs in selected scope**.
8. Select **Submit**, then copy the client ID and client secret into Cloudflare.

## Integration permissions

Cloudflare CASB requires `GET` access to the ServiceNow Table API. The authorizing user's roles and access control lists must permit reading the `incident`, `instance`, `kb_knowledge`, and `sys_user` tables. For more information, refer to the [ServiceNow Table API documentation](https://www.servicenow.com/docs/r/api-reference/rest-apis/c_TableAPI.html).

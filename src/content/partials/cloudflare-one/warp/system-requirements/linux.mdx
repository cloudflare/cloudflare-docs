|                            |                                                                                                                        |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **OS version**             | RHEL 9 [^1], RHEL 10, Debian 12, Debian 13, Fedora 43, Fedora 44, Ubuntu 22.04 LTS, Ubuntu 24.04 LTS, Ubuntu 26.04 LTS |
| **Processor**              | AMD64 / x86-64 or ARM64 / AArch64                                                                                      |
| **vCPU**                   | 3 minimum, 4 recommended                                                                                               |
| **RAM without a desktop**  | 1 GB minimum, 2 GB recommended (for example, Ubuntu Server)                                                            |
| **RAM with a desktop**     | 4 GB minimum, 8 GB recommended (for example, Ubuntu GNOME)                                                             |
| **Disk space**             | 250 MiB minimum, 500 MiB recommended                                                                                   |
| **Network interface type** | Wi-Fi or LAN                                                                                                           |
| **MTU**                    | 1381 bytes recommended [^2]                                                                                            |

[^1]: On RHEL 9 and later, enable the [Extra Packages for Enterprise Linux (EPEL)](https://docs.fedoraproject.org/en-US/epel/) repository (`sudo dnf install https://dl.fedoraproject.org/pub/epel/epel-release-latest-$(rpm -E %rhel).noarch.rpm`) before installing `cloudflare-warp`. On RHEL 10, also enable the CodeReady Linux Builder (CRB) repository. EPEL and CRB provide dependencies required by the client.

[^2]: Minimum 1281 bytes with [Path MTU Discovery](/cloudflare-one/team-and-resources/devices/cloudflare-one-client/deployment/mdm-deployment/path-mtu-discovery/)

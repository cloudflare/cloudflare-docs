Cloudflare Mesh is available in beta to Cloudflare One accounts, including accounts on the Free plan.

## Platform requirements

- Mesh nodes require a [supported Linux distribution](/cloudflare-one/team-and-resources/devices/cloudflare-one-client/download/#linux) or the [`cloudflare/mesh` container image](/mesh/guides/run-mesh-in-containers/).
- Client devices can use any [operating system supported by the Cloudflare One Client](/cloudflare-one/team-and-resources/devices/cloudflare-one-client/download/).
- Mesh nodes must use the MASQUE device tunnel protocol. Hostname routes, IPv6 CIDR routes, and high availability do not work with WireGuard.
- Using Cloudflare Mesh with Cloudflare WAN requires [Unified Routing mode](/cloudflare-wan/reference/traffic-steering/#unified-routing).

## Host sizing

We recommend a host with at least 4 virtual CPUs (vCPUs) and 4 GB of RAM for each Mesh node. On this host, a Mesh node typically carries 350 to 750 Mbps. A device that runs the Cloudflare One Client typically carries the same range.

Use these figures for planning. They are not guarantees, because your traffic and network path also affect throughput.

A host with fewer resources delivers less throughput. At this time, a host with more resources does not raise throughput above this range. For sustained throughput above 1 Gbps at a site, use [Cloudflare WAN](/cloudflare-one/networks/connectors/cloudflare-wan/).

To compare throughput across connectors, refer to [Connector selection](/cloudflare-one/networks/connectors/choose-a-connector/#throughput).

For deployment recommendations and interoperability constraints, refer to [Best practices](/mesh/best-practices/).

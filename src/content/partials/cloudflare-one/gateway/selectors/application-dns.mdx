You can apply {props.policyType} policies to Cloudflare-managed applications and [custom applications](/cloudflare-one/team-and-resources/app-library/custom-applications/) created in your account with the same Application selector. Refer to [Applications and app types](/cloudflare-one/traffic-controls/application-app-types/) for more information.

| UI name     | API example                | Evaluation phase                |
| ----------- | -------------------------- | ------------------------------- |
| Application | `any(app.ids[*] in {505})` | Before and after DNS resolution |

DNS application matching uses hostnames and resolved IP addresses, without checking the application's port/protocol constraints. Refer to [custom application matching](/cloudflare-one/traffic-controls/application-app-types/#custom-application-matching).

[Event subscriptions](/queues/event-subscriptions/) allow you to receive messages when events occur across your Cloudflare account. Cloudflare products (for example, [KV](/kv/), [Workers AI](/workers-ai/), and [Workers](/workers/)) can publish structured events to a [queue](/queues/). You can process these events with Workers or [HTTP pull consumers](/queues/configuration/pull-consumers/), or send them to [notification destinations](/queues/configuration/notification-consumers/).

For more information on [Event Subscriptions](/queues/event-subscriptions/), refer to the [management guide](/queues/event-subscriptions/manage-event-subscriptions/).

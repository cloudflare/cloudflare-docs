**On-demand video events** — Subscribe to the `stream` source to receive events for on-demand videos in your account. The `payload` mirrors the [`StreamVideo`](/stream/manage-video-library/bindings/) object returned by `env.STREAM.video(id).details()`.

**Live input events** — Subscribe to the `stream.liveInput` source to receive events for live inputs in your account.

#### `live_input.connected`

Triggered when a broadcaster connects to a live input and begins sending video.

**Example:**

```json
{
	"type": "cf.stream.liveInput.live_input.connected",
	"source": {
		"type": "stream.liveInput",
		"liveInputId": "fc0a8dc887b16759bfd87bce36f8f5b1"
	},
	"payload": {
		"uid": "fc0a8dc887b16759bfd87bce36f8f5b1",
		"status": {
			"current": {
				"state": "connected",
				"reason": null,
				"statusEnteredAt": "2026-05-28T18:00:11.000Z",
				"statusLastSeen": "2026-05-28T18:00:11.000Z"
			}
		}
	},
	"metadata": {
		"accountId": "f9f79265f388666de8122cfb508d7776",
		"eventSubscriptionId": "1830c4bb612e43c3af7f4cada31fbf3f",
		"eventSchemaVersion": 1,
		"eventTimestamp": "2026-05-28T18:00:11.084Z"
	}
}
```

### Live input events

**Live input events** — Subscribe to the `stream` source to receive live input events for your account. The `payload` mirrors the live input object returned by the [Stream API](/api/resources/stream/subresources/live_inputs/), with a top-level `status` field reflecting the current connection state.

:::caution

Live input event `payload` objects include RTMPS, SRT, and WebRTC stream keys and passphrases. Treat the message body as sensitive.

:::

#### `live_input.connected`

Triggered when a broadcaster connects to a live input and begins sending video.

**Example:**

```json
{

	"source": {
		"type": "stream"

			"name": "Live-on-Demand v2"
```

#### `live_input.errored`

Triggered when a live input encounters an error during a broadcast. The payload uses the same envelope as `live_input.connected` and `live_input.disconnected`, with `status` reflecting the error condition. For the list of possible error codes, refer to [Error codes](/stream/stream-live/webhooks/#error-codes).

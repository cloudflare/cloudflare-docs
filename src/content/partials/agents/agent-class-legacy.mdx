:::note[Start new agents with a harness]

The `Agent` class is the original way to build agents with the Agents SDK. It is still supported, but new agents should run a [harness](/agents/harnesses/) on a plain Durable Object and plug in only the [capabilities](/agents/capabilities/) they need. To get started that way, refer to the [Quick start](/agents/getting-started/quick-start/).

:::

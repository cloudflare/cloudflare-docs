You can determine which users have, or do not have, configuration edit access for Magic products, including Magic Transit, Cloudflare WAN (formerly Magic WAN), and Cloudflare Network Firewall.

For example, if multiple teams manage different Cloudflare products on the same account, you can provide select users with edit access and other users with read-only access.

## Assign permissions

1. Go to the **Members** page.

	 <DashButton url="/?to=/:account/members" />

2. In the search bar, enter an existing user's name, and select the three dots next to the user.
3. Select **View & Edit permission policies**. Then, select the three dots next to the policy, and select **Edit**.
4. In the search bar, enter `Network Services, Magic`.
5. Select one of two options:
   - **Network Services Write (Magic)** - Enables users to view and edit Magic configurations.
   - **Network Services Read (Magic)** - Enables users to view but not modify Magic configurations.

:::tip[Choosing a connector?]
If it is an application, use [Cloudflare Tunnel](/tunnel/). If it is a network, use [Cloudflare Mesh](/mesh/). Code on Cloudflare uses [Workers VPC](/workers-vpc/), and whole sites use [Cloudflare WAN](/cloudflare-one/networks/connectors/cloudflare-wan/). To compare them for your use case, refer to [Choose a connector](/cloudflare-one/networks/connectors/choose-a-connector/).
:::

:::tip[Choosing a connector]
[Cloudflare Mesh](/mesh/) is the default connector for private access and private networks. To publish an HTTP application on the public Internet, use [Cloudflare Tunnel](/tunnel/). For code on Cloudflare, use [Workers VPC](/workers-vpc/). For whole sites, use [Cloudflare WAN](/cloudflare-one/networks/connectors/cloudflare-wan/). To compare them, refer to [Connector selection](/cloudflare-one/networks/connectors/choose-a-connector/).
:::

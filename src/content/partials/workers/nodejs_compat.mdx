As of compatibility date `2026-08-04`, [Node.js compatibility](/workers/runtime-apis/nodejs/) is enabled by default for all Workers and Pages projects. If your compatibility date is `2026-08-04` or later, built-in runtime APIs and polyfills are available without any additional configuration.

If your compatibility date is before `2026-08-04`, add the [`nodejs_compat`](/workers/configuration/compatibility-flags/#nodejs-compatibility-flag) [compatibility flag](/workers/configuration/compatibility-flags/#nodejs-compatibility-flag) to your [Wrangler configuration file](/workers/wrangler/configuration/) to opt in:

<WranglerConfig>

```jsonc
{
	"compatibility_flags": [
		"nodejs_compat"
	],
	"compatibility_date": "$today"
}
```

</WranglerConfig>

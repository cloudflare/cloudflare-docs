| Use-case | Product                                          | Ideal for                                                                                                               |
| ------------------------------- | ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| Key-value storage | [Workers KV](/kv/)                               | Configuration data, feature flags, session storage, caching frequently-read data                                             |
| Object storage | [R2](/r2/)                                       | User uploads, images, videos, backups, static assets, large files without egress fees         |
| Accelerate existing databases | [Hyperdrive](/hyperdrive/)                       | Connect existing Postgres/MySQL databases with global acceleration and connection pooling                                                           |
| Real-time coordination | [Durable Objects](/durable-objects/)             | Chat applications, multiplayer games, collaborative tools, WebSocket connections, strong consistency  |
| Serverless SQL database | [D1](/d1/)                                       | User data, product catalogs, orders, relational data with global read replicas                           |
| Background job processing | [Queues](/queues/)                               | Email sending, API calls, data processing, batch operations, reliable message delivery |
| AI and vector search | [Vectorize](/vectorize/)                         | Semantic search, RAG applications, storing [embeddings](/workers-ai/models/#text-embeddings) from AI models  |
| Streaming data ingestion | [Pipelines](/pipelines/)                         | High-throughput data streams, clickstream analytics, real-time data processing |
| Time-series analytics | [Analytics Engine](/analytics/analytics-engine/) | Custom metrics, usage analytics, high-cardinality time-series data, customer-facing dashboards |

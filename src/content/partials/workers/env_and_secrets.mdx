## Compare secrets and environment variables

:::caution[Use secrets for sensitive information]
Do not use plaintext environment variables to store sensitive information. Use [secrets](/workers/configuration/secrets/) or [Secrets Store bindings](/secrets-store/integrations/workers/) instead.
:::

[Secrets](/workers/configuration/secrets/) are [environment variables](/workers/configuration/environment-variables/) with encrypted values. After you define a secret, its value is not available through Wrangler, the Cloudflare dashboard, or Workers configuration and version read responses. Those API responses may include the secret binding's name and type, but omit its value. Plaintext environment-variable values can appear in API responses.

Use secrets for sensitive data, including passwords and API tokens. Your Worker can access a secret's value at runtime, just like an environment variable.

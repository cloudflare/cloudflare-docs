<WranglerCommand command="r2 bucket catalog compaction enable" headingLevel={3}/>

Examples:

```bash
# Enable catalog-level compaction (requires token)
npx wrangler r2 bucket catalog compaction enable my-bucket --token <TOKEN>

# Enable table-level compaction
npx wrangler r2 bucket catalog compaction enable my-bucket my-namespace my-table --target-size 256
```

<WranglerCommand command="r2 bucket catalog compaction disable" headingLevel={3}/>

```bash
# Disable catalog-level compaction
npx wrangler r2 bucket catalog compaction disable my-bucket

# Disable table-level compaction
npx wrangler r2 bucket catalog compaction disable my-bucket my-namespace my-table
```

## `r2 object`

Interact with R2 objects.

:::note

The `r2 object` commands allow you to manage application data in the Cloudflare network to be accessed from Workers using [the R2 API](/r2/api/workers/workers-api-reference/).
:::

<AnchorHeading title="`get`" slug="r2-object-get" depth={3} />

Fetch an object from an R2 bucket.

```txt
wrangler r2 object get <OBJECT_PATH> [OPTIONS]
```

- `OBJECT_PATH` <Type text="string" /> <MetaInfo text="required" />
  - The source object path in the form of `{bucket}/{key}`.
- `--local` <Type text="boolean" /> <MetaInfo text="(default: true) optional" />
  - Interact with locally persisted data.
- `--remote` <Type text="boolean" /> <MetaInfo text="(default: false) optional" />
  - Interact with remote storage.
- `--persist-to` <Type text="string" /> <MetaInfo text="optional" />
  - Specify directory for locally persisted data.

<AnchorHeading title="`put`" slug="r2-object-put" depth={3} />

Create an object in an R2 bucket.

```txt
wrangler r2 object put <OBJECT_PATH> [OPTIONS]
```

- `OBJECT_PATH` <Type text="string" /> <MetaInfo text="required" />
  - The destination object path in the form of `{bucket}/{key}`.
- `--file` <Type text="string" /> <MetaInfo text="optional" />
  - The path of the file to upload. Note you must provide either `--file` or `--pipe`.
- `--pipe` <Type text="boolean" /> <MetaInfo text="optional" />
  - Enables the file to be piped in, rather than specified with the `--file` option. Note you must provide either `--file` or `--pipe`.
- `--content-type` <Type text="string" /> <MetaInfo text="optional" />
  - A standard MIME type describing the format of the object data.
- `--content-disposition` <Type text="string" /> <MetaInfo text="optional" />
  - Specifies presentational information for the object.
- `--content-encoding` <Type text="string" /> <MetaInfo text="optional" />
  - Specifies what content encodings have been applied to the object and thus what decoding mechanisms must be applied to obtain the media-type referenced by the `Content-Type` header field.
- `--content-language` <Type text="string" /> <MetaInfo text="optional" />
  - The language the content is in.
- `--cache-control` <Type text="string" /> <MetaInfo text="optional" />
  - Specifies caching behavior along the request/reply chain.
- `--expires` <Type text="string" /> <MetaInfo text="optional" />
  - The date and time at which the object is no longer cacheable.
- `--local` <Type text="boolean" /> <MetaInfo text="(default: true) optional" />
  - Interact with locally persisted data.
- `--remote` <Type text="boolean" /> <MetaInfo text="(default: false) optional" />
  - Interact with remote storage.
- `--persist-to` <Type text="string" /> <MetaInfo text="optional" />
  - Specify directory for locally persisted data.

<AnchorHeading title="`delete`" slug="r2-object-delete" depth={3} />

Delete an object in an R2 bucket.

```txt
wrangler r2 object delete <OBJECT_PATH> [OPTIONS]
```

- `OBJECT_PATH` <Type text="string" /> <MetaInfo text="required" />
  - The destination object path in the form of `{bucket}/{key}`.
- `--local` <Type text="boolean" /> <MetaInfo text="(default: true) optional" />
  - Interact with locally persisted data.
- `--remote` <Type text="boolean" /> <MetaInfo text="(default: false) optional" />
  - Interact with remote storage.
- `--persist-to` <Type text="string" /> <MetaInfo text="optional" />
  - Specify directory for locally persisted data.

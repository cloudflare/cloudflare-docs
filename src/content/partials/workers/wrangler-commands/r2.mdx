## `r2 bucket`

Interact with buckets in an R2 store.

:::note

The `r2 bucket` commands allow you to manage application data in the Cloudflare network to be accessed from Workers using [the R2 API](/r2/api/workers/workers-api-reference/).
:::

## Basin Catalog

Enable Basin Catalog on a bucket:

<PackageManagers
	type="exec"
	pkg="wrangler"
	args="basin catalog enable <BUCKET_NAME>"
/>

Disable Basin Catalog on a bucket:

<PackageManagers
	type="exec"
	pkg="wrangler"
	args="basin catalog disable <BUCKET_NAME>"
/>

Get the Basin Catalog status for a bucket:

<PackageManagers
	type="exec"
	pkg="wrangler"
	args="basin catalog get <BUCKET_NAME>"
/>

### `basin catalog compaction enable`

Enable catalog-level compaction with a service token:

<PackageManagers
	type="exec"
	pkg="wrangler"
	args={"basin catalog compaction enable my-bucket --token <TOKEN>"}
/>

Enable table-level compaction:

<PackageManagers
	type="exec"
	pkg="wrangler"
	args="basin catalog compaction enable my-bucket my-namespace my-table --target-size 256"
/>

### `basin catalog compaction disable`

Disable catalog-level compaction:

<PackageManagers
	type="exec"
	pkg="wrangler"
	args="basin catalog compaction disable my-bucket"
/>

Disable table-level compaction:

<PackageManagers
	type="exec"
	pkg="wrangler"
	args="basin catalog compaction disable my-bucket my-namespace my-table"
/>

Enable snapshot expiration:

<PackageManagers
	type="exec"
	pkg="wrangler"
	args="basin catalog snapshot-expiration enable <BUCKET_NAME>"
/>

Disable snapshot expiration:

<PackageManagers
	type="exec"
	pkg="wrangler"
	args="basin catalog snapshot-expiration disable <BUCKET_NAME>"
/>

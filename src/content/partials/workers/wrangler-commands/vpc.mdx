## VPC Services

Manage VPC Services — specific host and port combinations accessible through Cloudflare Tunnel.

:::note

The `vpc service` commands allow you to manage VPC Services in your private network accessible through [Cloudflare Tunnel](/cloudflare-one/connections/connect-networks/). Learn more about using VPC Services with Wrangler in the [VPC Services guide](/workers-vpc/configuration/vpc-services/).

:::

## VPC Networks

Manage VPC Networks — tunnel-wide access to your private network with optional custom DNS configuration.

:::note

The `vpc network` commands allow you to manage VPC Networks for tunnel-wide access to your private network. Learn more about using VPC Networks with Wrangler in the [VPC Networks guide](/workers-vpc/configuration/vpc-networks/).

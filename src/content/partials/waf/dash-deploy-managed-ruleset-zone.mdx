import { Steps, DashButton } from "~/components";

<Steps>
	1. In the Cloudflare dashboard, go to the Security **Settings** page.

		<DashButton url="/?to=/:account/:zone/security/settings" />
	2. (Optional) Filter by **Web application exploits**.
	3. Turn on the managed ruleset(s) you want to deploy:

		<ul>
			<li><strong>Cloudflare managed ruleset</strong> - Deploys the <a href="/waf/managed-rules/reference/cloudflare-managed-ruleset/">Cloudflare Managed Ruleset</a>.</li>
			<li><strong>OWASP Core</strong> - Deploys the <a href="/waf/managed-rules/reference/owasp-core-ruleset/">Cloudflare OWASP Core Ruleset</a>.</li>
			<li><strong>Sensitive data detection</strong> - Deploys the <a href="/waf/managed-rules/reference/sensitive-data-detection/">Cloudflare Sensitive Data Detection</a> managed ruleset.</li>
		</ul>

	4. Review the deployment settings. Edit the scope, if necessary, to apply the ruleset to a subset of the incoming requests, or configure any custom settings (also known as overrides).
	5. Select **Save**.
</Steps>

This operation deploys the managed ruleset for the current zone, creating a new rule with the _Execute_ action.

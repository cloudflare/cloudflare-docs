{props.product} a subset of SQLite extensions for added functionality, including:

- [FTS5 module](https://www.sqlite.org/fts5.html) for full-text search (including `fts5vocab`).
- [JSON extension](https://www.sqlite.org/json1.html) for JSON functions and operators.
- [Math functions](https://sqlite.org/lang_mathfunc.html).
- [R\*Tree module](https://www.sqlite.org/rtree.html) for spatial indexes.

Refer to the [`ALLOWED_SQLITE_FUNCTIONS`](https://github.com/cloudflare/workerd/blob/main/src/workerd/util/sqlite.c%2B%2B) array in the workerd source for the full list of supported functions.

Nova-3 supports the following language codes for real-time transcription:

| Language   | Codes                                             |
| ---------- | ------------------------------------------------- |
| English    | `en`, `en-US`, `en-AU`, `en-GB`, `en-IN`, `en-NZ` |
| Spanish    | `es`, `es-419`                                    |
| French     | `fr`, `fr-CA`                                     |
| German     | `de`, `de-CH`                                     |
| Hindi      | `hi`                                              |
| Russian    | `ru`                                              |
| Portuguese | `pt`, `pt-BR`, `pt-PT`                            |
| Japanese   | `ja`                                              |
| Italian    | `it`                                              |
| Dutch      | `nl`                                              |

If no language is specified, the model defaults to `en-US`. The model uses automatic language detection, which means it will attempt to identify the spoken language. For best accuracy, explicitly set the language code matching your audio.

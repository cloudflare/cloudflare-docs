---
title: Sends to verified destination addresses appear in Email Sending
description: Messages from a sending domain to verified destination addresses now appear in Email Sending analytics and logs, and they publish Email Sending events.
date: 2026-11-16
---

Messages that you send from a [sending domain](/email-service/configuration/domains/) to [verified destination addresses](/email-service/configuration/email-routing-addresses/#destination-addresses) now count as Email Sending traffic. Before, Email Service recorded them as Email Routing traffic, so they did not appear with the rest of your outbound email.

These messages now:

- Appear in the [Activity log](/email-service/observability/logs/) and in [Email Sending analytics](/email-service/observability/metrics-analytics/), and no longer appear in Email Routing analytics.
- Publish [Email Sending events](/email-service/reference/event-subscriptions/), such as `message.delivered` and `message.bounced`, to your event subscriptions.
- Stay free. They do not count toward your monthly quota or your daily sending limits.

To find these messages in the [GraphQL Analytics API](/analytics/graphql-api/), filter the Email Sending datasets on the new `isVerifiedRecipient` field:

```graphql graphql-api-explorer
query VerifiedRecipientSends($zoneTag: string!, $start: Date!, $end: Date!) {
	viewer {
		zones(filter: { zoneTag: $zoneTag }) {
			emailSendingAdaptiveGroups(
				filter: { date_geq: $start, date_leq: $end, isVerifiedRecipient: 1 }
				limit: 10000
				orderBy: [date_DESC]
			) {
				count
				dimensions {
					date
					status
				}
			}
		}
	}
}
```

Messages sent from a domain that has only Email Routing configured are unchanged. Refer to [Metrics and analytics](/email-service/observability/metrics-analytics/) for every Email Sending dimension.

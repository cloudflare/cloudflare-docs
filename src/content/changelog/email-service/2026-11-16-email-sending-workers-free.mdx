[Email Sending](/email-service/api/send-emails/) is now available on the Workers Free plan. You can onboard [sending domains](/email-service/configuration/domains/) and send to the [verified destination addresses](/email-service/configuration/email-routing-addresses/#destination-addresses) in your account. Use the Workers binding, the REST API, or SMTP to send alerts, reports, and notifications to your own team without a paid plan.

Sends to verified destination addresses are free on every plan. They do not count toward the monthly quota or the daily sending limits. They appear in the Activity log and in Email Sending analytics, and they publish [Email Sending events](/email-service/reference/event-subscriptions/).

On the Workers Free plan, Email Service rejects the whole message if any recipient in `to`, `cc`, or `bcc` is not a verified destination address. Each interface returns its own error:

- The Workers binding throws `E_RECIPIENT_PLAN_RESTRICTED`.
- The REST API returns `403` with code `10208`.
- SMTP refuses the recipient with `550 5.7.1`.

<TypeScriptExample filename="src/index.ts">

```ts
export default {
	async fetch(request, env): Promise<Response> {
		try {
			await env.EMAIL.send({
				from: "alerts@yourdomain.com",
				to: "oncall@example.com", // A verified destination address
				subject: "Disk usage above 90%",
				text: "Disk usage on db-1 is above 90%.",
			});
		} catch (error) {
			if (error.code === "E_RECIPIENT_PLAN_RESTRICTED") {
				return new Response("Recipient is not a verified destination address", {
					status: 403,
				});
			}
			throw error;
		}

		return new Response("Alert sent");
	},
} satisfies ExportedHandler<Env>;
```

</TypeScriptExample>

To send to any recipient, upgrade to the [Workers Paid plan](/workers/platform/pricing/). Refer to [Limits](/email-service/platform/limits/#verified-destination-addresses) and [Pricing](/email-service/platform/pricing/) for details.

---
title: SSH session duration for infrastructure applications set to 24 hours
description: Infrastructure applications have a configurable SSH session duration, defaulting to 24 hours.
date: 2026-10-06
products:

[Infrastructure applications](/cloudflare-one/access-controls/applications/non-http/infrastructure-apps/) now have a configurable SSH session duration with a default value of 24 hours. Active SSH sessions that exceed the configured duration will be disconnected.

Previously, infrastructure applications did not enforce a session duration limit. Sessions could persist beyond 24 hours in some cases, but were never guaranteed beyond 10 hours due to [Gateway connection limits](/cloudflare-one/access-controls/troubleshooting/#long-lived-ssh-sessions-disconnect).

When a target matches multiple infrastructure applications, the shortest session duration applies.

For more information, refer to [Session duration](/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/ssh/ssh-infrastructure-access/#session-duration).

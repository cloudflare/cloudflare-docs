---
title: Unified dashboard navigation for Zero Trust
description: Access Zero Trust and other Cloudflare products from one dashboard navigation.
date: 2026-10-12
---

The Cloudflare dashboard now combines Zero Trust and main dashboard navigation. You can move between Cloudflare products from the same navigation.

All customers can browse Zero Trust products from the primary navigation.

Zero Trust customers can also access other services from this navigation. These include the developer platform, account memberships, and tagging.

This update is available to all customers starting today.

For more information, refer to the [Cloudflare One documentation](/cloudflare-one/).

Cloudflare One now includes the **New Domain Visited with Rapidly Changing IPs** detection as a predefined risk behavior for user and entity behavior analytics (UEBA). When enabled, this detection contributes to a user's risk score. This is currently the only fast flux-related detection available as a UEBA risk behavior.

Fast flux is a DNS technique that rapidly changes the IP addresses returned for a domain. Threat actors can use it to make malicious infrastructure harder to track and take down. Detecting it can help security teams identify potentially risky activity and investigate it sooner.

To turn on the **New Domain Visited with Rapidly Changing IPs** detection, go to **Risk score** > **Risk behaviors** in the Cloudflare Zero Trust dashboard.

The **New Domain Visited with Rapidly Changing IPs** detection is available on Enterprise plans.

For more information, refer to [User risk score](/cloudflare-one/team-and-resources/users/risk-score/).

The Agents SDK can emit Cloudflare-native traces for AI SDK model and tool calls. Traces use OpenTelemetry Generative AI semantic conventions and appear in Workers Observability or configured OpenTelemetry Protocol (OTLP) destinations.

Turn on Workers traces in your Wrangler configuration:

<WranglerConfig>

```toml
[observability.traces]
enabled = true
```

</WranglerConfig>

Think agents are instrumented automatically. Each turn records an `invoke_agent` span, model calls as `chat` spans, and tool executions as `execute_tool` spans.

For AI SDK v6 or v7, wrap the SDK namespace before calling its generation functions:

<TypeScriptExample>

```ts
import * as ai from "ai";
import { wrapAISDK } from "agents/observability/ai";

const tracedAI = wrapAISDK(ai);
await tracedAI.streamText({ model, prompt: "Summarize this conversation" });
```

</TypeScriptExample>


Model messages and tool payloads can contain personally identifiable information (PII), so payload storage is off by default. Use `storeMessages` and `storeTools` to opt in. To turn native tracing off for the Worker, set `observability.traces.enabled` to `false`.

For setup options and emitted data, refer to [Agents SDK observability](/agents/runtime/operations/observability/#ai-sdk-tracing).

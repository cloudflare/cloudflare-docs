The latest release of [@cloudflare/agents](https://github.com/cloudflare/agents) brings resumable streaming, significant MCP client improvements, and critical fixes for schedules and Durable Object lifecycle management.

### Resumable streaming

You can now enable resumable streaming allowing clients to reconnect and continue receiving streamed responses without losing data. This is particularly useful for long-running AI responses or unreliable network conditions.

### MCP client API improvements

The `MCPClientManager` API has been redesigned for better clarity and control:

- **New `registerServer()` method**: Register MCP servers without immediately connecting
- **New `connectToServer()` method**: Establish connections to registered servers
- **Connection state observability**: New `onServerStateChanged()` event for tracking all server state changes
- **Improved reconnect logic**: `restoreConnectionsFromStorage()` now properly handles failed connections

```ts
// Register a server to Agent storage
const { id } = await this.mcp.registerServer({
	name: "my-server",
	url: "https://my-mcp-server.example.com",
});

// Connect when ready
await this.mcp.connectToServer(id);

// Discover tools, prompts and resources
await this.mcp.discoverIfConnected(id);
```

The SDK now includes a formalized `MCPConnectionState` enum with states: `idle`, `connecting`, `authenticating`, `connected`, `discovering`, and `ready`.

### Enhanced MCP discovery

The `MCPClientConnection` class now includes a dedicated `discover()` method with full lifecycle management:

- Handles state transitions (CONNECTED → DISCOVERING → READY on success)
- Supports cancellation via AbortController
- Configurable timeout (default 15s)
- New `cancelDiscovery()` method to abort in-flight discoveries
- Discovery failures now throw errors immediately instead of continuing with empty arrays

### Additional improvements

- Default JSON schema validator added to MCP client for better request validation
- Internal AI SDK stream events now convert to UIMessageStreamPart format for improved compatibility
- MCP server requests now use `relatedRequestId` in TransportOptions to send responses down POST streams when supported
- The SSE transport now properly forwards session IDs and request headers to MCP message handlers
- Schedules can now safely destroy the agent

### Bug fixes

- Fixed a bug where schedules meant to fire immediately with `this.schedule(0, ...)` or `this.schedule(new Date(), ...)` would not fire
- Fixed an issue where schedules that took longer than 30 seconds would occasionally time out

### Upgrade

To update to the latest version:

```sh
npm i agents@latest
```

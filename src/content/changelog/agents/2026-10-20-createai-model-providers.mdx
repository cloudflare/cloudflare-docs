The Agents SDK now ships [`createAI`](/agents/models/), one model provider for Workers AI and AI Gateway over the Worker's `AI` binding. There are two imports, with the same options:

- `agents/models/ai-sdk` for the [AI SDK](/agents/models/ai-sdk/). It replaces the `AI` binding mode of `workers-ai-provider` and `ai-gateway-provider`.
- `agents/models/pi-ai` for [Pi AI](/agents/models/pi-ai/) and the [Pi harness](/agents/harnesses/pi/). It gives Pi AI the same binding-based support, and needs `@earendil-works/pi-ai` 1.3.

The [OpenCode harness](/agents/harnesses/opencode/) uses the AI SDK provider through `agents/models/opencode`.

<TypeScriptExample>

```ts
import { createAI } from "agents/models/ai-sdk";
import { streamText } from "ai";

export default {
	async fetch(request: Request, env: Env) {
		const ai = createAI({ binding: env.AI, id: "my-gateway" });

		const result = streamText({
			model: ai("anthropic/claude-opus-5.5", {
				fallback: ["@cf/zai-org/glm-4.7-flash"],
			}),
			prompt: "Write a haiku about Durable Objects",
		});

		return result.toTextStreamResponse();
	},
};
```

</TypeScriptExample>

With `createAI` you get:

- **Every model by id.** Workers AI `@cf/` ids, any model in the [AI Gateway catalog](/ai/models/) such as `anthropic/claude-opus-5.5`, and [dynamic routes](/ai-gateway/features/dynamic-routing/) as `dynamic/<route>`.
- **Vendor model objects.** Pass a model from the vendor's own package, such as `ai(anthropic("claude-opus-5-5"))`. The request goes unchanged to AI Gateway's [provider-native endpoint](/ai-gateway/usage/providers/).
- **No API tokens.** Every request goes through the `AI` binding. AI Gateway bills through [Unified Billing](/ai-gateway/features/unified-billing/) or a [stored key](/ai-gateway/configuration/bring-your-own-keys/). `byokAlias` picks a stored key, `zdr` sets Zero Data Retention, and `vendorKey: "request"` sends a key you hold.
- **Gateway options.** Caching, logging, metadata, timeouts, and retries on the provider, the model, or the call.
- **Fallback.** Try models in order if one fails before it answers. Mix ids and model objects.
- **Stream resume.** A catalog or dynamic route stream that drops mid-answer resumes, with nothing lost or repeated.
- **Gateway metadata and typed errors.** Each result carries the log id, cache status, run id, and the model that answered. Failures throw `CloudflareAIError`.
- **Other model types.** Embeddings, images, speech, transcription, and reranking from Workers AI in the AI SDK provider, and images in Pi AI.

`createAI` does not use AI Gateway's deprecated [Universal Endpoint](/ai-gateway/usage/universal/). Once `createAI` covers everything `workers-ai-provider` and `ai-gateway-provider` do, those packages will be deprecated.

For more information, refer to [Models](/agents/models/).

Run Pi on Cloudflare Workers. The `PiHarness` is now available as part of the Agents SDK. It runs [Pi Durable](https://earendil.com/posts/pi-durable/), the new durable harness from the Pi project, inside a Cloudflare Durable Object. Built alongside the team at Earendil it is our first step toward first-class support for running third-party harnesses on Cloudflare.

:::caution[Beta]

`PiHarness` is in beta. Pi Durable is a new, experimental package, and the `PiHarness` API will likely change as Pi Durable matures.

:::

`PiHarness` ships as a Lifecycle capability. Pi Durable provides the agent harness and the Lifecycle keeps it running. The Lifecycle is a core concept in the Agents SDK ensuring that long-running work can run in a Durable Object, surviving restarts, crashes and network issues. We'll be sharing more on this foundational component in the near future.

## Install

<PackageManagers pkg="agents@latest @earendil-works/pi-durable @earendil-works/pi-ai" />

Both Pi packages are optional peer dependencies of `agents`, so you only install them if you use the harness.

## Use it in an Agent

Creating a Pi agent requires configuring the Pi `Harness` with model, skills and tools then registering the `PiHarness` with the `Agent` class.

<TypeScriptExample>

```ts
import { Agent } from "agents";
import { createModels } from "@earendil-works/pi-ai/models";
import { createRegistry, Harness } from "@earendil-works/pi-durable";
import { PiHarness } from "agents/harness/pi";
import { createAI } from "agents/models/pi-ai";

export class Assistant extends Agent<Env> {
	ai = createAI({ binding: this.env.AI });
	registry = createRegistry();

	harness = new PiHarness({
		harness: ({ storage, context }) => {
			const models = createModels();
			models.setProvider(this.ai.provider);
			return Harness.open(
				storage,
				{ models, registry: this.registry },
				context,
			);
		},
		defaults: { model: this.ai("@cf/moonshotai/kimi-k2.7-code") },
	});

	constructor(ctx: DurableObjectState, env: Env) {
		super(ctx, env);
		this.lifecycle.use(this.harness);
	}

	async ask(prompt: string) {
		const { text } = await this.harness.prompt(prompt);
		return text;
	}
}
```

</TypeScriptExample>

We've included support for AI Gateway and Workers AI models under the `agents/models/pi-ai` entrypoint so you can get started with Cloudflare models right away or alternatively use your existing `pi-ai` provider.

## Add tools with extensions

Both tools and system prompt sections are provided to the Pi `Harness` via extensions.

<TypeScriptExample>

```ts
import { Type } from "@earendil-works/pi-ai";
import type { ToolRegistration } from "@earendil-works/pi-durable";
import { skills } from "agents/harness/pi";

const WordCount = Type.Object({ text: Type.String() });

const wordCount: ToolRegistration<typeof WordCount> = {
	name: "word_count",
	description: "Count the words in a text.",
	parameters: WordCount,
	replay: "safe",
	async execute({ text }) {
		const words = text.split(/\s+/).filter(Boolean).length;
		return { content: [{ type: "text", text: String(words) }] };
	},
};

// In the harness factory, before Harness.open():
registry.install({
	name: "editor",
	sections: [
		{ key: "preamble", render: () => "You are an editor.", tag: false },
	],
	tools: [wordCount],
});
registry.install(await skills(sources));
```

</TypeScriptExample>

See the [Pi Extensions](/agents/harnesses/pi/extensions/) documentation for more information on creating and configuring extensions.

The [Cloudflare Agents SDK](/agents) now provides a `web_search` tool that searches the public web through the [Cloudflare Web Search API](/web-search/), powered by [ceramic.ai, Exa, and Linkup](/web-search/providers/).

When you give the `web_search` tool to your agent, the model provides a query and max results, and receives back a short numbered list of titles, URLs, and trimmed descriptions. When you also provide the [`web_fetch`](/agents/tools/web-fetch/) tool to your agent, the model is told to use it to read the pages that the `web_search` tool returns.

To use the `web_search` tool, make sure you have [Agents SDK v0.27.0](https://github.com/cloudflare/agents/releases/tag/agents%400.27.0) or greater installed, and add it to a [Pi Durable](/agents/harnesses/pi/) [extension registry](agents/harnesses/pi/extensions/) before opening the harness:

<TypeScriptExample>

```ts
import { webSearchTool } from "agents/websearch/pi";

this.registry.install({
	name: "web-tools",
	tools: [webSearchTool({ binding: this.env.AI, provider: "exa" })],
});
```

</TypeScriptExample>

The SDK also includes AI SDK and TanStack AI adapters. To search without a model, such as from a scheduled job, use `createAIWebSearch()` or `createHTTPWebSearch()` from `agents/websearch`.

For setup, options, and error handling, refer to [Web search](/agents/tools/web-search/).

## Experimental harnesses

Agents SDK 0.27.0 also adds three experimental harnesses. Each runs as a capability inside a Durable Object, recovers its work after an eviction, and has a similar interface to [`PiHarness`](/agents/harnesses/pi/), with `prompt()`, `submit()`, `sessions`, and `session(id)`.

- **`ThinkHarness`** from `agents/harness/think` runs the [Project Think](/agents/harnesses/think/) agent loop on a plain Durable Object. It stores transcripts and in-progress model output in the object's storage, so a turn interrupted by an eviction continues from its last saved point. `ThinkChat` serves a session to Think's `useAgentChat` client. Refer to the [Think harness example](https://github.com/cloudflare/agents/tree/main/examples/next/harnesses/think).
- **`ContainerHarness`** from `agents/harness/container` runs an agent CLI, such as Claude Code or Codex, in a [Container](/containers/) and drives it from a Durable Object. There is no image to build. `ContainerEgress` adds credentials outside the container, so the CLI only sees a placeholder key. An idle container stops after five minutes by default, and the CLI resumes its session on the next prompt. Refer to the [Container harness example](https://github.com/cloudflare/agents/tree/main/examples/next/harnesses/container).
- **`OpenCodeHarness`** from `agents/harness/opencode` runs [OpenCode](https://opencode.ai/) v2 inside a Durable Object, with OpenCode's tables in the object's SQLite storage. `createAI()` from `agents/models/opencode` serves Workers AI models to OpenCode. Refer to the [OpenCode harness example](https://github.com/cloudflare/agents/tree/main/examples/next/harnesses/opencode).

:::caution[Experimental]
These harnesses are experimental. Their APIs will change in future releases.
:::

For the full list of changes, refer to the [Agents SDK changelog](https://github.com/cloudflare/agents/blob/main/packages/agents/CHANGELOG.md#0270).

The [Agents SDK](/agents/) now supports [OpenCode 2.0](https://opencode.ai/v2/docs/build/sdk/) through the experimental `OpenCodeHarness`. Run OpenCode inside an `Agent` or a plain Durable Object, with sessions stored in SQLite and Lifecycle jobs that wake interrupted work after eviction.

The `agents/models/opencode` provider connects OpenCode to Workers AI through the `AI` binding. OpenCode plugins extend the harness with custom tools, remote MCP servers, and skills.

:::caution[Experimental]

`agents/harness/opencode` and `agents/models/opencode` are experimental. Their APIs may change between releases. The Workerd profile requires custom tools for filesystem and shell operations.

:::

Install Agents SDK 0.28.0 or later with the OpenCode packages:

<PackageManagers pkg="agents@latest @opencode/sdk@2 @opencode/plugin@2" />

Create a harness and register it with your Agent's Lifecycle:

<TypeScriptExample>

```ts
import { Agent } from "agents";
import { OpenCodeWorkerd } from "@opencode/sdk/workerd";
import { OpenCodeHarness } from "agents/harness/opencode";
import { createAI } from "agents/models/opencode";
import workerTools from "./worker-tools";

export class Assistant extends Agent<Env> {
	ai = createAI({ binding: this.env.AI });
	harness = new OpenCodeHarness({
		opencode: ({ storage }) =>
			OpenCodeWorkerd.create({
				storage,
				models: { fetch: false },
				plugins: [this.ai.plugin, workerTools],
			}),
		defaults: {
			model: this.ai("@cf/moonshotai/kimi-k2.7-code", {
				reasoningEffort: "low",
			}),
			agent: "build",
		},
	});

	constructor(ctx: DurableObjectState, env: Env) {
		super(ctx, env);
		this.lifecycle.use(this.harness);
	}

	async ask(prompt: string) {
		const { status, text, reason } = await this.harness.prompt(prompt);
		return { status, text, reason };
	}
}
```

</TypeScriptExample>

The [OpenCode harness guide](/agents/harnesses/opencode/) includes the `workerTools` plugin, Wrangler configuration, session APIs, and recovery limitations. The [working example](https://github.com/cloudflare/agents/tree/main/examples/next/harnesses/opencode) adds a browser UI, WebSocket streaming, and persistent note tools.

import { TypeScriptExample } from "~/components";

The [Agents SDK model providers](/agents/models/) now take any model id from the [AI Gateway catalog](/ai/models/), such as `anthropic/claude-opus-4.8`. You do not need a vendor package or a vendor key in your Worker.

<TypeScriptExample>

```ts
import { createAI } from "agents/models/ai-sdk";
import { streamText } from "ai";

export default {
	async fetch(request: Request, env: Env) {
		const ai = createAI({ binding: env.AI, id: "my-gateway" });

		const result = streamText({
			model: ai("anthropic/claude-opus-4.8"),
			prompt: "Write a haiku about Durable Objects",
		});

		return result.toTextStreamResponse();
	},
};
```

</TypeScriptExample>

`createAI` no longer uses AI Gateway's deprecated [Universal Endpoint](/ai-gateway/usage/universal/). Model ids, catalog ids included, run on `env.AI.run()`. A vendor's own model object, such as `ai(anthropic("claude-opus-4-8"))`, goes through the binding to AI Gateway's [provider-native endpoint](/ai-gateway/usage/providers/) for that vendor.

This release also:

- Adds the `byokAlias` option, which picks a [stored key](/ai-gateway/configuration/bring-your-own-keys/) by alias.
- Fixes catalog models and [dynamic routes](/ai-gateway/features/dynamic-routing/) in `agents/models/pi-ai`.
- Lets `agents/models/opencode` take catalog ids.
- Resumes a catalog or dynamic route stream that drops mid-answer, with nothing lost or repeated.

`createAI` from `agents/models/ai-sdk` replaces the `AI` binding mode of `workers-ai-provider` and `ai-gateway-provider`, which are now deprecated.

For more information, refer to the [AI SDK provider](/agents/models/ai-sdk/), the [Pi AI provider](/agents/models/pi-ai/), and the [OpenCode harness](/agents/harnesses/opencode/).

We have launched Adaptive Intelligence, a new bot detection engine built to close the gap between when an attack pattern first appears and when protection against it reaches every customer. You can [read the announcement blog](https://blog.cloudflare.com/introducing-adaptive-intelligence/) for the full story behind why we built it.

The machine learning model behind your bot score now retrains more frequently instead of shipping as a fixed, numbered version. As new bypass tools and bot frameworks appear, the model learns from them and folds that knowledge in without waiting for a scheduled release.

Every update is validated before it affects you. New model versions run in shadow mode against live traffic first, scored but not acted on, and are compared against the current model before rolling out gradually.

Enterprise customers with **Auto-update machine learning** switched on under Bot Management configurations get Adaptive Intelligence automatically, with no version to migrate and nothing else to configure.

To learn more, refer to [Adaptive Intelligence](/bots/concepts/bot-detection-engines/#adaptive-intelligence-business-and-enterprise) and [Machine Learning models](/bots/reference/machine-learning-models/).

title: Granular access controls for the top Personal Agents
description: Set zone-level policies for personal AI agents without applying the same action to all agent traffic.
date: 2026-10-30
publish_future_dated_entry: true
---

The **Configure AI bot policies** setting is now named **AI Crawler and Agent access policies**.

Personal agents act on a person's behalf, fetching information or browsing in response to a request. The updated policies let you set actions for the top Personal Agents individually. This gives you control over agent access while allowing visitors to use agents to find answers or compare products using your site's content.

Customize how Personal Agents access your site via **Security** > **Settings** > **AI Crawler and Agent access policies**.

![AI Crawler and Agent access policies dialog showing the Agents policy and individual Personal Agents settings](~/assets/images/changelog/bots/personal-agent-policies.png)

**Personal Agents** inherit your existing **Agents** policy by default. Cloudflare recommends _Allow (do not block)_ for Personal Agents.

For more information, refer to [AI Crawler and Agent access policies](/bots/additional-configurations/block-ai-bots/).

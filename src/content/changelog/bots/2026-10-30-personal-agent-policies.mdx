title: Granular access controls for the top Personal Agents
description: Set zone-level policies for personal AI agents without applying the same action to all agent traffic.
date: 2026-10-30
publish_future_dated_entry: true
---

AI bot policies are updated with granular access controls for the top Personal Agents. Customize how Personal Agents access your site via **Security** > **Settings** > **Configure AI bot policies**.

![Configure AI bot policies dialog showing the Agents policy and individual Personal Agents settings](~/assets/images/changelog/bots/personal-agent-policies.png)

**Personal Agents** inherit your existing **Agents** policy by default. Cloudflare recommends _Allow (do not block)_ for Personal Agents.

For more information, refer to [AI bot policies](/bots/additional-configurations/block-ai-bots/).

---
title: Precursor stability improvements
description: Precursor now has improved compatibility testing, rollout controls, and monitoring for more reliable operation.
date: 2026-10-28
---

Precursor now runs more reliably across common website frameworks. Expanded end-to-end testing checks changes before release. Improved rollout controls let Cloudflare deploy updates gradually, pause a rollout, or revert an update when needed.

Cloudflare can also identify when Precursor does not run as expected for a zone, helping us investigate and resolve issues faster. Detection updates can be released separately from Precursor updates, supporting a consistent visitor experience as bot detection improves.

For more information, refer to the [Precursor documentation](/cloudflare-challenges/precursor/).

title: Sippy now supports Azure Blob Storage and S3-compatible storage providers
description: Sippy can incrementally migrate data from Azure Blob Storage and any S3-compatible storage provider to R2.
products:
  - r2
date: 2026-07-24
---

[Sippy](/r2/data-migration/sippy/) can now incrementally migrate data from Azure Blob Storage and any S3-compatible object storage provider to [Cloudflare R2](/r2/), in addition to Amazon S3 and Google Cloud Storage.

For more information, refer to the [Sippy documentation](/r2/data-migration/sippy/).

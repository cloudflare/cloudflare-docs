You can now view R2 bandwidth by the Cloudflare location that served each request in the Cloudflare UI. This helps you see which locations consume the most bandwidth with options to select a specific bucket and download (rea) vs upload (write) bandwidth.

<DashButton url="/?to=/:account/r2/overview" buttonName="R2 overview" />

![R2 bandwidth by location chart showing throughput for the top five Cloudflare locations](~/assets/images/r2/r2-bandwidth-by-location.png)

By default, the chart shows the top five locations by total bandwidth consumed during the selected time range. Use the **Top 5 locations** dropdown to select other locations, up to six at a time.

For more information, refer to [R2 metrics and analytics](/r2/platform/metrics-analytics/).

---
title: Pages now skips superseded queued builds
description: Pages now skips a queued build when a newer build for the same project, branch, and deployment target is queued.
products:
  - pages
date: 2026-08-11
---

Pages now automatically skips a queued build when a newer build for the same project, branch, and deployment target is also queued. This reduces queue times and prevents outdated changes from being built.

This behavior is available to all customers and requires no configuration.

For more information, refer to [Build configuration](/pages/configuration/build-configuration/).

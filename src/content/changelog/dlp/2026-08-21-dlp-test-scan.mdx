---
title: DLP Test scan
description: Test text, files, and HAR data against DLP profiles and inspect match details without sending traffic through Gateway.
date: 2026-08-21
---

**Test scan** lets you check how DLP evaluates sample content before you apply a profile to production traffic. Paste text, upload a file, or upload a HAR file, then select the profiles you want to test.

Test scan sends content directly to the DLP scanner. Gateway policies are not evaluated, no traffic passes through Gateway, and no Gateway activity logs are created. Results include matched profiles, detection entries, confidence levels, match context, proximity keywords, file metadata, antivirus status, and OCR output.

Test scan is available to all Cloudflare Zero Trust customers. Profile availability depends on plan.

For more details, refer to the [Test scan documentation](/cloudflare-one/data-loss-prevention/test-scan/).

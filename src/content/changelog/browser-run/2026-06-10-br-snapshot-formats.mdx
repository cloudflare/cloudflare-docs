The [`/snapshot` endpoint](/browser-run/quick-actions/snapshot/) now supports a `formats` parameter that lets you return multiple page formats in a single API call. Previously, `/snapshot` returned only HTML content and a screenshot. You can now also include Markdown and the accessibility tree in the same response. Browser Run also provides individual endpoints for each format, such as [`/content`](/browser-run/quick-actions/content-endpoint/), [`/screenshot`](/browser-run/quick-actions/screenshot-endpoint/), [`/markdown`](/browser-run/quick-actions/markdown-endpoint/), and [more](/browser-run/quick-actions/).

Including these formats in a `/snapshot` response is particularly useful for AI agent workflows, where choosing the right page representation can reduce token usage and improve accuracy:

- Markdown provides a clean, token-efficient representation of page content that LLMs can process directly, without needing to parse noisy HTML markup.
- The accessibility tree provides a compact, semantic map of a page's interactive elements, including roles, labels, and hierarchy. This gives AI agents the structure they need to understand and act on a page (for example, identifying buttons, form fields, and navigation links) at a fraction of the token cost of raw HTML.

The following example returns a screenshot, Markdown, and the accessibility tree in one call:

```bash
curl -X POST 'https://api.cloudflare.com/client/v4/accounts/<accountId>/browser-rendering/snapshot' \
  -H 'Authorization: Bearer <apiToken>' \
  -H 'Content-Type: application/json' \
  -d '{
    "url": "https://example.com/",
    "formats": ["screenshot", "markdown", "accessibilityTree"]
  }'
```

You must request at least two formats. If you only need one, use the respective single-format endpoint instead: [`/content`](/browser-run/quick-actions/content-endpoint/), [`/screenshot`](/browser-run/quick-actions/screenshot-endpoint/), or [`/markdown`](/browser-run/quick-actions/markdown-endpoint/). A single-format accessibility tree endpoint is coming soon.

Refer to the [`/snapshot` documentation](/browser-run/quick-actions/snapshot/) for the full list of accepted values and examples using the TypeScript SDK and Workers Bindings.

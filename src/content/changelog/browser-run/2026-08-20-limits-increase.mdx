Browser Run now supports higher [limits](/browser-run/limits/#workers-paid) for Workers Paid users:

| Limit                           | Previous | New     |
| ------------------------------- | -------- | ------- |
| Concurrent browsers             | 120      | **200** |
| New browser instances / second  | 1        | **3**   |
| Quick Actions requests / second | 10       | **30**  |

Room to run more browsers in parallel and fire off more Quick Actions per second. If you need more, [request higher limits](https://forms.gle/CdueDKvb26mTaepa9).

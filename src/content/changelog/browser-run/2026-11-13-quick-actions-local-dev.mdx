You can now test [Browser Run Quick Actions](/browser-run/quick-actions/) locally. Under `npx wrangler dev`, the browser binding's `.quickAction()` method runs against a Chrome instance on your machine. Before, `.quickAction()` worked only in remote mode, and local calls failed with `The RPC receiver does not implement the method "quickAction"`.

:::note

There are currently two limitations in the local simulation:

- The `json` action is emulated. It requires an AI model to extract data, and the model is not available locally, so the action returns placeholder data that matches your schema.
- The [Kitesurf](/browser-run/kitesurf/) browser is not supported yet.

:::

For details, refer to [Test Quick Actions locally](/browser-run/quick-actions/#test-quick-actions-locally).

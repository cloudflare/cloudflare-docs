Durable Object keep-alive behavior covers more eligible pending outbound I/O. Each event can prevent eviction for up to 15 minutes after the caller disconnects.

New coverage includes fetches to service bindings, requests to other Durable Objects through remote procedure call (RPC) or `fetch()`, and `this.ctx.container.monitor()`. Existing coverage includes ordinary outbound fetches, TCP sockets, and outbound WebSockets.

Each eligible pending I/O event provides an active protection window of up to 15 minutes. Later eligible I/O can reset or extend the deadline, so the invocation has no fixed 15-minute limit.

![Timeline showing per-event I/O windows up to 15 minutes, later deadline extension, and standard 70–140 second eviction.](~/assets/images/durable-objects/pending-io-keep-alive.svg)

Long-running agents and container workloads can receive more time to finish while eligible I/O continues extending the window.

For more information, refer to [Lifecycle of a Durable Object](/durable-objects/concepts/durable-object-lifecycle/).

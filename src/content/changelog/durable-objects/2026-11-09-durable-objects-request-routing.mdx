---
title: Improved Request Routing to Durable Objects
description: Cloudflare has reduced network round trips when connecting to Durable Objects through forwarding records, which can reduce connection latency.
date: 2026-11-09
---

Cloudflare has reduced the number of round trips needed to connect to a Durable Object when a location lookup follows a forwarding record to another data center.

When an object's destination isn't cached in Cloudflare's network, the first data center contacted may have a forwarding record pointing to another data center. The first location can now return the intended destination directly, allowing the caller to establish the connection.

Streamlining the intermediate connections can reduce connection setup latency. Actual results depend on your workload and traffic patterns.

No code or configuration changes are required to benefit from this improvement.

To learn more about how Workers connect to Durable Objects, refer to [Durable Object namespaces](/durable-objects/api/namespace/#get).

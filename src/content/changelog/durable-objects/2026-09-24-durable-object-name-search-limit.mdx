---
title: Durable Object name search now supports 128 characters
description: Search for Durable Objects by names up to 128 characters in the Cloudflare dashboard, up from 20 characters.
products:
  - durable-objects
date: 2026-09-23
---

Durable Object name searches in the Cloudflare dashboard now accept up to 128 characters, up from 20.

Search results and recent invocation lists show up to 128 characters before being truncated with an ellipsis. This limit applies to the object filter on the **Metrics** tab and object search in **Data Studio**.

For more information, refer to [Metrics and analytics](/durable-objects/observability/metrics-and-analytics/) and [Data Studio](/durable-objects/observability/data-studio/).

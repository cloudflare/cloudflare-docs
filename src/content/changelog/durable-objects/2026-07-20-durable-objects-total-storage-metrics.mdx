You can now monitor the total SQLite storage used by a Durable Object namespace over time in the Cloudflare dashboard. The new **Total storage** chart shows the maximum storage reported during each hour. This helps you identify storage growth, validate data cleanup, and investigate unexpected usage.

![The Total storage chart showing 8.3 MB of storage used by a Durable Object namespace over time.](~/assets/images/changelog/durable-objects/durable-objects-total-storage.png)

<DashButton url="/?to=/:account/workers/durable-objects" />

The chart appears only for SQLite-backed Durable Object namespaces. It does not appear for namespaces that use the legacy key-value storage backend. When you filter by Durable Object ID or name, the chart displays a notice that total storage is unavailable for an individual object.

For more information, refer to [Metrics and analytics](/durable-objects/observability/metrics-and-analytics/#total-storage).

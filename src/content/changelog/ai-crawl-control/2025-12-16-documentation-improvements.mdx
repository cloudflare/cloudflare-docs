title: WAF, Transform Rule, and Crawler Guide improvements
description: New crawler reference guides and enhanced WAF and Transform Rule integration documentation for AI Crawl Control.
date: 2025-12-16
---

AI Crawl Control now includes comprehensive crawler reference guides and enhanced integration documentation. The new [Bot catalog](/ai-crawl-control/reference/bot-catalog/) provides detailed information about each crawler's stated purpose and official documentation, while [Configuration scenarios](/ai-crawl-control/reference/configuration-scenarios/) offers practical setup examples for common use cases. The [WAF integration guide](/ai-crawl-control/configuration/ai-crawl-control-with-waf/) now includes troubleshooting sections explaining how upstream rules can affect both allowed and blocked crawlers, and a new guide covers using [Transform Rules](/ai-crawl-control/configuration/ai-crawl-control-with-transform-rules/) to attach licensing information to crawler responses.

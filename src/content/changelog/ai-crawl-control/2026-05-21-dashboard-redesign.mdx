AI Crawl Control tabs have been renamed and the Overview layout has been updated.

**Tab name changes**

| Before | After | What lives here |
| --- | --- | --- |
| Crawlers | **Security** | Crawler access controls, block response configuration |
| Directives | **Signals** | Robots.txt monitoring, agent readiness |
| Settings | **Payments** | Pay Per Crawl pricing (Enterprise with Bot Management) |

**Overview** and **Metrics** tabs are unchanged.

**Other updates**

- **Quick Actions** row on the Overview tab for common tasks.
- Block response configuration moved from the former Settings tab into the **Security** tab alongside crawler controls.

Learn more about [managing AI crawlers](/ai-crawl-control/features/manage-ai-crawlers/) and [analyzing AI traffic](/ai-crawl-control/features/analyze-ai-traffic/).

AI Crawl Control metrics have been enhanced with new views, improved filtering, and better data visualization.

![AI Crawl Control path patterns](~/assets/images/ai-crawl-control/ai-crawl-control-path-patterns.png)

**Path pattern grouping** — The Most popular paths table now includes a Patterns tab that groups requests by URI pattern (`/blog/*`, `/api/v1/*`, `/docs/*`) so you can see which site areas crawlers target most.

**Enhanced referral analytics** — Destination patterns show which site areas receive AI-driven referral traffic. A new Referrals over time chart shows trends by operator or source.

**Data transfer metrics** — Toggle the Requests over time chart to show bandwidth consumption. A new Data transfer column in the Crawlers table shows bandwidth per crawler.

**Image exports** — Export charts and tables as images for reports and presentations.

Learn more about [analyzing AI traffic](/ai-crawl-control/features/analyze-ai-traffic/).

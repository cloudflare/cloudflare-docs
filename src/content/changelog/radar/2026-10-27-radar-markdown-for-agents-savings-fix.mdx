---
title: Fixed Markdown for Agents savings calculation on Cloudflare Radar
description: Radar's Markdown for Agents savings metric now only counts responses served to AI bots and crawlers.
products:
  - radar
date: 2026-10-27
---

We fixed a bug where Radar's [**Markdown for Agents savings**](https://radar.cloudflare.com/ai-insights#markdown-for-agents-savings) metric included conversions not served to AI bots or crawlers, overstating the median response size since August 27, 2026. Historical values are corrected on Radar and in the [API](/api/resources/radar/subresources/ai/subresources/markdown_for_agents/methods/summary).

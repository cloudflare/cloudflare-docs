The [**Cloudflare Radar**](/radar/) homepage has been redesigned to make global Internet data easier to explore, whether you are a network operator, researcher, journalist, or simply curious about the state of the Internet.

## Interactive traffic and outages map

The homepage now opens with an interactive world map showing the distribution of Cloudflare traffic, ongoing Internet outages, and Cloudflare data center locations. Use the map as a starting point to drill down from the global view into specific countries and trends.

![Screenshot of the interactive map on the redesigned Cloudflare Radar homepage](~/assets/images/radar/radar-homepage-redesign-map.webp)

## Tabbed data exploration

Below the map, a tabbed layout replaces the previous grid of charts. Each tab highlights summary statistics for an area of Radar data and links to the corresponding page for deeper exploration.

## Updated interface

The new design uses [Kumo](https://kumo-ui.com/) components for a cleaner, more consistent experience across Radar and other Cloudflare products.

For more details on the design process, read the [blog post](https://blog.cloudflare.com/radar-redesign/). To see the new homepage, visit [Cloudflare Radar](https://radar.cloudflare.com/).

Real-time transcription in RealtimeKit now supports 10 languages with regional variants, powered by [Deepgram Nova-3](/workers-ai/models/deepgram-nova-3/).

Set the language when [creating a meeting](/realtime/realtimekit/concepts/meeting/) via `ai_config.transcription.language`:

```json
{
	"ai_config": {
		"transcription": {
			"language": "fr-CA"
		}
	}
}
```

Supported languages include English, Spanish, French, German, Hindi, Russian, Portuguese, Japanese, Italian, and Dutch — with regional variants like `en-GB`, `fr-CA`, and `pt-BR`.

If you are building voice agents or real-time translation workflows, your agent can now transcribe in the caller's language natively without extra services or routing logic.

Hyperdrive is now available on the Free plan of Cloudflare Workers, enabling you to build Workers that connect to PostgreSQL or MySQL databases without compromise.

Over the past year, we've realized that Hyperdrive is critical to building Workers applications that connect to SQL databases. We want you to be able to build on fast, global apps on Workers,
regardless of the tools you use. So we made Hyperdrive available for all, to make it easier to build Workers that connect to PostgreSQL and MySQL.

To highlight this announcement, we wrote a [deep dive article](https://blog.cloudflare.com/how-hyperdrive-speeds-up-database-access) on how Hyperdrive can provide up to 4x faster database queries which you should check out.

---
title: DEX Supports Customer Metadata Boundary
description: Digital Experience Monitoring now fully supports the Customer Metadata Boundary
date: 2026-01-27
---

[Digital Experience Monitoring (DEX)](/cloudflare-one/insights/dex/) provides visibility into [WARP](/warp-client/) device connectivity and performance to any internal or external application.

Now, all DEX logs are fully compatible with Cloudflare's [Customer Metadata Boundary](/data-localization/metadata-boundary/) which ensures that these logs will stay in the 'EU' (European Union) or in the 'US' (United States), depending on the region the customer selects.

If a Cloudflare One customer using DEX enables CMB, they will not see any DEX data in the Cloudflare One dashboard. Customers can ingest DEX data via [LogPush](/logs/logpush/), and build their own analytics and dashboards.  

If a customer enables CMB in their account, they will see the following message in the Digital Experience dashboard, "DEX data is unavailable because Customer Metadata Boundary configuration is on. Use Cloudflare LogPush to export DEX datasets."

You can now attach files to a message in Agent Lee. Share a screenshot of an error, a PDF, or a log, HAR, or configuration file, and Agent Lee reads it as part of your question.

Previously, you had to describe what you were seeing or paste file contents into the chat by hand. A screenshot of a dashboard error or a long log was hard to get across that way.

### How it works

- Select the paperclip next to the message box, paste an image, or drag files onto the chat panel.
- Each file appears as a chip above the message box. Remove any you did not mean to add, then send your message.
- Agent Lee reads images directly, converts PDFs to text and reads them from the start, and reads text files in full or, for long files, from the start and the end.

Example requests:

- "Here's a screenshot of the error I get when I open my site. What's wrong?"
- "This HAR file is from a slow page load. Which requests are taking the longest?"
- "Here's the error log from my Worker. What is causing these failures?"

### Good to know

- **Supported files.** PNG, JPEG, and WebP images up to 3.5 MiB, PDFs up to 5 MiB, and text files (`.txt`, `.log`, `.json`, `.har`, `.csv`, `.yaml`, `.yml`, `.toml`, `.md`, `.xml`) up to 100 MiB. You can attach up to four files per message, up to 14 MiB in total.
- **Text files are trimmed in your browser.** A text file over 1 MiB (2 MiB for JSON, HAR, YAML, TOML, and XML) keeps its first and last lines. HAR files are always compacted before sending: request and response bodies and cookies are removed, and credential headers such as `Authorization` and `Cookie` are replaced with `[redacted]`.
- **Scanned PDFs are not read.** Agent Lee reads the text in a PDF. A PDF that is only scanned images, with no text layer, cannot be read.
- **Older attachments age out.** Agent Lee keeps attachments from your most recent messages in view. Attach a file again to bring an older one back into the conversation.
- **Attachments are stored with the conversation.** When an attachment ages out, it is removed from the stored conversation. Do not attach files that contain passwords, API tokens, or other secrets. For how Agent Lee uses your data, refer to [Data usage](/agent-lee/#data-usage).

Agent Lee remains in beta. Features and behaviors may change as the product evolves.

For details, refer to [Agent Lee](/agent-lee/#attachments).

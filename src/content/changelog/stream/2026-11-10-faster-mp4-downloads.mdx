Generating [MP4 downloads from Cloudflare Stream](/stream/viewing-videos/download-videos/#generate-downloadable-mp4-files) is now up to 40% faster, with no changes to your implementation required. This improvement is most impactful for on-demand videos over 1 minute in duration.

You can generate an MP4 download in the Dashboard, with the [`cf`, the Cloudflare CLI](/cf/) CLI, or by sending a `POST` request.

```sh title="cf cli"
cf stream videos downloads create default --identifier "$VIDEO_UID"
```

<APIRequest
	path="/accounts/{account_id}/stream/{identifier}/downloads/{download_type}"
	method="POST"
	parameters={{ download_type: "default" }}
/>

Both of these response include the download URL and processing progress:

```json
{
	"result": {
		"default": {
			"status": "inprogress",
			"percentComplete": 75.0,
			"url": "https://customer-<CODE>.cloudflarestream.com/<VIDEO_UID>/downloads/default.mp4"
		}
	},
	"success": true,
	"errors": [],
	"messages": []
}
```

For more information, refer to [Generate downloadable MP4 files](/stream/viewing-videos/download-videos/#generate-downloadable-mp4-files).

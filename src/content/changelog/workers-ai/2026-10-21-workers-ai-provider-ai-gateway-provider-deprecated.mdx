The Agents SDK has a new `createAI` function for the [AI SDK](/agents/models/ai-sdk/) and [Pi AI](/agents/models/pi-ai/). It unifies what `workers-ai-provider` and `ai-gateway-provider` did: Workers AI models, AI Gateway catalog models, dynamic routes, and vendor models, through the `AI` binding or an account id and API token.

`workers-ai-provider` and `ai-gateway-provider` are now feature frozen and marked as deprecated. Please migrate at your convenience.

```sh
npm i agents
```

```ts
import { createAI } from "agents/models/ai-sdk";

const ai = createAI({ binding: env.AI });

const model = ai("@cf/zai-org/glm-4.7-flash");
```

| Before                                      | After                                                 |
| ------------------------------------------- | ----------------------------------------------------- |
| `createWorkersAI({ binding })`              | `createAI({ binding })`                               |
| `createWorkersAI({ accountId, apiKey })`    | `createAI({ accountId, apiToken })`                   |
| `createAiGateway(...)`                      | `createAI(...)`, with `fallback` for a list of models |
| `createAISearch` from `workers-ai-provider` | `createAISearchNamespace` from `ai-search-provider`   |

For AI Search, use [`ai-search-provider`](/ai-search/agent-sdks/ai-sdk/). For more information, refer to [Models](/agents/models/).

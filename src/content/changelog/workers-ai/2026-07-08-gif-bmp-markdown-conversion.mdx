---
title: Markdown Conversion now supports GIF and BMP images
description: Convert GIF and BMP image files to Markdown text descriptions using toMarkdown.
date: 2026-07-08
---

The [Markdown Conversion](/workers-ai/features/markdown-conversion/) service now supports `.gif` and `.bmp` image files. These formats are processed through the same object detection and captioning pipeline as JPEG, PNG, and WebP images.

For animated GIF files, only the first frame is analyzed.

See the full list of [supported formats](/workers-ai/features/markdown-conversion/supported-formats/).

---
title: Brand Protection now allows bulk creation of queries
description: Brand Protection users can now create and save queries in bulk.
date: 2024-08-15
---

Brand Protection users can now create multiple saved queries in bulk for the brands they are tracking within their account.
This functionality is currently available via API. You can check out the documentation for more information here: [Brand Protection Bulk query creation API](https://developers.cloudflare.com/api/resources/brand_protection/subresources/queries/methods/bulk/).

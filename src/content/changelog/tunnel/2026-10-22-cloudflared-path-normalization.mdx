Starting 2027-02-08, new `cloudflared` releases will turn on URL normalization by default. This date replaces the original 2027-01-25 timeline. For the updated behavior in version `2026.11.0`, refer to the [URL normalization follow-up](/changelog/post/2026-11-04-cloudflared-matrix-path-parameters/). Test your path-based routing before that date, as this change may affect which ingress rule matches a request. Configurations without rules requiring Access validation are unaffected.

In three months, starting 2027-01-25, new `cloudflared` releases will turn on URL normalization by default. Test your path-based routing before that date, as this change may affect which ingress rule matches a request. Configurations without rules requiring Access validation are unaffected.

This setting is currently off by default. To turn it on, run:

```sh
cloudflared tunnel --disable-path-normalization=false run <TUNNEL_NAME_OR_UUID>
```

Alternatively, set `TUNNEL_DISABLE_PATH_NORMALIZATION=false` on each `cloudflared` replica and restart it.

For more information, refer to [ingress matching](/tunnel/features/locally-managed-tunnels/configuration-file/#how-traffic-is-matched) and [Access validation at the origin](/tunnel/reference/origin-parameters/#access).

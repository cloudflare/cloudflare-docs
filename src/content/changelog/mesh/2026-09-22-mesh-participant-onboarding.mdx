The Cloudflare Mesh dashboard now provides guided setup for Mesh nodes and client devices. Select **Add participant** from **Networking** > **Mesh** to choose the participant type.

The updated dashboard includes the following improvements:

- **More Mesh node deployment options** — Install a node on Linux, Kubernetes, Docker Compose, or Docker CLI. The dashboard provides requirements, commands, configuration, and links for each method.
- **Guided client device setup** — Review required account changes before applying them. The workflow then provides platform-specific installers, mobile QR codes, and enrollment instructions.
- **Unified participant management** — View nodes and enrolled client devices in one table. Search devices, filter participants by type or status, open device details, and load additional results from each participant source. If one source fails, participants from the other source remain available while you retry the request.

The client device workflow prepares your Cloudflare One account for enrollment. You must still install the Cloudflare One Client, enroll the device, and verify connectivity.

For setup instructions, refer to [Get started with Cloudflare Mesh](/cloudflare-one/networks/connectors/cloudflare-mesh/get-started/) and [Connect client devices](/cloudflare-one/networks/connectors/cloudflare-mesh/client-devices/).

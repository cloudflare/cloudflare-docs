[Cloudflare Mesh](/cloudflare-one/networks/connectors/cloudflare-mesh/) now makes it faster to add and manage participants from the dashboard. Select **Add participant** from **Networking** > **Mesh** to deploy a [Mesh node](/cloudflare-one/networks/connectors/cloudflare-mesh/get-started/) or connect a [client device](/cloudflare-one/networks/connectors/cloudflare-mesh/client-devices/) through a guided workflow.

![Adding a Cloudflare Mesh node through the guided dashboard workflow](~/assets/images/changelog/cloudflare-one/guided-participant-onboarding-clicks.gif)

The updated dashboard includes the following improvements:

- **More Mesh node deployment options** — Install a node on Linux, Kubernetes, Docker Compose, or Docker CLI. The dashboard provides requirements, commands, configuration, and links for each method. Refer to [Run Mesh in Docker / Kubernetes](/cloudflare-one/networks/connectors/cloudflare-mesh/containers/) for container deployment details.
- **Guided client device setup** — Review required account changes before applying them. The workflow then provides platform-specific [Cloudflare One Client](/cloudflare-one/team-and-resources/devices/cloudflare-one-client/) installers, mobile QR codes, and enrollment instructions.
- **Unified participant management** — View [Mesh nodes and enrolled client devices](/cloudflare-one/networks/connectors/cloudflare-mesh/client-devices/#1-enroll-the-cloudflare-one-client) in one table. Search devices, filter participants by type or status, open device details, and load additional results from each participant source. If one source fails, participants from the other source remain available while you retry the request.

The client device workflow prepares your Cloudflare One account for enrollment. You must still install the Cloudflare One Client, enroll the device, and verify connectivity.

For complete setup instructions, refer to [Get started with Cloudflare Mesh](/cloudflare-one/networks/connectors/cloudflare-mesh/get-started/).

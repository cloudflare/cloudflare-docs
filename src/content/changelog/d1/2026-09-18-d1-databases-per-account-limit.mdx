Beginning September 18, 2026, the limit for [D1](/d1/) databases per account on the [Workers Paid plan](/workers/platform/pricing/#workers) is 1,000,000, up from 50,000. You can create up to 1,000,000 databases without requesting a limit increase.

This increase supports architectures that use a database per tenant, user, or entity at scale. Pricing does not change — D1 pricing is based on query and storage usage, not the number of databases.

1,000,000 databases per account is a soft ceiling. If your use case needs more, you can request an increase. D1 can support millions to tens-of-millions of databases (or more) per account.

Refer to the [D1 limits documentation](/d1/platform/limits/) for more details.

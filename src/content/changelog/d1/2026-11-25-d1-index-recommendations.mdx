D1 Insights now recommends indexes for your D1 databases. Each recommendation includes a `CREATE INDEX` statement, the queries it is expected to speed up, and usage metrics for those queries.

Recommendations are on by default for accounts on the Free and Paid plans. Enterprise accounts can turn them on in the dashboard, with the Cloudflare CLI, or with the API.

Review recommendations on the **Metrics** tab of a database in the dashboard, or list them with the Cloudflare CLI:

```sh
cf d1 insights recommendations
```

For more information, refer to [Index recommendations](/d1/observability/metrics-analytics/index-recommendations/).

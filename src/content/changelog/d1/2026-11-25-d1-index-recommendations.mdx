D1 Insights can recommend indexes for active D1 databases. Each recommendation includes validated `CREATE INDEX` SQL, impacted queries, and measured query metrics.

Index recommendations are available on the Workers Paid plan and are turned on by default. Enterprise customers can opt in from the dashboard. You can turn Insights on or off for your account in the dashboard or with the API.

Use the Cloudflare dashboard, Cloudflare CLI (`cf`), Wrangler, or the REST API to review recommendations.

For more information, refer to [Index recommendations](/d1/observability/metrics-analytics/index-recommendations/).

---
title: D1 database undelete requests limited to the last 7 days
description: The D1 undelete API now only restores databases that were deleted within the last 7 days.
products:
  - d1
date: 2026-10-23
---

The [D1 undelete API](/api/resources/d1/subresources/database/methods/undelete/) now only accepts requests for databases that were deleted within the last 7 days.
Requests to undelete a database that was deleted more than 7 days ago will fail and return an error.

If you delete a D1 database by mistake, send the undelete request as soon as possible, and no later than 7 days after deletion.

For more information, refer to the [undelete D1 database API reference](/api/resources/d1/subresources/database/methods/undelete/).

D1 Insights can recommend indexes for active D1 databases. Each recommendation includes validated `CREATE INDEX` SQL, impacted queries, and measured query metrics.

Index recommendations are available from the Cloudflare dashboard, Cloudflare CLI (`cf`), Wrangler, and the REST API. For more information, refer to [Index recommendations](/d1/observability/metrics-analytics/index-recommendations/).

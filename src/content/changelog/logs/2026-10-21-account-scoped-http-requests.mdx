title: Account-scoped HTTP request logs in Logpush
description: Deliver HTTP request logs for every zone in an account with a single account-scoped Logpush job.
products:

date: 2026-10-21
---

Cloudflare Logpush now supports HTTP request logs as an [account-scoped dataset](/logs/logpush/logpush-job/datasets/account/http_requests/). Use one job to deliver logs for every zone in an account instead of maintaining a separate job for each zone.

Create the job at the account level in the Cloudflare dashboard or through the Logpush API. The `ZoneName` field identifies the source zone in each log entry.

Custom fields remain configured per zone. An account-scoped job honors the custom fields configuration for each zone but does not support account-wide custom fields configuration.

For setup details, refer to [API configuration](/logs/logpush/logpush-job/api-configuration/).

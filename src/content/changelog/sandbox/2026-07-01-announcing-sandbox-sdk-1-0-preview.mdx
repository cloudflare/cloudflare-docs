Following on from the [Sandbox SDK deprecations announcement](/changelog/post/2026-06-09-deprecating-sandbox-sdk-features/), we are announcing a new preview package that contains the replacement APIs.

Install the `1.0` preview with:

<PackageManagers pkg="@cloudflare/sandbox@next" />

The preview includes:

- A revised command interface that consolidates `exec()`, `execStream()`, and `startProcess()` into a single `exec()` process handle. Use `sandbox.exec(command).output()` for buffered output, or `sandbox.run(command)` for the previous buffered, session-shell behavior.
- Removal of HTTP and WebSocket transport selection. The SDK now uses one RPC control channel internally.
- Removal of hidden default sessions. Use explicit sessions when shell state must persist across commands.
- A new extensions API for adding reusable Sandbox capabilities outside the core SDK.
- Code Interpreter as an opt-in extension at `@cloudflare/sandbox/interpreter`.
- Explicit terminal resources through `sandbox.terminal(options).connect(request, options)`.
- Improved backup restore and tunnel recovery across sandbox runtime restarts.

We are aiming to ship this preview as `1.0.0` on July 31, 2026.

To get started, refer to [Migrate to Sandbox SDK 1.0](/sandbox/guides/migrating-to-1-0/). We also provide an [agent skill](/sandbox/guides/migrating-to-1-0/SKILL.md) to help with the migration.

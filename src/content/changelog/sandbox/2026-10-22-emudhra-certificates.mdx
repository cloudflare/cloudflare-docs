The private keys of [eight eMudhra intermediate certificate authorities](https://blog.cloudflare.com/emudhra-certificate-compromise/) can be recovered, so anyone can forge a certificate for any hostname that chains to them. Sandbox SDK images up to 0.12.12 trust these certificates. An HTTPS connection that leaves the container directly, such as one from `mountBucket()`, backups, `gitCheckout()`, tunnels, or code that runs in the sandbox, can be intercepted with a forged certificate.

## What you need to do

### Sandbox SDK 0.x

Update immediately. Install `@cloudflare/sandbox@0.12.13`, change the `FROM` line in your `Dockerfile` to the matching image, and redeploy. Keep any `-python`, `-opencode`, or `-musl` suffix on the image tag.

```dockerfile title="Dockerfile"
FROM docker.io/cloudflare/sandbox:0.12.13
```

If your sandboxes run `bun` or OpenCode, or `createBackup()` uploads archives of 10 MiB or more, also apply these workarounds until a later release updates Bun. All three check certificates against Bun's built-in CA list rather than the image's.

- For backups, pass `multipart: false` to [`createBackup()`](/sandbox/sdk/api/backups/#createbackup) to upload with `curl`, which uses the image's CA bundle.
- For `bun` and OpenCode, set [`interceptHttps = true`](/sandbox/sdk/guides/outbound-traffic/#https-traffic) and add an `outbound` handler that returns `fetch(request)`, so that Cloudflare checks their certificates.

If your sandboxes use none of these, updating to 0.12.13 is all you need to do.

### Sandbox SDK 1.x

You do not need to update the SDK, because it makes no TLS connections of its own. Your image decides which certificates your sandboxes trust, so pull your base image again and rebuild it without the Docker build cache to pick up updated CA certificates and runtimes.

## What changed in 0.12.13

In the 0.12.13 images, the system CA bundle, Node.js, `cloudflared`, and pip reject certificates from the compromised intermediates. The images ship updated Ubuntu and Alpine CA certificates, Node.js 22.23.4, `cloudflared` 2026.10.2, and pip 26.2.2 in the `-python` image.

---
title: Run Hermes Agent on Cloudflare
description: Run the Hermes web dashboard and coding tools in a per-user sandbox, with Access authentication and AI Gateway.
date: 2026-10-13
---

You can run [Hermes Agent](https://github.com/nousresearch/hermes-agent) on Cloudflare with the [Hermes template](https://github.com/cloudflare/templates/tree/main/hermes-agent-template). Each signed-in user gets a separate Linux sandbox for the Hermes web dashboard, embedded terminal, and coding tools.

[Cloudflare Access](/cloudflare-one/access-controls/) authenticates users before the Worker starts their container. Model requests go through [AI Gateway](/ai-gateway/) using the Worker's AI binding, so model API keys and Cloudflare API tokens stay outside the sandbox.

Use the template to give users a browser-based coding agent that can read and write files and run commands in an isolated environment. Workspaces are temporary: files and sessions are lost when a container stops or is replaced.

To get started, refer to [Run Hermes in a sandbox](/sandbox/coding-agents/hermes/).

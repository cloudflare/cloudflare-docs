title: Create additional Free accounts through the dashboard and API
description: Users can now create additional Free accounts through the dashboard and API. Organization Super Administrators can create Free accounts within Enterprise Organizations.
products:
  - fundamentals
date: 2026-09-17
---

Cloudflare users can now create five additional Free accounts through self-serve flows in the dashboard or programmatically via User-owned API tokens and OAuth access tokens.

Within an Enterprise Organization, Super Administrators can self-service create up to five Free accounts.

For API request fields and authentication requirements, refer to [Create Account](/api/resources/accounts/methods/create/). For eligibility and dashboard instructions, refer to [Create account](/fundamentals/account/create-account/). For Enterprise Organization behavior, refer to [Create new accounts](/fundamentals/organizations/for-enterprise/#create-new-accounts).

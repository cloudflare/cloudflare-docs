You can now configure [Artifacts](/artifacts/) namespaces, repos, and tokens directly from the Cloudflare dashboard.

You can view and create namespaces:

![Artifacts namespaces dashboard showing namespace search and create namespace controls](~/assets/images/changelog/artifacts/dashboard-namespaces.png)

You can view, create, fork, and search repos within a namespace:

![Artifacts repositories dashboard showing repo source, access, and created columns](~/assets/images/changelog/artifacts/dashboard-repositories.png)

You can open a repo to view its files and copy its Git remote URL.

You can also provision tokens directly from the dashboard to scope Git access to a single repo, with read tokens for clone, fetch, and pull workflows, or write tokens when a client needs to push changes:

![Artifacts repository overview showing files, commits, token management, and quick actions](~/assets/images/changelog/artifacts/dashboard-repo-overview.png)

To get started, go to the [Cloudflare dashboard](https://dash.cloudflare.com/) and select **Storage & databases** > **Artifacts**.

If you are enrolled in the Artifacts beta, you can use the dashboard to set up Artifacts. If you would like to join the beta, complete the [Request access](https://forms.gle/DwBoPRa3CWQ8ajFp7) form.

You can now assign [Access policies](/cloudflare-one/access-controls/policies/) to bookmark applications. This lets you control which users see a bookmark in the [App Launcher](/cloudflare-one/access-controls/access-settings/app-launcher/) based on identity, device posture, and other policy rules.

Previously, bookmark applications were visible to all users in your organization. With policy support, you can now:

- **Tailor the App Launcher to each user** — Users only see the applications they have access to, reducing clutter and preventing accidental clicks on irrelevant resources.
- **Restrict visibility of sensitive bookmarks** — Limit who can view bookmarks to internal tools or partner resources based on group membership, identity provider, or device posture.

Bookmark policies support all [Access policy selectors](/cloudflare-one/access-controls/policies/) except purpose justification, temporary authentication, and application isolation. If no policy is assigned, the bookmark remains visible to all users (maintaining backwards compatibility).

Additionally, self-hosted applications using private destinations can now be configured to appear in the App Launcher and accessed clientlessly through [browser isolation](/cloudflare-one/policies/browser-isolation/). Turn on **Show in App Launcher via clientless isolation** in the application settings to allow users to access private resources without installing the Cloudflare One client.

For more information, refer to [Add bookmarks](/cloudflare-one/access-controls/applications/bookmarks/).

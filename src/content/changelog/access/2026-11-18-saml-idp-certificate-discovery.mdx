title: Automatically retrieve SAML IdP signing certificates
description: Access retrieves signing certificates from SAML identity provider metadata to support certificate rotation without manual uploads.

Cloudflare Access can retrieve signing certificates from a SAML identity provider's metadata endpoint. Your IdP can publish replacement certificates without requiring you to upload each one to Access.

In your generic SAML identity provider configuration, set **Signing certificate source** to **Fetch certificates from IdP metadata** and enter the **IdP metadata URL**. The endpoint must return SAML metadata XML over public HTTPS, without authentication or redirects. It must not return a JSON Web Key Set (JWKS).

For API configurations, use `metadata_url` instead of manual certificate fields:

```json
{
	"type": "saml",
	"config": {
		"issuer_url": "https://idp.example.com",
		"sso_target_url": "https://idp.example.com/sso",
		"metadata_url": "https://idp.example.com/metadata.xml"
	}
}
```

Access caches the certificates and can refresh them during login if a signature cannot be verified, subject to a 60-second refresh limit. It does not poll the endpoint. Manual certificate configuration remains supported.

Removing a compromised certificate from metadata does not immediately revoke the cached certificate or existing Access sessions. For setup, planned rotation, and emergency replacement guidance, refer to [Discover IdP signing certificates](/cloudflare-one/integrations/identity-providers/generic-saml/#discover-idp-signing-certificates).

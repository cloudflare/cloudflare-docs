![Browser Rendering REST API rate limit increased from 3 to 10 requests per second](~/assets/images/changelog/browser-rendering/rest-api-limit-increase.png)

The [Browser Rendering](/browser-rendering/) [REST API](/browser-rendering/rest-api/) rate limit for Workers Paid plans has been increased from 3 requests per second (180/min) to **10 requests per second (600/min)**.

This applies to all REST API endpoints. No action is needed to benefit from the higher limit.

If you were previously hitting 429 errors on the REST API, your requests will now go through at the higher rate.

Increases to concurrent browser and new browser limits are also coming soon! Stay tuned.

For full details, refer to the [Browser Rendering limits page](/browser-rendering/limits/).

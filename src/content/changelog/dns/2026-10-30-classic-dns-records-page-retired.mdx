---
title: New DNS records experience is now the default for everyone
description: The classic DNS records page has been retired. All users now use the new DNS records experience.
date: 2026-10-30
---

The new DNS records experience [announced in May](/changelog/post/2026-05-20-new-dns-records-ux/) is now the default for all users on all plans, including Enterprise. The classic DNS records page has been retired and is no longer available in the Cloudflare dashboard.

## Changing a record's type

When the new experience first launched, it did not support changing the type of an existing DNS record. Based on your feedback, we have since added this, so you can now change a record's type (for example, from `A` to `CNAME`) directly from the DNS records page. Under the hood, the dashboard uses the [batch DNS records endpoint](/api/resources/dns/subresources/records/methods/batch/) for this.

## Questions or feedback

If you run into an issue with the new experience, contact your account team or [Cloudflare Support](/support/contacting-cloudflare-support/).

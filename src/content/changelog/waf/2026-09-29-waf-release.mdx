This release introduces new detections to enhance protection against a specific GitLab path traversal vulnerability, alongside advanced generic rules targeting HTTP request smuggling, directory traversal, and command injection attempts.

**Key Findings**
- CVE-2026-85706: A path traversal vulnerability affecting GitLab. Attackers can exploit this flaw to navigate beyond intended directory structures, potentially reading unauthorized files and exposing sensitive configuration data.

This release introduces updates to an existing PHP Remote Code Execution rule to improve detection accuracy, as well as a few new generic, PHP and Ruby CVE specific rules. The new PHP rules are being deployed in log mode by default (in lieu of False Positive risk) and can be overridden after evaluating requests matching the rules. Supplementary information around the CVEs are available through Zero Wire [phpAfterShell and six other PHP critical flaws](https://radar.cloudflare.com/zero-wire/php-november-2026-security-release-phpaftershell) and [ruby2shell: heap overflow in Ruby string case conversion](https://radar.cloudflare.com/zero-wire/ruby2shell).

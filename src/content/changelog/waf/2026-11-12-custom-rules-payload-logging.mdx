---
title: Payload logging for WAF custom rules
description: Payload logging now captures the request content that triggered WAF custom rules.
products:
  - waf
date: 2026-11-12
---

[Payload logging](/waf/payload-logging/) now supports WAF custom rules. Enterprise customers can configure an account-level public key, or a zone-level public key that takes precedence, to encrypt matched payloads for supported managed rules and custom rules.

This release does not add payload logging support for rate limiting rules.

Refer to [Configure payload logging via API](/waf/payload-logging/configure-api/) for configuration details.

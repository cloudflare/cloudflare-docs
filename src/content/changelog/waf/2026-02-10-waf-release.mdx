This week’s release introduces new detections for CVE-2025-68645 and CVE-2025-31125.

**Key Findings**

- CVE-2025-68645: Zimbra Collaboration Suite versions prior to 10.0.18 and 10.1.13 are vulnerable to unauthenticated local file inclusion via crafted requests to the `/h/rest` endpoint, potentially exposing sensitive files.
- CVE-2025-31125: Vite development servers prior to patched versions are vulnerable to arbitrary file disclosure due to improper access control when processing crafted import parameters.

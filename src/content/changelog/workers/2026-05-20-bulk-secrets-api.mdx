title: New Workers bulk secrets API endpoint
description: A new API endpoint lets you create, update, and delete multiple Worker secrets in a single request.
products:

date: 2026-05-20
---

You can now create, update, or delete multiple secrets in one request to the Workers API using the [`PATCH /secrets-bulk` endpoint](/api/resources/workers/subresources/scripts/subresources/secrets/methods/bulk_update/):

```sh
PATCH /accounts/{account_id}/workers/scripts/{script_name}/secrets-bulk
```

The following request body creates/updates `API_KEY` and `DB_PASSWORD`, and deletes `OLD_SECRET`:
```json
{
	"secrets": {
		"API_KEY": { "type": "secret_text", "name": "API_KEY", "text": "my-api-key" },
		"DB_PASSWORD": { "type": "secret_text", "name": "DB_PASSWORD", "text": "my-db-password" },
		"OLD_SECRET": null
	}
}
```

- Create or update a secret by including it with a value.
- Delete a secret key by setting its value to `null`.
- Secrets not included in the request are **left unchanged**.

Each request supports up to **25 operations** in total. Both secret updates and secret deletions count toward this limit.

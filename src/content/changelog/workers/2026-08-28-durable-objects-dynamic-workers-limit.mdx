---
title: Durable Objects can use up to ten Dynamic Workers concurrently
description: Each Durable Object can use up to ten Dynamic Workers with in-flight requests.
products:
  - workers
  - durable-objects
date: 2026-08-28
---

[Durable Objects](/durable-objects/) can have up to ten [Dynamic Workers](/dynamic-workers/) with in-flight requests. This limit applies across all requests to the same Durable Object. Other Workers can have up to four Dynamic Workers with in-flight requests per request.

For more information, refer to [Dynamic Workers limits](/dynamic-workers/platform/limits/).

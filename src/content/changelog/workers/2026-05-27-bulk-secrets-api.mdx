title: New Workers bulk secrets API endpoint
description: A new API endpoint lets you create, update, and delete multiple Worker secrets in a single request.
products:

date: 2026-05-27
---

You can now create, update, or delete multiple secrets on your Workers project using either the [bulk secrets endpoint](/api/resources/workers/subresources/scripts/subresources/secrets/methods/bulk_update/) 
or the [`wrangler secret bulk`](/workers/wrangler/commands/workers/#secret-bulk) command.

- Include a secret with a value to create or update.
- Set a secret to `null` to delete.
- Secrets not included in the request are left unchanged.

The following example uses the API endpoint. It creates `API_KEY`, updates the already existing `DB_PASSWORD`, and deletes `OLD_SECRET`:

```json
{
  "secrets": {
    "API_KEY": { "type": "secret_text", "name": "API_KEY", "text": "my-api-key" },
    "DB_PASSWORD": { "type": "secret_text", "name": "DB_PASSWORD", "text": "my-db-password" },
    "OLD_SECRET": null
  }
}
```

You can also use the Wrangler CLI to create, update, and delete secrets from the command line:

```sh
npx wrangler secret bulk < secrets.json
```
To delete a key, explicitly pass in a null value as shown in the API example above. 

Each request supports up to **25 total operations** (creates, updates, and deletes combined).

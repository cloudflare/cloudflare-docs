---
title: New Workers bulk secrets API endpoint
description: A new API endpoint lets you create, update, and delete multiple Worker secrets in a single request.
products:
  - workers
date: 2026-05-22
---

You can now create, update, or delete multiple secrets on a Worker's project in a single request using the new [`PATCH /secrets-bulk` endpoint](/api/resources/workers/subresources/scripts/subresources/secrets/methods/bulk_update/).

- Include a secret with a value to create or update.
- Set a secret to `null` to delete.

Secrets not included in the request are left unchanged.

The following example creates `API_KEY`, updates the already existing `DB_PASSWORD`, and deletes `OLD_SECRET`:

```json
{
  "secrets": {
    "API_KEY": { "type": "secret_text", "name": "API_KEY", "text": "my-api-key" },
    "DB_PASSWORD": { "type": "secret_text", "name": "DB_PASSWORD", "text": "my-db-password" },
    "OLD_SECRET": null
  }
}
```

Each request supports up to **25 total operations** (creates, updates, and deletes combined).

The [`wrangler secret bulk`](/workers/wrangler/commands/workers/#secret-bulk) command now uses this endpoint under the hood when uploading secrets from a JSON file:

```sh
npx wrangler secret bulk < secrets.json
```

Previously, `wrangler secret bulk` internally made two API calls to upload secrets. It now makes a single call, which is faster when uploading multiple secrets.

The [`wrangler secret delete`](/workers/wrangler/commands/workers/#secret-delete) command now also uses this endpoint when deleting secrets from a JSON file:

```sh
npx wrangler secret delete < secrets-to-delete.json
```

Previously, `wrangler secret delete` only supported removing one secret at a time. It now accepts a JSON file listing the secret keys to delete and removes them all in a single call, which is faster when cleaning up multiple secrets.

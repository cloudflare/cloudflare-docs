You can now deploy any supported framework to Cloudflare Workers by running a single command — no configuration file required. Starting with Wrangler **4.68.0**, [`wrangler deploy`](/workers/wrangler/commands/#deploy) automatically detects your framework, installs the necessary adapters, generates a `wrangler.jsonc` configuration file, and deploys your project. If you import a Git repository through the Cloudflare dashboard, Wrangler opens a pull request with the generated configuration for you to review before merging.

In December 2025, we [introduced automatic configuration](/changelog/2025-12-16-wrangler-autoconfig/) as an experimental feature. It is now the default behavior — no flags or manual setup needed.

## Get started

To deploy an existing project to Cloudflare Workers:

```sh
npx wrangler deploy
```

Or import your repository directly from the [Workers dashboard](https://dash.cloudflare.com/?to=/:account/workers-and-pages/create) and get a PR with the generated configuration to review and merge.

## Details

### Using Wrangler locally

When you run [`wrangler deploy`](/workers/wrangler/commands/#deploy) in a project directory without a [Wrangler configuration file](/workers/wrangler/configuration/), Wrangler automatically detects your framework and prompts you to confirm the detected settings. Once you confirm, Wrangler installs any required adapters, generates a `wrangler.jsonc` configuration file, and deploys your project to Cloudflare Workers.

You no longer need to pass the `--x-autoconfig` flag. This is now the default behavior. You can also use [`wrangler setup`](/workers/wrangler/commands/#setup) to configure your project without deploying, or pass the [`--yes` flag](/workers/wrangler/commands/#deploy) to skip confirmation prompts.

### Using the Cloudflare dashboard

![Automatic configuration pull request created by Workers Builds](~/assets/images/workers/ci-cd/builds/automatic-pr.png)

When you import a Git repository through the Cloudflare dashboard without a Wrangler configuration file, the deploy command (`wrangler deploy`) triggers [automatic configuration](/workers/framework-guides/) non-interactively. This detects your framework, creates the necessary configuration, and opens a [pull request](/workers/ci-cd/builds/) for you to review. This PR includes:

- A `wrangler.jsonc` [configuration file](/workers/wrangler/configuration/)
- Any required framework adapters
- Updated `package.json` scripts
- A [preview deployment](/workers/configuration/previews/) so you can test before merging

Once you merge the PR, your project is fully configured and future builds deploy normally. For more information, refer to [Workers Builds](/workers/ci-cd/builds/).

:::note
Wrangler only creates automatic pull requests when your deploy command is `npx wrangler deploy`. If you have a custom deploy command, automatic configuration still runs and configures your project, but Wrangler does not create a PR.
:::

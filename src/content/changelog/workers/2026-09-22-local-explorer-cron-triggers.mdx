Local Explorer can now send one-off Cron Trigger invocations to the `scheduled()` handler for a Worker during local development. This removes the need to construct request URLs when testing handler behavior.

The browser interface supports the following tasks:

- Invoke configured cron expressions
- Build ad hoc expressions
- Set reusable scheduled times
- Inspect outcomes and `noRetry()` status

Ad hoc triggers and scheduled time presets stay in your browser. They do not change your Wrangler configuration or deployed Cron Triggers. Full invocation logs and traces remain available in the Local Explorer **Observability** views.

The Local Explorer API exposes the same operation for tools and AI agents. The request targets an exact Worker name and accepts a cron expression and optional scheduled time:

```sh
curl -X POST \
  "http://localhost:8787/cdn-cgi/local/explorer/api/local/scheduled?worker=my-worker" \
  -H "Content-Type: application/json" \
  --data '{"cron":"0 * * * *","scheduled_time":1745856238000}'
```

For more details, refer to [Test Cron Triggers with Local Explorer](/workers/local-development/local-explorer/#test-cron-triggers).

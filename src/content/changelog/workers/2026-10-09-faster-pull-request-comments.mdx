---
title: Workers Builds now posts preview URLs in seconds
description: Workers Builds now consistently posts preview URLs to GitHub and GitLab within a few seconds of a build completing.
date: 2026-10-09
---

Workers Builds now consistently posts preview URLs to GitHub pull requests and GitLab merge requests within a few seconds of a build completing, so you can start testing and reviewing your changes sooner. Previously, posting preview URLs could often take minutes.

For details, refer to [Workers Builds GitHub integration](/workers/ci-cd/builds/git-integration/github-integration/#pull-request-comment) and [Workers Builds GitLab integration](/workers/ci-cd/builds/git-integration/gitlab-integration/#merge-request-comment).

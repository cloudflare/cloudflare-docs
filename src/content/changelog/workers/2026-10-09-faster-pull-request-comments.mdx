---
title: Workers Builds pull request comments now update faster
description: Workers Builds now updates pull request comments faster, reducing the wait for build status updates and preview URLs.
date: 2026-10-09
---

During peak load, Workers Builds pull request comments could arrive up to approximately 30 minutes late. We have optimized comment processing, reducing observed delays to approximately 5 seconds. This helps you check build status and open preview URLs sooner when reviewing changes.

For details, refer to [Workers Builds GitHub integration](/workers/ci-cd/builds/git-integration/github-integration/#pull-request-comment).

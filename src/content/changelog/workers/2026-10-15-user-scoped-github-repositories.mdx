---
title: GitHub repository picker reflects your access
description: Workers Builds and Pages show only repositories available to the authenticated GitHub user.
products:
  - workers
  - pages
date: 2026-10-15
---

When you connect a GitHub repository to Workers Builds or Pages, Cloudflare may ask you to authenticate or reauthenticate with GitHub. The repository picker then shows only the organizations and repositories that your GitHub user can access.

Existing repository connections remain connected. Builds from those connections continue without requiring reauthentication.

For more information, refer to the [Workers Builds GitHub integration](/workers/ci-cd/builds/git-integration/github-integration/) and [Pages GitHub integration](/pages/configuration/git-integration/github-integration/).

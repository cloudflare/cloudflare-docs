This [Workers Builds](/workers/ci-cd/builds/) build image update refreshes default runtimes and package managers. Node.js stays on the 24 long-term support (LTS) release line.

The updated defaults are:

| Tool    | Version |
| ------- | ------- |
| Node.js | 24.21.0 |
| Bun     | 1.4.3   |
| Python  | 3.14.8  |
| Ruby    | 3.4.11  |
| Go      | 1.27.2  |
| npm     | 11.19.0 |
| Yarn    | 4.18.1  |
| pnpm    | 10.34.6 |
| pip     | 26.2.1  |
| pipx    | 1.17.2  |
| Poetry  | 2.4.3   |
| uv      | 0.12.10 |

The image also preinstalls Node.js 22.23.3. Python 3.14 includes the `sqlite3` module.

Explicit runtime and supported package-manager version overrides remain unchanged. To keep a specific version, configure an [environment variable or version file](/workers/ci-cd/builds/build-image/#overriding-default-versions).

This update applies only to Workers Builds. Cloudflare Pages uses a separate build image.

For available tools and version settings, refer to the [Workers Builds build image documentation](/workers/ci-cd/builds/build-image/).

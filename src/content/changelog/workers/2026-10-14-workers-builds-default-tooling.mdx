Workers Builds now uses updated default versions of supported runtimes and package managers:

| Tool    | Previous version | New version |
| ------- | ---------------- | ----------- |
| Node.js | 24.18.0          | 24.21.0     |
| Yarn    | 4.9.1            | 4.18.1      |
| Bun     | 1.2.15           | 1.4.3       |
| Python  | 3.13.3           | 3.14.8      |
| Ruby    | 3.4.7            | 3.4.11      |
| Go      | 1.24.3           | 1.27.2      |
| pip     | 25.1.1           | 26.2.1      |
| pipx    | 1.7.1            | 1.17.2      |
| Poetry  | 2.1.3            | 2.4.3       |
| uv      | 0.7.13           | 0.12.10     |

Bun 1.4.3 supports both v1 and v2 lockfiles. Projects that specify runtime or package manager versions continue to use those versions.

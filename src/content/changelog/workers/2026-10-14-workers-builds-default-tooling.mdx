Workers Builds now uses updated default versions of supported runtimes and package managers:

| Tool    | Previous version | New version |
| ------- | ---------------- | ----------- |
| Node.js | 24.18.0          | 24.21.0     |
| Yarn    | 4.9.1            | 4.18.1      |
| Bun     | 1.2.15           | 1.4.3       |
| Python  | 3.13.3           | 3.14.8      |
| Ruby    | 3.4.7            | 3.4.11      |
| Go      | 1.24.3           | 1.27.2      |
| pip     | 25.1.1           | 26.2.1      |
| pipx    | 1.7.1            | 1.17.2      |
| Poetry  | 2.1.3            | 2.4.3       |
| uv      | 0.7.13           | 0.12.10     |

Bun 1.4.3 supports both v1 and v2 lockfiles. Projects that specify runtime or package manager versions continue to use those versions.

:::caution[npm 11 and pnpm 10 become the defaults on January 14, 2027]
On January 14, 2027, Workers Builds will update npm from 10.9.2 to 11.19.0 and pnpm from 9.10.0 to 10.34.6. These major updates may affect dependency installation.

To test or upgrade to npm 11 before the default changes, set `"packageManager": "npm@11.19.0"` in `package.json`. To test or upgrade to pnpm 10, set the `PNPM_VERSION` build variable to `10.34.6`.

pnpm 10 improves supply-chain security by preventing dependencies from running lifecycle scripts unless you explicitly approve them. This change may affect dependencies that use `preinstall`, `install`, or `postinstall` scripts. If your build is affected, run [`pnpm approve-builds`](https://pnpm.io/10.x/cli/approve-builds) locally, approve the dependencies you trust, and commit the resulting `pnpm-workspace.yaml` changes.

After the change, you can continue using npm 10 by setting `"packageManager": "npm@10.9.2"` in `package.json`. To continue using pnpm 9, set `PNPM_VERSION` to `9.10.0`.
:::

For more information, refer to [Override default versions](/workers/ci-cd/builds/build-image/#overriding-default-versions).

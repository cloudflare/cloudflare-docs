---
title: Bulk update secrets with a single API request
description: A new API endpoint lets you create, update, and delete multiple Worker secrets in a single request.
products:
  - workers
date: 2026-05-19
---

Previously, creating, updating, or deleting secrets required a separate API request for each secret. The new [`PATCH /secrets-bulk` endpoint](/api/resources/workers/subresources/scripts/subresources/secrets/methods/bulk_update/) lets you batch multiple secret operations into a single request:

```sh
PATCH /accounts/{account_id}/workers/scripts/{script_name}/secrets-bulk
```

Each request supports up to **25 total** update and delete operations.

For usage details, refer to the [API documentation](/api/resources/workers/subresources/scripts/subresources/secrets/methods/bulk_update/).

You can now query your [R2 Data Catalog](/r2/data-catalog/) tables with [R2 SQL](/r2-sql/) directly from the Cloudflare dashboard, without installing a CLI or wiring up a client. This makes it easy to explore your [Apache Iceberg](https://iceberg.apache.org/) data, validate queries, and inspect results in one place.

<Image src={screenshot} alt="R2 SQL Query Editor" />

To get started, go to [R2 Data Catalog](https://dash.cloudflare.com/?to=/:account/data-catalog/overview) in the Cloudflare dashboard and select **Query data** to launch the built-in SQL editor. From there you can:

- **Write and run queries** — A SQL editor with syntax highlighting and autocomplete for R2 SQL.
- **Browse your schema** — Explore namespaces, tables, and columns alongside the editor so you can build queries without leaving the page.
- **Inspect results and query plans** — View result sets with per-query statistics, export them, and format `EXPLAIN` and `EXPLAIN FORMAT JSON` output to better understand how a query runs.

:::note
Your R2 SQL credential is generated and stored for you and can be rotated in the R2 Data Catalog settings page.
:::

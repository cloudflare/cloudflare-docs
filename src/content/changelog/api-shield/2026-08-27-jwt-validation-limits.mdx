---
title: Increased limits for JWT validation configurations
description: Configure up to 32 token configurations per zone, with up to 16 keys in each configuration.
date: 2026-08-27
---

API Shield [JSON Web Token validation](/api-shield/security/jwt-validation/) now supports 32 token configurations per zone by default. Each token configuration can contain up to 16 keys.

These increased limits support more JWT configurations and provide additional capacity for key rotation.

Refer to [Configure JWT validation via the API](/api-shield/security/jwt-validation/api/) for configuration details.

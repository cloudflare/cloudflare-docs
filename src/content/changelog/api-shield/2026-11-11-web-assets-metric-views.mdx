---
title: Prioritize Web Assets operations with metric views
description: Compare and sort operations by traffic, errors, latency, response size, and security metrics.
date: 2026-11-11
---

The **Web Assets** > **Operations** page now includes metric-focused views for traffic, errors, latency, response size, and security. Each view surfaces the relevant metrics and supports server-side sorting, making it easier to prioritize operations in large inventories.

Refer to [Endpoint Management](/api-shield/management-and-monitoring/endpoint-management/) for more information about managing and analyzing operations.

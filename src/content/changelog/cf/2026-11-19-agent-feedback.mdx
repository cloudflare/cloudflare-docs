---
title: Send feedback from the Cloudflare CLI and MCP
description: Use cf feedback or the send_feedback MCP tool to report bugs, feature requests, and problems you encounter.
date: 2026-11-19
---

Send bug reports, feature requests, and feedback about where you got stuck
directly to Cloudflare.

From the terminal, use `cf feedback` with a short note.

```sh
cf feedback "The deploy output did not identify the selected environment"
```

Coding agents connected to the Cloudflare API Model Context Protocol (MCP)
server can use the `send_feedback` tool. Both options accept a short note or
a structured report with details such as the task, expected and actual
results, and impact. Both return a submission ID you can share.

For examples and CLI context settings, refer to [Agent feedback](/cf/agent-feedback/).

title: Send feedback from the Cloudflare CLI and MCP
description: Use cf feedback send or the submit_feedback MCP tool to report bugs, feature requests, and problems you encounter.
date: 2026-11-23
---

Send bug reports, feature requests, and feedback about where you got stuck
directly to Cloudflare.

To send a short note with `cf feedback send`, follow the
[Cloudflare CLI instructions](/cf/agent-feedback/#send-with-the-cloudflare-cli).

Coding agents connected to the Cloudflare API Model Context Protocol (MCP)
server can use the `submit_feedback` tool. The tool requires a `message`,
`type`, and `impact`. It accepts optional details such as the task and the
expected and actual results. Both options return a submission ID you can share.

For a prompt that looks for blockers and workarounds across a repository, refer
to [Review an existing project](/cf/agent-feedback/#review-an-existing-project).

[AI Search](/ai-search/) now supports larger datasets and more instances per account.

Index entire documentation sites, knowledge bases, or product catalogs in a single instance. With more instances per account, you can also build multi-tenant applications with a dedicated instance per customer or workspace, all in the same account.


| Limit                 | Previous | New       |
| --------------------- | -------- | --------- |
| Files per instance    | 100,000  | 1,000,000 |
| Instances per account | 10       | 50        |

Existing instances automatically benefit from the new limits. 

For more information, refer to [Limits and pricing](/ai-search/platform/limits-pricing/).

You can now use the Cloudflare CLI to manage and query [AI Search](/ai-search/) from your terminal, scripts, and agent workflows.

The `cf ai-search` command group supports instance and namespace management, search and chat completions across one or multiple instances, content and sync job operations, cache purging, and token management.

Run `cf ai-search --help` to explore the available commands.

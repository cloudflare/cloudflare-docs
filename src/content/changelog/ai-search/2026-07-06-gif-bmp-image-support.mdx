title: AI Search now supports GIF and BMP images
description: GIF and BMP image files are now indexed and converted to searchable text using Workers AI toMarkdown.
products:

date: 2026-07-06
---

AI Search now supports `.gif` and `.bmp` image files as indexable content. These formats are converted to searchable text descriptions using Workers AI [toMarkdown](/workers-ai/features/markdown-conversion/), the same pipeline used for JPEG, PNG, and WebP images.

Learn more about [supported file types](/ai-search/configuration/data-source/#supported-file-types).

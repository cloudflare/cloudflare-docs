title: Large-file indexing resumes from checkpoints
description: AI Search resumes large-file embedding work after interruptions.
products:

date: 2026-09-28
---

AI Search saves checkpoints while embedding large files. If indexing is interrupted, processing resumes from the latest checkpoint instead of starting the file again.

Learn more about [indexing and syncing](/ai-search/configuration/indexing/syncing/).

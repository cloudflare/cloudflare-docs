[AI Search](/ai-search/) now supports a `wrangler ai-search` command namespace, giving you a full CLI surface for managing instances without leaving your terminal.

The following commands are available:

| Command                     | Description                                      |
| --------------------------- | ------------------------------------------------ |
| `wrangler ai-search create` | Create a new instance with an interactive wizard |
| `wrangler ai-search list`   | List all instances in your account               |
| `wrangler ai-search get`    | Get details of a specific instance               |
| `wrangler ai-search update` | Update the configuration of an instance          |
| `wrangler ai-search delete` | Delete an instance                               |
| `wrangler ai-search search` | Run a search query against an instance           |
| `wrangler ai-search chat`   | Get an AI-generated answer against an instance   |
| `wrangler ai-search stats`  | Get usage statistics for an instance             |

The `create` command guides you through setup with an interactive wizard — picking a name, source type (`r2` or `web-crawler`), and data source. You can also pass all options as flags for non-interactive use:

```sh
wrangler ai-search create my-instance --type r2 --source my-bucket
```

Use `wrangler ai-search search` and `wrangler ai-search chat` to query an instance directly from the CLI, with support for metadata filters and custom system prompts:

```sh
wrangler ai-search search my-instance "how do I configure caching?" --filter type=docs

wrangler ai-search chat my-instance "Summarize the onboarding guide" \
  --system-prompt "You are a helpful documentation assistant."
```

All commands support `--json` for machine-readable output. Authentication is handled via `wrangler login` — no separate API credentials are required.

For full usage details, refer to the [AI Search CLI documentation](/ai-search/usage/cli/).

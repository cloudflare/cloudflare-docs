---
title: AI Search infers instance type from the source
description: Create an instance without specifying its type when the source identifies it.
products:
  - ai-search
date: 2026-09-28
---

When you create an AI Search instance, the `type` field is optional. AI Search infers a website source from an HTTP or HTTPS URL, or an R2 source from an existing bucket name.

Learn more about [AI Search data sources](/ai-search/configuration/data-source/).

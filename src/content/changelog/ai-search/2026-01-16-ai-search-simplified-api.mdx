You can now create [AI Search](/ai-search/) instances programmatically using the [API](/ai-search/get-started/api/). This enables you to automate instance creation and manage instances at scale.

If you have already created an AI Search instance via the [dashboard](/ai-search/get-started/dashboard/), your account has a [service API token](/ai-search/configuration/service-api-token/) registered and the `token_id` field becomes optional. Refer to the [REST API reference](/api/resources/ai_search/subresources/instances/methods/create/) for the full request schema. Here are some example requests:

**[R2 bucket](/ai-search/configuration/data-source/r2/):**

```bash
curl -X POST "https://api.cloudflare.com/client/v4/accounts/<ACCOUNT_ID>/ai-search/instances" \
  -H "Authorization: Bearer <API_TOKEN>" \
  -H "Content-Type: application/json" \
  --data '{
    "id": "my-r2-rag",
    "type": "r2",
    "source": "<R2_BUCKET_NAME>"
  }'
```

**[Website](/ai-search/configuration/data-source/website/):**

```bash
curl -X POST "https://api.cloudflare.com/client/v4/accounts/<ACCOUNT_ID>/ai-search/instances" \
  -H "Authorization: Bearer <API_TOKEN>" \
  -H "Content-Type: application/json" \
  --data '{
    "id": "my-web-rag",
    "type": "web-crawler",
    "source": "<DOMAIN_IN_YOUR_ACCOUNT>"
  }'
```

Learn more about [getting started with AI Search](/ai-search/get-started/).

AI Gateway now automatically creates a gateway for you on your first request. When you use `default` as a gateway ID, AI Gateway creates the gateway if it does not already exist — no need to set one up through the dashboard or API first.

The auto-created default gateway has authentication and log collection turned on, with caching and rate limiting turned off.

For more information, refer to [Default gateway](/ai-gateway/configuration/manage-gateway/#default-gateway).

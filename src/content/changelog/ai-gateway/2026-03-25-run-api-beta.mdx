AI Gateway introduces the Run API (`/run`), a new endpoint with its own request envelope separate from the OpenAI-compatible `/chat/completions` format. The Run API is in beta and currently supports [`google/nano-banana`](/workers-ai/models/google/nano-banana/) for image generation, with more models coming soon. Authenticate with [Unified Billing](/ai-gateway/features/unified-billing/) or [BYOK (Gateway Key Store)](/ai-gateway/configuration/bring-your-own-keys/).

Alongside the Run API, the Workers AI binding (`env.AI.run()`) now supports running third-party models proxied through AI Gateway. Today, `google/nano-banana` is the only supported model, but you can call it directly from a Cloudflare Worker without managing provider credentials in your code:

```ts
const response = await env.AI.run(
  "google/nano-banana",
  { prompt: "a cat riding a burrito" },
  { gateway: { id: "my-gateway" } },
);
```

For more information, refer to the [Run API](/ai-gateway/usage/run-api/) documentation.

title: Recommendations for Configurations
description: Providing recommendations for configuration updates for Email Security users.
date: 2026-02-01T21:11:33Z
---

Customers can now see a tab called **Optimize your Email Security setup** on the Overview page of Email Security.

When customers click **Get Started** in this tab, a side panel opens showing the steps and configurations that are still pending.

Completing these steps will help ensure the Email Security environment is fully configured and provide stronger protection for end users.

This feature is available for all Email Security packages:

- **Advantage**
- **Enterprise**
- **Enterprise + PhishGuard**

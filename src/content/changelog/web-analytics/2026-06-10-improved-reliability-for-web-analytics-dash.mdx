title: "Improved reliability for account-wide Web Analytics dashboards"
description: "Web Analytics introduces performance optimizations and safety thresholds for accounts tracking a large volume of websites."
date: 2026-06-10
products:

---

Cloudflare Web Analytics (Real User Monitoring) has rolled out performance optimizations to significantly improve the stability and loading speed of account-wide dashboards.

For large accounts monitoring a hundreds-to-thousands of websites, loading the aggregate account-wide view would often fail, running into timeouts or unexpected interface errors due to the massive scale of parallel query processing. This update optimizes how high-volume multi-site data is queried to reduce errors and providing a snappier dashboard experience.

As part of this optimization, Cloudflare is introducing a safety guardrail for a minority of complex accounts. If your account contains more than **1,000 active sites** AND more than **1,000 deleted sites**, a contextual warning will now appear on your account-wide Web Analytics view.

This warning states that the aggregate view _may_ include historical beacon data from recently-deleted sites alongside active properties.

Accounts affected by this warning should be limited to a small subset those who were previously simply presented with errors and no data whatsoever. If your workflow requires absolute, strict accuracy focused only on active sites, please use the filtering options at the top of the screen to select the relevant site(s).

You can now replace the credentials of a [Basin Pipelines](/basin-pipelines/) [sink](/basin-pipelines/sinks/). Previously, an expired or revoked token meant deleting and recreating the sink.

Pipelines keep the sink's earlier credentials until you update them. Updating a [failed pipeline](/basin-pipelines/pipelines/manage-pipelines/#fix-a-failed-pipeline) automatically restarts it.

![A failed pipeline's page with the reason it failed, the sink that changed, and the Update pipeline button](~/assets/images/pipelines/pipeline-failed-update.png)

## Dashboard

- **Update credentials** — On a sink's page, in **Destination**. Create a new API token, or enter the credentials of a token you created.
- **Update pipeline** — On a pipeline's page, when a stream or sink it uses has changed.

## API

Both requests need an [API token](/fundamentals/api/get-started/create-token/) with **Basin Pipelines Edit** permission.

First, update the sink. The following is an example of updating credentials of an R2 sink.

```bash wrap
curl "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/pipelines/v1/sinks/$SINK_ID" \
  --request PATCH \
  --header "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
  --json '{
    "config": {
      "credentials": {
        "access_key_id": "<ACCESS_KEY_ID>",
        "secret_access_key": "<SECRET_ACCESS_KEY>"
      }
    }
  }'
```

Then update each pipeline that uses it:

```bash wrap
curl "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/pipelines/v1/pipelines/$PIPELINE_ID/update_tables" \
  --request POST \
  --header "Authorization: Bearer $CLOUDFLARE_API_TOKEN"
```

For more information, refer to [Update sink credentials](/basin-pipelines/sinks/manage-sinks/#update-sink-credentials) and [Update a pipeline](/basin-pipelines/pipelines/manage-pipelines/#update-a-pipeline).

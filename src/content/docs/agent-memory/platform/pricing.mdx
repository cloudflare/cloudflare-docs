Agent Memory is currently in beta. Pricing details will be announced as the product moves toward general availability.

During the beta period, Agent Memory is available at no additional cost to users on the [Workers Paid plan](/workers/platform/pricing/).

For the latest pricing information, refer to the [Cloudflare pricing page](https://www.cloudflare.com/plans/developer-platform/).

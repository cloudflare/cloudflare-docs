AI Crawl Control works alongside other Cloudflare products, such as [Response Header Transform Rules](/rules/transform/response-header-modification/). You can use transform rules to add custom HTTP `Link` headers to responses sent to crawlers, even when those crawlers are blocked by WAF custom rules or subject to pay per crawl requirements.

## Using Link headers with blocked crawlers

[Response Header Transform Rules](/rules/transform/response-header-modification/) apply to all HTTP responses, including error responses generated by WAF custom rules. This means you can attach licensing information, terms of service, or payment URLs to responses even when crawlers are blocked.

This is particularly useful for:

- **Communicating licensing terms** — Add `Link` headers pointing to your content licensing terms when blocking training crawlers
- **Payment information** — Include URLs to hosted terms or payment pages when returning 402 (Payment Required) responses
- **RSL compliance** — Attach [RSL (Really Simple Licensing)](https://rslstandard.org/) license information to responses for standards-compliant crawlers

<Aside type="note">

Response Header Transform Rules work with AI Crawl Control's WAF-based blocking and pay per crawl features. The Link headers will be attached to the response regardless of whether the crawler is allowed, blocked, or required to pay.

</Aside>

## Example: Add licensing terms to blocked responses

You can create a Response Header Transform Rule that adds a `Link` header to responses sent to blocked AI crawlers, directing them to your licensing terms or payment information.

<Example>

**Expression:**

```txt
(cf.bot_management.verified_bot and http.response.code eq 403)
```

**Header modification:**

- **Operation:** Set static
- **Header name:** `Link`
- **Value:** `<https://example.com/ai-licensing-terms>; rel="license"; type="text/html"`

This rule adds a `Link` header to 403 (Forbidden) responses sent to crawlers, providing them with information about how to license your content.

</Example>

## Example: RSL license information

If you use [RSL (Really Simple Licensing)](https://rslstandard.org/) to express content licensing preferences, you can add RSL license information to responses using the standard `Link` header format.

<Example>

**Expression:**

```txt
(cf.bot_management.verified_bot)
```

**Header modification:**

- **Operation:** Set static
- **Header name:** `Link`
- **Value:** `<https://example.com/license.xml>; rel="license"; type="application/rsl+xml"`

This rule adds an RSL-compliant `Link` header to all responses sent to verified bots, communicating your licensing terms in a machine-readable format.

</Example>

## Compatibility with AI Crawl Control features

Response Header Transform Rules are compatible with all AI Crawl Control features:

- **WAF custom rules** — Link headers are attached to responses even when crawlers are blocked by WAF rules
- **Pay per crawl** — Link headers work with 402 responses and payment requirements
- **RSL licensing** — Use Link headers to communicate RSL license information alongside any AI Crawl Control configuration

For more information about Response Header Transform Rules, refer to [Response Header Transform Rules](/rules/transform/response-header-modification/).

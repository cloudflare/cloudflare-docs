Create a rule that charges matching requests for a resource.

## Review prerequisites

- Your account and zone meet the [eligibility requirements](/monetization-gateway/eligibility/).
- You have a receiving wallet.

## Configure a payment rule

<Steps>
1. In Monetization Gateway, select the domain you'd like to monetize
2. Select the receiving wallet for payments.
3. Enter the URL for the request to be monetized.
4. Select an audience:

	- Select _Everyone_ to charge all matching traffic.
	- Select _Verified Bots_ to charge bots identified by [BotBase](/bots/botbase/).

5. Select a pricing scheme:

	- Select _Fixed_ to charge the same amount per request.
	- Select _Variable_ to authorize a maximum amount.

6. Enter the price to be charged.

	The minimum amount is $0.001.
</Steps>

## Continue configuration

Configure [payment validation](/monetization-gateway/configuration/payment-validation/) at your origin.

To refine matching traffic, refer to [Rules](/monetization-gateway/configuration/rules/).

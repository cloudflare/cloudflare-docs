Your origin receives verified payment information in the `PAYMENT-CONTEXT` header. Validate this header before serving paid content.

## Validate the context

The header contains a JSON Web Token (JWT). Validate the signature with a recommended JWT library, reject the request if the signature verification fails.

Use only the [pinned JSON Web Key Set (JWKS)](https://payments.cloudflare.com/certs).

Recommended libraries include:

| Language                                                    | Library                        |
| ----------------------------------------------------------- | ------------------------------ |
| JavaScript, TypeScript, and [Cloudflare Workers](/workers/) | `jose`                         |
| Python                                                      | `PyJWT` with `cryptography`    |
| Java                                                        | Nimbus JOSE + JWT              |
| Go                                                          | `github.com/golang-jwt/jwt/v5` |
| Rust                                                        | `jsonwebtoken`                 |

:::caution
If `PAYMENT-CONTEXT` is absent, treat the request as unpaid and unverified. Do not serve paid content or set `PAYMENT-SETTLEMENT`.
:::

## Read the `PAYMENT-CONTEXT` contents:

### Fixed pricing rule match

Fixed pricing uses the x402 `exact` scheme. The following decoded example authorizes 25,000 atomic units for one audience:

```json
{
	"iat": 1770000000,
	"nbf": 1770000000,
	"exp": 1770000120,
	"aud": "https://api.example.com/premium-data",
	"scheme": "exact",
	"amount": "25000"
}
```

Monetization Gateway will settle the exact amount in the `PAYMENT-CONTEXT` which matches the previously configured rule.
A `PAYMENT-SETTLEMENT` header sent for a fixed pricing request will be ignored.

### Variable pricing rule match

Variable pricing uses the x402 `upto` scheme. The `amount` claim contains the authorized maximum.

The following decoded example authorizes up to 100,000 atomic units:

```json
{
	"iat": 1770000000,
	"nbf": 1770000000,
	"exp": 1770000120,
	"aud": "https://api.example.com/generate",
	"scheme": "upto",
	"amount": "100000"
}
```

Calculate the actual amount you wish to charge for this request. Express the amount in atomic units.

If the actual amount exceeds the authorized maximum configured in the rule and signed by the buyer, Monetization Gateway will settle the authorized maximum instead. Nothing will be settled if the actual amount is zero.

Set a `PAYMENT-SETTLEMENT` header with a base64 encoded JSON where the actual amount to be charged is expressed in atomic units:

```json
{ "amount": "50000" }
```

NOTE: a `PAYMENT-SETTLEMENT` header will be ignored for responses with an error HTTP status code (`400` or greater).

Monetization Gateway creates the payment receipt after settlement. It removes `PAYMENT-SETTLEMENT` from the response sent to the buyer.

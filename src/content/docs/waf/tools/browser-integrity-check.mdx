Browser Integrity Check is enabled by default.

## Disable Browser Integrity Check

### Disable globally

To disable BIC globally for your zone:

<Steps>

1. In the Cloudflare dashboard, go to the Security **Settings** page.

   <DashButton url="/?to=/:account/:zone/security/settings" />

2. (Optional) Filter by **DDoS attacks**.
3. Turn off **Browser integrity check**.

</Steps>

### Disable selectively

To disable BIC selectively, you can skip Browser Integrity Check using a [custom rule with a skip action](/waf/custom-rules/skip/).

Also, use a [configuration rule](/rules/configuration-rules/) to selectively enable or disable this feature for certain sections of your website using a filter expression (such as a matching hostname or request URL path).

:::note[Cloudflare-managed hostnames]
Your Browser Integrity Check setting, custom rules with a skip action, and configuration rules only apply to requests evaluated in your zone.

- Hostnames on Cloudflare-managed zones, such as `*.pages.dev` and `*.workers.dev`, always have Browser Integrity Check turned on. You cannot turn it off for these hostnames.
- Requests to a custom domain of a Pages project are also evaluated on the `pages.dev` zone. A rule in your zone that skips Browser Integrity Check does not prevent the check on the `pages.dev` zone. For more information, refer to [Pages known issues](/pages/platform/known-issues/).

If an automated client is blocked with [error 1010](/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/error-1010/) in these cases, configure it to send a descriptive `User-Agent` header that identifies your application.
:::

## Add custom rules to block harmful prompts

This example adds two [custom rules](/waf/custom-rules/) that use [AI Security for Apps fields](/waf/detections/ai-security-for-apps/fields/) in their expressions:

- The first rule blocks requests where Cloudflare detected personally identifiable information (PII) in the LLM prompt, using the [`cf.llm.prompt.pii_detected`](/ruleset-engine/rules-language/fields/reference/cf.llm.prompt.pii_detected/) field. The rule returns a custom JSON response.
- The second rule blocks requests where the LLM prompt is highly relevant to the `competitors` custom topic, using the [`cf.llm.prompt.custom_topic_categories`](/ruleset-engine/rules-language/fields/reference/cf.llm.prompt.custom_topic_categories/) field. The label in the expression must match a label in your [custom topics](#define-custom-topics) list.

To use these fields you must [enable AI Security for Apps](#enable-ai-security-for-apps).

<Details header="Required API token permissions">

At least one of the following [token permissions](/fundamentals/api/reference/permissions/) is required:

- `Zone WAF Write`

</Details>

Configure the [`cloudflare_ruleset`](https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/ruleset) resource:

```tf
resource "cloudflare_ruleset" "zone_custom_firewall_ai_security" {
  zone_id     = var.cloudflare_zone_id
  name        = "Phase entry point ruleset for custom rules in my zone"
  description = ""
  kind        = "zone"
  phase       = "http_request_firewall_custom"

  rules = [
    {
      ref         = "block_llm_prompts_with_pii"
      description = "Block LLM prompts containing PII"
      expression  = "(cf.llm.prompt.pii_detected)"
      action      = "block"
      action_parameters = {
        response = {
          status_code  = 403
          content      = "{\"error\": \"Your request was blocked. Please rephrase your request.\"}"
          content_type = "application/json"
        }
      }
    },
    {
      ref         = "block_llm_prompts_about_competitors"
      description = "Block LLM prompts about competitors"
      expression  = "(cf.llm.prompt.custom_topic_categories[\"competitors\"] lt 20)"
      action      = "block"
    }
  ]
}
```

A zone has a single entry point ruleset for custom rules. If you already manage this ruleset with Terraform, add the rules to the existing `cloudflare_ruleset` resource instead of creating a new one.

For more rule examples, refer to [Example mitigation rules](/waf/detections/ai-security-for-apps/example-rules/).

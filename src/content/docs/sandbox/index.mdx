<Plan type="workers-paid" />

A sandbox is an isolated place to run untrusted or generated code. Cloudflare provides two sandbox environments, and your [Worker](/workers/) decides what the code in each one receives:

- [Containers](/containers/) start a Linux virtual machine from a [Durable Object](/durable-objects/).
- [Dynamic Workers](/dynamic-workers/) load code at runtime into a new Worker that receives only the bindings you pass.

Documentation for existing applications on `@cloudflare/sandbox` 0.x is in [Sandbox SDK 0.x](/sandbox/sdk/).

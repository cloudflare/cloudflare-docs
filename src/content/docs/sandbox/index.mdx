A sandbox is an isolated place to run untrusted or generated code. The code cannot directly read your application's memory or data. Your Worker decides which application APIs and data the code receives and whether it can reach the public Internet. A Container also provides an isolated Linux filesystem and processes.

You can use a sandbox for agent-written code, user-uploaded applications, data analysis, development previews, build pipelines, or any other work that should not share a process with your application.

Cloudflare provides two sandbox environments. Both are accessible through a [Worker](/workers/), the application that already handles your traffic.

---

## Containers

[Containers](/containers/) run an image you provide. The instance is a full Linux environment, so you can run any language and keep processes running. Your Worker starts the instance and sends it work. HTTP from the Internet reaches the instance only through your Worker.

Each instance is a microVM with its own kernel and network, so no other workload shares it.

A Durable Object in your Worker starts the instance from an image and runs a command in it:

```ts
container.start({
	image: "cloudflare/debian-trixie",
	entrypoint: ["sleep", "infinity"],
	enableInternet: false,
});
const process = await container.exec(["uname", "-a"]);
const output = await process.output();
```

## Dynamic Workers

[Dynamic Workers](/dynamic-workers/) create a new Worker at runtime. The untrusted code can be JavaScript, Python, or WebAssembly. Compile TypeScript to JavaScript before loading it.

That code cannot see your application's memory. It can access your application only through the methods and data you pass, and your Worker decides whether it can reach the Internet.

Your Worker loads the untrusted module as a new Worker, blocks its outbound requests, and calls it:

```ts
const sandbox = env.LOADER.load({
	compatibilityDate: "$today",
	mainModule: "code.js",
	modules: { "code.js": untrustedModule },
	globalOutbound: null,
});
const entrypoint = sandbox.getEntrypoint<CodeEntrypoint>("Code");
const result = await entrypoint.evaluate();
```

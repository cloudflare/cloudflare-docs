Run isolated workloads on Cloudflare

</Description>

<Plan type="workers-paid" />

A sandbox is an isolated environment for untrusted, generated, or user-provided work. Cloudflare provides two primitives for that work:

- [Dynamic Workers](/dynamic-workers/) load JavaScript, TypeScript compiled to JavaScript, Python Workers, or WebAssembly in an isolate.
- [Containers](/containers/) attached to a [Durable Object](/durable-objects/) run a full Linux environment.

There is no separate Sandbox runtime or SKU. Pricing follows the primitive you use.

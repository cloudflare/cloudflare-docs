Untrusted code should not inherit your application's network. Block outbound access, then add back the APIs the sandbox needs.

## Dynamic Workers

Set `globalOutbound` to `null` when you load the Worker. `fetch()` and `connect()` inside the sandbox throw.

<TypeScriptExample filename="src/index.ts">

```ts
export default {
	async fetch(request: Request, env: Env): Promise<Response> {
		const worker = env.LOADER.load({
			compatibilityDate: "$today",
			mainModule: "src/index.js",
			modules: {
				"src/index.js": `
					export default {
						fetch() {
							return new Response("isolated");
						},
					};
				`,
			},
			globalOutbound: null,
		});

		return worker.getEntrypoint().fetch(request);
	},
};
```

</TypeScriptExample>

If you omit `globalOutbound`, the sandbox inherits the parent Worker's network access.

You can still pass [bindings](/dynamic-workers/usage/bindings/) so the sandbox can call APIs you implement. To intercept `fetch()` instead of blocking it, refer to [Egress control](/dynamic-workers/usage/egress-control/).

## Containers

Pass `enableInternet: false` to `start()`. The setting applies to that instance.

<TypeScriptExample filename="src/index.ts">

```ts
import { DurableObject } from "cloudflare:workers";

export class MyContainer extends DurableObject<Env> {
	async exec(argv: string[]) {
		if (!this.ctx.container.running) {
			this.ctx.container.start({
				image: "cloudflare/debian-trixie",
				enableInternet: false,
			});
		}

		const process = await this.ctx.container.exec(argv);
		const output = await process.output();
		return {
			stdout: new TextDecoder().decode(output.stdout),
			exitCode: output.exitCode,
		};
	}
}
```

</TypeScriptExample>

`enableInternet` defaults to `false` on `start()`. Set it to `true` only when the process should reach the public Internet.

To intercept outbound HTTP from the instance, refer to [Handle outbound traffic](/containers/guides/outbound-traffic/).

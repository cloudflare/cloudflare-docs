import { Steps, TypeScriptExample, WranglerConfig } from "~/components";

Load JavaScript you did not write, run it in a [Dynamic Worker](/dynamic-workers/), and return the result. The sandbox cannot reach the Internet.

Complete [Get started with Dynamic Workers](/sandbox/get-started/dynamic-workers/) first.

## Add a Worker Loader binding

<WranglerConfig>

```jsonc
{
	"worker_loaders": [
		{
			"binding": "LOADER",
		},
	],
}
```

</WranglerConfig>

## Load the code and call it

<Steps>

1. Read the untrusted source. In this example the body is the module text.
2. Call `env.LOADER.load()` with that module and `globalOutbound: null`.
3. Forward the incoming request to the sandbox entrypoint.
4. Catch load and fetch errors from the sandbox and return your own response.

</Steps>

<TypeScriptExample filename="src/index.ts">

```ts
export default {
	async fetch(request: Request, env: Env): Promise<Response> {
		if (request.method !== "POST") {
			return new Response("Send JavaScript in the POST body", { status: 405 });
		}

		const code = await request.text();

		try {
			const worker = env.LOADER.load({
				compatibilityDate: "$today",
				mainModule: "src/index.js",
				modules: {
					"src/index.js": code,
				},
				globalOutbound: null,
			});

			return await worker.getEntrypoint().fetch(request);
		} catch {
			return new Response("Sandbox execution failed", { status: 400 });
		}
	},
};
```

</TypeScriptExample>

`load()` creates a fresh Dynamic Worker on every call. Use it when the code is new each time, such as a model-generated tool call.

If the same source will receive later requests, use [`get()`](/dynamic-workers/api-reference/#get) with a stable ID. Change the ID when the code changes.

## Restrict what the sandbox can do

`globalOutbound: null` makes `fetch()` and `connect()` throw. The sandbox can still use APIs you pass in `env`.

To give it a method without exposing secrets, define a [`WorkerEntrypoint`](/workers/runtime-apis/bindings/service-bindings/rpc/#the-workerentrypoint-class) in your Worker and pass a stub. For more information, refer to [Bindings](/dynamic-workers/usage/bindings/).

To cap CPU time or subrequests, set `limits` on the code object or on `getEntrypoint()`. For more information, refer to [Custom resource limits](/dynamic-workers/usage/limits/).

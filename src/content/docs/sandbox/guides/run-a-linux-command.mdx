Run a command in a [Container](/containers/) instance and return stdout. Use this when the work needs a Linux process, not a Worker.

Complete [Get started with Containers](/sandbox/get-started/containers/) first. Your image must include the executable you invoke.

## Run the command from an RPC method

`exec()` starts another process in a running instance. It does not start a stopped Container.

<Steps>

1. In the RPC method, check `this.ctx.container.running`.
2. Call `this.ctx.container.start({ image: "cloudflare/debian-trixie" })` when the instance is stopped.
3. Pass the executable and arguments as an array. `exec()` does not start a shell.
4. Read stdout and the exit code from `process.output()`.

</Steps>

<TypeScriptExample filename="src/index.ts">

```ts
import { DurableObject } from "cloudflare:workers";

export class MyContainer extends DurableObject<Env> {
	async runVersion() {
		if (!this.ctx.container.running) {
			this.ctx.container.start({
				image: "cloudflare/debian-trixie",
				enableInternet: false,
			});
		}

		const process = await this.ctx.container.exec(["uname", "-a"]);
		const output = await process.output();
		return {
			stdout: new TextDecoder().decode(output.stdout),
			exitCode: output.exitCode,
		};
	}
}

export default {
	async fetch(request: Request, env: Env): Promise<Response> {
		const sandbox = env.MY_CONTAINER.getByName("sandbox");
		return Response.json(await sandbox.runVersion());
	},
};
```

</TypeScriptExample>

Each array item is one argument. Pipes, redirects, and globbing do not run unless you invoke a shell.

When the command needs a shell, use `["bash", "-lc", "<COMMAND>"]` if Bash exists in the image, or `["sh", "-c", "<COMMAND>"]` if it does not. Pass untrusted values as separate arguments. Do not interpolate them into the command string.

## Run a command after start

Call `exec()` after `start()` when you need setup in the same request. `output()` buffers stdout and stderr as separate `ArrayBuffer` values.

<TypeScriptExample filename="src/index.ts">

```ts
import { DurableObject } from "cloudflare:workers";

export class MyContainer extends DurableObject<Env> {
	async prepare() {
		if (!this.ctx.container.running) {
			this.ctx.container.start({
				image: "cloudflare/debian-trixie",
				enableInternet: false,
			});
		}

		const process = await this.ctx.container.exec(["uname", "-a"]);
		const output = await process.output();

		if (output.exitCode !== 0) {
			throw new Error(
				`Command failed: ${new TextDecoder().decode(output.stderr)}`,
			);
		}

		return new TextDecoder().decode(output.stdout);
	}
}
```

</TypeScriptExample>

For streaming, stdin, and process control, refer to [Execute commands](/containers/guides/execute-commands/).

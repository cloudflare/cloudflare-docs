Use this table when you already know you need a sandbox and want the facts in one place. For the reasons behind a choice, refer to [Choose an environment](/sandbox/concepts/choose-an-environment/).

| Property           | [Dynamic Workers](/dynamic-workers/)                                                 | [Containers](/containers/)                                                                |
| ------------------ | ------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------- |
| What you load      | JavaScript, TypeScript, Python, or WebAssembly                                       | An image you provide                                                                      |
| Starts from        | A [Worker Loader](/dynamic-workers/getting-started/#configure-worker-loader) binding | A [Durable Object](/durable-objects/) that owns the instance                              |
| Isolation          | V8 isolate, then the Workers process sandbox                                         | Firecracker microVM with its own kernel and network                                       |
| Memory             | Cannot read the parent Worker's memory                                               | Cannot read the Worker's memory                                                           |
| Filesystem         | No filesystem API                                                                    | Linux filesystem. Disk is ephemeral across sleep                                          |
| Processes          | Worker invocation                                                                    | Full Linux processes                                                                      |
| Default Internet   | Inherits the parent unless you set `globalOutbound`                                  | `enableInternet` defaults to `true`                                                       |
| Block the Internet | `globalOutbound: null`                                                               | `enableInternet = false`                                                                  |
| Grant APIs         | Pass [bindings](/dynamic-workers/usage/bindings/) in `env`                           | HTTP, `exec()`, and [Workers connections](/containers/configuration/workers-connections/) |
| Identity           | Optional ID on `get()`                                                               | Durable Object ID through `getContainer()`                                                |
| Typical start      | Milliseconds                                                                         | Often 1–3 seconds on a cold start, depending on image size                                |
| Plan               | [Workers Paid](/workers/platform/pricing/)                                           | [Workers Paid](/workers/platform/pricing/)                                                |

## Sandbox SDK

[`@cloudflare/sandbox`](/sandbox/sdk/) is a TypeScript API on Containers. It is not a third environment. Refer to the [Sandbox SDK API](/sandbox/sdk/api/) if your application already uses that package.

:::note
These pages document `@cloudflare/sandbox` 0.x for existing applications. Version 1.0 is a different library that works with a container you start from a Durable Object. To move an existing application to 1.0, refer to [Migrate from Sandbox SDK 0.x](/sandbox/sdk/migrate/). To start new work, refer to [Sandboxes](/sandbox/).
:::

Sandbox SDK 0.x gives your [Worker](/workers/) a `Sandbox` class built on [Containers](/containers/). A sandbox starts its container on first use, and its methods run commands, manage files, run background processes, and expose services in that container.

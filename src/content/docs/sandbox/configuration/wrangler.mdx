## Minimal configuration

The minimum required configuration for using Sandbox SDK:

```jsonc title="wrangler.jsonc"
{
	"name": "my-sandbox-worker",
	"main": "src/index.ts",
	"compatibility_date": "2025-10-13",
	"compatibility_flags": ["nodejs_compat", "enable_ctx_exports"],
	"containers": [
		{
			"class_name": "Sandbox",
			"image": "./Dockerfile",
		},
	],
	"migrations": [
		{
			"new_sqlite_classes": ["Sandbox"],
			"tag": "v1",
		},
	],
}
```

## Required settings

The Sandbox SDK is built on Cloudflare Containers. Your configuration requires two sections:

1. **containers** - Define the container image (your runtime environment)
2. **migrations** - Initialize the Durable Object class

The `enable_ctx_exports` compatibility flag enables [automatic loopback bindings](/changelog/2025-09-26-ctx-exports/), so you do not need to configure a Durable Object binding explicitly. Access the Sandbox class via `ctx.exports.Sandbox` in your Worker code.

For detailed configuration options, refer to the [Containers configuration documentation](/workers/wrangler/configuration/#containers).

## Troubleshooting

### Binding not found

**Error**: `TypeError: ctx.exports.Sandbox is undefined`

**Solution**: Ensure your `wrangler.jsonc` includes the `enable_ctx_exports` compatibility flag:

```jsonc
{
	"compatibility_flags": ["nodejs_compat", "enable_ctx_exports"],
}
```

### Missing migrations

**Error**: Durable Object not initialized

**Solution**: Add migrations for the Sandbox class:

```jsonc
{
	"migrations": [
		{
			"new_sqlite_classes": ["Sandbox"],
			"tag": "v1",
		},
	],
}
```

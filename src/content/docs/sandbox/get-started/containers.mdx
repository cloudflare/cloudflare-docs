You will POST `uname -a` to a Worker and read stdout that contains `Linux`.

## Run a command in Linux

<Steps>

1. Create a Worker project:

   <PackageManagers
   	type="create"
   	pkg="cloudflare@latest"
   	args={"sandbox-linux --category=hello-world --type=hello-world --lang=ts --no-deploy --no-git --no-agents"}
   />

2. Change into the project directory:

   ```sh
   cd sandbox-linux
   ```

3. Replace `wrangler.jsonc` so a Durable Object can start a container:

   <WranglerConfig>

   ```jsonc
   {
   	"$schema": "node_modules/wrangler/config-schema.json",
   	"name": "sandbox-linux",
   	"main": "src/index.ts",
   	"compatibility_date": "$today",
   	"containers": [
   		{
   			"class_name": "MyContainer",
   			"scheduling_policy": "durable_object",
   		},
   	],
   	"durable_objects": {
   		"bindings": [
   			{
   				"class_name": "MyContainer",
   				"name": "MY_CONTAINER",
   			},
   		],
   	},
   	"migrations": [
   		{
   			"new_sqlite_classes": ["MyContainer"],
   			"tag": "v1",
   		},
   	],
   }
   ```

   </WranglerConfig>

4. Generate types for the binding:

   <PackageManagers type="exec" pkg="wrangler" args="types" />

5. Replace `src/index.ts`. The Worker reads `argv` from the JSON body and runs it in Linux:

   <TypeScriptExample filename="src/index.ts">

   ```ts
   import { DurableObject } from "cloudflare:workers";

   export class MyContainer extends DurableObject<Env> {
   	async exec(argv: string[]) {
   		if (!this.ctx.container.running) {
   			this.ctx.container.start({
   				image: "cloudflare/debian-trixie",
   				enableInternet: false,
   			});
   		}

   		const process = await this.ctx.container.exec(argv);
   		const output = await process.output();
   		return {
   			stdout: new TextDecoder().decode(output.stdout),
   			exitCode: output.exitCode,
   		};
   	}
   }

   export default {
   	async fetch(request: Request, env: Env): Promise<Response> {
   		const { argv } = (await request.json()) as { argv: string[] };
   		const sandbox = env.MY_CONTAINER.getByName("sandbox");
   		return Response.json(await sandbox.exec(argv));
   	},
   };
   ```

   </TypeScriptExample>

   `cloudflare/debian-trixie` is Debian Trixie with Node.js 24. `enableInternet: false` blocks the public Internet.

6. Run `wrangler dev`:

   <PackageManagers type="exec" pkg="wrangler" args="dev" />

7. POST a command to the URL Wrangler printed. The default is `http://localhost:8787`:

   ```sh
   curl http://localhost:8787 --request POST --json '{"argv":["uname","-a"]}'
   ```

</Steps>

The JSON body includes `"exitCode":0`. `stdout` contains `Linux`. The Worker started a Linux VM and ran the command you sent.

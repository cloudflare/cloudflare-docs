In this guide, you will create a Worker that loads a second Worker at runtime. The second Worker returns a response. It cannot reach the Internet.

## Prerequisites

<Render file="prereqs" product="workers" />

## Create a Worker

<Steps>

1. Create a new Worker project:

   <PackageManagers
   	type="create"
   	pkg="cloudflare@latest"
   	args={"sandbox-dynamic-worker"}
   />

2. Change into the project directory:

   ```sh
   cd sandbox-dynamic-worker
   ```

</Steps>

## Add a Worker Loader binding

Open your Wrangler configuration file and add a [Worker Loader](/dynamic-workers/getting-started/#configure-worker-loader) binding. The binding does not point at an external resource. It exposes the API that creates Dynamic Workers.

<WranglerConfig>

```jsonc
{
	"name": "sandbox-dynamic-worker",
	"main": "src/index.ts",
	"compatibility_date": "$today",
	"worker_loaders": [
		{
			"binding": "LOADER",
		},
	],
}
```

</WranglerConfig>

## Load isolated code

Replace `src/index.ts` with a Worker that loads sandboxed code and forwards the request to it.

<TypeScriptExample filename="src/index.ts">

```ts
export default {
	async fetch(request: Request, env: Env): Promise<Response> {
		const worker = env.LOADER.load({
			compatibilityDate: "$today",
			mainModule: "src/index.js",
			modules: {
				"src/index.js": `
					export default {
						fetch() {
							return new Response("Hello from a sandbox");
						},
					};
				`,
			},
			globalOutbound: null,
		});

		return worker.getEntrypoint().fetch(request);
	},
};
```

</TypeScriptExample>

`globalOutbound: null` blocks `fetch()` and `connect()` inside the Dynamic Worker. For more information, refer to [Egress control](/dynamic-workers/usage/egress-control/).

## Run the Worker

<Steps>

1. Start a local session:

   <PackageManagers type="exec" pkg="wrangler" args="dev" />

2. Open the local URL printed in the terminal. The response body should be `Hello from a sandbox`.

</Steps>

The string in `modules` is the untrusted program. It runs in a new [Dynamic Worker](/dynamic-workers/). That Worker has its own memory and no Internet access. A `fetch()` or `connect()` call inside it throws.

Run code in your first sandbox. Choose the lesson that matches the code you need to run:

- [Run a Linux command](/sandbox/get-started/containers/) when the code needs Linux tools, packages, or processes. You send `uname -a` and read stdout that contains `Linux`.
- [Run JavaScript](/sandbox/get-started/dynamic-workers/) when the code needs only the APIs and data you pass it. You send JavaScript and read `{"result":["Ada"]}`.

For more information, refer to [Choose a sandbox environment](/sandbox/concepts/choose-an-environment/).

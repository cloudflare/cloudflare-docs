Event subscriptions allow you to receive messages when events occur across your Cloudflare account. Cloudflare products (for example, [KV](/kv/), [Workers AI](/workers-ai/), and [Workers](/workers/)) can publish structured events to a queue. You can process these events with Workers or [HTTP pull consumers](/queues/configuration/pull-consumers/), or send them to [notification destinations](/queues/configuration/notification-consumers/).

![Event subscriptions architecture](public/images/queues/queues-event-subscriptions.png)

## What is an event?

An event is a structured record of something happening in your Cloudflare account – like a Workers AI batch request being queued, a Worker build completing, or an R2 bucket being created. When you subscribe to these events, your queue will automatically start receiving messages when the events occur.

These guides show how to use AI Search from agent and application frameworks. Each guide starts from an empty project and ends with a working integration that queries an AI Search instance.

These pages cover how to _use_ an AI Search instance from a framework. To create and manage instances themselves, refer to the [REST API](/ai-search/api/), the [Workers binding](/ai-search/api/search/workers-binding/), or [Wrangler commands](/ai-search/wrangler-commands/).

Use the AI Search REST API to upload, list, and manage individual documents within an instance.

:::note
The Items API uploads files to an instance's built-in storage. For more details, refer to [Built-in storage](/ai-search/configuration/data-source/built-in-storage/).
:::

## Items endpoints

Manage individual documents within an AI Search instance.

| Description                                                                                              | Method   | Endpoint                                                                   |
| -------------------------------------------------------------------------------------------------------- | -------- | -------------------------------------------------------------------------- |
| [List items](/api/resources/ai_search/subresources/instances/subresources/items/methods/list/)           | `GET`    | `/accounts/{account_id}/ai-search/instances/{id}/items`                    |
| [Upload an item](/api/resources/ai_search/subresources/instances/subresources/items/methods/upload/)     | `POST`   | `/accounts/{account_id}/ai-search/instances/{id}/items`                    |
| [Get item info](/api/resources/ai_search/subresources/instances/subresources/items/methods/get/)         | `GET`    | `/accounts/{account_id}/ai-search/instances/{id}/items/{item_id}`          |
| [Delete an item](/api/resources/ai_search/subresources/instances/subresources/items/methods/delete/)     | `DELETE` | `/accounts/{account_id}/ai-search/instances/{id}/items/{item_id}`          |
| [Download an item](/api/resources/ai_search/subresources/instances/subresources/items/methods/download/) | `GET`    | `/accounts/{account_id}/ai-search/instances/{id}/items/{item_id}/download` |

### Example: Upload a document

```bash
curl -X POST "https://api.cloudflare.com/client/v4/accounts/<ACCOUNT_ID>/ai-search/instances/<INSTANCE_NAME>/items" \
  -H "Authorization: Bearer <API_TOKEN>" \
  -F "file=@/path/to/your/file.pdf"
```

### Example: List items

```bash
curl "https://api.cloudflare.com/client/v4/accounts/<ACCOUNT_ID>/ai-search/instances/<INSTANCE_NAME>/items" \
  -H "Authorization: Bearer <API_TOKEN>"
```

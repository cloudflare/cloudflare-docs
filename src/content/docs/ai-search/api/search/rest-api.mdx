The previous [AutoRAG API endpoints](/api/resources/autorag/) are no longer recommended for use. Refer to [Migrate from AutoRAG REST API](/ai-search/api/migration/rest-api/) for details.

## Instance-level

Search and chat with a specific instance.

| Description                                                                                   | Method | Endpoint                                                           |
| --------------------------------------------------------------------------------------------- | ------ | ------------------------------------------------------------------ |
| [Search](/api/resources/ai_search/subresources/instances/methods/search/)                     | `POST` | `/accounts/{account_id}/ai-search/instances/{id}/search`           |
| [Chat completions](/api/resources/ai_search/subresources/instances/methods/chat_completions/) | `POST` | `/accounts/{account_id}/ai-search/instances/{id}/chat/completions` |

### Example: Search

```bash
curl -X POST "https://api.cloudflare.com/client/v4/accounts/<ACCOUNT_ID>/ai-search/instances/<INSTANCE_NAME>/search" \
  -H "Authorization: Bearer <API_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [
      {
        "content": "What is Cloudflare?",
        "role": "user"
      }
    ]
  }'
```

### Example: Chat completions

```bash
curl -X POST "https://api.cloudflare.com/client/v4/accounts/<ACCOUNT_ID>/ai-search/instances/<INSTANCE_NAME>/chat/completions" \
  -H "Authorization: Bearer <API_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [
      {
        "content": "What is Cloudflare?",
        "role": "user"
      }
    ]
  }'
```

## Namespace-level

Search and chat across multiple instances in a single call. Pass `instance_ids` in `ai_search_options` to specify which instances to query. Each chunk in the response includes an `instance_id` field identifying which instance it came from.

| Description                                                                                    | Method | Endpoint                                                              |
| ---------------------------------------------------------------------------------------------- | ------ | --------------------------------------------------------------------- |
| [Search](/api/resources/ai_search/subresources/namespaces/methods/search/)                     | `POST` | `/accounts/{account_id}/ai-search/namespaces/{name}/search`           |
| [Chat completions](/api/resources/ai_search/subresources/namespaces/methods/chat_completions/) | `POST` | `/accounts/{account_id}/ai-search/namespaces/{name}/chat/completions` |

### Example: Namespace-wide search

```bash
curl -X POST "https://api.cloudflare.com/client/v4/accounts/<ACCOUNT_ID>/ai-search/namespaces/<NAMESPACE>/search" \
  -H "Authorization: Bearer <API_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [
      {
        "role": "user",
        "content": "What is Cloudflare?"
      }
    ],
    "ai_search_options": {
      "instance_ids": ["product-docs", "customer-abc123"]
    }
  }'
```

### Example: Namespace-wide chat completions

```bash
curl -X POST "https://api.cloudflare.com/client/v4/accounts/<ACCOUNT_ID>/ai-search/namespaces/<NAMESPACE>/chat/completions" \
  -H "Authorization: Bearer <API_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [
      {
        "role": "user",
        "content": "What is Cloudflare?"
      }
    ],
    "ai_search_options": {
      "instance_ids": ["product-docs", "customer-abc123"]
    }
  }'
```

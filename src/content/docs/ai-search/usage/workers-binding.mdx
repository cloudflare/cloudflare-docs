Use the `env.AI.aiSearch()` binding to query your AI Search instances from a Worker.

To use AI Search with Workers, add an AI binding to your Wrangler configuration:

<WranglerConfig>

```jsonc
{
	"ai": {
		"binding": "AI",
	},
}
```

</WranglerConfig>

:::note
If you are using the previous `env.AI.autorag()` binding, refer to the [legacy binding documentation](/ai-search/usage/workers-binding-legacy/).
:::

## Requirements

| Package                     | Minimum version |
| --------------------------- | --------------- |
| `@cloudflare/workers-types` | `4.20260304.0`  |
| `wrangler`                  | `4.68.1`        |

```ts
const aisearch = env.AI.aiSearch().get("my-instance");

const results = await aisearch.search({
	messages: [{ role: "user", content: "How do I configure caching?" }],
	ai_search_options: {
		retrieval: {
			retrieval_type: "hybrid",
			max_num_results: 10,
			match_threshold: 0.5,
		},
		reranking: {
			enabled: true,
			model: "@cf/baai/bge-reranker-base",
		},
```

## `search()`

Search for relevant content chunks from your indexed data source.

## Example

Query an AI Search instance and return the results:

```ts
export type Env = {
	AI: Ai;
};

export default {
	async fetch(request, env, ctx): Promise<Response> {
		// Get an AI Search instance by name
		const aisearch = env.AI.aiSearch().get("my-instance");

		// Search for relevant content
		const results = await aisearch.search({
			messages: [{ role: "user", content: "How do I configure caching?" }],
		});

		// Return matching chunks as JSON
		return Response.json(results);
	},
} satisfies ExportedHandler<Env>;
	},
});
```

## `chatCompletions()`

Generate chat completions using your AI Search instance as context. This method retrieves relevant content and uses it to generate a response.

```ts
const aisearch = env.AI.aiSearch().get("my-instance");

const response = await aisearch.chatCompletions({
	messages: [{ role: "user", content: "How do I configure caching?" }],
	model: "@cf/meta/llama-3.3-70b-instruct-fp8-fast",
	ai_search_options: {
		retrieval: {
			max_num_results: 5,
		},
		query_rewrite: {
			enabled: true,
		},
	},
});
```

### Streaming responses

To stream responses as they are generated, set `stream: true`:

```ts
const aisearch = env.AI.aiSearch().get("my-instance");

const response = await aisearch.chatCompletions({
	messages: [{ role: "user", content: "How do I configure caching?" }],
	stream: true,
});

// Returns a Response object with a readable stream
return response;
```

## Local development

Local development is supported by proxying requests to your deployed AI Search instance. When running in local mode, your application forwards queries to the configured remote AI Search instance and returns the generated responses as if they were served locally.

## Legacy API

The previous `env.AI.autorag()` binding is deprecated but will continue to work indefinitely. If you have existing code using the legacy API, refer to the [legacy binding documentation](/ai-search/usage/workers-binding-legacy/).

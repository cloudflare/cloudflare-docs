These guides walk through common AI Search use cases, from no-code setups to full agent applications. Use the difficulty column to find the right place to start.

| Guide                                                                                           | Difficulty   | What you build                                                                                           |
| ----------------------------------------------------------------------------------------------- | ------------ | -------------------------------------------------------------------------------------------------------- |
| [Add search to your website](/ai-search/how-to/add-search-to-your-website/)                     | Beginner     | Add a search bar, chat bubble, and search modal to a site with the prebuilt UI snippets.                 |
| [Connect your AI Search to an MCP client](/ai-search/how-to/connect-mcp-client/)                | Beginner     | Expose your indexed content as a search tool for any MCP client or AI assistant, with no code.           |
| [Create a simple search engine](/ai-search/how-to/simple-search-engine/)                        | Beginner     | Query an instance from a Worker using the search binding.                                                |
| [Multitenancy](/ai-search/how-to/per-tenant-search/)                                            | Intermediate | Keep each tenant's data separate with a per-tenant instance or a shared instance and metadata filtering. |
| [Search multiple sources at once](/ai-search/how-to/search-multiple-sources/)                   | Intermediate | Search a shared knowledge base and a tenant-specific one together in a single query.                     |
| [Fetch and index single web pages](/ai-search/how-to/fetch-and-index-web-pages/)                | Intermediate | Use Browser Run to fetch a page's rendered HTML, index it, and search it from one Worker.                |
| [Bring your own generation model](/ai-search/how-to/bring-your-own-generation-model/)           | Intermediate | Use AI Search for retrieval and an external model, such as OpenAI, for generation.                       |
| [Show source citations in responses](/ai-search/how-to/chunk-citations/)                        | Intermediate | Return AI-generated answers with citations to the source documents that informed them.                   |
| [Human-in-the-loop knowledge base updates](/ai-search/how-to/human-in-the-loop-knowledge-base/) | Advanced     | Build an agent that proposes new documents and pauses for human approval, with rollback.                 |

Use one AI Search instance per language, accessed through a single [namespace binding](/ai-search/concepts/namespaces/). This approach lets you scope search to a specific language based on a request parameter.

## Prerequisites

- One AI Search instance per language (for example, `blog-en`, `blog-fr`, `blog-es`), created via the [dashboard](/ai-search/get-started/dashboard/) or [Instance API](/ai-search/api/instances/workers-binding/)
- A Worker with an `ai_search_namespaces` binding configured

<WranglerConfig>

```toml
[[ai_search_namespaces]]
binding = "BLOG"
namespace = "default"
```

</WranglerConfig>

## Implementation

The Worker reads the `lang` query parameter and routes the search to the corresponding instance:

<TypeScriptExample>

```ts
export type Env = {
	BLOG: AiSearchNamespace;
};

export default {
	async fetch(request, env): Promise<Response> {
		const url = new URL(request.url);
		const lang = url.searchParams.get("lang") || "en";
		const query = url.searchParams.get("q") || "";

		const results = await env.BLOG.get(`blog-${lang}`).search({
			messages: [{ role: "user", content: query }],
		});

		return Response.json(results);
	},
} satisfies ExportedHandler<Env>;
```

</TypeScriptExample>

AI Search is a managed search service. Connect a website, an R2 bucket, or upload your own documents, and your application gets a natural language search API.

AI Search indexes your content automatically and keeps it up to date. Users ask questions in plain English and get answers grounded in your content. Use it for documentation search, knowledge bases, support chatbots, or any application where users need to find information. Access it from a [Workers binding](/ai-search/api/search/workers-binding/), the [REST API](/ai-search/api/search/rest-api/), or as an [MCP server](/ai-search/api/search/mcp/).

## Features

<Feature header="Automated indexing" href="/ai-search/configuration/indexing/" cta="View indexing">

Automatically and continuously index your data source, keeping your content fresh without manual reprocessing.

</Feature>

<Feature header="Metadata filtering" href="/ai-search/configuration/metadata/" cta="Add filters">

Define custom metadata fields and filter search results by category, version, language, or any attribute you define.

</Feature>

<Feature header="Built-in MCP and UI snippets" href="/ai-search/configuration/public-endpoint/" cta="Get started">

Every instance includes a built-in MCP endpoint for AI agents and embeddable search and chat components for your website.

</Feature>

<Feature header="Similarity caching" href="/ai-search/configuration/cache/" cta="Use caching">

Cache repeated queries and results to improve latency and reduce compute on repeated requests.

</Feature>

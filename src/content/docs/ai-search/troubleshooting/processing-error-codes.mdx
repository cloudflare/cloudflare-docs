Processing error codes appear after AI Search accepts an upload, sync, or crawl request, but cannot finish preparing an item for search.

These errors are stored on items instead of returned as immediate API error responses. You can view them by listing items, getting item details, checking [item logs](/api/resources/ai_search/subresources/namespaces/subresources/instances/subresources/items/methods/logs/), or reviewing instance stats.

If an API request fails immediately, refer to [API error codes](/ai-search/troubleshooting/api-error-codes/) instead.

## How errors are returned

Processing error codes are asynchronous: an upload, sync, or crawl request can succeed, then the item can later move to `status: "error"`.

If an error includes extra detail after a colon, use the text before the colon as the error type.

To retry one failed item, check [item logs](/api/resources/ai_search/subresources/namespaces/subresources/instances/subresources/items/methods/logs/), address any clear source or configuration issue, then [sync the item](/api/resources/ai_search/subresources/namespaces/subresources/instances/subresources/items/methods/sync/) again. For website and R2 data sources, you can also run a [source sync job](/ai-search/configuration/indexing/syncing/).

## File and content errors

These errors appear when AI Search cannot read, convert, chunk, or embed a source file. For supported formats and file size limits, refer to [Data source](/ai-search/configuration/data-source/). For chunking and model limits, refer to [Chunking](/ai-search/configuration/indexing/chunking/) and [Supported models](/ai-search/configuration/models/supported-models/).

| Error | Details | Recommended action |
| ----- | ------- | ------------------ |
| `unknown_error` | An unexpected processing error occurred. | Check [item logs](/api/resources/ai_search/subresources/namespaces/subresources/instances/subresources/items/methods/logs/) for the failed step, then [sync the item](/api/resources/ai_search/subresources/namespaces/subresources/instances/subresources/items/methods/sync/) again. If the error persists, [contact support](/support/contacting-cloudflare-support/). |
| `over_size` | The file exceeds the maximum allowed size. | Reduce the file size, split the file, or exclude it. Review [file limits](/ai-search/configuration/data-source/#file-limits). |
| `unsupported_type` | The file type is not supported. | Convert the file to a [supported file type](/ai-search/configuration/data-source/#supported-file-types), then upload or sync it again. |
| `file_not_found` | The file was not found in the source. | Restore the source file, then [sync the item](/api/resources/ai_search/subresources/namespaces/subresources/instances/subresources/items/methods/sync/) or run a [source sync job](/ai-search/configuration/indexing/syncing/). If the file was intentionally deleted, run a source sync so AI Search can update the index. |
| `invalid_url` | The file URL is invalid. | Fix the URL in the [website data source](/ai-search/configuration/data-source/website/) or sitemap, then run a source sync job. |
| `file_is_corrupt` | The file is corrupt. | Replace the file with an uncorrupted copy, then upload or sync it again. |
| `file_is_password_locked` | The file is encrypted or requires a password before AI Search can read its contents. | Remove the password, upload an unlocked copy, then sync the item again. |
| `invalid_pdf` | AI Search could not parse the file as a valid PDF. | Upload a PDF that opens correctly, or convert the content to another [supported file type](/ai-search/configuration/data-source/#supported-file-types). |
| `unable_to_convert_to_markdown` | AI Search could not convert the file to text. | Use a [supported file type](/ai-search/configuration/data-source/#supported-file-types) or replace scanned content with extractable text. |
| `markdown_too_large` | AI Search converted the file, but the generated Markdown exceeded AI Search processing limits. | If the source file is within [AI Search file limits](/ai-search/configuration/data-source/#file-limits), [contact support](/support/contacting-cloudflare-support/). As a workaround, split the source into smaller files if practical. |
| `markdown_conversion_empty` | AI Search converted the file, but the conversion returned no usable text. | If the file contains selectable text, [contact support](/support/contacting-cloudflare-support/). |
| `file_content_empty` | The file is empty or contains only headings. | Add searchable body content, then upload or sync the file again. |
| `chunk_too_large_for_storage` | AI Search generated a chunk that exceeded internal storage limits. | Lower [chunk size](/ai-search/configuration/indexing/chunking/) if you configured a high value. If the item still fails, [contact support](/support/contacting-cloudflare-support/). |
| `timeout_error` | Item processing timed out. | Sync the item again. Check [Cloudflare Status](https://www.cloudflarestatus.com) and [contact support](/support/contacting-cloudflare-support/) if the error persists. |
| `file_length_exceed_embedding_model` | The file is too long for the embedding model. | Use a smaller source file, or [contact support](/support/contacting-cloudflare-support/) if the file is within documented limits. |
| `file_too_large_for_embedder` | The file exceeds the maximum byte size accepted by the embedding model. | Use a smaller source file, or [contact support](/support/contacting-cloudflare-support/) if the file is within documented limits. |

## Website crawl errors

These errors appear when AI Search cannot fetch, render, or include a page from a [website data source](/ai-search/configuration/data-source/website/).

| Error | Details | Recommended action |
| ----- | ------- | ------------------ |
| `too_many_redirects` | The crawler followed too many redirects or found a redirect loop. | Fix the redirect chain for the [website data source](/ai-search/configuration/data-source/website/), then run a source sync job. |
| `invalid_host_after_redirect` | The page redirected to a hostname outside the current crawl scope. | Check item logs for the redirect target. If that target should be indexed, [contact support](/support/contacting-cloudflare-support/). Otherwise, exclude the original URL with [path filtering](/ai-search/configuration/indexing/path-filtering/). |
| `subdomains_not_allowed` | The URL is outside the hostnames AI Search can crawl for this website data source. | If this URL should be indexed by the instance, [contact support](/support/contacting-cloudflare-support/). Otherwise, exclude it with [path filtering](/ai-search/configuration/indexing/path-filtering/). |
| `blocked_by_robots_txt` | `robots.txt` disallowed the crawl. | Update `robots.txt` so the [AI Search crawler](/ai-search/configuration/data-source/website/#how-website-crawling-works) can access the site. |
| `blocked_by_robots_txt_path` | `robots.txt` disallowed the path. | Allow the path in `robots.txt`, or exclude it with [path filtering](/ai-search/configuration/indexing/path-filtering/) if you do not want it indexed. |
| `blocked_by_content_signal` | The site blocked the crawl with Content Signals. | Review Content Signals directives in `robots.txt`. If the content should not be indexed, exclude it with path filtering. |
| `excluded_by_path_filter` | Your path filter excluded the item. | Review [include and exclude rules](/ai-search/configuration/indexing/path-filtering/#filtering-behavior) if the item should be indexed. |
| `network_connection_lost` | The network connection was interrupted. | Sync the item again. If the error persists, check that the source is reachable. |
| `crawl_got_http_error` | The crawler received an HTTP error. | Check item logs for the HTTP status. Fix the origin response or access controls, then run a source sync job. |
| `crawl_got_http_401` | The crawler received `401 Unauthorized`. | Make the page accessible to the crawler. For protected pages, configure [extra headers](/ai-search/configuration/data-source/website/#extra-headers) or Cloudflare Access service credentials. |
| `crawl_got_http_403` | The crawler received `403 Forbidden`. | Allow the AI Search crawler through your access controls, origin firewall, or [WAF rules](/waf/custom-rules/). |
| `crawl_got_http_429` | The origin rate limited the crawler. | Allow the crawler, raise the origin limit, or narrow crawl scope with [path filtering](/ai-search/configuration/indexing/path-filtering/). |
| `blocked_by_payment` | The site returned `402 Payment Required`. | Exclude the page with path filtering. AI Search does not support paid crawls. |
| `blocked_by_waf` | A web application firewall (WAF) blocked the crawler. | Allow the AI Search crawler in your [WAF rules](/waf/custom-rules/). |
| `blocked_by_bot_management` | Bot controls blocked the crawler. | Allow the AI Search crawler in [bot protection](/bots/) settings. |
| `blocked_by_turnstile` | Turnstile blocked the crawler. | Allow the crawler in [Turnstile](/turnstile/) settings, or exclude the page with path filtering. |
| `http_4xx` | The site returned an HTTP 4xx error. | Check item logs for the exact status. Fix the URL or access controls, or exclude the page with path filtering. |
| `http_5xx` | The site returned an HTTP 5xx error. | Fix origin health, then sync the item or run a source sync job. |
| `unreachable_timeout` | The crawler could not reach the page before timeout. | Check origin latency, firewall rules, and page availability, then run a source sync job. |
| `unreachable_dns` | The source domain did not resolve. | Check [DNS records](/dns/manage-dns-records/how-to/create-dns-records/) for the source domain. |
| `page_limit_reached` | The crawl reached the page limit. | Narrow crawl scope with [path filtering](/ai-search/configuration/indexing/path-filtering/). |
| `browser_rendering_unknown_error` | Browser Rendering returned an unknown error. | Run a [source sync job](/ai-search/configuration/indexing/syncing/) again. Check [Cloudflare Status](https://www.cloudflarestatus.com) and [contact support](/support/contacting-cloudflare-support/) if the same page keeps failing. |
| `browser_rendering_authentication_error` | Browser Rendering required authentication. | Configure [extra headers](/ai-search/configuration/data-source/website/#extra-headers) for protected pages, or exclude the page. |
| `browser_rendering_no_body_status_error` | Browser Rendering returned no page content for AI Search to index. | If the page should be indexed, [contact support](/support/contacting-cloudflare-support/). Otherwise, exclude the page with [path filtering](/ai-search/configuration/indexing/path-filtering/). |
| `browser_rendering_timeout_error` | Browser Rendering timed out. | Run a [source sync job](/ai-search/configuration/indexing/syncing/) again. Check [Cloudflare Status](https://www.cloudflarestatus.com) and [contact support](/support/contacting-cloudflare-support/) if the error persists. |
| `browser_rendering_network_connection_closed_error` | The browser connection closed during rendering. | Run a [source sync job](/ai-search/configuration/indexing/syncing/) again. Check [Cloudflare Status](https://www.cloudflarestatus.com) and [contact support](/support/contacting-cloudflare-support/) if the error persists. |
| `browser_rendering_server_refused_connection_error` | The origin refused the browser connection. | Allow Browser Rendering traffic through origin network controls, then run a source sync job. |
| `browser_rendering_rate_limit_error` | Browser Rendering was rate limited. | Run a [source sync job](/ai-search/configuration/indexing/syncing/) later. If the error persists, [contact support](/support/contacting-cloudflare-support/). |

## Storage and source errors

These errors appear when AI Search cannot access the configured [data source](/ai-search/configuration/data-source/), [R2 bucket](/ai-search/configuration/data-source/r2/), or [service API token](/ai-search/configuration/indexing/service-api-token/).

| Error | Details | Recommended action |
| ----- | ------- | ------------------ |
| `r2_not_enabled` | R2 is not enabled for the account. | Enable [R2](/r2/get-started/) for the account, then run a source sync job. |
| `r2_unknown_error` | R2 returned an unknown error. | Run a [source sync job](/ai-search/configuration/indexing/syncing/) again. Check [Cloudflare Status](https://www.cloudflarestatus.com) and [contact support](/support/contacting-cloudflare-support/) if the error persists. |
| `r2_internal_error` | R2 returned an internal error. | Run a [source sync job](/ai-search/configuration/indexing/syncing/) again. Check [Cloudflare Status](https://www.cloudflarestatus.com) and [contact support](/support/contacting-cloudflare-support/) if the error persists. |
| `bucket_unauthorized` | AI Search cannot access the R2 bucket. | Check the [service API token](/ai-search/configuration/indexing/service-api-token/) and R2 bucket permissions, then run a source sync job. |
| `external_source_missing_api_token` | The external source is missing API credentials. | Add or update the [service API token](/ai-search/configuration/indexing/service-api-token/), then run a source sync job. |
| `bucket_not_found` | The source R2 bucket was not found. | Check the [R2 data source](/ai-search/configuration/data-source/r2/) bucket name and account. |
| `bucket_name_invalid` | The R2 bucket name is invalid. | Use a valid bucket name without uppercase letters or underscores, then update the R2 data source. |
| `managed_resources_config_error` | AI Search found an internal managed resource configuration issue. | Run a [source sync job](/ai-search/configuration/indexing/syncing/) again. Check [Cloudflare Status](https://www.cloudflarestatus.com) and [contact support](/support/contacting-cloudflare-support/) if the error persists. |
| `invalid_custom_header` | A custom crawl header is invalid. | Remove or update the [extra header](/ai-search/configuration/data-source/website/#extra-headers), then run a source sync job. |

## Model and gateway errors

These errors appear when [embedding models](/ai-search/configuration/models/supported-models/#embedding), [Workers AI](/workers-ai/), external providers, or [AI Gateway](/ai-gateway/) cannot process item content.

| Error | Details | Recommended action |
| ----- | ------- | ------------------ |
| `error_embedding_data_with_workers_ai` | Workers AI could not generate embeddings. | Sync the item again. Check [Cloudflare Status](https://www.cloudflarestatus.com) and [contact support](/support/contacting-cloudflare-support/) if the error persists. |
| `workers_ai_invalid_input` | Workers AI rejected the input. | Check file content, file type, and [embedding model support](/ai-search/configuration/models/supported-models/#embedding). |
| `workers_ai_free_allocation_exceeded` | Workers AI free tier allocation was exceeded. | Review [Workers AI pricing](/workers-ai/platform/pricing/) and wait for allocation reset, or upgrade your Workers plan. |
| `workers_ai_internal_error` | Workers AI returned an internal error. | Sync the item again. Check [Cloudflare Status](https://www.cloudflarestatus.com) and [contact support](/support/contacting-cloudflare-support/) if the error persists. |
| `workers_ai_out_of_capacity_error` | Workers AI capacity was unavailable. | Retry later and review [Workers AI limits](/workers-ai/platform/limits/). |
| `workers_ai_timeout_error` | Workers AI timed out. | Sync the item again. Check [Cloudflare Status](https://www.cloudflarestatus.com) and [contact support](/support/contacting-cloudflare-support/) if the error persists. |
| `error_external_model_unknown_error` | An external embedding model returned an unknown error. | Check provider status and [AI Gateway logs](/ai-gateway/observability/logging/), then sync the item again. |
| `error_external_model_rate_limited` | An external embedding model rate limited the request. | Run a [source sync job](/ai-search/configuration/indexing/syncing/) later. If the error persists, [contact support](/support/contacting-cloudflare-support/). |
| `error_external_model_unauthorized` | An external embedding model rejected authentication. | Check provider credentials in [AI Gateway](/ai-gateway/configuration/bring-your-own-keys/), then sync the item again. |
| `ai_gateway_request_blocked_firewall` | AI Gateway Guardrails blocked the request. | Review [AI Gateway Guardrails](/ai-gateway/features/guardrails/set-up-guardrail/) prompt settings for the configured gateway, then run a source sync job again. |
| `ai_gateway_dlp_blocked` | AI Gateway Data Loss Prevention (DLP) blocked content. | Review [AI Gateway DLP settings](/ai-gateway/features/dlp/set-up-dlp/) and the item content. |
| `ai_gateway_response_blocked_firewall` | AI Gateway Guardrails blocked the response. | Review [AI Gateway Guardrails](/ai-gateway/features/guardrails/set-up-guardrail/) response settings for the configured gateway, then run a source sync job again. |
| `ai_gateway_not_configured` | AI Gateway is not configured. | Confirm the instance has a valid AI Gateway configured in [model settings](/ai-search/configuration/models/#model-providers). If it does, [contact support](/support/contacting-cloudflare-support/). |
| `ai_gateway_rate_limited` | AI Gateway rate limited the request. | Run a [source sync job](/ai-search/configuration/indexing/syncing/) later. If the error persists, [contact support](/support/contacting-cloudflare-support/). |

## Vectorize and index errors

These errors appear when AI Search stores vectors in [Vectorize](/vectorize/), updates [hybrid search](/ai-search/configuration/indexing/hybrid-search/) indexes, or reaches an [AI Search limit](/ai-search/platform/limits-pricing/#limits).

| Error | Details | Recommended action |
| ----- | ------- | ------------------ |
| `vectorize_not_found` | The Vectorize index was not found. | [Contact support](/support/contacting-cloudflare-support/). |
| `vectorize_unauthorized` | AI Search cannot access the Vectorize index. | [Contact support](/support/contacting-cloudflare-support/). |
| `vectorize_rate_limited` | Vectorize rate limited the operation. | Run a [source sync job](/ai-search/configuration/indexing/syncing/) later. If the error persists, [contact support](/support/contacting-cloudflare-support/). |
| `vectorize_in_invalid_state` | Vectorize is in an invalid state for the operation. | Sync the item again. Check [Cloudflare Status](https://www.cloudflarestatus.com) and [contact support](/support/contacting-cloudflare-support/) if the error persists. |
| `vectorize_ingestion_timeout` | Vectorize did not process the mutation in time. | Sync the item again. Check [Cloudflare Status](https://www.cloudflarestatus.com) and [contact support](/support/contacting-cloudflare-support/) if the error persists. |
| `vectorize_upstream_error` | Vectorize returned a transient upstream error. | Sync the item again. Check [Cloudflare Status](https://www.cloudflarestatus.com) and [contact support](/support/contacting-cloudflare-support/) if the error persists. |
| `hybrid_search_indexing_failed` | Hybrid search indexing failed. | Sync the item again. Check [Cloudflare Status](https://www.cloudflarestatus.com) and [contact support](/support/contacting-cloudflare-support/) if the error persists. |
| `hybrid_search_is_full` | The hybrid search index is full. | Hybrid search has lower [AI Search limits](/ai-search/platform/limits-pricing/#limits). Reduce indexed content with path filtering or [contact support](/support/contacting-cloudflare-support/). |
| `ai_search_is_full` | The AI Search instance is full. | Reduce indexed content, review [AI Search limits](/ai-search/platform/limits-pricing/#limits), or request a higher limit. |

## Troubleshoot processing error codes

Use [item logs](/api/resources/ai_search/subresources/namespaces/subresources/instances/subresources/items/methods/logs/) to identify the processing step that failed. Logs usually include a more specific error message.

For transient service errors, sync the item again after a short delay. If an error persists, [contact Cloudflare support](/support/contacting-cloudflare-support/) with the item ID, instance ID, error code, and request timestamp.

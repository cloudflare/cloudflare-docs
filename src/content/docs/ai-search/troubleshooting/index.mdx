## Choose a reference

| If you see this | Use this reference |
| --------------- | ------------------ |
| A request fails and returns `errors: [{ code, message }]` | [API error codes](/ai-search/troubleshooting/api-error-codes/) |
| A Workers binding call throws `AiSearchError`, `AiSearchNotFoundError`, or `AiSearchInternalError` | [API error codes](/ai-search/troubleshooting/api-error-codes/) |
| A public endpoint request fails before search runs | [API error codes](/ai-search/troubleshooting/api-error-codes/#public-endpoint-operations) |
| An uploaded, synced, or crawled item has `status: "error"` | [Indexing error codes](/ai-search/troubleshooting/indexing-error-codes/) |
| Instance stats show indexing errors | [Indexing error codes](/ai-search/troubleshooting/indexing-error-codes/) |

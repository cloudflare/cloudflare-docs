title: Deactivate Cloudflare One Appliance

import { DashButton } from "~/components";

1. Go to the **Connectors** page.

<DashButton url="/?to=/:account/magic-networks/connections" />

2. Go to the **Appliances** tab > **Appliances**.
3. From the list, find the Cloudflare One Appliance you want to deactivate > select the three dots next to it > **Edit**.
4. In **Status**, select _Deactivated_ from the drop-down menu.
5. Select **Update**.

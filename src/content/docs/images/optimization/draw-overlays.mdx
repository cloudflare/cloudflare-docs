Use Images to draw text, watermarks, and logos over other images. Overlays support transparency, positioning, and compositing modes.

You can draw overlays through all three Images interfaces:

- **[URL interface](#draw-with-cfimage)** — Use the `draw` parameter to place image and text overlays directly from the URL without a Worker.
- **[`cf.image` on a fetch subrequest in Workers](#draw-with-cfimage)** — Add a `draw` array to the image options to overlay with text or images. Overlay images and custom fonts must be accessible via URL.
- **[Images binding in Workers](#draw-with-the-images-binding)** — Chain `.draw()` calls to overlay images from any source, including [hosted images](/images/storage/binding/) or [R2](/r2/), or to overlay text.

<a id="draw-with-cfimage"></a>
## Draw with the URL interface or `cf.image` in Workers

Use the `draw` parameter in a transformation URL or the `draw` array in `cf.image` on a Worker `fetch()` subrequest. Overlay images and custom fonts must be accessible through a URL.

:::note

The URL interface supports `draw` only in transformation URLs for remote images.

To watermark a hosted image, configure the overlay in a [predefined variant](/images/optimization/hosted-images/create-variants/) or use the [Images binding in Workers](/images/optimization/binding/).

:::

Each entry draws either an image or text:

- **Image** — Set `url` to the absolute URL of the image. Apply [optimization parameters](/images/optimization/features/) like [`width`](/images/optimization/features/#width--w), [`height`](/images/optimization/features/#height--h), [`fit`](/images/optimization/features/#fit), [`blur`](/images/optimization/features/#blur), and [`rotate`](/images/optimization/features/#rotate).
- **Text** — Set `text` to the string to render. Style it with the same `font`, `color`, and `size` settings that are available in the binding `.text()` method. Refer to [`.text()`](/images/optimization/binding/#textcontent-options) for the available options, defaults, and limits.

Overlays are drawn in the order they appear — the last entry is the topmost layer.

<Tabs>
  <TabItem label="URL interface">
    ```txt
    https://example.com/cdn-cgi/image/width=800,height=600,draw=((url=https%3A%2F%2Fexample.com%2Fbranding%2Flogo.png,bottom=5,right=5,fit=contain,width=100,height=50,opacity=0.8),(text=HELLO,font=(url=https%3A%2F%2Fexample.com%2Ffont.otf),color=%23223E49,size=96,top=40))/https://example.com/image.png
    ```
  </TabItem>
  <TabItem label="Workers">

              width: 800,
              height: 600,

                  bottom: 5,
                  right: 5,
                  fit: "contain",
                  width: 100,
                  height: 50,
                  opacity: 0.8,
                },
                {
                  text: "HELLO",
                  font: { url: "https://example.com/font.otf" },

                  top: 40,
                },
              ],
            },
          },
        });
      },

## Draw with the Images binding

The [Images binding](/images/optimization/binding/) uses a chainable `.draw()` method to draw an overlay on top of an image. You can chain multiple `.draw()` calls for multiple overlays.

Pass the overlay as the first argument, then the draw settings as the second. The overlay can be an image or text:

- **Image** — Pass the image bytes or an `.input()` chain. To apply [optimization parameters](/images/optimization/features/) to the overlay image, pass an `.input()` chain with `.transform()` as the first argument.
- **Text** — Pass a handle created with `.text()`. Set the font, color, and size in the `.text()` `options` argument. Refer to [`.text()`](/images/optimization/binding/#textcontent-options) for the available options, defaults, and limits.

```js
export default {
	async fetch(request, env) {
		const img = await fetch("https://example.com/base.png");
		const watermark = await fetch("https://example.com/overlay.png");

		const response = (
			await env.IMAGES.input(img.body)
				.draw(env.IMAGES.input(watermark.body).transform({ width: 100 }), {
					bottom: 10,
					right: 10,
					opacity: 0.5,
				})
				.draw(
					env.IMAGES.text("HELLO", {
						font: { url: "https://example.com/font.otf" },
						color: "#223E49",
						size: 96,
					}),
					{ top: 40 },
				)
				.output({ format: "image/avif" })
		).response();

		return response;
	},
};
```

## Settings

The dimensions of the output image are always determined by the base image. The overlay is then drawn onto the base image's canvas.

The following draw-specific settings can be used for positioning and blending. In the URL interface and cf.image, these settings are grouped beneath `draw`. With the Images binding, pass the corresponding settings as the second argument to .draw().

### `url`

Absolute URL of the overlay image when drawing with the URL interface or with `cf.image`. `url` applies only to image overlays. To draw text, create the overlay using `text` instead.

Accepts any [supported image format](/images/get-started/limits/). For watermarks or non-rectangular overlays, use PNG or WebP images.

When drawing an image overlay with the binding, the overlay is passed as image bytes or an `.input()` chain instead of a URL. Refer to [Draw with the Images binding](#draw-with-the-images-binding).

### `text`

Renders a text string as an overlay when drawing with the URL interface or with `cf.image`. When drawing with the Images binding, create the text overlay with `.text()` instead.

Style the text with `font`, `color`, and `size` settings. These apply to the URL interface, `cf.image` text entries, and the binding `.text()` method. Refer to [`.text()`](/images/optimization/binding/#textcontent-options) for the available settings, defaults, and limits.

### `width` and `height`

Sets the maximum dimensions of the overlay image when drawing with the URL interface or with `cf.image`. These settings apply only to image overlays. The dimensions of a text overlay are determined by its text string and styling.

Accepts an integer (pixels) or a decimal between `0` and `1` representing a fraction of the base image's dimension. For example, `height:0.25` (`cf.image`) sets the overlay height to 25% of the height of the base image.

Use [`fit`](/images/optimization/features/#fit) and [`gravity`](/images/optimization/features/#gravity--g) to control how the overlay image is resized and cropped.

When drawing with the Images binding, the dimensions of the overlay image can be set using the [`.transform()`](/images/optimization/binding/#transformoptions) method.

### `repeat`

Determines whether to tile the overlay across the image.

Accepts the following values:

- `true` — Tiles the overlay to cover the entire area. This is useful for watermarks.
- `x` — Tiles the overlay horizontally only.
- `y` — Tiles the overlay vertically only.

### `top`, `left`, `bottom`, `right`

Sets the position of the overlay as an offset, in pixels, to the specified edge. `0` aligns the overlay flush to the edge. If no position is specified, then the overlay is centered.

For example, `{ bottom: 0, right: 10 }` (`cf.image`) places the overlay at the bottom-right corner, 10 pixels inward from the right edge.

Setting both `left` and `right`, or both `top` and `bottom` returns an error.

### `opacity`

Sets the opacity of the overlay. Accepts a decimal value between `0.0` (fully transparent) and `1.0` (fully opaque). For example, `opacity: 0.5` (`cf.image`) makes the overlay semitransparent.

### `composite`

Controls how the overlay is blended with the base image using [Porter-Duff compositing operations](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/feComposite). The default is `over`.

The composite mode only affects the area within the overlay's bounding box. The base image is always preserved outside of this area.

Accepts the following values:

#### `over`

Draws the overlay on top of the base image. This is the default `composite` behavior.

The overlay covers the base where they overlap. Both images are visible where they do not overlap.

<img
	src={compositeOver.src}
	alt="composite=over output"
	style="max-width:300px"
/>

#### `in`

Shows the overlay only where the base image is opaque. If the overlay has transparent pixels that overlap with the base image, then those areas of the base image will also become transparent.

<img src={compositeIn.src} alt="composite=in output" style="max-width:300px" />

#### `atop`

Draws the overlay on top of the base image, but only where the base image is opaque. This will clip the overlay to the shape of the base image.

If the overlay has transparent pixels that overlap with the base image, then the base image remains visible (unlike `in`).

<img
	src={compositeAtop.src}
	alt="composite=atop output"
	style="max-width:300px"
/>

#### `out`

Shows the overlay only where the base image is transparent. Within the overlay's bounding box, opaque areas of the base image will become transparent.

<img
	src={compositeOut.src}
	alt="composite=out output"
	style="max-width:300px"
/>

#### `xor`

Shows the areas of each image where the other is transparent. Overlapping opaque areas will become transparent. This can be used to create [rounded corners](/images/optimization/draw-overlays/#rounded-corners) or custom shapes.

<img
	src={compositeXor.src}
	alt="composite=xor output"
	style="max-width:300px"
/>

#### `lighter`

Adds the color values of both images, which makes the overlapping areas brighter.

	style="max-width:300px"

### Rounded corners

Cut rounded corners from an image. A corner mask is drawn at each corner and rotated to match the position. `xor` removes the overlapping pixels.

The example below shows how this can be done using the [Images binding](/images/optimization/binding/).

```ts
const image = await fetch("https://example.com/photo.png");
const mask = await fetch("https://example.com/corner-mask.png");

let [topLeft, topRight] = mask.body.tee();
let bottomLeft, bottomRight;
[topLeft, bottomLeft] = topLeft.tee();
[topLeft, bottomRight] = topLeft.tee();

const output = await env.IMAGES.input(image.body)
	.draw(env.IMAGES.input(topLeft).transform({ rotate: 0 }), {
		left: 0,
		top: 0,
		composite: "xor",
	})
	.draw(env.IMAGES.input(topRight).transform({ rotate: 90 }), {
		right: 0,
		top: 0,
		composite: "xor",
	})
	.draw(env.IMAGES.input(bottomRight).transform({ rotate: 180 }), {
		bottom: 0,
		right: 0,
		composite: "xor",
	})
	.draw(env.IMAGES.input(bottomLeft).transform({ rotate: 270 }), {
		bottom: 0,
		left: 0,
		composite: "xor",
	})
	.output({ format: "image/png" });

return output.response();
```

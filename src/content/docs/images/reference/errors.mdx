This page provides a reference for error codes you may encounter when using Cloudflare Images. For [image transformation](/images/transform-images/) errors, the response body contains an error message explaining the reason, as well as the `Cf-Resized` header containing `err=code`.

For general Images troubleshooting, refer to [Troubleshooting](/images/reference/troubleshooting/).

## Client configuration errors

| Error code | HTTP status | Description |
| --- | --- | --- |
| `9401` | 400 | Missing or invalid resizing parameters: test options |
| `9401` | 400 | Could not resize the image: test settings error |
| `9401` | 403 | Transformation origin is not in [allowed origins list](/images/transform-images/sources/) |
| `9424` | 400 | Missing or invalid HTTP request parameters |
| `9432` | 400 | Bad request: bad request |

## Processing errors

| Error code | HTTP status | Description |
| --- | --- | --- |
| `9403` | 508 | Requested resized version of an [already-resized image](/images/transform-images/transform-via-workers/#prevent-request-loops) |
| `9412` | 415 | Conversion between SVG and raster formats is not supported |
| `9412` | 415 | Could not resize the image: The HEIC format is not supported, and there are no plans to support it. You must convert HEIC files to one of the supported formats (e.g. JPEG or PNG) before uploading them. |
| `9412` | 415 | Could not resize the image: The TIFF format is not supported. You must convert TIFF files to one of the supported formats (e.g. JPEG or PNG) before uploading them. |
| `9412` | 415 | Could not resize the image: AVIF input is not enabled for this account. |
| `9412` | 415 | Could not resize the image: The requested file is not an image. Please make sure the server always serves an image (e.g. not an error page, or a login page) |
| `9413` | 403 | Could not resize the image: The image enlarged too much: 1000×10000, but maximum dimension allowed is 5000 |
| `9413` | 403 | Could not resize the image: The image has width or height of size 0 |
| `9413` | 403 | Could not resize the image: The animation is too large. Animation resolution is 100×100, and at this size the maximum number of animation frames allowed is 0 (total area of all frames together must be less than 500000). |
| `9413` | 403 | Could not resize the image: Output format rejected |
| `9416` | 422 | Could not resize the image: error occurred while downloading the image |
| `9520` | 415 | Original image has unsupported format |

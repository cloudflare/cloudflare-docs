Argo for Packets optimizes IP layer network routing to your [Cloudflare Network Interconnect (CNI)](/network-interconnect/) for Cloudflare network services products, including [Magic Transit](/magic-transit/) and [Cloudflare WAN](/cloudflare-wan/) (formerly Magic WAN).

Argo for Packets monitors the performance of network paths between every Cloudflare data center and your origin. It uses existing Layer 4 traffic data and network analytics to select the lowest latency path to your CNI.

To begin using Argo for Packets, contact your account manager.

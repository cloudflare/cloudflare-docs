Use the Artifacts REST API to manage repos, remotes, forks, imports, and tokens from external systems.

## Base URL and authentication

Artifacts uses the standard Cloudflare v4 API.

Base URL:

```txt
https://api.cloudflare.com/client/v4/accounts/{accountId}/artifacts
```

The route examples on this page are relative to that base URL.

Requests use Bearer authentication:

```txt
Authorization: Bearer <ARTIFACTS_JWT>
```

The following examples assume:

```sh
export ARTIFACTS_ACCOUNT_ID="<YOUR_ACCOUNT_ID>"
export ARTIFACTS_BASE_URL="https://api.cloudflare.com/client/v4/accounts/${ARTIFACTS_ACCOUNT_ID}/artifacts"
export ARTIFACTS_NAMESPACE="default"
export ARTIFACTS_REPO="starter-repo"
export ARTIFACTS_JWT="<YOUR_ARTIFACTS_JWT>"
```

## Shared types

```ts
export type NamespaceName = string;
export type RepoName = string;
export type Scope = "read" | "write";
export type ArtifactToken = string;
export type Cursor = string;

export interface RepoInfo {
	id: string;
	name: RepoName;
	createdAt: string;
	source: string | null;
	readOnly: boolean;
}

export interface RemoteRepoInfo extends RepoInfo {
	remote: string;
}

export interface TokenInfo {
	id: string;
	scope: Scope;
	createdAt: string;
	expiresAt: string;
}
```

## Repos

### Create a repo

Route: `POST /namespaces/:namespace/repos`

Request body:

- `name` <Type text="RepoName" /> <MetaInfo text="required" />
- `readOnly` <Type text="boolean" /> <MetaInfo text="optional" />

Response type:

```ts
export interface CreateRepoRequest {
	name: RepoName;
	readOnly?: boolean;
}

export interface CreateRepoResponse {
	id: string;
	name: RepoName;
	remote: string;
	token: ArtifactToken;
	expiresAt: string;
}
```

```bash
curl "$ARTIFACTS_BASE_URL/namespaces/$ARTIFACTS_NAMESPACE/repos" \
--header "Authorization: Bearer $ARTIFACTS_JWT" \
--header "Content-Type: application/json" \
--data '{
  "name": "starter-repo"
}'
```

```json
{
	"id": "repo_123",
	"name": "starter-repo",
	"remote": "https://<ACCOUNT_ID>.artifacts.cloudflare.dev/git/default/starter-repo.git",
	"token": "art_v1_0123456789abcdef0123456789abcdef01234567?expires=1760000000",
	"expiresAt": "<ISO_TIMESTAMP>"
}
```

### List repos

Route: `GET /namespaces/:namespace/repos?limit=&cursor=`

Query parameters:

- `limit` <Type text="number" /> <MetaInfo text="optional (default: 50, max: 200)" />
- `cursor` <Type text="Cursor" /> <MetaInfo text="optional" />

Response type:

```ts
export interface ListReposQuery {
	limit?: number;
	cursor?: Cursor;
}

export interface ListReposResponse {
	repos: RepoInfo[];
	total: number;
	cursor?: Cursor;
}
```

```bash
curl "$ARTIFACTS_BASE_URL/namespaces/$ARTIFACTS_NAMESPACE/repos?limit=20" \
--header "Authorization: Bearer $ARTIFACTS_JWT"
```

```json
{
	"repos": [
		{
			"id": "repo_123",
			"name": "starter-repo",
			"createdAt": "<ISO_TIMESTAMP>",
			"source": null,
			"readOnly": false
		}
	],
	"total": 1
}
```

### Get a repo

Route: `GET /namespaces/:namespace/repos/:name`

Response type:

```ts
export type GetRepoResponse = RemoteRepoInfo;
```

```bash
curl "$ARTIFACTS_BASE_URL/namespaces/$ARTIFACTS_NAMESPACE/repos/$ARTIFACTS_REPO" \
--header "Authorization: Bearer $ARTIFACTS_JWT"
```

```json
{
	"id": "repo_123",
	"name": "starter-repo",
	"createdAt": "<ISO_TIMESTAMP>",
	"source": null,
	"readOnly": false,
	"remote": "https://<ACCOUNT_ID>.artifacts.cloudflare.dev/git/default/starter-repo.git"
}
```

### Delete a repo

Route: `DELETE /namespaces/:namespace/repos/:name`

Response type:

```ts
export interface DeleteRepoResponse {
	deleted: RepoName;
}
```

```bash
curl --request DELETE \
"$ARTIFACTS_BASE_URL/namespaces/$ARTIFACTS_NAMESPACE/repos/$ARTIFACTS_REPO" \
--header "Authorization: Bearer $ARTIFACTS_JWT"
```

```json
{
	"deleted": "starter-repo"
}
```

### Fork a repo

Route: `POST /namespaces/:namespace/repos/:name/fork`

Request body:

- `name` <Type text="RepoName" /> <MetaInfo text="required" />
- `readOnly` <Type text="boolean" /> <MetaInfo text="optional" />

Response type:

```ts
export interface ForkRepoRequest {
	name: RepoName;
	readOnly?: boolean;
}

export interface ForkRepoResponse extends CreateRepoResponse {
	objects: number;
}
```

```bash
curl "$ARTIFACTS_BASE_URL/namespaces/$ARTIFACTS_NAMESPACE/repos/$ARTIFACTS_REPO/fork" \
--header "Authorization: Bearer $ARTIFACTS_JWT" \
--header "Content-Type: application/json" \
--data '{
  "name": "starter-repo-copy"
}'
```

```json
{
	"id": "repo_456",
	"name": "starter-repo-copy",
	"remote": "https://<ACCOUNT_ID>.artifacts.cloudflare.dev/git/default/starter-repo-copy.git",
	"token": "art_v1_89abcdef0123456789abcdef0123456789abcdef?expires=1760003600",
	"expiresAt": "<ISO_TIMESTAMP>",
	"objects": 128
}
```

### Import a GitHub repository

Route: `POST /namespaces/:namespace/repos/:name/import`

Request body:

- `url` <Type text="string" /> <MetaInfo text="required" />
- `branch` <Type text="string" /> <MetaInfo text="optional" />
- `readOnly` <Type text="boolean" /> <MetaInfo text="optional" />

Response type:

```ts
export interface ImportRepoRequest {
	url: string; // full GitHub URL
	branch?: string;
	readOnly?: boolean;
}

export type ImportRepoResponse = CreateRepoResponse;
```

The REST API currently requires `url` to be a full GitHub URL, for example `https://github.com/facebook/react`.

```bash
curl "$ARTIFACTS_BASE_URL/namespaces/$ARTIFACTS_NAMESPACE/repos/react-mirror/import" \
--header "Authorization: Bearer $ARTIFACTS_JWT" \
--header "Content-Type: application/json" \
--data '{
  "url": "https://github.com/facebook/react",
  "branch": "main"
}'
```

```json
{
	"id": "repo_789",
	"name": "react-mirror",
	"remote": "https://<ACCOUNT_ID>.artifacts.cloudflare.dev/git/default/react-mirror.git",
	"token": "art_v1_fedcba9876543210fedcba9876543210fedcba98?expires=1760007200",
	"expiresAt": "<ISO_TIMESTAMP>"
}
```

## Tokens

### List tokens for a repo

Route: `GET /namespaces/:namespace/repos/:name/tokens`

Response type:

```ts
export interface ListTokensResponse {
	tokens: TokenInfo[];
}
```

```bash
curl "$ARTIFACTS_BASE_URL/namespaces/$ARTIFACTS_NAMESPACE/repos/$ARTIFACTS_REPO/tokens" \
--header "Authorization: Bearer $ARTIFACTS_JWT"
```

```json
{
	"tokens": [
		{
			"id": "tok_123",
			"scope": "read",
			"createdAt": "<ISO_TIMESTAMP>",
			"expiresAt": "<ISO_TIMESTAMP>"
		}
	]
}
```

### Create a token

Route: `POST /namespaces/:namespace/tokens`

Request body:

- `repo` <Type text="RepoName" /> <MetaInfo text="required" />
- `scope` <Type text='"read" | "write"' /> <MetaInfo text='optional (default: "write")' />
- `ttl` <Type text="number" /> <MetaInfo text="optional (seconds, default: 86400)" />

Response type:

```ts
export interface CreateTokenRequest {
	repo: RepoName;
	scope?: Scope;
	ttl?: number;
}

export interface CreateTokenResponse {
	id: string;
	plaintext: ArtifactToken;
	scope: Scope;
	expiresAt: string;
}
```

```bash
curl "$ARTIFACTS_BASE_URL/namespaces/$ARTIFACTS_NAMESPACE/tokens" \
--header "Authorization: Bearer $ARTIFACTS_JWT" \
--header "Content-Type: application/json" \
--data '{
  "repo": "starter-repo",
  "scope": "read",
  "ttl": 3600
}'
```

```json
{
	"id": "tok_123",
	"plaintext": "art_v1_0123456789abcdef0123456789abcdef01234567?expires=1760000000",
	"scope": "read",
	"expiresAt": "<ISO_TIMESTAMP>"
}
```

### Validate a token

Route: `POST /namespaces/:namespace/tokens/validate`

Request body:

- `repo` <Type text="RepoName" /> <MetaInfo text="required" />
- `token` <Type text="ArtifactToken" /> <MetaInfo text="required" />

Response type:

```ts
export interface ValidateTokenRequest {
	token: ArtifactToken;
	repo: RepoName;
}

export interface ValidateTokenResponse {
	valid: boolean;
	scope?: Scope;
}
```

```bash
curl "$ARTIFACTS_BASE_URL/namespaces/$ARTIFACTS_NAMESPACE/tokens/validate" \
--header "Authorization: Bearer $ARTIFACTS_JWT" \
--header "Content-Type: application/json" \
--data '{
  "repo": "starter-repo",
  "token": "art_v1_0123456789abcdef0123456789abcdef01234567?expires=1760000000"
}'
```

```json
{
	"valid": true,
	"scope": "read"
}
```

### Revoke a token

Route: `POST /namespaces/:namespace/tokens/revoke`

Request body:

- `token` <Type text="ArtifactToken" /> <MetaInfo text="optional" />
- `id` <Type text="string" /> <MetaInfo text="optional" />

Provide either `token` or `id`.

Response type:

```ts
export interface RevokeTokenRequest {
	token?: ArtifactToken;
	id?: string;
}

export interface RevokeTokenResponse {
	revoked: true;
}
```

```bash
curl "$ARTIFACTS_BASE_URL/namespaces/$ARTIFACTS_NAMESPACE/tokens/revoke" \
--header "Authorization: Bearer $ARTIFACTS_JWT" \
--header "Content-Type: application/json" \
--data '{
  "id": "tok_123"
}'
```

```json
{
	"revoked": true
}
```

## Errors

The API can return application errors and authentication errors.

```ts
export interface ApiError {
	error: string;
}

export interface AuthError {
	success: false;
	errors: Array<{
		code: 10000;
		message: string;
	}>;
}
```

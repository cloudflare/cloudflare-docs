Use [Wrangler](/workers/wrangler/) or the Cloudflare CLI to create and manage Hyperdrive configurations.

:::note
The Wrangler and Cloudflare CLI command families are not one-to-one. For example, `wrangler hyperdrive create` accepts a positional name and connection string, while `cf hyperdrive create` uses named origin fields. The Cloudflare CLI also includes `replace` and `restart`, while Wrangler includes `planetscale signature`. Use the syntax shown for your selected CLI instead of translating flags directly.
:::

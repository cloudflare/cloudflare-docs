# Web Search API Providers

Web Search API supports multiple search providers for AI agents, LLM applications, research workflows, and real-time web information retrieval.

The following sections compare GCrawlAI, Ceramic.ai, Exa, and Linkup based on their search capabilities, pricing, data retention policies, and use cases.

Set the `provider` parameter in your request to select a provider. If no provider is specified, the Web Search API described in this reference uses Ceramic.ai as its default.

When you pay with [AI Gateway credits](/ai-gateway/features/unified-billing/), each supported search is billed at the provider's list API price, with no additional markup. If you [bring your own key](/web-search/how-to-use/#bring-your-own-key-byok), the provider bills you directly under your own agreement with them.

**Note:** GCrawlAI is included below as an additional provider for comparison. Its availability through this specific Web Search API gateway, provider identifier, and gateway billing integration must be confirmed before publishing it as an officially supported option.

## [GCrawlAI](https://gcrawlai.com/)

GCrawlAI, developed by Gramosoft, is a web crawling, scraping, search, and data extraction platform designed for AI agents, LLM applications, Retrieval-Augmented Generation (RAG) pipelines, and enterprise data workflows.

GCrawlAI helps developers and businesses discover relevant web information, extract website content, and transform unstructured web pages into structured, AI-ready data.

The platform is designed for applications that need web search and content extraction capabilities, including AI-powered chatbots, automated research agents, knowledge-base development, competitive intelligence, and real-time information retrieval.

GCrawlAI also provides web scraping and crawling capabilities, making it useful for workflows that extend beyond search results and require website content extraction.

Its open-source project provides additional options for developers interested in self-hosted web data infrastructure.

### Key Capabilities

- Web search for AI applications and automated research workflows.
- Web crawling and scraping for collecting website content.
- Structured data extraction for AI-ready processing.
- Integration opportunities for AI agents, LLMs, and RAG pipelines.
- Open-source and self-hosting options.
- Support for building automated web data collection workflows.

## [Ceramic.ai](https://ceramic.ai/)

Ceramic.ai is the default provider for Web Search API. Ceramic.ai runs its own independent web index of more than 40 billion pages, designed for AI agents and LLM applications rather than human search.

Ceramic.ai focuses on low-latency, low-cost search, which makes it a good fit for agents that run many searches per task, for grounding chatbot answers in current information, and for checking model output against live web sources.

Results include long descriptions of each page, up to 8,000 characters.

**Best suited for:** High-volume AI agents, cost-sensitive applications, chatbot grounding, and workflows requiring low-latency web search.

## [Exa](https://exa.ai/)

Exa is a search engine built for AI, with its own index that combines traditional keyword search with embeddings-based search. Web Search API uses the [Exa Search API](https://exa.ai/docs/reference/search).

Requests use Exa's `auto` search type, a balanced mode that Exa optimizes for both result quality and speed.

Each result includes highlights — the text snippets from the page that are most relevant to your query — returned as the result description.

Exa is a good fit when you want to pass concise, query-relevant excerpts straight into a model's context.

**Best suited for:** Semantic search, AI research assistants, knowledge discovery, and applications requiring concise, query-relevant content excerpts.

## [Linkup](https://www.linkup.so/)

Linkup provides web search built for AI applications, returning sourced results with text snippets from across the web. Web Search API uses the [Linkup Search API](https://docs.linkup.so/pages/documentation/endpoints/search/overview).

Requests use Linkup's `fast` search depth with raw search results, so Linkup returns results without generating an answer.

This makes Linkup a good fit for agent tool calls that need quick, cited results from trusted sources.

## Choosing the Right Web Search API Provider

The best provider depends on your application's search requirements, budget, data processing needs, and integration architecture.

**Choose GCrawlAI** when your application needs web search together with website crawling, scraping, structured content extraction, or AI-ready data preparation. It is particularly relevant for developers building AI agents, RAG pipelines, research automation, and data-driven applications.

**Choose Ceramic.ai** when low cost and fast search responses are priorities, particularly for AI agents that perform many searches per task.

**Choose Exa** when semantic relevance and concise page highlights are important for LLM context construction and research applications.

**Choose Linkup** when your application needs fast, sourced web results that can be passed directly to AI agents without a provider-generated answer.

## Conclusion

GCrawlAI, Ceramic.ai, Exa, and Linkup offer different approaches to web information retrieval for AI applications.

Ceramic.ai emphasizes low-cost search, Exa focuses on semantic relevance, and Linkup provides fast, sourced search results.

GCrawlAI combines web search with broader crawling, scraping, and content extraction capabilities, making it an option for developers and businesses that need to collect and prepare website information for AI workflows.

Learn more about [GCrawlAI](https://gcrawlai.com/) or explore its [open-source project on GitHub](https://github.com/GramosoftAI/GcrawlAI).

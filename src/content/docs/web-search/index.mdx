Give your agents real-time web context with a single API call.

</Description>

<Plan type="beta" />

Web Search API lets your AI agents and applications search the Internet and ground their responses in live information. Instead of guessing URLs or relying on a model's training cutoff, your agent sends a search query and receives structured results — titles, URLs, and descriptions — that you can pass straight into a model's context.

Web Search API runs through [AI Gateway](/ai-gateway/), so every search gets the same logging, analytics, billing, and access controls as your model inference requests. You can call it from any backend with the REST API, or from a Worker with the AI binding.

## Features

<Feature header="Multiple search providers" href="/web-search/providers/" cta="View providers">

Choose between Ceramic.ai, Exa, and Linkup with a single `provider` parameter. All providers return results in the same format, so you can switch without changing your code.

</Feature>

<Feature header="Unified Billing" href="/ai-gateway/features/unified-billing/" cta="Learn about Unified Billing">

Pay for searches with your AI Gateway credits at each provider's list API price, with no additional markup. You can also bring your own provider API key.

</Feature>

<Feature header="Observability" href="/ai-gateway/observability/logging/" cta="View logging">

Search requests appear in your AI Gateway logs and analytics alongside your model inference requests.

</Feature>

<Feature header="Responsible crawling" href="/web-search/about/#crawler-standards" cta="Learn more">

Every provider commits to Cloudflare's [verified bot](/bots/concepts/bot/verified-bots/) requirements and returns a link to the source of every result.

</Feature>

Check the **Security Insights** tab for a list of detected insights that you should address.

For each detected insight, you can resolve it or archive it, after understanding its risks.

1. In the Cloudflare dashboard, go to the **Security Insights** page.

   <DashButton url="/?to=/:account/security-center" />

2. Next to the insight you wish to address, select **Details** to review it.

## Resolve an insight

:::warning
After you address an insight, it remains in **Active** until an applicable scan no longer detects the issue. You can manually trigger a scan or wait for the [automatic scan](/security/security-insights/how-it-works/#scan-frequency). [Archiving](#archive-insights) hides an insight without resolving the underlying issue.
:::

In the Resolve insights page, if you choose to update a configuration based on the recommendation actions, follow the instructions on the insight details page.

The following insights follow a different yet straightforward workflow to be resolved:

- **Minimum Version of TLS 1.2 not enforced**: To resolve this insight:
  - Go to **SSL/TLS** > **Edge Certificates**.
  - Select **TLS 1.2**.
- **Domains without "Always use HTTPS"**: To resolve this insight:
  - Go to **SSL/TLS** > **Edge Certificates**.
  - Select **Always Use HTTPS**.

## Export insights

You can export security insights to a CSV format directly from the dashboard.

To export security insights:

1. In the Cloudflare dashboard, go to the **Security Insights** page.

   <DashButton url="/?to=/:account/security-center" />

2. Select **Export insights**.

Exporting security insights allow you to perform a deeper analysis of your insights.

The exported CSV file includes information such as the severity of your data, insight type scan date, issue class and additional optional fields, such as insight details, risk assessment, detection method, and recommended actions.

## Archive insights

Archive an insight by classifying it as a false positive, an accepted risk, or another reason. Archiving removes the insight from **Active** and suppresses it across subsequent scans until you unarchive it. It does not change your Cloudflare configuration or resolve the underlying issue.

The classifications have different reason requirements:

| Classification | When to use it | Reason |
| --- | --- | --- |
| _False positive_ | The insight incorrectly identifies an issue. | Optional |
| _Accept risk_ | You understand the issue and accept its risk. | Required |
| _Other_ | You are archiving the insight for another reason. | Required |

To archive or unarchive insights, you need [permission to modify insights](/security/security-insights/roles-and-permissions/).

### Archive selected insights

<Steps>

1. In the Cloudflare dashboard, go to the **Security Insights** page.

   <DashButton url="/?to=/:account/security-center" />

2. In **Active**, select the insights you want to archive.
3. Select **Classify selected**, then choose _False positive_, _Accept risk_, or _Other_.
4. In **Add a reason**, enter a reason if required.
5. Select **Confirm**.

</Steps>

The same classification and reason apply to all selected insights.

### Restore an archived insight

The **Archived** tab shows archived insights that are still detected. It uses your current insight filters. Clear any filters that hide the insight you want to restore.

<Steps>

1. On the **Security Insights** page, select **Archived**.
2. Open the insight's three-dot menu and select **Unarchive**.

</Steps>

Unarchiving clears the classification and returns the insight to **Active**. To change an insight's classification, unarchive it first, then classify it again.

## Enable alerts

You can enable alerts for critical insights.

To enable alerts:

1. In the Cloudflare dashboard, go to the **Security Insights** page.

   <DashButton url="/?to=/:account/security-center" />

2. Select the security insight(s) you want to create an alert for, then select **Create alert for selected classes**.
3. Enter the notification name, and choose one or more insights classes to filter a notification.
4. Select **Add email recipient** and enter an email address to receive the alert.
5. Select **Save**.

This page describes the settings available in **Security** > **Settings** for a given zone.

## Detections

### Web application firewall

In web application firewall detections you can perform the following tasks:

- Enable one or WAF managed rulesets, provided by Cloudflare and updated regularly:
  - [Cloudflare Managed Ruleset](/waf/managed-rules/reference/cloudflare-managed-ruleset/)
  - [Cloudflare OWASP Core Ruleset](/waf/managed-rules/reference/owasp-core-ruleset/)
- Enable one or more [detections](/waf/detections/) to run on your incoming traffic:
  - [Leaked credentials checks](/waf/detections/leaked-credentials/)
  - [Malicious uploads detection](/waf/detections/malicious-uploads/)
  - [Sensitive data detection](/waf/managed-rules/reference/sensitive-data-detection/)

Refer to each linked page for details.

Security Rules perform security-related actions on incoming requests that match specified filters. Rules are evaluated and executed in order, from first to last.

## Security rules

The **Security rules** tab includes a list of different types of rules configured in your zone to protect your applications and resources.

To create a security rule:

1. (Optional) Select **Templates**, and then select a template from the list. You can customize the default configuration of the template before deploying the new rule. Refer to the resources listed in the next step.

1. Select **Create rule** > select the type of rule you want to create. Refer to the following resources about each type of rule:

- [Custom rules](/waf/custom-rules/create-dashboard/)
- [Rate limiting rules](/waf/rate-limiting-rules/create-zone-dashboard/)
- [API sequence rules](/api-shield/security/sequence-mitigation/#create-a-sequence-rule)
- [API JWT validation rules](/api-shield/security/jwt-validation/#add-a-jwt-validation-rule)
- [Managed rules](/waf/managed-rules/)
- [Client-side rules](/page-shield/policies/) (previously known as Page Shield policies)
- [IP Access rules](/waf/tools/ip-access-rules/create/)
- [User agent blocking rules](/waf/tools/user-agent-blocking/#create-a-user-agent-blocking-rule)
- [Zone lockdown rules](/waf/tools/zone-lockdown/#create-a-zone-lockdown-rule)

:::note
The **Security rules** tab includes functionality available in different products in the previous dashboard navigation structure, such as the [WAF](/waf/), [API Shield](/api-shield/), and [Page Shield](/page-shield/).
:::

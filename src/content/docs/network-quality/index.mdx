<Description>

Measure the quality of connections between your end users or devices and the Cloudflare network.

</Description>

<Plan type="private-beta" />

The Network Quality API lets clients measure the quality of their connection to the nearest Cloudflare data center, including download and upload speed, latency, and jitter. Only authorized clients can run Network Quality tests on behalf of your Cloudflare account.

A service you operate decides which clients, such as end users or devices, are authorized. This service requests authorization tokens from Cloudflare and hands them over to authorized clients. Refer to [Authorization tokens](/network-quality/guides/authorization-tokens/) for more information.

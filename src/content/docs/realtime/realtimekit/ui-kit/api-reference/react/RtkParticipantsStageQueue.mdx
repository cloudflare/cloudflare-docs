A component that displays participants waiting in the stage queue.
 Shows users who are waiting to be promoted to the stage in meetings
 with stage functionality enabled.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `size` | `Size1` | ✅ | - | Size |

## Usage Examples

### Basic Usage

```tsx
import { RtkParticipantsStageQueue } from '@cloudflare/realtimekit-react-ui';

function MyComponent() {
  return <RtkParticipantsStageQueue />;
}
```

### With Properties

```tsx
import { RtkParticipantsStageQueue } from '@cloudflare/realtimekit-react-ui';

function MyComponent() {
  return (
    <RtkParticipantsStageQueue
      meeting={meeting}
      size="md"
    />
  );
}
```

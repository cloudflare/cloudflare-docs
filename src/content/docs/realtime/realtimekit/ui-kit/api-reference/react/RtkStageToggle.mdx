## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `size` | `Size1` | ✅ | - | Size |
| `states` | `States1` | ✅ | - | States |

## Usage Examples

### Basic Usage

```tsx
import { RtkStageToggle } from '@cloudflare/realtimekit-react-ui';

function MyComponent() {
  return <RtkStageToggle />;
}
```

### With Properties

```tsx
import { RtkStageToggle } from '@cloudflare/realtimekit-react-ui';

function MyComponent() {
  return (
    <RtkStageToggle
      meeting={meeting}
      size="md"
    />
  );
}
```

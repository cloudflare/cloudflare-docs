A sidebar UI component with tabbed navigation.
 Provides a container for sidebar content with tab switching functionality.
 Can be displayed as a sidebar or in full-screen mode.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `currentTab` | `string` | ✅ | - | Default tab to open |

## Usage Examples

### Basic Usage

```tsx
import { RtkSidebarUi } from '@cloudflare/realtimekit-react-ui';

function MyComponent() {
  return <RtkSidebarUi />;
}
```

### With Properties

```tsx
import { RtkSidebarUi } from '@cloudflare/realtimekit-react-ui';

function MyComponent() {
  return (
    <RtkSidebarUi
      currentTab="example"
    />
  );
}
```

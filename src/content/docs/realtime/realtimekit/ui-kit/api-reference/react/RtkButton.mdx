A button that follows RTK Design System.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `size` | `Size` | ✅ | - | Size |

## Usage Examples

### Basic Usage

```tsx
import { RtkButton } from '@cloudflare/realtimekit-react-ui';

function MyComponent() {
  return <RtkButton />;
}
```

### With Properties

```tsx
import { RtkButton } from '@cloudflare/realtimekit-react-ui';

function MyComponent() {
  return (
    <RtkButton
      size="md"
    />
  );
}
```

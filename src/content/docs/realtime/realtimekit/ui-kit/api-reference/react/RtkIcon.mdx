An icon component which accepts an svg string and renders it.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `icon` | `string` | ✅ | - | Icon |

## Usage Examples

### Basic Usage

```tsx
import { RtkIcon } from '@cloudflare/realtimekit-react-ui';

function MyComponent() {
  return <RtkIcon />;
}
```

### With Properties

```tsx
import { RtkIcon } from '@cloudflare/realtimekit-react-ui';

function MyComponent() {
  return (
    <RtkIcon
      icon="example"
    />
  );
}
```

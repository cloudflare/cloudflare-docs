A component which allows you to change current page and view mode
 of active participants list. This is reflected in the `rtk-grid` component.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `size` | `Size` | ✅ | - | Size Prop |
| `states` | `States` | ✅ | - | States |

## Usage Examples

### Basic Usage

```tsx
import { RtkGridPagination } from '@cloudflare/realtimekit-react-ui';

function MyComponent() {
  return <RtkGridPagination />;
}
```

### With Properties

```tsx
import { RtkGridPagination } from '@cloudflare/realtimekit-react-ui';

function MyComponent() {
  return (
    <RtkGridPagination
      meeting={meeting}
      size="md"
    />
  );
}
```

A menu component.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `size` | `Size` | ✅ | - | Size |

## Usage Examples

### Basic Usage

```tsx
import { RtkMenu } from '@cloudflare/realtimekit-react-ui';

function MyComponent() {
  return <RtkMenu />;
}
```

### With Properties

```tsx
import { RtkMenu } from '@cloudflare/realtimekit-react-ui';

function MyComponent() {
  return (
    <RtkMenu
      size="md"
    />
  );
}
```

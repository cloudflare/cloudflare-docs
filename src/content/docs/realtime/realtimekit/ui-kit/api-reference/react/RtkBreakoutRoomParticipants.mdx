A component which lists all participants, with ability to
 run privileged actions on each participant according to your permissions.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |

## Usage Examples

### Basic Usage

```tsx
import { RtkBreakoutRoomParticipants } from '@cloudflare/realtimekit-react-ui';

function MyComponent() {
  return <RtkBreakoutRoomParticipants />;
}
```

### With Properties

```tsx
import { RtkBreakoutRoomParticipants } from '@cloudflare/realtimekit-react-ui';

function MyComponent() {
  return (
    <RtkBreakoutRoomParticipants
      meeting={meeting}
    />
  );
}
```

A button which toggles your microphone.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `size` | `Size` | ✅ | - | Size |

## Usage Examples

### Basic Usage

```tsx
import { RtkMicToggle } from '@cloudflare/realtimekit-react-ui';

function MyComponent() {
  return <RtkMicToggle />;
}
```

### With Properties

```tsx
import { RtkMicToggle } from '@cloudflare/realtimekit-react-ui';

function MyComponent() {
  return (
    <RtkMicToggle
      meeting={meeting}
      size="md"
    />
  );
}
```

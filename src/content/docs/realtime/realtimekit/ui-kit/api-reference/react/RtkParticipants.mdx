A component which lists all participants, with ability to
 run privileged actions on each participant according to your permissions.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `size` | `Size` | ✅ | - | Size |
| `states` | `States` | ✅ | - | States object |

## Usage Examples

### Basic Usage

```tsx
import { RtkParticipants } from '@cloudflare/realtimekit-react-ui';

function MyComponent() {
  return <RtkParticipants />;
}
```

### With Properties

```tsx
import { RtkParticipants } from '@cloudflare/realtimekit-react-ui';

function MyComponent() {
  return (
    <RtkParticipants
      meeting={meeting}
      size="md"
    />
  );
}
```

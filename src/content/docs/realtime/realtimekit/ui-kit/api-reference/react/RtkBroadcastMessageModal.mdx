A modal for sending broadcast messages to all meeting participants.
 Allows hosts and moderators to send important announcements that
 appear prominently to all users in the meeting.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `states` | `States1` | ✅ | - | States object |

## Usage Examples

### Basic Usage

```tsx
import { RtkBroadcastMessageModal } from '@cloudflare/realtimekit-react-ui';

function MyComponent() {
  return <RtkBroadcastMessageModal />;
}
```

### With Properties

```tsx
import { RtkBroadcastMessageModal } from '@cloudflare/realtimekit-react-ui';

function MyComponent() {
  return (
    <RtkBroadcastMessageModal
      meeting={meeting}
    />
  );
}
```

 A component which renders a text message from chat.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `message` | `TextMessage` | ✅ | - | Text message object |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-text-message></rtk-text-message>
```

### With Properties

```html
<!-- component.html -->
<rtk-text-message
 [message]="textmessage">
</rtk-text-message>
```

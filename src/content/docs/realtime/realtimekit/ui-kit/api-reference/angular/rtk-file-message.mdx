 A component which renders a file message from chat.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `message` | `FileMessage` | ✅ | - | Text message object |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-file-message></rtk-file-message>
```

### With Properties

```html
<!-- component.html -->
<rtk-file-message
 [message]="filemessage">
</rtk-file-message>
```

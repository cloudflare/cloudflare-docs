A component which renders an image message.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `url` | `string` | ✅ | - | Url of the image |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-image-message-view></rtk-image-message-view>
```

### With Properties

```html
<!-- component.html -->
<rtk-image-message-view
 url="example">
</rtk-image-message-view>
```

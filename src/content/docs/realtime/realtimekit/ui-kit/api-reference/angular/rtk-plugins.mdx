A component which lists all available plugins from their preset,
 and ability to enable or disable plugins.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `size` | `Size` | ✅ | - | Size |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-plugins></rtk-plugins>
```

### With Properties

```html
<!-- component.html -->
<rtk-plugins
 [meeting]="meeting"
 size="md">
</rtk-plugins>
```

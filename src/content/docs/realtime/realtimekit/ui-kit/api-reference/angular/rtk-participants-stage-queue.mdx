A component that displays participants waiting in the stage queue.
 Shows users who are waiting to be promoted to the stage in meetings
 with stage functionality enabled.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `size` | `Size1` | ✅ | - | Size |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-participants-stage-queue></rtk-participants-stage-queue>
```

### With Properties

```html
<!-- component.html -->
<rtk-participants-stage-queue
 [meeting]="meeting"
 size="md">
</rtk-participants-stage-queue>
```

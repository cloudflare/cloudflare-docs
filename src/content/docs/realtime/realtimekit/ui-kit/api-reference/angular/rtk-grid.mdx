The main grid component which abstracts all the grid handling logic and renders it for you.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `size` | `Size` | ✅ | - | Size |
| `states` | `States` | ✅ | - | States |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-grid></rtk-grid>
```

### With Properties

```html
<!-- component.html -->
<rtk-grid
 [meeting]="meeting"
 size="md">
</rtk-grid>
```

A number picker with increment and decrement buttons.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `size` | `Size1` | ✅ | - | Size |
| `value` | `number` | ✅ | - | Initial value |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-counter></rtk-counter>
```

### With Properties

```html
<!-- component.html -->
<rtk-counter
 size="md"
 value="42">
</rtk-counter>
```

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `activeTab` | `Tab` | ✅ | - | Active tab |
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `size` | `Size` | ✅ | - | Size |
| `states` | `States` | ✅ | - | States object |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-tab-bar></rtk-tab-bar>
```

### With Properties

```html
<!-- component.html -->
<rtk-tab-bar
 [activeTab]="tab"
 [meeting]="meeting"
 size="md">
</rtk-tab-bar>
```

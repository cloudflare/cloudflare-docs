An icon component which accepts an svg string and renders it.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `icon` | `string` | ✅ | - | Icon |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-icon></rtk-icon>
```

### With Properties

```html
<!-- component.html -->
<rtk-icon
 icon="example">
</rtk-icon>
```

A troubleshooting component to identify and fix any issues in the meeting.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `size` | `Size` | ✅ | - | Size |
| `states` | `States` | ✅ | - | States object |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-debugger></rtk-debugger>
```

### With Properties

```html
<!-- component.html -->
<rtk-debugger
 [meeting]="meeting"
 size="md">
</rtk-debugger>
```

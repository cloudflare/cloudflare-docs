A screen which shows a meeting has ended.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Global states |
| `size` | `Size` | ✅ | - | Size |
| `states` | `States` | ✅ | - | Global states |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-ended-screen></rtk-ended-screen>
```

### With Properties

```html
<!-- component.html -->
<rtk-ended-screen
 [meeting]="meeting"
 size="md">
</rtk-ended-screen>
```

A screen shown before joining the meeting, where you can edit your display name,
 and media settings.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `size` | `Size` | ✅ | - | Size |
| `states` | `States` | ✅ | - | States object |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-setup-screen></rtk-setup-screen>
```

### With Properties

```html
<!-- component.html -->
<rtk-setup-screen
 [meeting]="meeting"
 size="md">
</rtk-setup-screen>
```

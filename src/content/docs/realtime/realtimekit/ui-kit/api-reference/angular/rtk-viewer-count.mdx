A component which shows count of total joined participants in a meeting.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-viewer-count></rtk-viewer-count>
```

### With Properties

```html
<!-- component.html -->
<rtk-viewer-count
 [meeting]="meeting">
</rtk-viewer-count>
```

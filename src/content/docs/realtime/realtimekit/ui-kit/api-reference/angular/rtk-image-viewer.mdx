A component which shows an image sent via chat.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `image` | `ImageMessage` | ✅ | - | Image message |
| `size` | `Size` | ✅ | - | Size |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-image-viewer></rtk-image-viewer>
```

### With Properties

```html
<!-- component.html -->
<rtk-image-viewer
 [image]="imagemessage"
 size="md">
</rtk-image-viewer>
```

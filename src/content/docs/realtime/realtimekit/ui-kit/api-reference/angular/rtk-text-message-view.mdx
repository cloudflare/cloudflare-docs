A component which renders a text message from chat.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `text` | `string` | ✅ | - | Text message |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-text-message-view></rtk-text-message-view>
```

### With Properties

```html
<!-- component.html -->
<rtk-text-message-view
 text="example">
</rtk-text-message-view>
```

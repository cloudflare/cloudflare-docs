A button which toggles your microphone.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `size` | `Size` | ✅ | - | Size |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-mic-toggle></rtk-mic-toggle>
```

### With Properties

```html
<!-- component.html -->
<rtk-mic-toggle
 [meeting]="meeting"
 size="md">
</rtk-mic-toggle>
```

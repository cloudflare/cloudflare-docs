A grid component which renders only the participants in a simple grid.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `size` | `Size` | ✅ | - | Size |
| `states` | `States` | ✅ | - | States object |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-simple-grid></rtk-simple-grid>
```

### With Properties

```html
<!-- component.html -->
<rtk-simple-grid
 [meeting]="meeting"
 size="md">
</rtk-simple-grid>
```

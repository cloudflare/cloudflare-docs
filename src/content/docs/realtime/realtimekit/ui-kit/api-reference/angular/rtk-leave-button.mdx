## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `size` | `Size` | ✅ | - | Size |

```html
<!-- component.html -->
<rtk-leave-button></rtk-leave-button>
```

### With Properties

 size="md">
</rtk-leave-button>

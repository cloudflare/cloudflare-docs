A component which loads the logo from your config, or via the `logo-url` attribute.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `logoUrl` | `string` | ✅ | - | Logo URL |
| `meeting` | `Meeting` | ✅ | - | Meeting object |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-logo></rtk-logo>
```

### With Properties

```html
<!-- component.html -->
<rtk-logo
 logoUrl="example"
 [meeting]="meeting">
</rtk-logo>
```

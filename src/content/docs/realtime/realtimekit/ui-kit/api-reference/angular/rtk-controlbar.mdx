Controlbar component provides you with various designs as variants.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting |
| `size` | `Size` | ✅ | - | Size |
| `states` | `States` | ✅ | - | States |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-controlbar></rtk-controlbar>
```

### With Properties

```html
<!-- component.html -->
<rtk-controlbar
 [meeting]="meeting"
 size="md">
</rtk-controlbar>
```

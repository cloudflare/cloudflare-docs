A component which shows a participant's name.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `participant` | `Peer` | ✅ | - | Participant object |
| `size` | `Size` | ✅ | - | Size |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-name-tag></rtk-name-tag>
```

### With Properties

```html
<!-- component.html -->
<rtk-name-tag
 [meeting]="meeting"
 [participant]="participant"
 size="md">
</rtk-name-tag>
```

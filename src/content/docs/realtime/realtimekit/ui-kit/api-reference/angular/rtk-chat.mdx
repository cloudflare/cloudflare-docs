Fully featured chat component with image & file upload, emoji picker and auto-scroll.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `size` | `Size` | ✅ | - | Size |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-chat></rtk-chat>
```

### With Properties

```html
<!-- component.html -->
<rtk-chat
 [meeting]="meeting"
 size="md">
</rtk-chat>
```

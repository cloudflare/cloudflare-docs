A grid component which handles screenshares, plugins and participants.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `size` | `Size` | ✅ | - | Size |
| `states` | `States` | ✅ | - | States object |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-mixed-grid></rtk-mixed-grid>
```

### With Properties

```html
<!-- component.html -->
<rtk-mixed-grid
 [meeting]="meeting"
 size="md">
</rtk-mixed-grid>
```

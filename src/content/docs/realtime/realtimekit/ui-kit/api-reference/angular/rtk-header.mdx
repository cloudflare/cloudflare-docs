A component that houses all the header components.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting |
| `size` | `Size` | ✅ | - | Size |
| `states` | `States` | ✅ | - | States |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-header></rtk-header>
```

### With Properties

```html
<!-- component.html -->
<rtk-header
 [meeting]="meeting"
 size="md">
</rtk-header>
```

Displays the title of the meeting.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-meeting-title></rtk-meeting-title>
```

### With Properties

```html
<!-- component.html -->
<rtk-meeting-title
 [meeting]="meeting">
</rtk-meeting-title>
```

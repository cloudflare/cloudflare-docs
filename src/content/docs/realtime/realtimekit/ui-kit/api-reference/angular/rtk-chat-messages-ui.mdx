## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `selectedGroup` | `string` | ✅ | - | Selected group key |
| `selfUserId` | `string` | ✅ | - | User ID of self user |
| `size` | `Size1` | ✅ | - | Size |

## Usage Examples

### Basic Usage

```html
<!-- component.html -->
<rtk-chat-messages-ui></rtk-chat-messages-ui>
```


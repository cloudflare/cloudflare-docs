A modal for sending broadcast messages to all meeting participants.
 Allows hosts and moderators to send important announcements that
 appear prominently to all users in the meeting.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `states` | `States1` | ✅ | - | States object |

## Usage Examples

### Basic Usage

```html
<rtk-broadcast-message-modal></rtk-broadcast-message-modal>
```

### With Properties

```html
<rtk-broadcast-message-modal>
</rtk-broadcast-message-modal>
```


```html
<script>
  const el = document.querySelector("rtk-broadcast-message-modal");

  el.meeting= meeting
</script>
```

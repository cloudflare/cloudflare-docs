A number picker with increment and decrement buttons.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `size` | `Size1` | ✅ | - | Size |
| `value` | `number` | ✅ | - | Initial value |

## Usage Examples

### Basic Usage

```html
<rtk-counter></rtk-counter>
```

### With Properties

```html
<rtk-counter
 size="md">
</rtk-counter>
```


```html
<script>
  const el = document.querySelector("rtk-counter");

  el.value= 42;
</script>
```

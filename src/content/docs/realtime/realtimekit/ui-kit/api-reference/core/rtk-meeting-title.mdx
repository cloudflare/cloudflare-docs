Displays the title of the meeting.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |

## Usage Examples

### Basic Usage

```html
<rtk-meeting-title></rtk-meeting-title>
```

### With Properties

```html
<rtk-meeting-title>
</rtk-meeting-title>
```


```html
<script>
  const el = document.querySelector("rtk-meeting-title");

  el.meeting= meeting
</script>
```

A button which toggles visibility of chat.
 You need to pass the `meeting` object to it to see the unread messages count badge.
 When clicked it emits a `rtkStateUpdate` event with the data:
 ```ts
 { activeSidebar: boolean; sidebar: 'chat' }
 ```

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `size` | `Size` | ✅ | - | Size |
| `states` | `States` | ✅ | - | States object |

## Usage Examples

### Basic Usage

```html
<rtk-chat-toggle></rtk-chat-toggle>
```

### With Properties

```html
<rtk-chat-toggle
 size="md">
</rtk-chat-toggle>
```


```html
<script>
  const el = document.querySelector("rtk-chat-toggle");

  el.meeting= meeting
</script>
```

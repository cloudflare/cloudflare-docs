A button which toggles visilibility of the leave confirmation dialog.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `size` | `Size` | ✅ | - | Size |

## Usage Examples

### Basic Usage

```html
<rtk-leave-button></rtk-leave-button>
```

### With Properties

```html
<rtk-leave-button
 size="md">
</rtk-leave-button>
```


```html
<script>
  const el = document.querySelector("rtk-leave-button");

</script>
```

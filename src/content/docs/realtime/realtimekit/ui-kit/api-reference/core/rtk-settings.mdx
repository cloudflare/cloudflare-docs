A settings component to see and change your audio/video devices
 as well as see your connection quality.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `size` | `Size` | ✅ | - | Size |
| `states` | `States` | ✅ | - | States object |

## Usage Examples

### Basic Usage

```html
<rtk-settings></rtk-settings>
```

### With Properties

```html
<rtk-settings
 size="md">
</rtk-settings>
```


```html
<script>
  const el = document.querySelector("rtk-settings");

  el.meeting= meeting
</script>
```

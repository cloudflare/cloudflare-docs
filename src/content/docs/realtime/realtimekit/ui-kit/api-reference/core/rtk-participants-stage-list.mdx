A component which lists all participants, with ability to
 run privileged actions on each participant according to your permissions.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `size` | `Size` | ✅ | - | Size |
| `states` | `States1` | ✅ | - | Meeting object |

## Usage Examples

### Basic Usage

```html
<rtk-participants-stage-list></rtk-participants-stage-list>
```

### With Properties

```html
<rtk-participants-stage-list
 size="md">
</rtk-participants-stage-list>
```


```html
<script>
  const el = document.querySelector("rtk-participants-stage-list");

  el.meeting= meeting
</script>
```

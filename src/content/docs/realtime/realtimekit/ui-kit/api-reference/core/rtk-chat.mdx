Fully featured chat component with image & file upload, emoji picker and auto-scroll.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `size` | `Size` | ✅ | - | Size |

## Usage Examples

### Basic Usage

```html
<rtk-chat></rtk-chat>
```

### With Properties

```html
<rtk-chat
 size="md">
</rtk-chat>
```


```html
<script>
  const el = document.querySelector("rtk-chat");

  el.meeting= meeting
</script>
```

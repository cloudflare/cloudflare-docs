A dialog component.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `size` | `Size` | ✅ | - | Size |
| `states` | `States` | ✅ | - | States object |

## Usage Examples

### Basic Usage

```html
<rtk-dialog></rtk-dialog>
```

### With Properties

```html
<rtk-dialog
 size="md">
</rtk-dialog>
```


```html
<script>
  const el = document.querySelector("rtk-dialog");

  el.meeting= meeting
</script>
```

A component that houses all the header components.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting |
| `size` | `Size` | ✅ | - | Size |
| `states` | `States` | ✅ | - | States |

## Usage Examples

### Basic Usage

```html
<rtk-header></rtk-header>
```

### With Properties

```html
<rtk-header
 size="md">
</rtk-header>
```


```html
<script>
  const el = document.querySelector("rtk-header");

  el.meeting= meeting
</script>
```

A component which plays a participants video and allows for placement
 of components like `rtk-name-tag`, `rtk-audio-visualizer` or any other component.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `participant` | `Peer` | ✅ | - | Participant object |
| `size` | `Size` | ✅ | - | Size |
| `states` | `States` | ✅ | - | States object |

## Usage Examples

### Basic Usage

```html
<rtk-participant-tile></rtk-participant-tile>
```

### With Properties

```html
<rtk-participant-tile
 size="md">
</rtk-participant-tile>
```


```html
<script>
  const el = document.querySelector("rtk-participant-tile");

  el.meeting= meeting
  el.participant= participant
</script>
```

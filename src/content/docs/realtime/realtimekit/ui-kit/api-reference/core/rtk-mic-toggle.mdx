A button which toggles your microphone.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `size` | `Size` | ✅ | - | Size |

## Usage Examples

### Basic Usage

```html
<rtk-mic-toggle></rtk-mic-toggle>
```

### With Properties

```html
<rtk-mic-toggle
 size="md">
</rtk-mic-toggle>
```


```html
<script>
  const el = document.querySelector("rtk-mic-toggle");

  el.meeting= meeting
</script>
```

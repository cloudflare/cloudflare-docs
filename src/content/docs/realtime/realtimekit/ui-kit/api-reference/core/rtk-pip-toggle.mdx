A toggle button for enabling/disabling Picture-in-Picture mode.
 Allows users to switch the video display to a floating window that stays
 on top of other applications.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `size` | `Size1` | ✅ | - | Size |
| `states` | `States1` | ✅ | - | States object |

## Usage Examples

### Basic Usage

```html
<rtk-pip-toggle></rtk-pip-toggle>
```

### With Properties

```html
<rtk-pip-toggle
 size="md">
</rtk-pip-toggle>
```


```html
<script>
  const el = document.querySelector("rtk-pip-toggle");

  el.meeting= meeting
</script>
```

A button that follows RTK Design System.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `size` | `Size` | ✅ | - | Size |

## Usage Examples

### Basic Usage

```html
<rtk-button></rtk-button>
```

### With Properties

```html
<rtk-button
 size="md">
</rtk-button>
```


```html
<script>
  const el = document.querySelector("rtk-button");

</script>
```

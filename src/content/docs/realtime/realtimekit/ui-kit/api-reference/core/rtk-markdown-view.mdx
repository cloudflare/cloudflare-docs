## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `text` | `string` | ✅ | - | raw text to render as markdown |

## Usage Examples

### Basic Usage

```html
<rtk-markdown-view></rtk-markdown-view>
```

### With Properties

```html
<rtk-markdown-view
 text="example">
</rtk-markdown-view>
```


```html
<script>
  const el = document.querySelector("rtk-markdown-view");

</script>
```

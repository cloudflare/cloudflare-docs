A poll component.
 Shows a poll where a user can vote.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `permissions` | `RTKPermissionsPreset` | ✅ | - | Permissions Object |
| `poll` | `Poll` | ✅ | - | Poll |
| `self` | `string` | ✅ | - | Self ID |

## Usage Examples

### Basic Usage

```html
<rtk-poll></rtk-poll>
```

### With Properties

```html
<rtk-poll
 self="example">
</rtk-poll>
```


```html
<script>
  const el = document.querySelector("rtk-poll");

</script>
```

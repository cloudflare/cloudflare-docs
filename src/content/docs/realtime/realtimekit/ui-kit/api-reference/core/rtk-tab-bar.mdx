## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `activeTab` | `Tab` | ✅ | - | Active tab |
| `meeting` | `Meeting` | ✅ | - | Meeting object |
| `size` | `Size` | ✅ | - | Size |
| `states` | `States` | ✅ | - | States object |

## Usage Examples

### Basic Usage

```html
<rtk-tab-bar></rtk-tab-bar>
```

### With Properties

```html
<rtk-tab-bar
 size="md">
</rtk-tab-bar>
```


```html
<script>
  const el = document.querySelector("rtk-tab-bar");

  el.meeting= meeting
</script>
```

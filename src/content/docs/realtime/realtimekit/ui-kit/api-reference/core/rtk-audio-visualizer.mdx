An audio visualizer component which visualizes a participants audio.
 Commonly used inside `rtk-name-tag`.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `participant` | `Peer` | ✅ | - | Participant object |
| `size` | `Size` | ✅ | - | Size |

## Usage Examples

### Basic Usage

```html
<rtk-audio-visualizer></rtk-audio-visualizer>
```

### With Properties

```html
<rtk-audio-visualizer
 size="md">
</rtk-audio-visualizer>
```


```html
<script>
  const el = document.querySelector("rtk-audio-visualizer");

  el.participant= participant
</script>
```

## Prerequisites

To integrate RealtimeKit in your application, you must have a [Cloudflare account](https://dash.cloudflare.com).

## Create an API token

Use an API token with **Realtime Admin** access scoped to your account for the Cloudflare API requests in this guide. Keep this token on your backend. Participants join meetings with separate participant auth tokens, created in [Add participants](#add-participants).

### Create the token manually

<Tabs>
<TabItem label="Dashboard" class="space-y-4">

<Steps>
1. Open **API Tokens** in your Cloudflare profile and select **Create Token**.

   <DashButton url="/profile/api-tokens" />

2. Select **Realtime** > **Realtime Admin** and scope the token to your account.
3. Configure [access policies and restrictions](/fundamentals/api/reference/permissions/), then create the token and save it in backend secret storage.
</Steps>

For the full procedure, refer to [Create API token](/fundamentals/api/get-started/create-token/).

</TabItem>
<TabItem label="cf CLI" class="space-y-4">

[Install `cf`](/cf/get-started/), then authenticate with the starter credential described in [Create tokens via API](/fundamentals/api/how-to/create-via-api/#generating-the-initial-token). Use the **Create additional tokens** template for user-token creation. Keep this starter credential separate from the RealtimeKit backend token you create.

Find the current **Realtime Admin** permission ID and inspect the create request:

```sh
cf user tokens permission-groups list
cf schema user tokens create
```

Create an account-scoped user token with that permission. Save its one-time secret in backend secret storage. Verify that the token can list RealtimeKit apps.

</TabItem>
<TabItem label="API" class="space-y-4">

Follow [Create tokens via API](/fundamentals/api/how-to/create-via-api/) to create a user-owned token. Scope its policy to your account with the **Realtime Admin** permission, then verify that it can list RealtimeKit apps.

</TabItem>
</Tabs>

## Create a meeting

Use our [Meetings API](/api/resources/realtime_kit/subresources/meetings/methods/create/) to create a meeting. We will use the **ID from the response** in subsequent steps.

```bash
curl --location 'https://api.cloudflare.com/client/v4/accounts/<account_id>/realtime/kit/<app_id>/meetings' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer <api_token>' \
--data '{"title": "My First Cloudflare RealtimeKit meeting"}'
```

## Add participants

A participant is added to a meeting using the `Meeting ID` created above and selecting a `Preset Name` from the available options.

The response includes the participant's auth token in `data.token`. Pass this value to the Client SDK as `authToken` to join the meeting. Deliver it only to that participant's frontend session. Keep the Cloudflare API token used to create participants on your backend.

```bash
curl --location 'https://api.cloudflare.com/client/v4/accounts/<account_id>/realtime/kit/<app_id>/meetings/<meeting_id>/participants' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer <api_token>' \
--data '{
  "name": "Mary Sue",
  "preset_name": "<preset_name>",
  "custom_participant_id": "<uuid_of_the_user_in_your_system>"
}'
```

Learn more about adding participants in the [API reference](/api/resources/realtime_kit/subresources/meetings/methods/add_participant/).

## Frontend integration

You can now add the RealtimeKit Client SDK to your application.

<RTKCodeSnippet id="web-react">
Inside your react application, add the following code:
```ts

import { useEffect } from "react";
import {
	useRealtimeKitClient,
	useRealtimeKitMeeting,
	RealtimeKitProvider,
} from "@cloudflare/realtimekit-react";
import { RtkMeeting } from "@cloudflare/realtimekit-react-ui";

export default function App() {
  const [meeting, initMeeting] = useRealtimeKitClient();

useEffect(() => {
initMeeting({ authToken: '<auth-token>' });
}, []);

return (

<RealtimeKitProvider value={meeting}>
	<MyMeetingUI />
</RealtimeKitProvider>
); }

export default function MyMeetingUI() {
  const { meeting } = useRealtimeKitMeeting();
  return (
    <RtkMeeting mode="fill" meeting={meeting} showSetupScreen={true} />
  );

}

````
Replace `<auth-token>` with the authToken obtained from the previous step.

Run the application and navigate to the meeting page to see the RealtimeKit Client SDK in action.
```bash
npm run dev
````

_Optional:_ If you are using our ready-made template, run the following command to start the application:

```bash
npm i -g vite && npm run dev
```

Open the app in your browser. To join the meeting, append your auth token to the preview URL:

```bash
http://localhost:5173?authToken=<auth_token>
```

</RTKCodeSnippet>

<RTKCodeSnippet id="web-web-components">
Inside your html application, add the following code:
```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta http-equiv="X-UA-Compatible" content="IE=edge" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Default Meeting UI | RealtimeKit</title>

    <!-- Import helper to load UI Kit components -->
    <script type="module">
      import { defineCustomElements } from 'https://cdn.jsdelivr.net/npm/@cloudflare/realtimekit-ui@latest/loader/index.es2017.js';
      defineCustomElements();
    </script>

    <!-- Import RealtimeKit Core via CDN -->
    <script src="https://cdn.jsdelivr.net/npm/@cloudflare/realtimekit@latest/dist/browser.js"></script>

  </head>
  <body>
    <rtk-meeting id="my-meeting" show-setup-screen="true" />

    <script>
      const searchParams = new URL(window.location.href).searchParams;

      const authToken = searchParams.get('authToken');

      if (!authToken) {
        alert(
          "An authToken wasn't passed, please pass an authToken in the URL query to join a meeting."
        );
      }

      // Initialize a meeting
      RealtimeKitClient.init({
        authToken,
      }).then((meeting) => {
        document.getElementById('my-meeting').meeting = meeting;
      });
    </script>

  </body>
</html>

````

    	class AppComponent {
    	title = 'MyProject';
    	@ViewChild('myid') meetingComponent: RtkMeeting;
    	rtkMeeting: RealtimeKitClient;

    		const meeting = await RealtimeKitClient.init({
    		authToken: '<auth-token>',
    		});
    		meeting.join();
    		this.rtkMeeting = meeting;
    		if (this.meetingComponent) this.meetingComponent.meeting = meeting;
    	}
    	}

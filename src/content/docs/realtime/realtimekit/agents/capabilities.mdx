A human participant joins a meeting with the [RealtimeKit SDKs](/realtime/realtimekit/humans/sdk-selection/). An agent joins with the [Agent WebSocket](/realtime/realtimekit/agents/get-started/). The table compares what each can do once it is in the meeting.

:::note
Agents can only receive meeting events today. Sending is planned, and those capabilities are marked explicitly below.
:::

| Capability                                                                                                  | Human | Agent        |
| ----------------------------------------------------------------------------------------------------------- | ----- | ------------ |
| Receive live transcripts                                                                                    | ✅    | ✅           |
| Receive participant joins and leaves                                                                        | ✅    | ✅           |
| Receive [broadcasts](/realtime/realtimekit/collaboration/message-broadcast/)                                | ✅    | ✅           |
| Send broadcasts                                                                                             | ✅    | No (Planned) |
| Send or receive audio, video, and screen share                                                              | ✅    | No (Planned) |
| Send or receive chat and polls                                                                              | ✅    | No (Planned) |
| Use plugins and the [meeting key-value store](/realtime/realtimekit/collaboration/meeting-key-value-store/) | ✅    | No           |
| Meeting controls, such as stage, removing participants, and recording                                       | ✅    | No           |

For what the agent receives, refer to [Events](/realtime/realtimekit/agents/events/).

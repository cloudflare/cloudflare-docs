RealtimeKit retains data for the following periods:

| Data type                       | Retention period                                                                                                                                                                                                                                                                                                  |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Meeting and participant records | Indefinitely                                                                                                                                                                                                                                                                                                      |
| Meeting chat                    | 7 days. If [`persist_chat`](</api/resources/realtime_kit/subresources/meetings/methods/create/#(resource)%20realtime_kit.meetings%20%3E%20(method)%20create%20%3E%20(params)%200%20%3E%20(param)%20persist_chat%20%3E%20(schema)>) is enabled when you create the meeting, RealtimeKit retains chat indefinitely. |
| Track recordings                | 7 days                                                                                                                                                                                                                                                                                                            |
| Composite recordings            | 7 days                                                                                                                                                                                                                                                                                                            |
| Transcripts                     | 7 days                                                                                                                                                                                                                                                                                                            |
| Call analytics                  | 3 months                                                                                                                                                                                                                                                                                                          |
| SDK logs                        | 1 month                                                                                                                                                                                                                                                                                                           |
| Webhook logs                    | 1 month                                                                                                                                                                                                                                                                                                           |

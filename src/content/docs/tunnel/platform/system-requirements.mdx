`cloudflared` is lightweight enough to run on a Raspberry Pi or a data center server. Tunnel throughput is primarily limited by the number of ports configured in system software, not hardware.

## Baseline recommendations

Run a `cloudflared` [replica](/tunnel/configuration/#replicas-and-high-availability) on two dedicated hosts per location with a minimum of 4 GB RAM and 4 CPU cores. Allocate 50,000 ports per host.

## Throughput

On a host that meets the baseline recommendations, one `cloudflared` replica typically carries:

- About 750 Mbps of public Internet traffic to published applications.
- 350 to 500 Mbps of private traffic from Cloudflare One Client users.

Use these figures for planning. They are not guarantees, because your traffic and network path also affect throughput.

A host with fewer resources delivers less throughput. At this time, a host with more resources does not raise one replica above these values. To add capacity, run more replicas on identical hosts. For sustained throughput above 1 Gbps at a site, use [Cloudflare WAN](/cloudflare-one/networks/connectors/cloudflare-wan/).

To compare throughput across connectors, refer to [Connector selection](/cloudflare-one/networks/connectors/choose-a-connector/#throughput).

## Capacity calculator

To estimate tunnel capacity requirements for your deployment:
1. Use the [metrics endpoint](/tunnel/observability/#cloudflared-metrics) to measure `cloudflared_tcp_total_sessions` and `cloudflared_udp_total_sessions`.
2. Compute the average **TCP requests per second** by dividing `cloudflared_tcp_total_sessions` by total time.
3. Compute the average **Non-DNS UDP requests per second** by dividing `cloudflared_udp_total_sessions` by total time.
4. Input **TCP requests per second** and **Non-DNS UDP requests per second** into the calculator below. (You can leave **Private DNS requests per second** as `0` unless you are using the tunnel for [private network access](/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/tunnel-availability/system-requirements/).)

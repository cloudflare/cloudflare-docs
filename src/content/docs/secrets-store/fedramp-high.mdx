Secrets Store is available to accounts in Cloudflare's [FedRAMP High](https://www.cloudflare.com/cloudflare-for-government/) environment. It uses the same API routes, Workers binding, and error codes as the standard environment, with the differences listed on this page.

## Data location

For accounts in the FedRAMP High environment, Secrets Store runs only in FedRAMP High data centers, and secrets and their metadata are stored within the FedRAMP High boundary. Secret values are encrypted with AES-256-GCM using FIPS 140-3 validated cryptographic modules.

## Feature availability

| Feature                                                                  | Standard environment | FedRAMP High environment |
| ------------------------------------------------------------------------ | -------------------- | ------------------------ |
| [Secrets Store API](/api/resources/secrets_store/)                       | Yes                  | Yes                      |
| [Wrangler commands](/workers/wrangler/commands/secrets-store/)           | Yes                  | Yes                      |
| [Workers binding](/secrets-store/integrations/workers/)                  | Yes                  | Yes                      |
| Dashboard                                                                | Yes                  | No                       |
| [AI Gateway integration](/ai-gateway/configuration/bring-your-own-keys/) | Yes                  | No                       |

## Manage secrets

The dashboard does not support Secrets Store in the FedRAMP High environment. Use the API or Wrangler to create and manage secrets, and to add Secrets Store bindings to your Workers.

### Use the API

Send Secrets Store API requests to the FedRAMP High API endpoint, `https://api.fed.cloudflare.com/client/v4`, instead of `https://api.cloudflare.com/client/v4`. The request paths and bodies are the same as in the [Secrets Store API](/api/resources/secrets_store/) reference.

### Use Wrangler

Set the `CLOUDFLARE_COMPLIANCE_REGION` environment variable to `fedramp_high` so that Wrangler sends requests to the FedRAMP High environment:

```sh
CLOUDFLARE_COMPLIANCE_REGION=fedramp_high npx wrangler secrets-store secret create <STORE_ID> --name MY_SECRET_NAME --scopes workers --remote
```

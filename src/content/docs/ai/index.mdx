## Features

- **Unified model catalog** - Browse all available models in one place
- **Single API** - Use `env.AI.run()` for any model, regardless of where it runs
- **Automatic routing** - Model IDs determine routing (`@cf/` for Workers AI, `provider/model` for AI Gateway)

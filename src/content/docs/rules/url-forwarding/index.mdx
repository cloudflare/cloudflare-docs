A redirect sends visitors from one URL to another URL with an HTTP status code, such as `301`. Redirects are also known as URL forwarding. Single Redirects and Bulk Redirects replace the _Forwarding URL_ setting in Page Rules.

In the Cloudflare dashboard, Single Redirects appear as **Redirect Rules**.

## Choose a redirect product

Use the following table to choose a redirect product for your use case:

| Goal                                                                        | Product                              | Refer to                                                                                                                                                                                        |
| --------------------------------------------------------------------------- | ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| Send every page of an old domain to the homepage of a new domain            | Single Redirects                     | [Redirect requests for a domain to a new domain](/rules/url-forwarding/examples/redirect-all-different-domain-root/)                                                                    |

## Redirect products

- [**Single Redirects**](/rules/url-forwarding/single-redirects/): Static or dynamic redirects for one zone (a domain you added to Cloudflare, including its subdomains). With a [wildcard pattern](/rules/url-forwarding/single-redirects/settings/#wildcard-url-redirect), one rule can cover thousands of URLs without functions or regular expressions. You can also match requests by country, device, header, or cookie with a [custom filter expression](/ruleset-engine/rules-language/expressions/edit-expressions/).

- [**Bulk Redirects**](/rules/url-forwarding/bulk-redirects/): Lists of source and target URLs at the account level, which can apply across domains in your account. Each URL redirect maps one source URL to one target URL. Bulk Redirects do not support wildcards or regular expressions, but [URL redirect parameters](/rules/url-forwarding/bulk-redirects/reference/parameters/), such as **Subpath matching** and **Include subdomains**, control how source URLs match.

- [**Snippets**](/rules/snippets/): Short pieces of JavaScript code for complex redirect logic. Refer to the [Snippets examples](/rules/snippets/examples/) to get started.

## Redirect Rules templates

<Render file="rules-templates" product="rules" />

Redirect templates include **Redirect from HTTP to HTTPS**, **Redirect from WWW to root**, and **Redirect from root to WWW**. The **Redirect from HTTP to HTTPS** template uses the request URL `http://*` and the target URL `https://${1}`.

The **Redirect from WWW to root** and **Redirect from root to WWW** templates match HTTPS requests only. To also redirect HTTP requests, turn on [Always Use HTTPS](/ssl/edge-certificates/additional-options/always-use-https/), or change the request URL to start with `http*://` and update the wildcard references in the target URL. Refer to [How wildcard references are numbered](/rules/url-forwarding/single-redirects/settings/#how-wildcard-references-are-numbered).

## Availability

Single Redirects and Bulk Redirects are available on all Cloudflare plans. The exact quotas and features depend on your plan.

### Bulk Redirects

|  | Free | Pro | Business | Enterprise |
| - | - | - | - | - |
| Availability | Yes | Yes | Yes | Yes |
| Bulk Redirect Rules | 15 | 15 | 15 | 50 |
| Bulk Redirect Lists | 5 | 5 | 5 | 25 |
| URL redirects across lists | 10,000 | 25,000 | 50,000 | 1,000,000 |

For _URL redirects across lists_, this table provides the default quota for the Enterprise plan. Bulk Redirects supports several million URL redirects — to get more redirects, contact your account team.

Bulk Redirects features and quotas are per account and they depend on the highest Cloudflare plan on your account.

### Single Redirects

|  | Free | Pro | Business | Enterprise |
| - | - | - | - | - |
| Availability | Yes | Yes | Yes | Yes |
| Number of rules | 10 | 25 | 50 | 300 |
| Wildcard support | Yes | Yes | Yes | Yes |
| Regex support | No | No | Yes | Yes |

Single Redirects features and quotas are per zone and depend on the zone plan.

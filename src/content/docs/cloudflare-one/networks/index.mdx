Cloudflare One connects your private networks to Cloudflare's global network. Traffic arriving through a connector follows the same policies as user traffic.

To compare the available on-ramps, refer to [connectivity options](/cloudflare-one/networks/connectivity-options/). Four building blocks define how your private network reaches Cloudflare:

- [Connectors](/cloudflare-one/networks/connectors/) attach a host, private network, or branch site to Cloudflare. Choose Cloudflare Tunnel, Cloudflare Mesh, or Cloudflare WAN based on what you connect.
- [Routes](/cloudflare-one/networks/routes/) map IP addresses, hostnames, and published applications to a connector.
- [Virtual networks](/cloudflare-one/networks/virtual-networks/) separate routing domains so that overlapping private IP ranges can coexist.
- [Resolvers and proxies](/cloudflare-one/networks/resolvers-and-proxies/) control how internal DNS queries resolve and how proxied traffic reaches Cloudflare.

Use these guides to configure Cloud Workload Security resources:

- [Configure policies](/cloudflare-one/cloud-workload-security/guides/configure-policies/): define workloads, write policies, and attach policy sets to deployments.
- [Manage traffic scope](/cloudflare-one/cloud-workload-security/guides/manage-traffic-scope/): configure domain access control lists and manage Basic Auth secrets.
- [Manage policy reference resources](/cloudflare-one/cloud-workload-security/guides/policy-reference/): create reusable Rego modules, metadata, and tenant structures.

To understand how CWS validates requests, refer to [Request Validation](/cloudflare-one/cloud-workload-security/concepts/request-validation/). To connect your first proxy and test a policy, follow [Get started](/cloudflare-one/cloud-workload-security/get-started/).

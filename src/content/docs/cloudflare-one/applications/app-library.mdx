The Zero Trust Application Library consolidates applications under a single home in the dashboard, gives users visibility into and control over Gateway Application definitions, and provides a home for long-term management of other application concepts.

The App Library consolidates applications between [Gateway](/cloudflare-one/policies/gateway/), [Access](/cloudflare-one/policies/access/), and [Cloud Access Security Broker (CASB)](/cloudflare-one/applications/casb/).

To access the Application Library, in [Zero Trust](https://one.dash.cloudflare.com/), go to **My team** > **App Library**.

Your Cloudflare One organization is made up of the users you enroll, the devices they connect from, and the applications they reach. Policies reference these objects, so review them before you write rules.

- [Users](/cloudflare-one/team-and-resources/users/) covers enrolling members, reviewing their sessions, and revoking access.
- [Devices](/cloudflare-one/team-and-resources/devices/) covers deploying the Cloudflare One Client, so devices send DNS queries to Cloudflare or proxy all traffic through Cloudflare's network.
- [Application Library](/cloudflare-one/team-and-resources/app-library/) shows every SaaS application Cloudflare One detects, along with its hostnames and which products act on it.

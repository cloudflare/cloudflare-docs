## Integration prerequisites

- A Zoom account
- Account Owner or Admin role in the Zoom account
- A Cloudflare Zero Trust account (free plan supports up to 2 integrations)

## Adding the app

The Zoom integration connects through Cloudflare's pre-built OAuth application. No manual app setup in Zoom is required.

<Steps>
1. Log in to [Cloudflare One](https://one.dash.cloudflare.com/) and go to **Cloud & SaaS findings** > **Integrations**.
2. Select **Connect an integration** or **Add integration**.
3. Browse the available integrations and select **Zoom**.
4. Follow the step-by-step integration instructions in the UI. You will be redirected to Zoom to authorize the connection. The authorizing user must have an Account Owner or Admin role so that all required API scopes can be granted.
5. To run your first scan, select **Save integration**.
</Steps>

After the first scan, CASB will automatically scan your Zoom account on a frequent basis to keep up with any changes.

If you encounter issues during setup, refer to [Troubleshoot CASB integrations](/cloudflare-one/cloud-and-saas-findings/troubleshoot-casb/).

## Usage

### What CASB scans for

The Zoom integration scans your Zoom account for security misconfigurations and data risks across account settings, user accounts, meetings, and recordings. Findings are grouped by category and ordered by severity level.

Once CASB detects at least one finding, you can view and manage your findings in Cloudflare One under **Cloud & SaaS findings** > **Findings**.

### Plan tier notes

The following optional Zoom API scopes require a specific Zoom plan tier to produce findings:

- Dashboard scopes (`dashboard:read:*`) — require a Zoom Business or higher plan
- Cloud Recording scopes (`cloud_recording:read:*`) — require a Zoom Pro or higher plan
- Master Account scopes (`account:read:*:master`) — require a Zoom Enterprise ISV or reseller Master Account

If your Zoom account does not have the required tier for an optional scope, those scopes will produce no findings. This is expected behavior, not an error.

## Integration permissions

For the Zoom integration to function, Cloudflare CASB requires the following Zoom API scopes:

- `account:read:sub_account:admin`
- `account:read:settings:admin`
- `account:read:lock_settings:admin`
- `dashboard:read:list_meetings:admin`
- `dashboard:read:meeting:admin`
- `dashboard:read:list_meeting_participants_qos:admin`
- `dashboard:read:meeting_quality_score:admin`
- `group:read:list_groups:admin`
- `group:read:group:admin`
- `meeting:read:list_meetings:admin`
- `meeting:read:meeting:admin`
- `cloud_recording:read:list_user_recordings:admin`
- `cloud_recording:read:list_recording_files:admin`
- `cloud_recording:read:recording_settings:admin`
- `report:read:list_users:admin`
- `role:read:list_roles:admin`
- `role:read:role:admin`
- `user:read:list_users:admin`
- `user:read:user:admin`
- `user:read:settings:admin`

If the integration is installed on a Zoom Master Account, the following additional scopes are required:

- `account:read:settings:master`
- `account:read:lock_settings:master`
- `account:read:list_sub_accounts:master`
- `account:read:sub_account:master`

These permissions follow the principle of least privilege to ensure that only the minimum required access is granted. To learn more about each scope, refer to the [Zoom API scopes reference](https://developers.zoom.us/docs/api/).

## Removing the app

Removing the Zoom integration is a two-part process. Both steps are required to fully disconnect Cloudflare CASB from your Zoom account.

### Step 1: Remove from Zoom Marketplace

<Steps>
1. Log in to the [Zoom Marketplace](https://marketplace.zoom.us/) with your Zoom account.
2. Go to **Manage** > **Added Apps**.
3. Find the **Cloudflare CASB** app and select **Remove**.
4. Confirm removal.
</Steps>

This revokes Zoom's OAuth grant and prevents Cloudflare from making further API calls to your Zoom account.

### Step 2: Delete from Cloudflare One

<Steps>
1. Log in to [Cloudflare One](https://one.dash.cloudflare.com/) and go to **Cloud & SaaS findings** > **Integrations**.
2. Find the Zoom integration and select **Configure**.
3. Select **Disenroll**.
</Steps>

:::caution
Deleting an integration removes all OAuth data stored in Cloudflare. This action cannot be undone. To resume scanning, you will need to add the integration again. Deletion also permanently removes all CASB scan data and findings associated with this integration.
:::

### Data handling

Removing the Cloudflare CASB app from the Zoom Marketplace does not automatically delete the integration or its stored data from Cloudflare. Similarly, deleting the integration from the Cloudflare One dashboard does not revoke the OAuth grant in Zoom. You must complete both steps to fully remove the connection and stop data retention on Cloudflare's side.

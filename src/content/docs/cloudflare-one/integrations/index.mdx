Cloudflare One works with the identity, security, and SaaS tools you already run. Each integration supplies signals that your policies can evaluate.

- [Identity providers](/cloudflare-one/integrations/identity-providers/) authenticate your users. You can connect several providers at once for partners and contractors, or send a one-time PIN to approved email addresses.
- [Cloud and SaaS integrations](/cloudflare-one/integrations/cloud-and-saas/) let [Cloudflare CASB](/cloudflare-one/cloud-and-saas-findings/) scan your cloud environments and SaaS applications for posture and data findings.
- [Service providers](/cloudflare-one/integrations/service-providers/) send device posture data from third-party endpoint security vendors to the Cloudflare One Client.

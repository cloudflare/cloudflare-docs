The Data security analytics dashboard provides a dashboard that reports security issues and sensitive data found within your SaaS applications, cloud environments, and HTTP traffic.

To view the Data security analytics dashboard:

1. Log into [Zero Trust](https://one.dash.cloudflare.com).
2. Go to **Analytics** > **Dashboards**.
3. Select **Data security analytics**.

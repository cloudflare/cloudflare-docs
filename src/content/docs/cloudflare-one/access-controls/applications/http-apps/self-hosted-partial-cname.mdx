If your domain's DNS is managed by another provider and you do not want to transfer your nameservers to Cloudflare, you can still use Cloudflare Access to protect your applications. This is called a [partial (`CNAME`) setup](/dns/zone-setups/partial-setup/). Because Cloudflare does not control your DNS in this configuration, you must manually create DNS records at your external provider.

If your domain uses a [full setup](/dns/zone-setups/full-setup/), refer to [Publish a self-hosted application to the Internet](/cloudflare-one/access-controls/applications/http-apps/self-hosted-public-app/) instead.

## Prerequisites

- An active domain on Cloudflare using a [partial (`CNAME`) setup](/dns/zone-setups/partial-setup/)
- A [Business or Enterprise plan](/dns/zone-setups/partial-setup/#availability)
- [`cloudflared`](/cloudflare-one/networks/connectors/cloudflare-tunnel/get-started/tunnel-useful-terms/#connector) installed on your origin server

## 2. Create a Cloudflare Tunnel

[Set up a Cloudflare Tunnel](/cloudflare-one/networks/connectors/cloudflare-tunnel/get-started/create-remote-tunnel/) to connect your internal application to Cloudflare. Only users who match your Access policies will be granted access.

:::note
Create your Access application before setting up the tunnel route. If you do not have an Access application in place, the published application will be available to anyone on the Internet.
:::

## 3. Add a public hostname to the tunnel

In the tunnel configuration, [add a public hostname](/cloudflare-one/networks/connectors/cloudflare-tunnel/routing-to-tunnel/) that maps to your internal service. For example, set the public hostname to `app.example.com` and point it to `http://localhost:8080`.

## 4. Create a CNAME record at your DNS provider

In a [full DNS setup](/dns/zone-setups/full-setup/), Cloudflare automatically creates DNS records when you add a public hostname to a tunnel. In a partial (`CNAME`) setup, Cloudflare does not manage your DNS zone, so it cannot create records on your behalf. You must add a CNAME record at the DNS provider that hosts your domain (your authoritative DNS provider).

At your external DNS provider, create a CNAME record with the following values:

- **Name**: The hostname you configured in the tunnel (for example, `app.example.com`)
- **Target**: `<HOSTNAME>.cdn.cloudflare.net` (for example, `app.example.com.cdn.cloudflare.net`)

:::note
The zone apex (for example, `example.com`) cannot use a CNAME record due to [DNS specification restrictions](https://datatracker.ietf.org/doc/html/rfc1912#section-2.4). Some DNS providers work around this with [CNAME flattening](/dns/zone-setups/partial-setup/#cname-flattening), which resolves the CNAME at the provider level. If your provider does not support CNAME flattening, use a subdomain instead.
:::

If you do not have an integration:

1. In [Cloudflare dashboard](https://dash.cloudflare.com/), go to **Zero Trust** > **Email security**.

   <DashButton url="/?to=/:account/email-security" zeroTrust />

2. Go to **Settings** > **Domain management** > **Domains** > select **View**.
3. Locate your domain, select the three dots > Select **Associate an integration**.
4. Select **Connect an integration**. You will then be redirected to the **Add an integration** page.
5. Select **Google Workspace CASB+EMAIL** > **Select Integration**.
6. Once you select an integration, you can [enable Gmail BCC integration](/cloudflare-one/email-security/setup/post-delivery-deployment/bcc-journaling/bcc-setup/gmail-bcc-setup/enable-gmail-integration/#enable-gmail-bcc-integration).

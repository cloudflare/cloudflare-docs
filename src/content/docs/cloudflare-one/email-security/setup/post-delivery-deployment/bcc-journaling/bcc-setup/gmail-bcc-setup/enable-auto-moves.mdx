If you do not have an integration:

1. Go to **Settings** > **Domain management** > **Domains** > select **View**.
2. Locate your domain, select the three dots > Select **Associate an integration**.
3. Select **Connect an integration**. You will then be redirected to the Add an integration page, where you will have to select **Google Workspace CASB+EMAIL** > **Select Integration**.
4. [Enable Gmail BCC integration](/cloudflare-one/email-security/setup/post-delivery-deployment/bcc-journaling/bcc-setup/gmail-bcc-setup/enable-gmail-integration/#enable-gmail-bcc-integration).

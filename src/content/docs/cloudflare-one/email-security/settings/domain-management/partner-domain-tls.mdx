To add additional TLS (Transport Layer Security) requirements for emails coming from certain domains, you can enforce higher levels of SSL/TLS inspection. If TLS is required, mail without TLS from the specified domain will be dropped.

:::note
To enforce TLS across all emails, you will need to enforce TLS requirements when you are onboarding your domain. To only enforce TLS for specific emails, you can do so by going to **Settings** > **Partner domain TLS** > **Add a domain**.
:::

## Set up partner domain TLS

To set up a partner domain:

1. Log in to [Cloudflare One](https://one.dash.cloudflare.com/) and select **Email security**.
2. Select **Settings** > **Partner domain TLS** > **View**.
3. Select **Add a domain**.
4. Enter a valid domain name. You can also exclude subdomains by selecting **Add exclude**.
5. (Optional) Add an optional note to describe your rule(s).
6. Select **Save**.

## Manage partner domains

### Edit a partner domain

To edit a partner domain, select the three dots > **Edit**.

### Delete a partner domain

To delete a partner domain, select the three dots > **Delete**.

## TLS requirements

When you configure partner domain TLS, the following requirements apply:

- **TLS version**: Minimum TLS version required for email communication
- **Certificate validation**: Ensures valid SSL/TLS certificates are used
- **Encryption standards**: Enforces specific encryption protocols
- **Connection security**: Verifies secure connection establishment

## Benefits of partner domain TLS

Implementing partner domain TLS provides several security benefits:

- **Enhanced security**: Ensures encrypted communication with trusted partners
- **Data protection**: Protects sensitive email content during transmission
- **Compliance**: Helps meet regulatory requirements for secure communication
- **Trust verification**: Validates the identity of email senders through certificate verification

## Troubleshooting

If you encounter issues with partner domain TLS:

- Verify that the partner domain supports the required TLS version
- Check that SSL/TLS certificates are valid and not expired
- Ensure firewall rules allow TLS connections on the required ports
- Contact your email administrator if connection issues persist

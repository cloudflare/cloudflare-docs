To call AI Gateway from the [AI SDK](https://ai-sdk.dev/), use `createAI` from `agents/models/ai-sdk`. It calls models from the [model catalog](/ai/models/), [dynamic routes](/ai-gateway/features/routing/dynamic-routing/), and a vendor's own AI SDK models through your gateway. This page covers the AI Gateway features. For the full reference, refer to [AI SDK](/agents/models/ai-sdk/).

The `ai-gateway-provider` package is deprecated. Use `createAI` instead.

## Installation

Install the Agents SDK and the AI SDK. `createAI` needs `ai@^7` and `@ai-sdk/provider@^4`:

<PackageManagers pkg="agents ai @ai-sdk/provider" />

In a Worker, add the `AI` binding to your Wrangler configuration:

<WranglerConfig>

```jsonc
{
	"ai": {
		"binding": "AI",
	},
}
```

</WranglerConfig>

## Call a catalog model

Pass an `<author>/<model>` id from the [model catalog](/ai/models/). You do not need a vendor package or a vendor key. AI Gateway bills the request through [Unified Billing](/ai-gateway/features/unified-billing/), or uses a [key stored on the gateway](/ai-gateway/configuration/bring-your-own-keys/):

<TypeScriptExample>

```ts
import { createAI } from "agents/models/ai-sdk";
import { streamText } from "ai";

export default {
	async fetch(request: Request, env: Env) {
		const ai = createAI({ binding: env.AI, id: "my-gateway" });

		const result = streamText({
			model: ai("anthropic/claude-opus-5.5"),
			messages: [{ role: "user", content: "Write a short story" }],
		});

		return result.toTextStreamResponse();
	},
};
```

</TypeScriptExample>

Use the catalog's spelling of the id, such as `anthropic/claude-opus-5.5` or `openai/gpt-5.5`. `id` sets the gateway and defaults to `default`. A [dynamic route](/ai-gateway/features/routing/dynamic-routing/) on that gateway is `dynamic/<route>`, for example `ai("dynamic/support")`.

## Call a vendor's model object

Pass a model from the vendor's own AI SDK package. The request goes unchanged to the vendor's [provider-native endpoint](/ai-gateway/usage/providers/) on your gateway. AI Gateway holds the credential, so the vendor's `apiKey` is a placeholder:

```ts
import { createAnthropic } from "@ai-sdk/anthropic";
import { createAI } from "agents/models/ai-sdk";

const ai = createAI({ binding: env.AI, id: "my-gateway" });
const anthropic = createAnthropic({ apiKey: "cloudflare" });

const model = ai(anthropic("claude-opus-5-5"));
```

Use the vendor's own model id here, such as `claude-opus-5-5`. To send a key you hold instead, refer to [Unified billing and BYOK](/agents/models/ai-sdk/#unified-billing-and-byok).

## Fall back to another model

`fallback` lists models to try in order if the primary model fails before it produces any output. Mix catalog ids, dynamic routes, Workers AI ids, and model objects:

```ts
const model = ai(anthropic("claude-opus-5-5"), {
	fallback: ["openai/gpt-5.5", "@cf/zai-org/glm-4.7-flash"],
});
```

## Set gateway options

Set [caching](/ai-gateway/features/caching/), logging, metadata, timeouts, and retries on the provider, on a model, or per call under `providerOptions.cloudflare`:

```ts
const ai = createAI({
	binding: env.AI,
	id: "my-gateway",
	cacheTtl: 60,
	metadata: { app: "support-bot" },
});

await generateText({
	model: ai("openai/gpt-5.5"),
	prompt: "Summarize this ticket",
	providerOptions: {
		cloudflare: { skipCache: true, metadata: { userId: "u_123" } },
	},
});
```

For every option, refer to [Set options](/agents/models/ai-sdk/#set-options).

## Use an account id and API token

To use a gateway in another account, or to call from outside a Worker, pass `accountId` and `apiToken` instead of `binding`:

```ts
const ai = createAI({
	accountId: "<ACCOUNT_ID>",
	apiToken: env.CLOUDFLARE_API_TOKEN,
	gateway: "my-gateway",
});
```

The call forms and options are the same. [Create an API token](/fundamentals/api/get-started/create-token/) with the **Workers AI Read** permission for model ids and **AI Gateway Run** for model objects.

[Android Studio](https://developer.android.com/studio/gemini/use-a-remote-model) supports third-party remote model providers for AI chat and agent features. Point a remote provider at AI Gateway's [OpenAI-compatible endpoint](/ai-gateway/usage/chat-completion/) to route requests through your gateway. Authenticate with a Cloudflare API token and use [Unified Billing](/ai-gateway/features/unified-billing/) or a stored [provider key](/ai-gateway/configuration/bring-your-own-keys/) to authenticate with the model provider.

This configuration applies to Android Studio's built-in AI assistant. It does not configure the GitHub Copilot plugin.

## Prerequisites

Before you start, you need:

- Your Cloudflare account ID. To find it, refer to [Find your account and zone IDs](/fundamentals/account/find-account-and-zone-ids/).
- An [authenticated AI Gateway](/ai-gateway/configuration/authentication/). You can use your account's `default` gateway or [create a gateway](/ai-gateway/get-started/) and use its slug.
- A [Cloudflare API token](/fundamentals/api/get-started/create-token/) with **Account** > **AI Gateway** > **Run** permission.
- [Unified Billing credits](/ai-gateway/features/unified-billing/#load-credits) or a stored [provider key](/ai-gateway/configuration/bring-your-own-keys/) for the models you select.
- [Android Studio](https://developer.android.com/studio) installed with support for third-party remote model providers.

## Configure the remote provider

<Steps>

1. In Android Studio settings, go to **Tools** > **AI** > **Model Providers**.

2. Select **Add** > **Third-Party Remote Provider**.

3. For **Description**, enter a name such as `Cloudflare AI Gateway`.

4. For **URL**, enter the following value. Replace `<ACCOUNT_ID>` and `<GATEWAY_ID>` with your Cloudflare account ID and gateway slug. You can use `default` as the gateway slug.

   ```txt
   https://gateway.ai.cloudflare.com/v1/<ACCOUNT_ID>/<GATEWAY_ID>/compat
   ```

   Enter the base URL without `/chat/completions`. Android Studio retrieves the model list before you select a model.

   :::note
   The `/compat` endpoint is deprecated for standard single-model calls. This integration uses it because Android Studio retrieves a model list during setup. The recommended [REST API](/ai-gateway/usage/rest-api/) does not provide a `/v1/models` endpoint.
   :::

5. For **API key**, enter your Cloudflare API token.

6. Select **Refresh** to retrieve the model list. Select the models you want to use, then select **OK** to save your settings.

   Choose models supported by your Unified Billing credits or stored provider keys. A model appearing in the list does not mean you have configured credentials for it.

7. Open the AI chat window. Use the model picker to select a model from your remote provider, then send a prompt.

</Steps>

Some specialized Android Studio AI features may not work with third-party models. For feature compatibility, refer to [Use a remote model](https://developer.android.com/studio/gemini/use-a-remote-model).

To confirm traffic reaches AI Gateway, refer to [Verify it works](/ai-gateway/integrations/coding-agents/#verify-it-works).

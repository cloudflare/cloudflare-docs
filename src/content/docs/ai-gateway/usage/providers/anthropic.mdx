[Anthropic](https://www.anthropic.com/) helps build reliable, interpretable, and steerable AI systems.

## Endpoint
**Base URL**

```txt
https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/anthropic
```

When supplying a provider key to `/anthropic/v1/messages`, send it in `x-api-key`. AI Gateway does not recognize `Authorization: Bearer` as provider credentials on this endpoint. Authenticate to AI Gateway separately with `cf-aig-authorization`.

For stored keys and Unified Billing, refer to [credential precedence](/ai-gateway/features/unified-billing/#credential-precedence). If provider credentials are required but AI Gateway cannot find them, refer to [error `2044`](/ai-gateway/reference/troubleshooting/#400-provider-credentials-required-2044).

### Anthropic SDK

Set `x-api-key` explicitly when supplying your Anthropic key. SDK authentication headers can differ between versions. Setting `Authorization` to `null` removes the SDK-generated bearer header. Use `cf-aig-authorization` separately to authenticate to AI Gateway.

<Details header="With Key in Request">
<Tabs>
<TabItem label="With Authenticated Gateway">
```js title=""
import Anthropic from "@anthropic-ai/sdk";

const baseURL = `https://gateway.ai.cloudflare.com/v1/{accountId}/{gatewayId}/anthropic`;
const providerKey = "{ANTHROPIC_API_KEY}";

const anthropic = new Anthropic({
	apiKey: providerKey,
	baseURL,
	defaultHeaders: {
		"x-api-key": providerKey,
		"cf-aig-authorization": "Bearer {CF_AIG_TOKEN}",
		Authorization: null,
	},
});

const message = await anthropic.messages.create({
	model: "claude-sonnet-4-5",
	messages: [{ role: "user", content: "What is Cloudflare?" }],
	max_tokens: 1024,
});
```
</TabItem>
<TabItem label="Unauthenticated Gateway">

<Details header="With Stored Keys (BYOK) / Unified Billing" open>
```js title=""
import Anthropic from "@anthropic-ai/sdk";

const baseURL = `https://gateway.ai.cloudflare.com/v1/{accountId}/{gatewayId}/anthropic`;

const anthropic = new Anthropic({
	apiKey: "placeholder",
	baseURL,
	defaultHeaders: {
		"cf-aig-authorization": "Bearer {CF_AIG_TOKEN}",
		"x-api-key": null,
		Authorization: null,
	},
});

const message = await anthropic.messages.create({
	model: "claude-sonnet-4-5",
	messages: [{ role: "user", content: "What is Cloudflare?" }],
	max_tokens: 1024,
});
```

<Aside type="note">
The placeholder satisfies the SDK's credential configuration. The `null` headers remove SDK-generated provider credentials before sending the request. AI Gateway uses an applicable stored BYOK key, or falls back to Unified Billing when allowed. If **Require provider credentials** is on and no applicable stored key exists, the request returns [error `2044`](/ai-gateway/reference/troubleshooting/#400-provider-credentials-required-2044).

Supplying a real key in `x-api-key` instead selects request-key authentication. This bypasses stored keys and Unified Billing.
</Aside>
</Details>

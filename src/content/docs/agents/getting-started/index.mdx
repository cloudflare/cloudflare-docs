An agent on Cloudflare is a Durable Object with the Agents SDK [Lifecycle](/agents/runtime/lifecycle/) installed. The Lifecycle starts the [capabilities](/agents/runtime/capabilities/) you add to it, such as [`WebSockets`](/agents/runtime/capabilities/websockets/), [`State`](/agents/runtime/capabilities/state/), and [`Scheduler`](/agents/runtime/capabilities/scheduler/). A harness is the capability that runs the agent loop. Pick the path that matches where you are starting from.

Tools give agents capabilities such as [searching the web](/agents/tools/web-search/), [reading webpages and documents](/agents/tools/web-fetch/), browsing the web, processing payments, and running code. The model can call each tool directly, or write code that calls several of them in one run. For the second, refer to [Code Mode](/agents/concepts/code-mode/).

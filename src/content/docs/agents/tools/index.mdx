Tools give agents capabilities such as [searching the web](/agents/tools/web-search/), [reading webpages and documents](/agents/tools/web-fetch/), browsing the web, processing payments, and running code. Agents can call tools in different ways. Use [Code Mode](/agents/concepts/code-mode/) to let models call many tools by writing code, or use direct tool calls for simple actions.

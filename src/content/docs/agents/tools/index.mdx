Tools give agents capabilities such as [searching the web](/agents/tools/web-search/), [reading webpages and documents](/agents/tools/web-fetch/), browsing the web, processing payments, and running code. Agents can call tools in different ways. Use [Code Mode](/agents/tools/codemode/) to let models discover and orchestrate multiple tools by writing code, or use direct tool calls for simple actions.

For a working directory, file tools, and an isolated environment to run code, refer to [Sandboxes and workspaces](/agents/sandboxes-and-workspaces/).

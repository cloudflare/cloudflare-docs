Give your agent a working directory for notes, drafts, source files, and generated output. Add code execution when the agent needs to process those files or use command-line tools.

## Choose a task

| Your agent needs to                                                          | Start here                                                                       |
| ---------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| Read, write, and search files that survive restarts                          | [Give an agent persistent files](/agents/tools/files-and-code/persistent-files/) |
| Run JavaScript modules against those files                                   | [Run JavaScript](/agents/tools/files-and-code/run-javascript/)                   |
| Run Linux commands, native binaries, or package managers against those files | [Run Linux commands](/agents/tools/files-and-code/run-linux/) — experimental     |
| Understand which files and processes survive a restart                       | [Understand what persists](/agents/tools/files-and-code/persistence/)            |

These guides use [Cloudflare Computer](https://github.com/cloudflare/computer). Its `Workspace` stores files in a Durable Object's SQLite database and provides tools such as `read`, `write`, `edit`, and `grep`.

An execution backend lets code operate on the same files. Start with files alone, then add JavaScript or Linux execution as needed. The [API reference](/agents/tools/files-and-code/reference/) covers workspace configuration, file operations, and execution methods.

:::note[Availability]
The workspace, file tools, and JavaScript backend are stable. The Linux container backend and JavaScript restart recovery are experimental. Refer to [Component status](https://github.com/cloudflare/computer/tree/main/packages/computer#status).
:::

## Run commands without a shared workspace

If your agent only needs commands and files inside a Linux container, follow [Give an agent a sandbox](/agents/tools/sandbox/). That guide uses container-local files. Use the Linux guide in this section when commands need to share the agent's persistent workspace files.

Code Mode integrates with Model Context Protocol (MCP) in two directions.

Use existing MCP tools inside a Code Mode runtime with an MCP connector. Each MCP tool becomes a method in the connector namespace.

You can also publish a Code Mode MCP server for MCP clients. Wrap an existing MCP server as one `code` tool, or create `search` and `execute` tools from an OpenAPI specification.

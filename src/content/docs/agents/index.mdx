Build and host agents on Cloudflare. Every agent is a [Durable Object](/durable-objects/): an addressable instance with its own SQLite database, alarms, and WebSocket connections. You can run one agent per user, conversation, or task, and an idle agent costs close to nothing.

To build an agent, extend `DurableObject`, install a [Lifecycle](/agents/lifecycle/), and add the [capabilities](/agents/capabilities/) you need:

<TypeScriptExample>

```ts
import { DurableObject } from "cloudflare:workers";
import { PiHarness } from "agents/harness/pi";
import { Lifecycle } from "agents/lifecycle";
import { MCPClientManager } from "agents/mcp/client";
import { Scheduler } from "agents/schedules";

export class Assistant extends DurableObject<Env> {
	readonly harness = new PiHarness({
		/* model and tools */
	});
	readonly mcp = new MCPClientManager("assistant", "1.0.0", { env: this.env });
	readonly scheduler = new Scheduler({ callbacks: {} });

	readonly lifecycle = Lifecycle.install(this)
		.use(this.harness)
		.use(this.mcp)
		.use(this.scheduler);
}
```

</TypeScriptExample>

Deploy once, and Cloudflare runs your agents across its global network, scaling to tens of millions of instances.

<AgentsPlatformDiagram />

An agent on Cloudflare has these parts:

- **The Lifecycle** runs startup, routes requests to capabilities, and owns the object's durable job queue and its single alarm. It keeps work going across eviction, deploys, and crashes.
- **A harness** runs the loop around the model: prompts, tool calls, retries, and recovery. Install the [Pi harness](/agents/harnesses/pi/), extend [Project Think](/agents/harnesses/think/), or build your own from [Sessions, Streams, and Tasks](/agents/capabilities/#build-your-own-harness).
- **Capabilities** add what else the agent needs: an [MCP client](/agents/capabilities/#mcp-client), [schedules](/agents/capabilities/#scheduler), [queues](/agents/capabilities/#queue), [WebSockets](/agents/capabilities/#websockets) and [state](/agents/capabilities/#state) for clients, and [routed agents](/agents/capabilities/#routed-agents).
- **Tools** let the model act: [browser automation](/agents/tools/browser/), [sandboxed code execution](/agents/tools/sandbox/), [AI Search](/agents/tools/ai-search/), [MCP tools](/agents/tools/mcp/), and [payments](/agents/tools/payments/). [Code Mode](/agents/tools/codemode/) lets models orchestrate tools by writing code.

The [`Agent` class](/agents/agent-class/) is a Durable Object with the Lifecycle and a set of capabilities already installed. It adds `@callable()` methods, [chat](/agents/agent-class/communication-channels/chat/), [voice](/agents/agent-class/communication-channels/voice/), [email](/agents/agent-class/communication-channels/email/), and other [communication channels](/agents/agent-class/communication-channels/).

### Get started

Build an assistant on the Pi harness in a few minutes. No API keys required, because it uses [Workers AI](/workers-ai/) by default.

- [Quick start](/agents/getting-started/quick-start/) builds the agent step by step.
- [Add to an existing project](/agents/getting-started/add-to-existing-project/) adds an agent to a Worker you already have.

You can also deploy the Pi harness example, which streams sessions to a browser over WebSockets:

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/cloudflare/agents/tree/main/examples/next/harnesses/pi)

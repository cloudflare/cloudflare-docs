:::caution[Zone Analytics API is sunset]
The legacy Zone Analytics REST endpoint (`GET /zones/{zone_id}/analytics/dashboard`) is sunset and returns API error `1015`. Use the [GraphQL Analytics API](/analytics/graphql-api/) instead.
:::

## Query zone HTTP analytics with GraphQL

Unlike the retired Zone Analytics API, the GraphQL Analytics API lets you request only the metrics and dimensions you need.

Before running a query:

- Choose `$start` and `$end` timestamps within your zone plan's retention window.
- Confirm dataset availability for your zone. `httpRequestsAdaptiveGroups` is available on all plans with at least 31 days of retention, while aggregated rollup datasets such as `httpRequests1mGroups` and `httpRequests1hGroups` have per-plan availability and retention limits.
- Query the [Settings node](/analytics/graphql-api/features/discovery/settings/) to inspect `enabled`, `maxDuration`, and `notOlderThan` for your zone, or review [GraphQL Analytics limits](/analytics/graphql-api/limits/#node-limits-and-availability).

To retrieve the same set of metrics and dimensions that Zone Analytics previously returned, query `httpRequests1mGroups`:

```graphql graphql-api-explorer
query ZoneAnalyticsMigrationSample($zoneTag: string, $start: Time, $end: Time) {
	viewer {
		zones(filter: { zoneTag: $zoneTag }) {
			httpRequests1mGroups(
				orderBy: [datetimeFiveMinutes_ASC]
				limit: 100
				filter: { datetime_geq: $start, datetime_lt: $end }
			) {
				dimensions {
					datetimeFiveMinutes
				}
				sum {
					browserMap {
						pageViews
						uaBrowserFamily
					}
					bytes
					cachedBytes
					cachedRequests
					contentTypeMap {
						bytes
						requests
						edgeResponseContentTypeName
					}
					clientSSLMap {
						requests
						clientSSLProtocol
					}
					countryMap {
						bytes
						requests
						threats
						clientCountryName
					}
					encryptedBytes
					encryptedRequests
					ipClassMap {
						requests
						ipType
					}
					pageViews
					requests
					responseStatusMap {
						requests
						edgeResponseStatus
					}
					threats
					threatPathingMap {
						requests
						threatPathingName
					}
				}
				uniq {
					uniques
				}
			}
		}
	}
}
```

Specify the request time period using a dataset filter (refer to [Filtering](/analytics/graphql-api/features/filtering/)). The legacy `continuous` parameter is no longer needed because GraphQL Analytics provides data as soon as it is available.

To retrieve totals for a period rather than a time-series breakdown, remove the `datetimeFiveMinutes` field under `dimensions`.

## Legacy Zone Analytics comparison

For reference when migrating existing integrations, the retired Zone Analytics API accepted optional `since`, `until`, and `continuous` query parameters and returned a fixed payload of metrics across all dimensions. Do not use this endpoint for new queries — it is sunset and returns API error `1015`.

```bash
# Sunset endpoint — shown for historical migration comparison only
curl "https://api.cloudflare.com/client/v4/zones/<ZONE_ID>/analytics/dashboard?since=2019-09-08T20:00:00Z&until=2019-09-08T20:02:00Z&continuous=false" \
--header "Authorization: Bearer <API_TOKEN>" --silent | jq .
```

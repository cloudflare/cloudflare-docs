## Abstract

This reference architecture outlines how Cloudflare and SentinelOne solutions integrate to create an AI-driven security ecosystem that combines autonomous endpoint protection with Zero Trust network access, shared risk intelligence, and automated remediation and recovery workflows. Organizations can leverage this integration to enforce risk-based access policies, accelerate threat hunting with generative AI, and orchestrate autonomous responses across both platforms.

## Introduction

Today's cybersecurity landscape presents organizations with a complex set of challenges. The expanding attack surface created by remote work, cloud migration, and increasingly automated, AI-assisted threats requires a cohesive approach that spans endpoint protection, network security, and identity.

Cloudflare One and the SentinelOne Singularity™ Platform provide a powerful integrated solution to these challenges. By combining SentinelOne's AI-driven, autonomous endpoint protection with Cloudflare's secure network and Zero Trust capabilities, organizations can implement comprehensive protection that secures both their devices and their network traffic, while simplifying operations through automation, shared risk intelligence, and consistent policy.

### Why integrate Cloudflare and SentinelOne

**Autonomous, context-aware Zero Trust:** Identity alone is no longer sufficient for trust. Cloudflare Access ingests real-time SentinelOne device posture — agent operational state, network connectivity, infection status, and active-threat count — while SentinelOne endpoint detection and response (EDR) signals also feed Cloudflare's user risk score. Together, they enforce dynamic, risk-based policies, so that only healthy, threat-free devices operated by low-risk users can reach sensitive resources, blocking compromised endpoints even when user credentials are valid.

**Unified visibility with AI-powered analytics:** Network and endpoint data too often reside in disconnected silos. This integration streams Cloudflare's rich network telemetry (from Cloudflare Gateway, Cloudflare WAF, DNS, Cloudflare Access, and Cloudflare Email Security) via Logpush into SentinelOne Singularity AI SIEM, where it is retained in the Singularity Data Lake alongside endpoint telemetry. Analysts can correlate network blocks with the exact endpoint processes behind them — and Purple AI™ lets them hunt across the combined dataset using natural language queries.

**Autonomous remediation and recovery:** By connecting enforcement points across Cloudflare and SentinelOne, security teams move from manual reaction to autonomous protection. A threat detected on the endpoint can trigger an immediate block at the Cloudflare edge (and vice versa) through Singularity Hyperautomation — and, uniquely, SentinelOne can roll back ransomware damage on affected Windows endpoints, reducing both mean time to respond (MTTR) and mean time to recover.

### Key integration points

The integration between Cloudflare and SentinelOne creates a powerful security ecosystem where device security posture directly influences access decisions. This continuous verification process is enhanced by bidirectional data sharing between the platforms:

- **Device posture assessment:** SentinelOne's real-time endpoint telemetry — agent activity, network status, operational state, infection status, and active-threat count — informs Cloudflare Zero Trust access decisions. A service-to-service posture check reads endpoint data from SentinelOne via the Cloudflare One Client, matching devices by serial number.
2. **User risk scoring:** SentinelOne EDR signals feed Cloudflare's user risk score (user and entity behavior analytics, or UEBA), classifying each user as Low, Medium, or High. Where Okta is the identity provider, Cloudflare can share this risk score to Okta to enforce SSO-level policies.
3. **Unified security logging:** Cloudflare forwards network and security telemetry via Logpush to SentinelOne Singularity AI SIEM, where it is stored and correlated in the Singularity Data Lake.
4. **Autonomous remediation and recovery workflows:** Security events trigger coordinated, automated responses across both platforms — orchestrated via Singularity Hyperautomation — including on-endpoint rollback of ransomware damage and automatic updates to Cloudflare policies.

## Integration architecture overview

The integration between Cloudflare and SentinelOne establishes a comprehensive security architecture centered on a bi-directional intelligence exchange. This ecosystem connects autonomous endpoint security with Zero Trust network access, AI-powered analytics, and automated response and recovery.

### Key use cases

The integration between Cloudflare and SentinelOne enables six use cases that address critical security challenges:

- **Risk-based Zero Trust access** — Enforce real-time, multi-signal conditional access using SentinelOne device posture and a SentinelOne-informed user risk score directly in Cloudflare Access policies.
- **AI-accelerated threat hunting** — Stream Cloudflare Gateway, WAF, DNS, and Access logs into Singularity AI SIEM, then hunt across the unified Singularity Data Lake using natural language with Purple AI.
- **Autonomous edge containment** — Use Singularity Hyperautomation to automatically trigger no-code remediation actions within Cloudflare based on detected threats.
- **Ransomware containment and one-click recovery** — Combine autonomous endpoint containment with network access revocation and Singularity's one-click Rollback to restore both security and productivity.
- **Insider risk and data protection** — Combine Cloudflare DLP inspection with SentinelOne behavioral analytics and network device discovery to detect and block data theft.
- **Proactive application defense** — Enrich application security with SentinelOne threat intelligence and AI triage, creating an adaptive immune system for web assets.

## Use case: Risk-based Zero Trust access with agent health and active-threat posture

This use case demonstrates how the integration helps prevent compromised or unmanaged devices from accessing corporate resources — using multiple discrete signals rather than a single score.

### Phase 1: Continuous posture and risk assessment

The SentinelOne Singularity agent continuously monitors the endpoint, maintaining real-time device state: whether the agent is active, whether it is connected to the SentinelOne service, the agent's operational state, whether the device is infected, and the number of active threats. In parallel, SentinelOne EDR signals feed Cloudflare's user risk score (UEBA), which classifies each user as Low, Medium, or High risk.

### Phase 2: Policy evaluation

When a user requests access to an application, Cloudflare Access intercepts the request and evaluates a device posture policy composed of discrete SentinelOne attributes — for example, `Is Active = true`, `Infected = false`, `Active Threats = 0`, and a healthy `Operational State` — together with user identity and the current user risk score.

### Phase 3: Access enforcement

Cloudflare permits the connection only if every posture attribute passes and the user's risk score is within the tolerance defined in the Zero Trust policy; otherwise, the user is presented with a Cloudflare Access block page, typically instructing them to remediate the device. Where Okta is the identity provider, Cloudflare can also share the user risk score to trigger SSO-level step-up authentication or session revocation.

## Use case: AI-accelerated threat hunting with Purple AI

This use case focuses on providing comprehensive visibility and eliminating blind spots between network traffic and endpoint activity — while compressing investigation time.

### Phase 1: Data ingestion

Cloudflare Logpush filters and forwards HTTP requests, DNS queries, Gateway and firewall events, and Access authentication logs to Singularity AI SIEM, where they are normalized and stored in the Singularity Data Lake alongside endpoint telemetry.

### Phase 2: Correlation and enrichment

Singularity automatically correlates related endpoint events into a single attack narrative using Storyline™, and the Data Lake unifies this endpoint context with Cloudflare network telemetry so analysts can query one schema instead of stitching together separate tools.

### Phase 3: Natural-language investigation

Using Purple AI, an analyst investigates in plain language — for example, "show every device that reached this command-and-control domain through Cloudflare Gateway in the last 24 hours" — and pivots instantly from a network block to the exact endpoint process that caused the infection, collapsing hours of manual query-writing into seconds.

![Figure 3 — AI-accelerated threat hunting.](~/assets/images/reference-architecture/cloudflare-sase-with-sentinelone/figure3.svg "Figure 3 — AI-accelerated threat hunting.")

## Use case: Autonomous edge containment with Singularity Hyperautomation

This use case demonstrates how Singularity Hyperautomation helps reduce the MTTR for rapidly evolving threats — without custom scripting.

### Phase 1: Threat detection

Singularity Endpoint detects a specific indicator of compromise (IOC), such as a malicious IP address or domain contacted by multiple endpoints, and Storyline classifies the behavior.

### Phase 2: No-code orchestration

A Singularity Hyperautomation workflow is triggered by the detection, using pre-built connectors and logic rather than bespoke code.

### Phase 3: Edge mitigation

The workflow calls the Cloudflare API to add the malicious indicator to a blocklist in Cloudflare Gateway or WAF, instantly protecting the entire organization — including devices that do not run the agent — from that threat source.

![Figure 4 — Autonomous edge containment.](~/assets/images/reference-architecture/cloudflare-sase-with-sentinelone/figure4.svg "Figure 4 — Autonomous edge containment.")

## Use case: Ransomware containment and one-click recovery

This use case outlines how the combined integration pillars contain an active endpoint compromise, prevent lateral movement, and restore affected systems — going beyond detection to recovery.

### Phase 1: Autonomous detection and containment

The Singularity agent detects ransomware behavior and autonomously kills the malicious processes and quarantines the device at machine speed — even when the endpoint is offline. It updates the device's posture (`Infected = true`, `Active Threats > 0`) and raises an alert to the SentinelOne console.

### Phase 2: Instant network access revocation

On the very next request, Cloudflare Access re-evaluates the SentinelOne posture attributes, fails the policy, and blocks the user from SaaS apps, email, and internal tools — effectively quarantining the identity from the network while the endpoint is contained.

### Phase 3: Remediation and one-click rollback

Singularity Hyperautomation automates a response playbook: it isolates the endpoint, adds the user to a custom list in Cloudflare to enforce heightened policies, and — on Windows endpoints — initiates SentinelOne's one-click Rollback to restore encrypted files to their pre-attack state. Once the device is verified clean and its posture returns to a healthy state, Cloudflare access is automatically restored.

![Figure 5 — Ransomware containment and one-click recovery.](~/assets/images/reference-architecture/cloudflare-sase-with-sentinelone/figure5.svg "Figure 5 — Ransomware containment and one-click recovery.")

## Use case: Insider risk and data protection with unmanaged-device visibility

This use case demonstrates how the unified approach helps prevent and respond to data exfiltration by trusted insider actors — including from devices the organization does not manage.

### Phase 1: DLP monitoring

Cloudflare DLP scans upload traffic. It detects source code markers or other sensitive-data patterns and logs the event to Singularity AI SIEM via Logpush, while momentarily blocking the specific request.

### Phase 2: Behavioral correlation and device discovery

Singularity AI SIEM correlates this DLP event with endpoint behavior captured by Storyline — for example, recent USB mass-storage usage, bulk file access, or archive creation — and raises the user's risk. In parallel, Singularity Network Discovery (formerly Ranger®) identifies whether the activity involved an unmanaged or rogue device on the network, closing a common insider blind spot.

### Phase 3: Adaptive control

Singularity Hyperautomation updates the Cloudflare Zero Trust policy to require step-up authentication or route the user's sessions through Remote Browser Isolation (RBI), preventing further data movement — even for legitimate tasks — until the user is cleared by HR or security.

![Figure 6 — Insider risk and data protection.](~/assets/images/reference-architecture/cloudflare-sase-with-sentinelone/figure6.svg "Figure 6 — Insider risk and data protection.")

## Use case: Proactive application defense with shared threat intelligence

This use case explores the power of the integrated solutions to defend public applications against botnets and evolving exploits.

### Phase 1: Attack identification

Cloudflare WAF blocks a series of SQL injection or credential-stuffing attempts from a specific subnet. These logs are streamed to Singularity AI SIEM.

### Phase 2: Intelligence enrichment and AI triage

Singularity Threat Intelligence enriches the log data, attributing the subnet to a known threat actor or campaign, and Purple AI summarizes the activity and recommended response so the analyst can decide quickly.

### Phase 3: Defensive tuning

Singularity Hyperautomation triggers a workflow to update Cloudflare's application-layer defenses: it increases bot-mitigation sensitivity for the affected region and creates a proactive block rule for the entire autonomous system number (ASN) associated with the attack, hardening the application before a larger assault begins.

## Implementation components

The integration between Cloudflare and SentinelOne leverages key components from each platform to create a cohesive security ecosystem.

### Cloudflare components

| Component | Purpose |
|-----------|---------|
| **Zero Trust Network Access (ZTNA)** | Controls access to applications based on identity, device posture, and user risk score |
| **Secure Web Gateway (SWG)** | Inspects and filters Internet-bound traffic, including URL filtering, malware protection, and file type controls |
| **Data Loss Prevention (DLP)** | Prevents unauthorized data exfiltration using built-in and custom data profiles |
| **Remote Browser Isolation (RBI)** | Executes web content in a secure cloud environment with file and keyboard controls |
| **Email Security** | Prevents email-based threats including phishing, malicious attachments, and BEC |
| **CASB** | API-driven monitoring of SaaS usage, permissions, and data security posture |
| **WAF and Bot Management** | ML-driven detection, custom rules, managed rule sets, and rate limiting |

### SentinelOne components

| Component | Purpose |
|-----------|---------|
| **Singularity Endpoint (agent)** | AI-driven autonomous endpoint protection including behavioral AI, on-device response, one-click Rollback, and Storyline attack correlation |
| **Device posture and risk telemetry** | Shares real-time agent activity, network status, infection status, active-threat count, and EDR signals with Cloudflare |
| **Singularity AI SIEM and Data Lake** | Centralizes security monitoring, high-scale log ingestion, threat detection, and unified endpoint + Cloudflare network telemetry |
| **Singularity XDR** | Extended detection and response: cross-domain detection, automated investigation, threat hunting, and guided remediation |
| **Singularity Hyperautomation** | No-code security orchestration for automated containment, enrichment, recovery, and bi-directional actioning |
| **Purple AI** | Generative-AI security analyst for natural-language threat hunting, automated investigation summaries, and recommended next actions |
| **Singularity Threat Intelligence** | IOC and actor attribution with campaign and TTP context for enriching Cloudflare network events |

## Summary

The integration between Cloudflare and SentinelOne provides organizations with a comprehensive security solution that combines autonomous endpoint security, Zero Trust network access, AI-powered analytics, and application protection. By leveraging the strengths of both platforms, organizations can achieve better visibility into their security posture, automate responses to threats, and recover from destructive attacks such as ransomware without lengthy manual rebuilds.

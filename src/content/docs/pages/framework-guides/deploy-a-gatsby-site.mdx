[Gatsby](https://www.gatsbyjs.com/) is a React-based framework for generating static websites and web applications.

To deploy a Gatsby site to Cloudflare, refer to the [Gatsby Workers guide](/workers/framework-guides/web-apps/more-web-frameworks/gatsby/).

If you maintain an existing Gatsby project on Cloudflare Pages, refer to [Framework presets](/pages/configuration/build-configuration/#framework-presets) for build settings, or follow the [Pages to Workers migration guide](/workers/static-assets/migration-guides/migrate-from-pages/) to move to Workers.

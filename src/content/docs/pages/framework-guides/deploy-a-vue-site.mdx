[Vue](https://vuejs.org/) is a progressive JavaScript framework for building user interfaces and single-page applications.

To deploy a Vue application to Cloudflare, refer to the [Vue Workers guide](/workers/framework-guides/web-apps/vue/).

If you maintain an existing Vue project on Cloudflare Pages, refer to [Framework presets](/pages/configuration/build-configuration/#framework-presets) for build settings, or follow the [Pages to Workers migration guide](/workers/static-assets/migration-guides/migrate-from-pages/) to move to Workers.

[React](https://react.dev/) is a JavaScript library for building user interfaces.

To deploy a React application to Cloudflare, refer to the [React + Vite Workers guide](/workers/framework-guides/web-apps/react/).

If you maintain an existing React project on Cloudflare Pages, refer to [Framework presets](/pages/configuration/build-configuration/#framework-presets) for build settings, or follow the [Pages to Workers migration guide](/workers/static-assets/migration-guides/migrate-from-pages/) to move to Workers.

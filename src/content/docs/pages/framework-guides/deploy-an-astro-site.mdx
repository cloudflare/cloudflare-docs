[Astro](https://astro.build/) is a web framework for building fast, content-driven websites and full-stack applications.

To deploy an Astro application to Cloudflare, refer to the [Astro Workers guide](/workers/framework-guides/web-apps/astro/).

If you maintain an existing Astro project on Cloudflare Pages, refer to [Framework presets](/pages/configuration/build-configuration/#framework-presets) for build settings, or follow the [Pages to Workers migration guide](/workers/static-assets/migration-guides/migrate-from-pages/) to move to Workers.

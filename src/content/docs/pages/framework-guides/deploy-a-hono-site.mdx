[Hono](https://hono.dev/) is a lightweight web framework built on Web Standards.

To deploy a Hono application to Cloudflare, refer to the [Hono web app Workers guide](/workers/framework-guides/web-apps/more-web-frameworks/hono/) or the [Hono API Workers guide](/workers/framework-guides/apis/hono/).

If you maintain an existing Hono project on Cloudflare Pages, follow the [Pages to Workers migration guide](/workers/static-assets/migration-guides/migrate-from-pages/) to move to Workers.

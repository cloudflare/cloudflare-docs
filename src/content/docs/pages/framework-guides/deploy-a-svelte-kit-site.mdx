[SvelteKit](https://svelte.dev/docs/kit/introduction) is a full-stack web framework powered by Svelte.

To deploy a SvelteKit application to Cloudflare, refer to the [SvelteKit Workers guide](/workers/framework-guides/web-apps/sveltekit/).

If you maintain an existing SvelteKit project on Cloudflare Pages, refer to [Framework presets](/pages/configuration/build-configuration/#framework-presets) for build settings, or follow the [Pages to Workers migration guide](/workers/static-assets/migration-guides/migrate-from-pages/) to move to Workers.

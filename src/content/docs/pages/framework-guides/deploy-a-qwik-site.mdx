[Qwik](https://qwik.dev/) is a resumable web application framework designed for fast initial load performance.

To deploy a Qwik application to Cloudflare, refer to the [Qwik Workers guide](/workers/framework-guides/web-apps/more-web-frameworks/qwik/).

If you maintain an existing Qwik project on Cloudflare Pages, refer to [Framework presets](/pages/configuration/build-configuration/#framework-presets) for build settings, or follow the [Pages to Workers migration guide](/workers/static-assets/migration-guides/migrate-from-pages/) to move to Workers.

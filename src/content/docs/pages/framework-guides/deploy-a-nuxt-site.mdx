[Nuxt](https://nuxt.com/) is a full-stack web framework built on Vue.

To deploy a Nuxt application to Cloudflare, refer to the [Nuxt Workers guide](/workers/framework-guides/web-apps/more-web-frameworks/nuxt/).

If you maintain an existing Nuxt project on Cloudflare Pages, refer to [Framework presets](/pages/configuration/build-configuration/#framework-presets) for build settings, or follow the [Pages to Workers migration guide](/workers/static-assets/migration-guides/migrate-from-pages/) to move to Workers.

[Sphinx](https://www.sphinx-doc.org/) is a documentation generator written in Python. In this guide, you will create a new Sphinx project and deploy it using Cloudflare Pages.

## Prerequisites

- [Python 3](https://www.python.org/downloads/) (Cloudflare Pages Build Image v3 includes Python 3.13 by default; refer to [Build image](/pages/configuration/build-image/) for supported versions).
- [`pip`](https://pypi.org/project/pip/) for installing Python packages.

## Create a Sphinx project

1. Create a new project directory, set up a Python virtual environment, and install Sphinx:

```sh
mkdir my-sphinx-project
cd my-sphinx-project
python3 -m venv .venv
source .venv/bin/activate
pip install sphinx
```

2. Record your dependencies in a `requirements.txt` file so Cloudflare Pages automatically installs Sphinx during builds:

```sh
echo "sphinx" > requirements.txt
```

3. Run `sphinx-quickstart` to scaffold your documentation site:

```sh
sphinx-quickstart
```

When prompted, answer the setup questions:

```txt output
Separate source and build directories (y/n) [n]: y
Project name: <Your project name>
Author name(s): <Your author name>
Project release []: <Leave blank or provide a version>
Project language [en]: <Leave blank for en or provide a language code>
```

4. Add a `.gitignore` file so your local virtual environment and build output are not committed to Git:

```txt title=".gitignore"
.venv/
build/
```

This creates a project structure with `requirements.txt`, `Makefile`, and a `source/` directory containing `conf.py` and `index.rst`. For more details on authoring documentation with Sphinx, refer to the [Sphinx documentation](https://www.sphinx-doc.org/en/master/usage/quickstart.html).

## Deploy with Cloudflare Pages

<Render file="deploy-to-pages-steps-no-preset" product="pages" />

| Configuration option | Value        |
| -------------------- | ------------ |
| Production branch    | `main`       |
| Build command        | `make html`  |
| Build directory      | `build/html` |

Cloudflare Pages detects `requirements.txt` and installs your Python dependencies before running `make html`. If you need a specific Python version rather than the build image default, set the `PYTHON_VERSION` environment variable as described in [Override default versions](/pages/configuration/build-image/#override-default-versions).

:::note

For the complete guide to deploying your first site to Cloudflare Pages, refer to the [Get started guide](/pages/get-started/).

:::

After deploying your site, you will receive a unique subdomain for your project on `*.pages.dev`. Every time you commit new code to your Sphinx site, Cloudflare Pages automatically rebuilds your project and deploys it.

You will also get access to [preview deployments](/pages/configuration/preview-deployments/) on new pull requests, so you can preview how changes look to your site before deploying them to production.

[Pelican](https://docs.getpelican.com) is a static site generator written in Python. With Pelican, you can write your content directly with your editor of choice in reStructuredText or Markdown formats.

## Create a Pelican project

To begin, create a Pelican project directory, set up a virtual environment, and install Pelican:

```sh
mkdir my-pelican-site
cd my-pelican-site
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install pelican
```

Record Pelican (and any plugins or themes you use) in `requirements.txt` so Cloudflare Pages installs them automatically during builds:

```sh
echo "pelican" > requirements.txt
```

Create a directory in your project named `content` and add `.venv/` to `.gitignore`:

```sh
mkdir content
echo ".venv/" >> .gitignore
```

This is the directory name that you will set in the build command.

## Deploy with Cloudflare Pages

<Render file="deploy-to-pages-steps-no-preset" product="pages" />

<PagesBuildPreset framework="pelican" />

Cloudflare Pages Build Image v3 includes Python 3.13 by default and automatically installs packages listed in `requirements.txt`. If you need to pin a specific Python version, set `PYTHON_VERSION` under **Environment variables** as described in [Override default versions](/pages/configuration/build-image/#override-default-versions).

For the complete guide to deploying your first site to Cloudflare Pages, refer to the [Get started guide](/pages/get-started/).

After deploying your site, you will receive a unique subdomain for your project on `*.pages.dev`.

Every time you commit new code to your Pelican site, Cloudflare Pages will automatically rebuild your project and deploy it. You will also get access to [preview deployments](/pages/configuration/preview-deployments/) on new pull requests and be able to preview how changes look to your site before deploying them to production.

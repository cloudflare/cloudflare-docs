[MkDocs](https://www.mkdocs.org/) is a documentation platform where teams can document products, internal knowledge bases, and APIs.

## Install MkDocs

MkDocs requires Python 3 and the Python package manager `pip`. To install Python and `pip`, refer to the [MkDocs installation guide](https://www.mkdocs.org/user-guide/installation/). With `pip` installed, create a virtual environment and install MkDocs:

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install mkdocs
```

## Create an MkDocs project

Use the `mkdocs new` command to create a new application:

```sh
mkdocs new <PROJECT_NAME>
cd <PROJECT_NAME>
```

Create a `requirements.txt` file listing MkDocs (and any themes or plugins your site uses) so Cloudflare Pages installs them automatically during builds:

```sh
echo "mkdocs" > requirements.txt
```

## Deploy with Cloudflare Pages

<PagesBuildPreset framework="mkdocs" />

Cloudflare Pages Build Image v3 includes Python 3.13 by default and automatically installs packages listed in `requirements.txt`. If you need to pin a specific Python version, set `PYTHON_VERSION` under **Environment variables** as described in [Override default versions](/pages/configuration/build-image/#override-default-versions).

After deploying your site, you will receive a unique subdomain for your project on `*.pages.dev`.

Every time you commit new code to your MkDocs site, Cloudflare Pages will automatically rebuild your project and deploy it. You will also get access to [preview deployments](/pages/configuration/preview-deployments/) on new pull requests and be able to preview how changes to your site look before deploying them to production.

For the complete guide to deploying your first site to Cloudflare Pages, refer to the [Get started guide](/pages/get-started/).

[Next.js](https://nextjs.org) is an open-source React framework for creating websites and applications.

Cloudflare recommends [vinext on Workers](/workers/framework-guides/web-apps/nextjs/) for full-stack Next.js applications, including server-side rendering, React Server Components, Server Actions, route handlers, and middleware.

Use Pages if you already have a Pages project, or you need a Pages-only capability (for example, a custom domain whose DNS is not on Cloudflare):

- To deploy a static Next.js site with Pages, refer to [Static site](/pages/framework-guides/nextjs/deploy-a-static-nextjs-site/).
- To maintain an existing project that uses `@cloudflare/next-on-pages`, refer to [Next on Pages](/pages/framework-guides/nextjs/next-on-pages/).

[Angular](https://angular.dev/) is a web framework for building single-page and server-rendered applications with TypeScript.

To deploy an Angular application to Cloudflare, refer to the [Angular Workers guide](/workers/framework-guides/web-apps/more-web-frameworks/angular/).

If you maintain an existing Angular project on Cloudflare Pages, refer to [Framework presets](/pages/configuration/build-configuration/#framework-presets) for build settings, or follow the [Pages to Workers migration guide](/workers/static-assets/migration-guides/migrate-from-pages/) to move to Workers.

[Docusaurus](https://docusaurus.io/) is a static site generator built with React for documentation and content websites.

To deploy a Docusaurus site to Cloudflare, refer to the [Docusaurus Workers guide](/workers/framework-guides/web-apps/more-web-frameworks/docusaurus/).

If you maintain an existing Docusaurus project on Cloudflare Pages, refer to [Framework presets](/pages/configuration/build-configuration/#framework-presets) for build settings, or follow the [Pages to Workers migration guide](/workers/static-assets/migration-guides/migrate-from-pages/) to move to Workers.

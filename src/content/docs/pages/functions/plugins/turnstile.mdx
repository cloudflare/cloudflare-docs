[Turnstile](/turnstile/) is Cloudflare's smart CAPTCHA alternative.

The Turnstile Pages Plugin validates Cloudflare Turnstile tokens.

## Installation

<PackageManagers pkg="@cloudflare/pages-plugin-turnstile" />

## Usage

```typescript
import turnstilePlugin from "@cloudflare/pages-plugin-turnstile";

interface Env {
	TURNSTILE_SECRET_KEY: string;
}

/**
 * POST /register (when mounted in functions/register.ts)
 */
export const onRequestPost: PagesFunction<Env>[] = [
	(context) =>
		turnstilePlugin({
			// Store your production secret key as an encrypted Pages secret.
			// For local testing, use a Turnstile dummy test secret key such as
			// "1x0000000000000000000000000000000AA".
			secret: context.env.TURNSTILE_SECRET_KEY,
		})(context),
	async (context) => {
		// Request has been validated as coming from a human
		const formData = await context.request.formData();
		// Additional solve metadata is available at context.data.turnstile
		return new Response(
			`Successfully verified! ${JSON.stringify(context.data.turnstile)}`,
		);
	},
];
```

This Plugin only exposes a single route to verify an incoming Turnstile response in a `POST` request as the `cf-turnstile-response` parameter. It is available wherever it is mounted. In the example above, mounting it in `functions/register.ts` validates requests to `/register`.

For local development and automated tests, refer to [Turnstile dummy secret keys](/turnstile/troubleshooting/testing/).

## Properties

The Plugin is mounted with a single object parameter with the following properties:

- `secret` (mandatory): Found in the [Turnstile dashboard](https://dash.cloudflare.com/?to=/:account/turnstile). Store this value as an encrypted [secret](/pages/functions/bindings/#secrets) in your Pages project.
- `response` (optional): The Turnstile token string to verify. If omitted, the plugin extracts the `cf-turnstile-response` value from a `multipart/form-data` request.
- `remoteip` (optional): The requester's IP address string. Defaults to the `CF-Connecting-IP` header of the request.
- `onError` (optional): A function that takes the Pages Function context object and returns a `Promise` of a `Response`. By default, it returns a human-readable error `Response`.

`context.data.turnstile` is populated in subsequent Pages Functions (including for the `onError` function) with [the Turnstile Siteverify response object](/turnstile/get-started/server-side-validation/).

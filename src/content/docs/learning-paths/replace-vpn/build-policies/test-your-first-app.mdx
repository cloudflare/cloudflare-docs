After you have set up your [Zero Trust organization](), [configured the WARP client](), [installed the WARP client on a device](), and [set up your Access and or Gateway policies](), you can test your policies.

First, test if the Access or Gateway policy that you configured is working by using a device with the WARP client installed to reach an internal application or external website through that policy.

If you cannot reach an Access application or external application through Gateway as expected:

- Review the [WARP troubleshooting guide](/cloudflare-one/team-and-resources/devices/warp/troubleshooting/troubleshooting-guide/)
- Review the [troubleshooting component in this learning path](/learning-paths/replace-vpn/troubleshooting/)

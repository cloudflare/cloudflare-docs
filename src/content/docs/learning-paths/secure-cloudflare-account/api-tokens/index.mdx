Any script, CI/CD pipeline, or tool that talks to the Cloudflare API needs credentials. How you manage those credentials determines whether programmatic access is a well-controlled, auditable operation or an untracked liability. This module covers eliminating global API keys, designing scoped tokens, and securing those tokens in automated pipelines.

## Objectives

By the end of this module, you will be able to:

- Explain why API tokens are preferable to global API keys and migrate away from keys.
- Design tokens with minimal scope for each use case.
- Store and rotate tokens safely in CI/CD pipelines.

Getting your account structure right before onboarding team members saves significant rework later. The decisions you make here — how many accounts to use, how super admin access is managed, and how authentication is enforced — are foundational to everything else in this guide.

## Objectives

By the end of this module, you will be able to:

- Explain the difference between accounts, zones, and organizations and when to use multiple accounts.
- Configure authentication and admin access before onboarding any team members.

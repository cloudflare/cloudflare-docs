### Block or isolate AI applications

Control access to generative AI tools to prevent data leakage.

You can block or isolate all AI applications with a single policy:

<Tabs syncKey="dashPlusAPI">

<TabItem label="Dashboard">

| Selector    | Operator | Value                     | Action |
| ----------- | -------- | ------------------------- | ------ |
| Application | in       | _Artificial Intelligence_ | Block  |

</TabItem>

<TabItem label="API">

<APIRequest
	path="/accounts/{account_id}/gateway/rules"
	method="POST"
	json={{
		name: "Block AI applications",
		description: "Block access to generative AI tools to prevent data leakage",
		enabled: true,
		action: "block",
		filters: ["http"],
		traffic: "any(app.type.ids[] in {23})",
		identity: "",
		device_posture: "",
	}}
/>

</TabItem>

<TabItem label="Terraform">

```tf
resource "cloudflare_zero_trust_gateway_policy" "block_ai_applications" {
  account_id  = var.cloudflare_account_id
  name        = "Block AI applications"
  description = "Block access to generative AI tools to prevent data leakage"
  enabled     = true
  action      = "block"
  filters     = ["http"]
  traffic     = "any(app.type.ids[*] in {23})"
  identity    = ""
}
```

</TabItem>

</Tabs>

### Control file uploads and downloads

Restrict file transfers to risky or unsanctioned applications:

<Tabs syncKey="dashPlusAPI">

<TabItem label="Dashboard">

| Selector         | Operator | Value                | Logic | Action |
| ---------------- | -------- | -------------------- | ----- | ------ |
| Application      | in       | _File Sharing_       | And   | Block  |
| Application      | not in   | _Google Drive_       | And   |        |
| Application      | not in   | _Microsoft OneDrive_ | And   |        |
| Upload Mime Type | in       | _All File Types_     |       |        |

</TabItem>

<TabItem label="API">

<APIRequest
	path="/accounts/{account_id}/gateway/rules"
	method="POST"
	json={{
		name: "Block file uploads to personal cloud storage",
		description:
			"Restrict file transfers to risky or unsanctioned cloud storage applications",
		enabled: true,
		action: "block",
		filters: ["http"],
		traffic:
			'any(app.type.ids[*] in {17}) and not(any(app.ids[*] in {478 505})) and http.upload.mime_type != ""',
		identity: "",
		device_posture: "",
	}}
/>

</TabItem>

<TabItem label="Terraform">

```tf
resource "cloudflare_zero_trust_gateway_policy" "block_file_uploads_personal_cloud" {
  account_id  = var.cloudflare_account_id
  name        = "Block file uploads to personal cloud storage"
  description = "Restrict file transfers to risky or unsanctioned cloud storage applications"
  enabled     = true
  action      = "block"
  filters     = ["http"]
  traffic     = "any(app.type.ids[*] in {17}) and not(any(app.ids[*] in {478 505})) and http.upload.mime_type != \"\""
  identity    = ""
}
```

</TabItem>

## Policy ordering

Order your policies from most specific to most general:

1. HTTP Allow policies for approved applications
2. Tenant control policies
3. DLP policies
4. Browser Isolation policies
5. HTTP Block policies for specific applications
6. HTTP Block policies for categories
7. Default allow (if using allowlist approach)

For more information, refer to [Order of enforcement](/cloudflare-one/traffic-policies/order-of-enforcement/).

## Testing policies

Before deploying and enforcing your Gateway HTTP policies broadly, test them in a trial environment:

1. Set action to _Allow_ with logging turned on to see what would be blocked.
2. Apply policies to a trial group of users first.
3. Review logs for false positives and user impact.
4. Adjust and expand based on feedback.

### Allow only approved applications (allowlist)

Allow access to only approved applications.

<Tabs syncKey="dashPlusAPI">

<TabItem label="Dashboard">

| Selector    | Operator | Value                     | Action |
| ----------- | -------- | ------------------------- | ------ |
| Application | not in   | _Corporate Approved Apps_ | Block  |

</TabItem>

<TabItem label="API">

<APIRequest
	path="/accounts/{account_id}/gateway/rules"
	method="POST"
	json={{
		name: "Allow only approved applications",
		description: "Block access to applications not in the approved list",
		enabled: true,
		action: "block",
		filters: ["http"],
		traffic: "not(any(app.ids[*] in $<LIST_UUID>))",
		identity: "",
		device_posture: "",
	}}
/>

To get the UUIDs of your lists, use the [List Zero Trust lists](/api/resources/zero_trust/subresources/gateway/subresources/lists/methods/list/) endpoint.

</TabItem>

<TabItem label="Terraform">

```tf
resource "cloudflare_zero_trust_gateway_policy" "allow_only_approved_apps" {
  account_id  = var.cloudflare_account_id
  name        = "Allow only approved applications"
  description = "Block access to applications not in the approved list"
  enabled     = true
  action      = "block"
  filters     = ["http"]
  traffic     = "not(any(app.ids[*] in $<LIST_UUID>))"
  identity    = ""
}
```

To get the UUIDs of your lists, use the [List Zero Trust lists](/api/resources/zero_trust/subresources/gateway/subresources/lists/methods/list/) endpoint.

</TabItem>

</Tabs>

### Block by domain

Block access to a specific domain and all subdomains.

<Tabs syncKey="dashPlusAPI">

<TabItem label="Dashboard">

| -------- | ------------- | --------------- | ------ |
| Domain   | matches regex | `*.example.com` | Block  |

</TabItem>

<TabItem label="API">

<APIRequest

		name: "Block domain",
		description: "Block access to a specific domain and all subdomains",

For data protection, consider:

- **Include mode**: Route only specific applications or domains through Cloudflare (recommended for initial deployments)
- **Exclude mode**: Route all traffic except specified applications through Cloudflare (recommended for comprehensive protection)

For more information, refer to [Split Tunnels](/cloudflare-one/connections/connect-devices/warp/configure-warp/route-traffic/split-tunnels/).

## Verify WARP deployment

Confirm that WARP is working correctly:

1. Check that the WARP client shows as **Connected** on user devices.
2. Visit [https://help.teams.cloudflare.com/](https://help.teams.cloudflare.com/) to verify the device is connected to your Zero Trust organization.
3. In [Zero Trust](https://one.dash.cloudflare.com/), go to **My Team** > **Devices** to see enrolled devices.

## Troubleshooting

If users experience connectivity issues:

- Verify the Cloudflare certificate is installed and trusted
- Check split tunneling configuration
- Review firewall rules to ensure Cloudflare IPs are allowed
- Consult [WARP troubleshooting](/cloudflare-one/connections/connect-devices/warp/troubleshooting/)

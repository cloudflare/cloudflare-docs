The WARP client routes traffic from user devices through Cloudflare's network for inspection and policy enforcement.

## Configure WARP settings

Before you deploy WARP, enroll your organization's devices and optionally configure [Split Tunnels](#split-tunnels) and [Local Domain Fallback](#local-domain-fallback).

### Split Tunnels

<Render file="warp/split-tunnel-intro" product="cloudflare-one" />

To protect sensitive data in transit, consider:

| Mode                        | Description                                                        | Recommendation           |
| --------------------------- | ------------------------------------------------------------------ | ------------------------ |
| **Include IPs and domains** | Route only specific applications or domains through Cloudflare     | Initial deployments      |
| **Exclude IPs and domains** | Route all traffic except specified applications through Cloudflare | Comprehensive protection |

For more information, refer to [Split Tunnels](/cloudflare-one/team-and-resources/devices/warp/configure-warp/route-traffic/split-tunnels/).

## Deploy at scale

To deploy WARP at scale, you can use device management tools such as [Intune](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/partners/intune/) or [Jamf](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/partners/jamf/). For a full list of supported MDM providers, refer to [WARP managed deployment](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/).

Alternatively, you can deploy WARP manually on each device. To download the WARP client, refer to [Download WARP](/cloudflare-one/team-and-resources/devices/warp/download-warp/).

## Verify WARP deployment

To confirm that WARP is deployed and working correctly:

1. On your users' devices, check that the WARP client displays **Connected** for Zero Trust.
2. In a browser, visit [https://help.teams.cloudflare.com/](https://help.teams.cloudflare.com/) to verify the device is connected to your Zero Trust organization.
3. In [Cloudflare One](https://one.dash.cloudflare.com/), go to **Team & Resources** > **Your devices**. Cloudflare One should list your enrolled devices.

## Troubleshooting

If users experience connectivity issues:

- Verify the Cloudflare certificate is installed and trusted
- Check split tunneling configuration
- Review firewall rules to ensure Cloudflare IPs are allowed
- Consult [WARP troubleshooting](/cloudflare-one/team-and-resources/devices/warp/troubleshooting/)

## Next steps

With WARP deployed, you can now:

- Analyze traffic patterns in Gateway Analytics
- Build HTTP policies based on observed usage
- Apply DLP policies to protect sensitive data

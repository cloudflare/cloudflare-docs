Gateway must be deployed and configured with TLS inspection before you can apply data protection policies to encrypted traffic.

## Turn on Gateway proxy

Gateway proxy intercepts HTTP and HTTPS traffic from your users, allowing you to inspect and apply policies.

## Turn on TLS decryption

TLS decryption (HTTPS inspection) is required to inspect encrypted traffic for sensitive data and security threats.

## Configure TLS inspection settings

After turning on TLS decryption, configure which traffic to inspect:

1. In [Zero Trust](https://one.dash.cloudflare.com/), go to **Settings** > **Network**.
2. Under **TLS decryption**, configure:
   - **Do Not Inspect**: Add applications that should bypass TLS inspection (for example, applications with certificate pinning)
   - **Inspection mode**: Choose between full inspection or certificate-only inspection

For more information, refer to [TLS decryption](/cloudflare-one/traffic-policies/http-policies/tls-decryption/).

## Verify Gateway deployment

Test that Gateway is working correctly:

1. On a device with WARP connected, visit a test website.
2. Check the certificate details in your browser — you should see the Cloudflare certificate.
3. In [Zero Trust](https://one.dash.cloudflare.com/), go to **Logs** > **Gateway** > **HTTP** to verify traffic is being logged.

## Next steps

With Gateway deployed and TLS inspection turned on, you can now:

- Deploy the WARP client to user devices
- Build HTTP policies to control application access
- Apply DLP policies to detect sensitive data in transit

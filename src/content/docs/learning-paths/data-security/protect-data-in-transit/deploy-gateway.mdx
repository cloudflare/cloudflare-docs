Gateway must be deployed and configured with TLS inspection before you can apply data protection policies to encrypted traffic.

## Turn on Gateway proxy

Gateway proxy intercepts HTTP and HTTPS traffic from your users, allowing you to inspect and apply policies.

<Render file="tunnel/enable-gateway-proxy" product="cloudflare-one" />

## Turn on TLS decryption

TLS decryption (HTTPS inspection) is required to inspect encrypted traffic for sensitive data and security threats.

<Render file="gateway/enable-tls-decryption" product="cloudflare-one" />

## Turn on antivirus scanning

Antivirus scanning protects against malware in file uploads and downloads.

<Render file="gateway/enable-av-scanning" product="cloudflare-one" />

For more information, refer to [AV scanning](/cloudflare-one/traffic-policies/http-policies/antivirus-scanning/).

## Certificate management

For TLS inspection to work, user devices must trust the Cloudflare root certificate.

### Install certificate using WARP

Cloudflare recommends deploying certificates automatically through the WARP client. WARP installs the certificate to the device's system certificate store without requiring manual user intervention.

For more information, refer to [Install certificate using WARP](/cloudflare-one/team-and-resources/devices/user-side-certificates/automated-deployment/).

### Install certificate manually

For devices that do not support automated certificate installation through WARP, or for specific applications that require manual certificate installation, you can download and install the certificate manually.

<Render file="gateway/download-cert" product="cloudflare-one" />

For detailed instructions on installing the certificate on different operating systems and applications, refer to [Install certificate manually](/cloudflare-one/team-and-resources/devices/user-side-certificates/manual-deployment/).

## Verify Gateway deployment

To verify that Gateway is deployed properly, test it with a device in your organization:

{/* prettier-ignore-start */}

1. On a device with WARP connected, visit a test website, such as [https://cloudflare.com](https://cloudflare.com).
2. Check the certificate details in your browser:

	<Tabs>
	<TabItem label="Chrome">

	1. Select the site information icon in the address bar.
	2. Select **Connection is secure**.
	3. Select **Certificate is valid**.

	</TabItem>
	<TabItem label="Firefox">

	1. Select the lock icon in the address bar.
	2. Select **Connection secure**.
	3. Select **More information**.
	4. Select **View Certificate**.

	</TabItem>
	<TabItem label="Safari">

	1. Select the lock icon in the address bar.
	2. Select **Show Details**.
	3. Select **View Certificate**.

	</TabItem>
	<TabItem label="Edge">

	1. Select the site information icon in the address bar.
	2. Select **Connection is secure**.
	3. Select **Certificate is valid**.

	</TabItem>
	</Tabs>

	The certificate issued by Cloudflare should be in use.

{/* prettier-ignore-end */}

3. In [Cloudflare One](https://one.dash.cloudflare.com/), go to **Insights** > **Logs**.
4. Choose **HTTP request logs**.
5. Verify that Gateway logs are available.

## Next steps

With Gateway deployed and TLS inspection turned on, you can now:

- Deploy the WARP client to user devices
- Build HTTP policies to control application access
- Apply DLP policies to detect sensitive data in transit

Data in transit refers to information actively moving across networks, such as web traffic, file uploads and downloads, and API calls. Protecting data in transit requires inline inspection and policy enforcement as data flows through your network.

Cloudflare Gateway acts as a secure web gateway (SWG) and inline cloud access security broker (CASB) to inspect and control data in transit. By deploying Gateway with TLS inspection and DLP policies, you can prevent sensitive data from leaving your organization through web applications, cloud services, and other Internet destinations.

## Objectives

By the end of this module, you will be able to:

- Deploy the Gateway proxy with TLS inspection enabled.
- Install and configure the WARP client on user devices.
- Use Gateway Analytics and Shadow IT Discovery to understand application usage.
- Build HTTP policies to control access to applications and data.
- Implement tenant controls to restrict access to corporate SaaS instances.
- Monitor policy effectiveness and adjust based on analytics.

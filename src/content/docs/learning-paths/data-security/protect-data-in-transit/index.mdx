Data in transit refers to information actively moving across networks — web traffic, file uploads and downloads, API calls, and more. Protecting data in transit requires inline inspection and policy enforcement as data flows through your network.

Cloudflare Gateway acts as a secure web gateway (SWG) and inline CASB to inspect and control data in transit. By deploying Gateway with TLS inspection and DLP policies, you can prevent sensitive data from leaving your organization through web applications, cloud services, and other Internet destinations.

## Overview

This module covers:

- Deploying Gateway proxy and enabling TLS decryption
- Installing the WARP client and root certificate on devices
- Analyzing traffic patterns and discovering shadow IT
- Building baseline HTTP policies for security
- Implementing tenant controls for SaaS applications
- Creating DLP policies to detect and block sensitive data
- Monitoring and fine-tuning policies based on analytics

## Objectives

By the end of this module, you will be able to:

- Deploy Gateway proxy with TLS inspection enabled.
- Install and configure the WARP client on user devices.
- Use Gateway Analytics and Shadow IT Discovery to understand application usage.
- Build HTTP policies to control access to applications and data.
- Implement tenant controls to restrict access to corporate SaaS instances.
- Create DLP policies to prevent sensitive data exfiltration.
- Monitor policy effectiveness and adjust based on analytics.

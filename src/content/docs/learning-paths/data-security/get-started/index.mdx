In this learning path, you will learn how to protect your organization's sensitive data using Cloudflare One's comprehensive data security features. You will deploy solutions to secure data in transit (using Gateway and DLP), data at rest (using CASB), and data in use (using Browser Isolation).

This guide will walk you through setting up your Cloudflare Zero Trust environment and implementing data protection policies across your organization. You will learn how to prevent data exfiltration, discover shadow IT, control access to generative AI tools, and secure your SaaS applications.

## Objectives

By the end of this module, you will be able to:

- Understand the architecture and requirements for a comprehensive data security deployment.

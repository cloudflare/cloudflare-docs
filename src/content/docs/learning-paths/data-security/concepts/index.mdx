Learn the core concepts of using Cloudflare One to protect your organization's sensitive data across all states: in transit, at rest, and in use.

## Objectives

By the end of this module, you will be able to:

- Understand what data security features Cloudflare offers.
- Describe the different states of data and how to protect each.
- Identify which data protection approach best fits your organization's needs.
- Recognize common data security use cases and how Cloudflare addresses them.

## What is Zero Trust Network Access (ZTNA)?

Zero Trust Network Access provides secure access to private applications and networks based on user identity and device posture, without exposing resources to the Internet.

For more information, refer to the [Cloudflare Tunnel documentation](/cloudflare-one/networks/connectors/cloudflare-tunnel/) and [Replace your VPN learning path](/learning-paths/replace-vpn/concepts/).

## What is the WARP client?

The WARP client is a lightweight agent that runs on user devices to route traffic through Cloudflare's network for inspection and policy enforcement.

For more information, refer to the [WARP client documentation](/cloudflare-one/team-and-resources/devices/warp/).

## What is Application Granular Controls?

Application Granular Controls provides granular control over user actions within specific SaaS applications. This allows you to give users access to an application while restricting specific actions they can take within the application.

Application Granular Controls works with Gateway HTTP policies and supports various SaaS applications including ChatGPT, Google Workspace, Microsoft 365, and more.

For more information, refer to [Application Granular Controls](/cloudflare-one/traffic-policies/http-policies/granular-controls/).

Data Loss Prevention (DLP) is your primary defense against sensitive data leaving your organization. This module provides an in-depth look at DLP capabilities, profile configuration, and advanced detection techniques.

## Overview

This module covers:

- Understanding DLP profiles and detection entries
- Choosing between predefined and custom profiles
- Configuring advanced DLP settings (OCR, context analysis, confidence levels)
- Using Exact Data Match (EDM) for specific datasets
- Integrating with Microsoft Information Protection (MIP)
- Best practices for creating and managing DLP policies

## When to use different DLP approaches

### Predefined profiles

Use predefined profiles when:

- Detecting common sensitive data types (credit cards, SSNs, etc.)
- Starting quickly with minimal configuration
- Meeting standard compliance requirements (PCI, HIPAA)

### Custom profiles

Use custom profiles when:

- Detecting organization-specific data patterns
- Identifying proprietary information formats
- Creating industry-specific detection rules (for example, source code patterns for tech companies)

### Exact Data Match (EDM)

Use EDM when:

- Protecting specific datasets (employee lists, customer databases)
- Detecting exact values rather than patterns
- Minimizing false positives for known sensitive data

## Objectives

By the end of this module, you will be able to:

- Understand the difference between DLP profiles and detection entries.
- Choose the appropriate DLP approach for different data types.
- Configure advanced DLP settings to optimize detection accuracy.
- Create and manage Exact Data Match datasets.
- Integrate DLP with Microsoft Information Protection labels.
- Apply DLP best practices to prevent data exfiltration.

Data Loss Prevention (DLP) is your primary defense against sensitive data leaving your organization. This module provides comprehensive coverage of DLP, from understanding core concepts to building policies and configuring advanced detection techniques.

## Objectives

By the end of this module, you will be able to:

- Understand the difference between DLP profiles and detection entries.
- Build Gateway HTTP policies that use DLP to prevent data exfiltration.
- Create and manage Exact Data Match datasets.
- Integrate DLP with Microsoft Information Protection labels.

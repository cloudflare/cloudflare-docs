After understanding DLP profiles and detection entries, you can build Gateway HTTP policies that use DLP to detect and prevent sensitive data exfiltration.

## How DLP works with Gateway

Cloudflare DLP scans traffic inline as it flows through Gateway, detecting sensitive data patterns in:

- File uploads and downloads
- Form submissions
- API requests and responses
- Copy/paste operations (when using Browser Isolation)

When DLP detects sensitive data that matches a profile, the associated Gateway HTTP policy action is taken (Block, Allow, Isolate).

## Build DLP policies

Create Gateway HTTP policies that reference your DLP profiles to enforce data protection.

### Block sensitive data uploads to AI applications

Prevent users from sharing sensitive information with AI tools.

<Tabs syncKey="dashPlusAPI"> <TabItem label="Dashboard">

| Selector         | Operator | Value                          | Logic | Action |
| ---------------- | -------- | ------------------------------ | ----- | ------ |
| Application      | in       | _Artificial Intelligence_      | And   | Block  |
| DLP Profile      | in       | _Financial Information_, _PII_ | And   |        |
| Upload Mime Type | in       | _All File Types_               |       |        |

</TabItem> <TabItem label="API">

```bash
curl https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/rules \
--header "Authorization: Bearer <API_TOKEN>" \
--header "Content-Type: application/json" \
--data '{
  "name": "Block sensitive data uploads to AI",
  "conditions": [
    {
      "type": "traffic",
      "expression": "any(app.ids[*] in {\"b0694d0e-b5e5-4e4f-8d5e-1e4e4e4e4e4e\"}) and any(dlp.profiles[*] in {\"financial_information\", \"pii\"}) and any(http.request.mime_types[*] in {\"*/*\"})"
    }
  ],
  "action": "block",
  "enabled": true
}'
```

</TabItem> <TabItem label="Terraform">

```tf
resource "cloudflare_zero_trust_gateway_policy" "block_ai_sensitive_data" {
  account_id  = var.account_id
  name        = "Block sensitive data uploads to AI"
  description = "Prevent users from sharing sensitive information with AI tools"
  action      = "block"
  enabled     = true
  filters     = ["http"]
  traffic     = "any(app.ids[*] in {\"b0694d0e-b5e5-4e4f-8d5e-1e4e4e4e4e4e\"}) and any(dlp.profiles[*] in {\"financial_information\", \"pii\"}) and any(http.request.mime_types[*] in {\"*/*\"})"
}
```

</TabItem> </Tabs>

### Block source code uploads to personal repositories

Prevent intellectual property leakage.

<Tabs syncKey="dashPlusAPI"> <TabItem label="Dashboard">

| Selector            | Operator | Value                | Logic | Action |
| ------------------- | -------- | -------------------- | ----- | ------ |
| Application         | in       | _GitHub_             | And   | Block  |
| GitHub Organization | not in   | `your-corporate-org` | And   |        |
| DLP Profile         | in       | _Source Code_        |       |        |

</TabItem> <TabItem label="API">

```bash
curl https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/rules \
--header "Authorization: Bearer <API_TOKEN>" \
--header "Content-Type: application/json" \
--data '{
  "name": "Block source code uploads to personal GitHub",
  "conditions": [
    {
      "type": "traffic",
      "expression": "app.id == \"github\" and not(github.org == \"your-corporate-org\") and any(dlp.profiles[*] in {\"source_code\"})"
    }
  ],
  "action": "block",
  "enabled": true
}'
```

</TabItem> <TabItem label="Terraform">

```tf
resource "cloudflare_zero_trust_gateway_policy" "block_personal_github_source_code" {
  account_id  = var.account_id
  name        = "Block source code uploads to personal GitHub"
  description = "Prevent intellectual property leakage to personal repositories"
  action      = "block"
  enabled     = true
  filters     = ["http"]
  traffic     = "app.id == \"github\" and not(github.org == \"your-corporate-org\") and any(dlp.profiles[*] in {\"source_code\"})"
}
```

</TabItem> </Tabs>

### Detect sensitive data in file uploads

Monitor and optionally block sensitive data uploads to cloud storage.

<Tabs syncKey="dashPlusAPI"> <TabItem label="Dashboard">

| Selector         | Operator | Value            | Logic | Action |
| ---------------- | -------- | ---------------- | ----- | ------ |
| Application      | in       | _File Sharing_   | And   | Block  |
| DLP Profile      | in       | _PII_            | And   |        |
| Upload Mime Type | in       | _All File Types_ |       |        |

:::note
Before you enforce blocks, you can set the action to _Allow_ with logging enabled to monitor uploads and understand false positives.
:::

</TabItem> <TabItem label="API">

```bash
curl https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/rules \
--header "Authorization: Bearer <API_TOKEN>" \
--header "Content-Type: application/json" \
--data '{
  "name": "Block PII uploads to cloud storage",
  "conditions": [
    {
      "type": "traffic",
      "expression": "any(app.ids[*] in {\"cloud_storage\"}) and any(dlp.profiles[*] in {\"pii\"}) and any(http.request.mime_types[*] in {\"*/*\"})"
    }
  ],
  "action": "block",
  "enabled": true
}'
```

</TabItem> <TabItem label="Terraform">

```tf
resource "cloudflare_zero_trust_gateway_policy" "block_pii_cloud_storage" {
  account_id  = var.account_id
  name        = "Block PII uploads to cloud storage"
  description = "Monitor and block sensitive data uploads to cloud storage"
  action      = "block"
  enabled     = true
  filters     = ["http"]
  traffic     = "any(app.ids[*] in {\"cloud_storage\"}) and any(dlp.profiles[*] in {\"pii\"}) and any(http.request.mime_types[*] in {\"*/*\"})"
}
```

## DLP policy patterns

The following DLP policy patterns help you implement more sophisticated data protection strategies.

### Monitor before blocking

To understand data flows before enforcing blocks, set the action for a DLP profile to _Allow_ with logging turned on. After you review your logs to identify false positives, you can refine the policy and change the action to _Block_.

<Tabs syncKey="dashPlusAPI"> <TabItem label="Dashboard">

| Selector    | Operator | Value                   | Action |
| ----------- | -------- | ----------------------- | ------ |
| DLP Profile | in       | _Financial Information_ | Allow  |

</TabItem> <TabItem label="API">

```bash
curl https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/rules \
--header "Authorization: Bearer <API_TOKEN>" \
--header "Content-Type: application/json" \
--data '{
  "name": "Monitor financial information",
  "conditions": [
    {
      "type": "traffic",
      "expression": "any(dlp.profiles[*] in {\"financial_information\"})"
    }
  ],
  "action": "allow",
  "enabled": true
}'
```

</TabItem> <TabItem label="Terraform">

```tf
resource "cloudflare_zero_trust_gateway_policy" "monitor_financial_info" {
  account_id  = var.account_id
  name        = "Monitor financial information"
  description = "Audit mode to understand data flows"
  action      = "allow"
  enabled     = true
  filters     = ["http"]
  traffic     = "any(dlp.profiles[*] in {\"financial_information\"})"
}
```

</TabItem> </Tabs>

### Scope DLP to specific applications

Apply DLP only to high-risk applications.

<Tabs syncKey="dashPlusAPI"> <TabItem label="Dashboard">

| Selector    | Operator | Value                                     | Logic | Action |
| ----------- | -------- | ----------------------------------------- | ----- | ------ |
| Application | in       | _Artificial Intelligence_, _File Sharing_ | And   | Block  |
| DLP Profile | in       | _Source Code_                             |       |        |

</TabItem> <TabItem label="API">

```bash
curl https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/rules \
--header "Authorization: Bearer <API_TOKEN>" \
--header "Content-Type: application/json" \
--data '{
  "name": "Block source code to high-risk apps",
  "conditions": [
    {
      "type": "traffic",
      "expression": "any(app.ids[*] in {\"cloud_storage\", \"ai\", \"file_sharing\"}) and any(dlp.profiles[*] in {\"source_code\"})"
    }
  ],
  "action": "block",
  "enabled": true
}'
```

</TabItem> <TabItem label="Terraform">

```tf
resource "cloudflare_zero_trust_gateway_policy" "scope_dlp_high_risk_apps" {
  account_id  = var.account_id
  name        = "Block source code to high-risk apps"
  description = "Apply DLP only to high-risk applications"
  action      = "block"
  enabled     = true
  filters     = ["http"]
  traffic     = "any(app.ids[*] in {\"cloud_storage\", \"ai\", \"file_sharing\"}) and any(dlp.profiles[*] in {\"source_code\"})"
}
```

</TabItem> </Tabs>

Enforce stricter DLP for contractors or high-risk users.

| ---------------- | -------- | ------------------- | ----- | ------ |

</TabItem> <TabItem label="API">

  "enabled": true

## Monitor DLP effectiveness

Once you have implemented DLP policies, monitor their effectiveness in Gateway logs:

1. In [Cloudflare One](https://one.dash.cloudflare.com/), go to **Insights** > **Logs**.
2. Choose **HTTP request logs**.
3. Filter by **DLP profiles** to see which data types are being detected.

Review your logs regularly to identify false positives and adjust your DLP profiles and policies accordingly.

Microsoft Purview Information Protection (MIP) provides [sensitivity labels](https://learn.microsoft.com/purview/sensitivity-labels) to classify and protect sensitive data. By integrating your Microsoft account with Cloudflare One, you can enforce DLP policies based on these sensitivity labels across all applications, not just within Microsoft 365.

## Prerequisites

- Microsoft 365 E3 or E5 license with Purview Information Protection labels configured
- Cloudflare Enterprise plan with DLP
- Administrator access to both Microsoft 365 and Cloudflare Zero Trust

## Set up MIP integration

1. In [Cloudflare One](https://one.dash.cloudflare.com/), go to **Integrations** > **Cloud & SaaS**.
2. Select **Add integration**, then choose **Microsoft**
3. Follow the Microsoft authentication flow.
4. Grant the required permissions for MIP label access.

For more information, refer to [Microsoft 365 CASB integration](/cloudflare-one/integrations/cloud-and-saas/casb-integrations/microsoft-365/).

## Use MIP labels in DLP policies

After configuring the Microsoft integration, a new integration profile named **MIP Sensitivity Labels** will automatically appear under **Data loss prevention** > **Profiles**. This profile contains all your Microsoft sensitivity labels.

You can use the Microsoft integration profile directly in Gateway policies, or add specific labels to a custom DLP profile:

1. In [Cloudflare One](https://one.dash.cloudflare.com/), go to **Data loss prevention** > **Profiles**.
2. Create a new custom profile, or choose an existing one and select **Edit**.
3. Select **Add existing entries**.
4. Choose **Microsoft Information Protection Label** and select the labels you want to detect.
5. Select **Save profile**.

## Example policies

### Block highly confidential uploads

Prevent files labeled as "Highly Confidential" from being uploaded to non-Microsoft applications.

<Tabs syncKey="dashPlusAPI"> <TabItem label="Dashboard">

| Selector         | Operator | Value                    | Logic | Action |
| ---------------- | -------- | ------------------------ | ----- | ------ |
| Application      | not in   | _Microsoft 365_          | And   | Block  |
| DLP Profile      | in       | _MIP Sensitivity Labels_ | And   |        |
| Upload Mime Type | in       | _All File Types_         |       |        |

In the DLP Profile selector, choose the **MIP Sensitivity Labels** integration profile and select the `Highly Confidential` label.

</TabItem> <TabItem label="API">

```bash
curl https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/rules \
--header "Authorization: Bearer <API_TOKEN>" \
--header "Content-Type: application/json" \
--data '{
  "name": "Block highly confidential uploads to non-Microsoft apps",
  "conditions": [
    {
      "type": "traffic",
      "expression": "not any(app.ids[*] in {1489}) and any(dlp.profiles[*] in {\"<mip_profile_id>\"}) and any(http.request.mime_types[*] in {\"*/*\"})"
    }
  ],
  "action": "block",
  "enabled": true
}'
```

Replace `<mip_profile_id>` with your MIP Sensitivity Labels integration profile ID. The app ID `1489` represents Microsoft 365.

</TabItem> <TabItem label="Terraform">

```tf
resource "cloudflare_zero_trust_gateway_policy" "block_highly_confidential_uploads" {
  account_id  = var.account_id
  name        = "Block highly confidential uploads to non-Microsoft apps"
  description = "Prevent Highly Confidential labeled files from being uploaded outside Microsoft 365"
  action      = "block"
  enabled     = true
  filters     = ["http"]
  traffic     = "not any(app.ids[*] in {1489}) and any(dlp.profiles[*] in {\"<mip_profile_id>\"}) and any(http.request.mime_types[*] in {\"*/*\"})"
}
```

Replace `<mip_profile_id>` with your MIP Sensitivity Labels integration profile ID.

</TabItem> </Tabs>

### Isolate confidential files

Allow access to confidential files in external applications but restrict actions like downloads and copy/paste using Browser Isolation.

<Tabs syncKey="dashPlusAPI"> <TabItem label="Dashboard">

| Selector    | Operator | Value                    | Logic | Action  |
| ----------- | -------- | ------------------------ | ----- | ------- |
| Application | not in   | _Microsoft 365_          | And   | Isolate |
| DLP Profile | in       | _MIP Sensitivity Labels_ |       |         |

In the DLP Profile selector, choose the **MIP Sensitivity Labels** integration profile and select the `Confidential` label (with or without children).

In the policy settings, configure isolation options:

- Disable file downloads
- Disable copy/paste
- Disable printing

</TabItem> <TabItem label="API">

```bash
curl https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/rules \
--header "Authorization: Bearer <API_TOKEN>" \
--header "Content-Type: application/json" \
--data '{
  "name": "Isolate confidential files in external apps",
  "conditions": [
    {
      "type": "traffic",
      "expression": "not any(app.ids[*] in {1489}) and any(dlp.profiles[*] in {\"<mip_profile_id>\"})"
    }
  ],
  "action": "isolate",
  "enabled": true,
  "rule_settings": {
    "isolate": {
      "disable_copy_paste": true,
      "disable_download": true,
      "disable_printing": true
    }
  }
}'
```

Replace `<mip_profile_id>` with your MIP Sensitivity Labels integration profile ID.

</TabItem> <TabItem label="Terraform">

```tf
resource "cloudflare_zero_trust_gateway_policy" "isolate_confidential_files" {
  account_id  = var.account_id
  name        = "Isolate confidential files in external apps"
  description = "Allow access to confidential files but restrict actions using Browser Isolation"
  action      = "isolate"
  enabled     = true
  filters     = ["http"]
  traffic     = "not any(app.ids[*] in {1489}) and any(dlp.profiles[*] in {\"<mip_profile_id>\"})"

  rule_settings {
    isolate {
      disable_copy_paste = true
      disable_download   = true
      disable_printing   = true
    }
  }
}
```

Replace `<mip_profile_id>` with your MIP Sensitivity Labels integration profile ID.

</TabItem> </Tabs>

### Syncing

Allow 24 hours for label additions and edits in your Microsoft account to propagate to Cloudflare DLP. Deletions in your Microsoft account will not delete entries in your Cloudflare DLP profile.

### Supported file types

MIP labels are supported for Microsoft Office files, PDFs, and some other file formats with embedded labels.

### Managed entries

Detection entries in the MIP integration profile are managed by Microsoft and cannot be manually added, edited, or deleted within Cloudflare DLP.

## Combine with content-based DLP

You can layer label-based and content-based detection for comprehensive protection. For example, create a profile that detects files with a "Confidential - Financial" label OR files containing credit card patterns, providing both label-based and pattern-based coverage.

## Best practices

- Start with high-sensitivity labels (Highly Confidential, Restricted) before expanding to lower sensitivity levels
- Use label-based policies for broad categories and content-based DLP for specific data patterns
- Test label detection with sample labeled files before deploying policies
- Ensure TLS inspection is enabled for label scanning

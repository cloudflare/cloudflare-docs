import { DashButton } from "~/components";

1. In the [Cloudflare dashboard](https://dash.cloudflare.com/), go to **Zero Trust** > **Email security** > **Settings**.

   <DashButton url="/?to=/:account/email-security/settings" zeroTrust />
3. Select **Connect an integration**, choose **Google Workspace CASB + EMAIL**, then select **Select Integration**.
4. Follow the wizard to create an integration, then select **Create Integration**. Refer to [Enable Gmail BCC integration](/cloudflare-one/email-security/setup/post-delivery-deployment/bcc-journaling/bcc-setup/gmail-bcc-setup/enable-gmail-integration/) for further instructions.

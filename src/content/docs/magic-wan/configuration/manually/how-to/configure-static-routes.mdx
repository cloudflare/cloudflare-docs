## Next steps

Refer to [Set up a site](#) to create a site. Sites represent the local network of a data center, office or other physical location that combine all on-ramps used by your account. Sites also allow you to check, at a glance, the state of your on-ramps and set up health alert settings so that you get notified when there are issues with the site's on-ramps.

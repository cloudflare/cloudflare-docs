## Overview

Modern enterprises need to secure a distributed workforce accessing applications from anywhere. Traditional perimeter-based security is no longer sufficient. Cloudflare One provides a complete SASE platform to protect users, devices, and data without sacrificing performance.

### Common challenges

- **Remote workforce** - Employees access applications from untrusted networks
- **VPN limitations** - Legacy VPNs are slow, complex, and provide excessive access
- **Phishing attacks** - Email remains the primary vector for security breaches
- **Data loss** - Sensitive data can leak through web, email, and SaaS applications
- **Shadow IT** - Employees use unsanctioned applications without visibility

## Architecture patterns

### Zero Trust access

Replace VPNs with identity-aware application access:

1. **Access** authenticates users against your identity provider
2. **Tunnel** connects applications without exposing them to the internet
3. **Device posture** checks ensure only compliant devices connect

### Secure web gateway

Protect users from internet threats:

1. **WARP** routes device traffic through Cloudflare
2. **Gateway** applies DNS and HTTP policies
3. **Browser Isolation** renders risky content safely

### Email security

Defend against phishing and email-based attacks:

1. **Email Security** scans inbound messages for threats
2. **Link isolation** protects users who click suspicious links
3. **DMARC Management** prevents domain spoofing

Protect your website or application from attacks, bots, and abuse with Cloudflare's security solutions.

<DirectoryListing />

## Prerequisites

- A [Cloudflare account](https://dash.cloudflare.com/sign-up).
- A domain [added to Cloudflare](/fundamentals/manage-domains/add-site/). All products in this use case — SSL/TLS, WAF (Web Application Firewall), DDoS (Distributed Denial of Service) Protection, Bot Security, and Client-side security — require your domain's DNS records to be proxied through Cloudflare so that traffic passes through Cloudflare's network before reaching your origin.

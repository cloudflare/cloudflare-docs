## What you get

- **Managed rulesets** (Application Security / Web Application Firewall (WAF)) - Pre-configured rules covering OWASP Top 10 and emerging threats, updated by Cloudflare
- **Zero-day protection** (Application Security / WAF) - Rules are updated as new vulnerabilities are discovered, with no action required from you
- **Custom rules** (Custom Rules) - Block or challenge requests based on any request attribute including headers, cookies, and IP reputation
- **Rate limiting** (Rate Limiting) - Prevent brute force attacks and Application Programming Interface (API) abuse with flexible per-endpoint request limits

## Features

- **Managed rulesets** (Application security) - Pre-configured rules covering OWASP Top 10 and emerging threats, updated by Cloudflare
- **Zero-day protection** (Application security) - Rules are updated as new vulnerabilities are discovered, with no action required from you
- **Custom rules** (Application security) - Block or challenge requests based on any request attribute including headers, cookies, and IP reputation
- **Rate limiting** (Rate limiting) - Prevent brute force attacks and Application Programming Interface (API) abuse with flexible per-endpoint request limits

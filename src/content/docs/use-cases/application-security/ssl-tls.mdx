## What you get

- **Free certificates** (SSL/TLS) - Universal SSL certificates provisioned automatically at no cost
- **Automatic renewal** (SSL/TLS) - Certificates renew before expiration with no manual intervention
- **Full encryption** (SSL/TLS) - End-to-end encryption between visitors and your origin server
- **Custom domain certificates** (SSL for SaaS) - Provision and manage certificates for customer-owned domains at scale

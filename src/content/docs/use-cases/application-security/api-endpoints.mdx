## What you get

- **API discovery** (API Shield) - Automatically identify API endpoints in your traffic, including undocumented ones
- **Schema validation** (API Shield) - Reject requests that do not conform to your OpenAPI specification
- **Sequence mitigation** (API Shield) - Detect and block API abuse patterns such as out-of-order requests
- **mTLS authentication** (mutual TLS / mTLS) - Require client certificates for machine-to-machine API access

For the complete guide, refer to [API Shield get started](/api-shield/get-started/).

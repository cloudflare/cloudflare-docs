## Features

- **Script monitoring** (Client-side security) - Track every JavaScript resource loading on your pages, including third-party scripts
- **Malicious script detection** (Client-side security) - Receive alerts when scripts exhibit suspicious behavior such as data exfiltration patterns
- **Connection monitoring** (Client-side security) - See which external endpoints scripts are sending data to
- **CSP management** (Client-side security) - Generate and manage Content Security Policies (CSPs) based on observed script behavior

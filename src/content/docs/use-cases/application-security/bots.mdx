## What you get

- **Bot scores** (Bot Security) - Every request receives an ML-derived bot score from 1 (bot) to 99 (human)
- **Verified bots** (Bot Security) - Allow known good bots like search engine crawlers while blocking malicious ones
- **Challenge pages** (Super Bot Fight Mode) - Present JavaScript (JS) or managed challenges to suspicious traffic on Pro plans and above
- **Form protection** (Turnstile) - Privacy-preserving CAPTCHA alternative that protects login, signup, and checkout forms without friction

## What you get

- **Fast DNS resolution** (DNS) - Cloudflare's authoritative DNS responds in under 10ms globally
- **DNS-layer DDoS protection** (DNS) - DNS infrastructure is protected against volumetric attacks such as DNS amplification, query floods, and NXDOMAIN floods at the network layer. This is separate from HTTP Distributed Denial of Service (DDoS) protection, which is covered under [Protect your store](/use-cases/e-commerce/protect/)
- **DNSSEC** (DNS) - Domain Name System Security Extensions (DNSSEC) provides cryptographic verification that prevents DNS spoofing and cache poisoning
- **Domain privacy** (Registrar) - WHOIS privacy protection included at no extra cost when registering through Cloudflare

## What you get

- **Real user metrics** (Web Analytics) - Core Web Vitals and performance data collected from actual visitors without cookies or sampling
- **Security visibility** (Security Analytics) - Understand Web Application Firewall (WAF) rule triggers, bot activity patterns, and attack trends in one view
- **Compliance logging** (Logs) - Export detailed request logs to your Security Information and Event Management (SIEM) system or data warehouse for audit trails and forensic analysis

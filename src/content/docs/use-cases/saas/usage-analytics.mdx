## What you get

- **Per-tenant metrics** (Workers Analytics Engine) - Track request counts, latency, and bytes transferred broken down by tenant ID
- **Billing data** (Workers Analytics Engine + Logpush) - Query usage data per customer to power usage-based billing calculations
- **Compliance logging** (Logpush) - Export detailed logs to your Security Information and Event Management (SIEM) system or data warehouse for audit trails and enterprise compliance
- **Performance insights** (Workers Analytics Engine) - Identify which tenants are generating the most load or experiencing the most errors

### Usage tracking

<Details header="Track per-tenant usage with Analytics Engine">

Add the following to your Worker's `src/index.ts`. The Worker writes a data point to Workers Analytics Engine on every request, recording the tenant ID, country, response time, and payload size.

```ts
export default {
	async fetch(request: Request, env: Env): Promise<Response> {
		const tenantId = request.headers.get("X-Tenant-ID") ?? "unknown";
		const startTime = Date.now();

		// Process request
		const response = await handleRequest(request, env);

		// Record usage metrics
		env.ANALYTICS.writeDataPoint({
			blobs: [tenantId, request.cf?.country ?? ""],
			doubles: [
				Date.now() - startTime,
				Number(response.headers.get("Content-Length") ?? 0),
			],
			indexes: [tenantId],
		});

		return response;
	},
};
```

Query usage for billing:

```sql
SELECT
  blob1 as tenant_id,
  COUNT(*) as requests,
  SUM(double2) as bytes_transferred
FROM analytics
WHERE timestamp > now() - interval '30 days'
GROUP BY tenant_id
```

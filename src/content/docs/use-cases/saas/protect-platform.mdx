## What you get

- **Platform protection** (Application Security) - Web Application Firewall (WAF) managed rulesets block common attacks against your platform and your customers' endpoints
- **Per-tenant limits** (Rate Limiting) - Apply rate limits per customer identifier to prevent one tenant from degrading service for others
- **Admin security** (Access) - Gate internal dashboards and admin tools behind Zero Trust identity policies
- **API protection** (Application Security + Rate Limiting) - Secure platform Application Programming Interfaces (APIs) with WAF rules and per-API-key rate limits

### Security configuration

<Details header="Per-tenant rate limiting">

Configure rate limits that apply per customer:

1. Go to **Security** > **Application Security** > **Rate limiting rules**
2. Create a rule with:
   - **Expression**: `http.host contains "customer-domain.com"`
   - **Counting expression**: Use customer identifier header or cookie
   - **Rate**: Set appropriate limits per tenant tier

Example for API rate limiting:

```
(http.request.uri.path contains "/api/") and
(http.request.headers["x-tenant-id"] eq "tenant-123")
```

</Details>

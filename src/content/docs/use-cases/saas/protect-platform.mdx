## Features

- **Platform protection** (Application Security) - Web Application Firewall (WAF) managed rulesets block common attacks against your platform and your customers' endpoints
- **Per-tenant limits** (Rate Limiting) - Apply rate limits per customer identifier to prevent one tenant from degrading service for others
- **Admin security** (Cloudflare One) - Gate internal dashboards and admin tools behind Zero Trust identity policies
- **API protection** (Application Security + Rate Limiting) - Secure platform Application Programming Interfaces (APIs) with WAF rules and per-API-key rate limits

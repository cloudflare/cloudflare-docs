Store customer data with appropriate isolation using Cloudflare's storage products.

## Solutions

<CardGrid>

<LinkTitleCard title="D1" href="/d1/" icon="d1">

Serverless SQL database built on SQLite, with global read replication.

</LinkTitleCard>

<LinkTitleCard title="R2" href="/r2/" icon="r2">

S3-compatible object storage with zero egress fees.

</LinkTitleCard>

<LinkTitleCard title="Durable Objects" href="/durable-objects/" icon="durable-objects">

Stateful objects with strongly consistent storage and coordination.

</LinkTitleCard>

<LinkTitleCard title="KV" href="/kv/" icon="kv">

Globally distributed key-value storage for low-latency reads.

</LinkTitleCard>

</CardGrid>

### D1

- **Database per tenant** - Create isolated D1 databases per customer for complete data separation, or use row-level isolation in a shared database

### R2

- **Object storage** - Store customer files and assets per tenant using prefix or bucket-level isolation, with no egress fees

### Durable Objects

- **Real-time coordination** - Manage stateful workflows and provide strong consistency for multi-tenant operations

### KV

- **Edge configuration** - Store per-tenant settings, feature flags, and session data at the edge for low-latency reads

## What you get

- **Global deployment** (Workers) - API handlers run in 300+ Cloudflare locations worldwide with no regional configuration
- **Auto-scaling** (Workers) - Handle traffic spikes without provisioning servers or setting capacity limits
- **Async processing** (Queues) - Offload webhook delivery and background jobs without blocking the API response
- **Integrated storage** (D1 / Durable Objects) - Structured Query Language (SQL) database and strongly consistent state storage available as Worker bindings

## Get started

<Details header="Build a REST API with Workers">

1. In your terminal, create a new Worker project:

   ```sh
   npm create cloudflare@latest my-api -- --template hello-world
   cd my-api
   ```

2. In `src/index.ts`, build your Representational State Transfer (REST) API:

   ```ts
   export default {
   	async fetch(request: Request, env: Env): Promise<Response> {
   		const url = new URL(request.url);

   		// Route requests
   		if (url.pathname === "/api/users" && request.method === "GET") {
   			const users = await env.DB.prepare("SELECT * FROM users").all();
   			return Response.json(users.results);
   		}

   		if (url.pathname === "/api/users" && request.method === "POST") {
   			const body = await request.json();
   			await env.DB.prepare("INSERT INTO users (name, email) VALUES (?, ?)")
   				.bind(body.name, body.email)
   				.run();
   			return Response.json({ success: true }, { status: 201 });
   		}

   		return new Response("Not Found", { status: 404 });
   	},
   };
   ```

3. Back in your terminal, deploy your API:
   ```sh
   npx wrangler deploy
   ```

</Details>

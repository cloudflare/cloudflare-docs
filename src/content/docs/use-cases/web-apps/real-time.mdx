## What you get

- **WebSocket support** (Durable Objects) - Maintain persistent connections and broadcast messages across clients in real time
- **Collaborative editing** (Durable Objects) - Build multiplayer and co-editing experiences with strongly consistent shared state
- **Event processing** (Queues) - Handle webhooks and background jobs reliably without blocking the main request path
- **Strong consistency** (Durable Objects) - Coordinate state across many concurrent connections with transactional guarantees

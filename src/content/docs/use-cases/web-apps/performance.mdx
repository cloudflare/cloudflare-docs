## What you get

- **Edge caching** (Cache) - Serve responses from the nearest Cloudflare location to reduce latency and origin load
- **Smart routing** (Argo Smart Routing) - Automatically avoid congested network paths between edge and origin
- **Asset optimization** (Speed) - Automatic minification of HTML, CSS, and JavaScript plus Brotli compression
- **Core Web Vitals** (Speed) - Improve Largest Contentful Paint (LCP), Interaction to Next Paint (INP), and Cumulative Layout Shift (CLS) scores with built-in optimizations

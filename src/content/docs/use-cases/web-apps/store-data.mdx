## What you get

- **SQL database** (D1) - Full Structured Query Language (SQL) with global read replication built on SQLite
- **Key-value storage** (KV) - Fast globally-distributed reads for configuration, sessions, and cached data
- **Object storage** (R2) - Store user-uploaded files and assets with no egress fees
- **Real-time state** (Durable Objects) - Strongly consistent coordination for collaborative features and live data

### Getting started with D1

<Details header="Set up a D1 database">

1. In your terminal, create a database:

   ```sh
   npx wrangler d1 create my-database
   ```

2. In `wrangler.toml`, add the D1 binding:

   ```toml
   [[d1_databases]]
   binding = "DB"
   database_name = "my-database"
   database_id = "your-database-id"
   ```

3. Back in your terminal, create the schema:

   ```sh
   npx wrangler d1 execute my-database --command "CREATE TABLE users (id INTEGER PRIMARY KEY, name TEXT, email TEXT)"
   ```

4. In `src/index.ts`, query your database from the Worker:
   ```ts
   const users = await env.DB.prepare("SELECT * FROM users WHERE id = ?")
   	.bind(userId)
   	.first();
   ```

</Details>

For the complete guide, refer to [D1 get started](/d1/get-started/).

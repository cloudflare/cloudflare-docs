## Solutions

<CardGrid>

## Features

- **SQL database** (D1) - Full Structured Query Language (SQL) with global read replication built on SQLite
- **Key-value storage** (KV) - Fast globally-distributed reads for configuration, sessions, and cached data
- **Object storage** (R2) - Store user-uploaded files and assets with no egress fees
- **Real-time state** (Durable Objects) - Strongly consistent coordination for collaborative features and live data

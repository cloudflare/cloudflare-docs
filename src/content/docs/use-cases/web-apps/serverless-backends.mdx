## What you get

- **Global deployment** (Workers) - Code runs at the Cloudflare location nearest to each user automatically
- **No cold starts** (Workers) - Sub-millisecond startup times with no warm-up period
- **Auto-scaling** (Workers) - Handle traffic spikes without provisioning or configuration
- **Scheduled tasks** (Cron Triggers) - Run Workers on a fixed schedule for background jobs and periodic tasks
- **Async processing** (Queues) - Reliably process background jobs and webhooks without blocking request handling

### Getting started with Workers

<Details header="Create and deploy a Worker">

1. In your terminal, create a new project:

   ```sh
   npm create cloudflare@latest my-app
   cd my-app
   ```

2. In `src/index.ts`, replace the default handler with your Worker code:

   ```ts
   export default {
   	async fetch(request: Request, env: Env): Promise<Response> {
   		const url = new URL(request.url);

   		if (url.pathname === "/api/hello") {
   			return Response.json({ message: "Hello from the edge!" });
   		}

   		return new Response("Not found", { status: 404 });
   	},
   };
   ```

3. Back in your terminal, test locally:

   ```sh
   npm run dev
   ```

4. Deploy:
   ```sh
   npm run deploy
   ```

</Details>

For the complete guide, refer to [Workers get started](/workers/get-started/).

## Features

- **Global deployment** (Workers) - Code runs at the Cloudflare location nearest to each user automatically
- **No cold starts** (Workers) - Sub-millisecond startup times with no warm-up period
- **Auto-scaling** (Workers) - Handle traffic spikes without provisioning or configuration
- **Scheduled tasks** (Cron Triggers) - Run Workers on a fixed schedule for background jobs and periodic tasks
- **Async processing** (Queues) - Reliably process background jobs and webhooks without blocking request handling

## Architecture patterns

### Full-stack application

Build a complete application with frontend and backend:

1. **Workers** serves your frontend assets (React, Vue, Astro, and similar frameworks) and handles Application Programming Interface (API) routes
2. **D1** stores application data
3. **R2** stores user uploads and assets

### Real-time collaborative app

Build multiplayer or collaborative features:

1. **Durable Objects** coordinates state and WebSocket connections
2. **Workers** handles HTTP requests and routing
3. **KV** caches frequently accessed data
4. **Queues** processes background tasks

### Static site with dynamic features

Add interactivity to static content:

1. **Workers** serves static HTML/CSS/JavaScript (JS) and handles form submissions and API calls
2. **KV** stores form data and user preferences
3. **R2** stores uploaded files

## Prerequisites

- A [Cloudflare account](https://dash.cloudflare.com/sign-up). Workers, D1, KV, R2, Durable Objects, and Queues are account-level products — you do not need a domain added to Cloudflare to deploy a Worker or use storage bindings.
- [Node.js](https://nodejs.org/) (version 16.17.0 or later) installed on your machine.
- [Wrangler](/workers/wrangler/install-and-update/) installed. Wrangler is the CLI for creating, testing, and deploying Workers projects.
- For security features (SSL/TLS, WAF, DDoS protection, Bot security): a domain [added to Cloudflare](/fundamentals/manage-domains/add-site/) with DNS records proxied through Cloudflare.

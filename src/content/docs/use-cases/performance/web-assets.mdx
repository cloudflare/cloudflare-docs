## What you get

- **Minification** (Speed) - Remove whitespace and unnecessary characters from HTML, CSS, and JavaScript automatically
- **Compression** (Speed) - Brotli and Gzip compression applied to all text-based assets at the edge
- **Third-party optimization** (Zaraz) - Load analytics, marketing tags, and other third-party tools through Cloudflare without blocking page rendering
- **Core Web Vitals** (Speed + Zaraz) - Improve Largest Contentful Paint (LCP), Interaction to Next Paint (INP), and Cumulative Layout Shift (CLS) scores by deferring non-critical scripts and optimizing asset delivery

### Configure optimizations

<Details header="Enable Speed optimizations">

1. Go to the [Cloudflare dashboard](https://dash.cloudflare.com/) and select your domain.
2. Go to **Speed** > **Optimization**.
3. Turn on optimizations:
   - **Auto Minify**: Minify HTML, CSS, and JavaScript
   - **Brotli**: Turn on Brotli compression
   - **Rocket Loader**: Defer JavaScript loading
   - **Mirage**: Optimize image loading on mobile

</Details>

For the complete guide, refer to [Speed documentation](/speed/).

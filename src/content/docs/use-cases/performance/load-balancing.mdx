## What you get

- **Traffic distribution** (Load Balancing) - Spread incoming load across multiple origin servers using weighted or latency-based policies
- **Health monitoring** (Health Checks) - Continuously probe origins and automatically remove unhealthy servers from rotation
- **Failover** (Load Balancing) - Reroute traffic to healthy origins instantly when a server fails its health check
- **Geographic steering** (Load Balancing) - Route users to the nearest or best-performing origin based on latency or geography

## What you get

- **Real user metrics** (Web Analytics) - Performance data collected from actual visitor sessions, not synthetic tests
- **Core Web Vitals** (Web Analytics) - Track Largest Contentful Paint (LCP), Interaction to Next Paint (INP), and Cumulative Layout Shift (CLS) scores across your real user base
- **Performance testing** (Observatory) - Run on-demand speed tests and receive prioritized optimization recommendations
- **No sampling** (Web Analytics) - 100% of page views are measured without cookies, consent banners, or data sampling

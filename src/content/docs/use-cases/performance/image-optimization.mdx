## What you get

- **Automatic compression** (Polish) - Reduce image file sizes through lossless or lossy compression without visible quality loss
- **Modern formats** (Images) - Automatically serve WebP or AV1 Image File Format (AVIF) to supported browsers, falling back gracefully for others
- **Responsive images** (Images) - Resize and transform images on-the-fly via URL parameters without pre-generating variants
- **Lazy loading** (Speed) - Defer loading of off-screen images to improve initial page load and Core Web Vitals

### Configure image optimization

<Details header="Enable Polish and WebP">

1. Go to the [Cloudflare dashboard](https://dash.cloudflare.com/) and select your domain.
2. Go to **Speed** > **Optimization** > **Image Optimization**.
3. Turn on **Polish** and select compression level:
   - **Lossless**: No quality loss, smaller file size reduction
   - **Lossy**: Slight quality reduction, larger file size reduction
4. Turn on **WebP** to serve modern formats to supported browsers.

</Details>

## Features

- **Zero egress fees** (R2) - No charges for data transferred out, regardless of volume
- **S3 compatibility** (R2) - Use any S3-compatible tool, SDK, or library without code changes
- **Custom processing pipelines** (Workers) - Build media transformation, validation, and routing logic that runs at the edge
- **Direct uploads** (R2) - Issue presigned URLs so clients upload directly to R2 without routing through your servers

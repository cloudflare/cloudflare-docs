## Features

- **Automatic encoding** (Stream) - Videos transcoded to multiple resolutions and formats on upload with no infrastructure to manage
- **Adaptive bitrate** (Stream) - HTTP Live Streaming (HLS) and Dynamic Adaptive Streaming over HTTP (DASH) automatically adjusts quality to match viewer bandwidth
- **Global delivery** (Stream) - Video served directly from Cloudflare's edge network without a separate Content Delivery Network (CDN)
- **Live streaming** (Stream Live) - Low-latency live video with automatic recording and instant playback after the stream ends
- **Real-time communication** (Calls) - Add peer-to-peer video and audio directly to your application

## What you get

- **Global edge caching** (CDN / Cache) - Media content served from 300+ edge locations to reduce latency for global audiences
- **Origin offload** (CDN / Cache) - Cached content is served directly from the edge, reducing origin bandwidth and compute costs
- **Smart routing** (Argo Smart Routing) - Requests that miss cache are routed through the fastest available network paths to origin
- **Tiered caching** (Tiered Cache) - Regional cache tiers absorb repeated requests before they reach the origin, further reducing load

### Cache configuration for media

<Details header="Optimize caching for media files">

**Configure Cache Rules for media:**

1. Go to **Caching** > **Cache Rules**.
2. Create rules for different media types:

**Video files (long TTL):**

- Match: `http.request.uri.path.extension in {"mp4" "webm" "m3u8" "ts"}`
- Cache Time to Live (TTL): 1 year
- Turn on: Origin Cache Control

**Images (medium TTL):**

- Match: `http.request.uri.path.extension in {"jpg" "jpeg" "png" "webp" "avif"}`
- Cache TTL: 30 days
- Turn on: Polish, WebP conversion

**Turn on Tiered Cache:**

1. Go to **Caching** > **Tiered Cache**.
2. Turn on **Smart Tiered Cache Topology**.

</Details>

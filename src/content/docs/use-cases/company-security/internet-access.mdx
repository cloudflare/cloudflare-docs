## Features

- **Threat protection** (Gateway) - Block malware, phishing, and command-and-control domains at the DNS and HTTP layers
- **Content filtering** (Gateway) - Enforce acceptable use policies by blocking categories of domains across the organization
- **Data protection** (Gateway) - Inspect HTTP traffic and prevent sensitive data from being uploaded to unauthorized destinations
- **Browser isolation** (Cloudflare One) - Execute risky web content in a remote browser, keeping malware away from user devices

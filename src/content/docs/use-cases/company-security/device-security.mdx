## Features

- **Posture checks** (Cloudflare One) - Verify OS version, disk encryption status, and antivirus presence before granting access
- **Endpoint integration** (Cloudflare One) - Pull real-time device health signals from CrowdStrike, SentinelOne, and other Endpoint Detection and Response (EDR) tools
- **Conditional access** (Cloudflare One) - Gate application access on device posture results, so only healthy devices can connect
- **Always-on protection** (WARP Client) - Route device traffic through Cloudflare One at all times, enforcing Gateway policies regardless of network

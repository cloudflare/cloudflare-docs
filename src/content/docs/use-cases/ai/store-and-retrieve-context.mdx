## What you get

- **Vector search** (Vectorize) - Store embeddings and find semantically similar content for Retrieval Augmented Generation (RAG) and recommendation features
- **Structured storage** (D1) - Structured Query Language (SQL) database for conversation history, user data, and application metadata
- **Object storage** (R2) - Store documents, training data, and generated assets with no egress fees
- **Edge caching** (KV) - Cache frequent AI responses at the edge to reduce inference costs and latency

## Get started

<Details header="Set up Vectorize for RAG">

1. In your terminal, create a Vectorize index:

   ```sh
   npx wrangler vectorize create my-index --dimensions=768 --metric=cosine
   ```

2. In `wrangler.toml`, add the Vectorize binding:

   ```toml
   [[vectorize]]
   binding = "VECTORIZE"
   index_name = "my-index"
   ```

3. In `src/index.ts`, insert vectors into your index:

   ```ts
   const vectors = [
     { id: "doc1", values: [0.1, 0.2, ...], metadata: { text: "Document content" } }
   ];
   await env.VECTORIZE.upsert(vectors);
   ```

4. Still in `src/index.ts`, query for similar vectors:

   ```ts
   const queryVector = [0.1, 0.2, ...];
   const results = await env.VECTORIZE.query(queryVector, { topK: 5 });
   ```

</Details>

For the complete guide, refer to [Vectorize get started](/vectorize/get-started/).

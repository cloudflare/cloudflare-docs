Cloudflare Workers hosts your application logic, serves your frontend, and provides the binding through which Workers AI runs inference. AI Gateway sits in front of any provider to add caching, rate limiting, and observability. Durable Objects coordinate stateful workflows and multi-turn conversations.

## Features

- **Global inference** (Workers AI) - Run models at the Cloudflare location nearest to the user, reducing round-trip latency
- **Pay-per-use pricing** (Workers AI) - No GPU reservations or idle costs; pay only for tokens processed
- **Streaming responses** (Workers) - Stream AI responses token-by-token as they generate, without buffering the full reply
- **Full-stack deployment** (Workers) - Serve frontend and backend from a single deployment without managing separate infrastructure
- **Provider flexibility** (AI Gateway) - Route requests to OpenAI, Anthropic, Workers AI, or any other provider through a single endpoint
- **Unified observability** (AI Gateway) - Track request volume, latency, costs, and errors across all providers in one place
- **Stateful workflows** (Durable Objects) - Coordinate multi-step AI pipelines and maintain conversation state across requests

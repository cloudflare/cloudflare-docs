Build and deploy AI applications to Cloudflare's global network with inference at the edge, vector databases, model gateways, and more.

<YouTube id="uv1Cz_BDFmo" />

AI applications present unique infrastructure challenges: unpredictable inference costs, latency-sensitive user experiences, and the need to work with multiple model providers. Cloudflare provides a complete platform for building AI applications that are fast, cost-effective, and globally distributed.

<DirectoryListing />

## Architecture patterns

### Retrieval Augmented Generation (RAG)

Combine vector search with Large Language Model (LLM) inference to ground responses in your own data:

1. **Vectorize** stores embeddings of your knowledge base
2. **Workers** receives user queries and searches for relevant context
3. **Workers AI** or **AI Gateway** generates responses using retrieved context

### Multi-provider AI gateway

Use AI Gateway to route requests across providers while maintaining a single interface:

1. **AI Gateway** proxies requests to OpenAI, Anthropic, or Workers AI
2. Built-in caching reduces costs for repeated queries
3. Unified logging and analytics across all providers

### Real-time AI features

Deploy low-latency AI features directly at the edge:

1. **Workers** handles requests at the nearest Cloudflare location and runs inference via the Workers AI binding — no round-trips to origin servers
2. **KV** caches frequent responses to reduce inference calls and latency
3. **D1** stores session state and conversation history alongside the inference logic

---

## Prerequisites

- A [Cloudflare account](https://dash.cloudflare.com/sign-up). Workers AI, AI Gateway, Vectorize, D1, R2, and KV are account-level products — you do not need a domain added to Cloudflare to use them.
- [Node.js](https://nodejs.org/) (version 16.17.0 or later) installed on your machine.
- [Wrangler](/workers/wrangler/install-and-update/) installed. Wrangler is the command-line interface (CLI) for deploying Workers and managing bindings.

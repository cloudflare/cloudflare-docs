D1 exposes analytics to track billing metrics (rows read, rows written, and total storage) across all databases in your account.

The metrics displayed in the [Cloudflare dashboard](https://dash.cloudflare.com/) are sourced from Cloudflare's [GraphQL Analytics API](/analytics/graphql-api/). You can access the metrics [programmatically](/d1/observability/metrics-analytics/#query-via-the-graphql-api) by using a GraphQL or HTTP client.

## View metrics in the dashboard

### Billable Usage Dashboard

The Billable Usage Dashboard gives Pay-as-you-go (PayGo) customers daily visibility into usage-based costs across their Cloudflare account. Data is sourced from the same system that generates your monthly invoice, so the figures you see in the dashboard will match your bill.

The Billable Usage Dashboard shows usage-based overage charges only. Fixed-fee plan subscriptions (for example, a Pro plan) are not included.

:::note
The Billable Usage Dashboard is available to PayGo accounts only. Enterprise contract accounts are not currently supported.

To access the dashboard, you must have the Billing read permission on your account.
:::

#### Access the dashboard

1. Log in to the Cloudflare dashboard.
2. Select your account.
3. Go to **Manage Account** > **Billing**.

   <DashButton url="/?to=/:account/billing" />
4. Select **Billable Usage**.

#### What you will see

**Chart**

A bar chart displays your daily usage charges for the selected billing period. Each bar represents the total rated cost across all usage-based products on your account for that day.

**Usage table**

Below the chart, a sortable table breaks down each charge period by product and day:

| Column              | Description                                                           |
| ------------------- | --------------------------------------------------------------------- |
| Service Name        | The Cloudflare product generating the usage charge                    |
| Billing Period Start| The start date of the billing cycle this charge falls within          |
| Charge Period Start | The start of the daily charge period                                  |
| Charge Period End   | The end of the daily charge period                                    |
| Consumed Quantity   | The amount of the resource used during the charge period              |
| Consumed Unit       | The unit of measurement (for example, Requests, Minutes, Bytes)       |
| Cost                | The cost for that charge period in your billing currency              |
| Cumulative Cost     | The running total cost accumulated since the billing period start     |

#### Date range

By default, the dashboard shows data for your current billing period. Use the date picker to view a previous billing period.

#### How data aligns with your invoice

The dashboard reads from the same data source used to generate your monthly invoice.

- Usage data is aligned to your billing cycle, not the calendar month. Your billing period start date is determined by the first purchase date on your account.
- Costs reflect the published rate card for your account.
- The cumulative cost shown at the end of a completed billing period will match the usage overage charges on the corresponding invoice.

:::note
Previous versions of the Billable Usage Dashboard used GraphQL queries from a different data source. Those figures were approximate and aligned to the calendar month. The current dashboard corrects both of these discrepancies.
:::

#### Covered products

The dashboard shows charges for all usage-based products active on your account. The products that appear depend on your subscriptions. Examples of usage-based products include Workers, R2, Stream, Images, Argo, and Load Balancing.

:::note
There may be up to a 24-hour delay before the previous day's usage appears.
:::

#### Limitations

- **Account-level data only** - Zone-level breakdowns are not yet available.
- **No data export** - CSV/JSON export is not yet available.
- **Enterprise accounts not supported** - This dashboard is available to PayGo accounts only.
- **24-hour data latency** - Usage from the current day may not yet appear.

### Set up usage notifications

To avoid unexpected overage charges, configure usage-based notifications in the Cloudflare dashboard. Notifications can alert you when usage exceeds a defined threshold during a billing period.

To set up notifications:

1. Log in to the Cloudflare dashboard.
2. Select your account.
3. Go to **Notifications**.

   <DashButton url="/?to=/:account/notifications" />
4. Create a new notification for **Billable Usage**.

## Billing Notifications

Usage-based billing notifications are available in the [Cloudflare dashboard](https://dash.cloudflare.com) to help you monitor your total account usage.

You can set up notifications for the following metrics:
- Rows Read
- Rows Written

Worker configuration defines project settings, bindings, and deployment
options. Use
[`cloudflare.config.ts`](/workers/configuration/cloudflare-config/) for typed,
programmatic configuration.

You can also use a [Wrangler configuration
file](/workers/wrangler/configuration/) with Wrangler and supported build
tools.

For more information on Wrangler, refer to [Wrangler](/workers/wrangler/).

**Category:** [Internal Errors](/workers/platform/error-codes/#internal-errors)

**HTTP Status:** 500 Internal Server Error

**Message:** `Failed to verify account entitlements due to an internal error. Retry the request. If this error persists, report to workers-sdk (https://github.com/cloudflare/workers-sdk/issues) or contact support.`

**When this occurs:**
Failed to load account entitlements.

**How to fix:**
Retry the request. If persistent, contact support.

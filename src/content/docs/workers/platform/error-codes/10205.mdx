**Message:** CPU limits are only supported with the 'standard' usage model. Switch to the standard usage model to set CPU limits.


**Category:** [Limits & Quotas](/workers/platform/error-codes/#limits-quotas)

**HTTP Status:** 400 Bad Request


**When this occurs:**
Attempting to set CPU limits with bundled/unbound usage model.

**How to fix:**
Use the `standard` usage model.

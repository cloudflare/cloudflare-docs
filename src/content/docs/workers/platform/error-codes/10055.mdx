**Message:** Too many text bindings ((count)). The limit is (limit). Remove some bindings and try again.

**Category:** [Bindings - General](/workers/platform/error-codes/#bindings--general)

**HTTP Status:** 400 Bad Request

**When this occurs:**
Your Worker has too many text/secret bindings (environment variables). Refer to [environment variable limits](/workers/platform/limits/#environment-variables) for current plan limits.

**How to fix:**

1. Remove unused bindings
2. Consolidate related values into a single JSON binding:

```jsonc
// Instead of many separate bindings:
// API_KEY_1, API_KEY_2, API_KEY_3...

// Use a single JSON binding:
{
	"vars": {
		"CONFIG": "{\"apiKeys\": [\"key1\", \"key2\", \"key3\"]}",
	},
}
```

3. Use [KV](/kv/) for large numbers of configuration values

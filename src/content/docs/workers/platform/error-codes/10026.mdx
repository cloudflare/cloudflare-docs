**Category:** [Request Validation](/workers/platform/error-codes/#request-validation)

**HTTP Status:** 400 Bad Request

**Message:** `Could not parse request body. Verify the request format matches the API specification and try again.`

**When this occurs:**
The request body could not be parsed as valid JSON or expected format.

**How to fix:**

1. Verify JSON syntax is valid
2. Check `Content-Type` header matches the body format
3. Ensure request body is not empty when required

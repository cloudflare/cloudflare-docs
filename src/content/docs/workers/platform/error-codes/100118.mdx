**Message:** Cannot change the Worker for a custom domain using this endpoint. Use the domain-scoped update endpoint instead.


**Category:** [Custom Domains](/workers/platform/error-codes/#custom-domains)

**HTTP Status:** 400 Bad Request


**How to fix:**
Use the [domain update endpoint](/api/resources/workers/subresources/domains/methods/update/) instead.

**Category:** [Bindings - Queues](/workers/platform/error-codes/#bindings--queues)

**HTTP Status:** 409 Conflict

**Message:** `Queue name '{name}' already exists on this account. Choose a different name and try again.`

**When this occurs:**
A queue with this name already exists on your account.

**How to fix:**
Use a different queue name.

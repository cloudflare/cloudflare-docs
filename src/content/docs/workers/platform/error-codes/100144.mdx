**Category:** [Bindings - Other](/workers/platform/error-codes/#bindings--other)

**HTTP Status:** 400 Bad Request

**Message:** `Analytics Engine dataset name '{name}' is invalid: {reason}. Use a valid dataset name and try again.`

**Requirements:**

- Letters, numbers, dashes, underscores only
- Maximum 128 characters

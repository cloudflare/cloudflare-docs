**Category:** [Scripts & Workers](/workers/platform/error-codes/#scripts-workers)

**HTTP Status:** 404 Not Found

**Message:** `Environment not found on this Worker. Verify the environment name is correct.`

**When this occurs:**
The requested environment does not exist for this Worker.

**How to fix:**

1. List environments for the Worker
2. Verify the environment name is correct
3. Create the environment if needed

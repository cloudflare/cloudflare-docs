**Message:** Worker (script) has no environment named (environment). Verify the environment name is correct.


**Category:** [Bindings - Durable Objects](/workers/platform/error-codes/#bindings--durable-objects)

**HTTP Status:** 400 Bad Request


**When this occurs:**
The specified environment doesn't exist for the target Worker.

**How to fix:**
Verify the environment name in your binding configuration.

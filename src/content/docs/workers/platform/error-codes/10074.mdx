**Message:** (migration error details)

**Category:** [Bindings - Durable Objects](/workers/platform/error-codes/#bindings--durable-objects)

**HTTP Status:** 400 Bad Request

**When this occurs:**
A Durable Object migration failed.

**Common migration types include:**

- `new_sqlite_classes` - Create new DO class with SQLite storage
- `new_classes` - Create new DO class with in-memory storage
- `deleted_classes` - Delete a DO class

Refer to [Durable Objects Migrations](/durable-objects/reference/durable-objects-migrations/) for the complete migration specification.

**How to fix:**

1. Review migration configuration in `wrangler.jsonc`:

```jsonc
{
	"migrations": [
		{
			"tag": "v1",
			"new_sqlite_classes": ["MyDurableObject"],
		},
		{
			"tag": "v2",
			"renamed_classes": [
				{
					"from": "MyDurableObject",
					"to": "RenamedDurableObject",
				},
			],
		},
	],
}
```

2. Ensure migrations are applied in order (tags must be sequential)
3. Check the migration tag matches the expected state on the server
4. Verify class names match exported classes exactly

**Category:** [Observability](/workers/platform/error-codes/#observability)

**HTTP Status:** 400 Bad Request

**Message:** `A Worker with only a tail handler cannot tail itself. Configure a different Worker as the tail consumer.`

**When this occurs:**
A Tail Worker with only a `tail()` handler is configured as its own tail consumer, creating a circular reference.

**Why this fails:**
A Tail Worker that only processes logs cannot generate meaningful logs to send to itself.

**How to fix:**

1. Remove the self-referencing tail consumer configuration
2. Configure a different Worker as the tail consumer
3. If you need the Worker to tail itself, add a `fetch()` or other handler that generates logs

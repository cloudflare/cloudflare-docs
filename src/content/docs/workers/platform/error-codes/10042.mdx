**Message:** KV namespace (namespaceId) is invalid. Verify the namespace ID format and try again.


**Category:** [Bindings - KV](/workers/platform/error-codes/#bindings--kv)

**HTTP Status:** 400 Bad Request


**When this occurs:**
The KV namespace ID format is invalid.

**How to fix:**
Verify the namespace ID is a valid UUID.

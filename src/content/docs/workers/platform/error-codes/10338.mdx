**Category:** [Versions & Deployments](/workers/platform/error-codes/#versions-deployments)

**HTTP Status:** 404 Not Found

**Message:** `Cannot delete the active deployment. Deploy a different version first, then delete this deployment.`

**When this occurs:**
Attempting to delete the currently active deployment.

**How to fix:**
You cannot delete the active deployment. Create a new deployment first.

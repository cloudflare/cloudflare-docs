**Message:** Durable Object namespace (namespaceId) not found. Verify the namespace ID is correct and try again.


**Category:** [Bindings - Durable Objects](/workers/platform/error-codes/#bindings--durable-objects)

**HTTP Status:** 400 Bad Request


**When this occurs:**
The Durable Object namespace specified in the binding doesn't exist.

**How to fix:**

1. Verify the namespace ID or class name
2. Ensure the Durable Object class is exported from your Worker
3. Run migrations if needed

- [Durable Objects](/durable-objects/)

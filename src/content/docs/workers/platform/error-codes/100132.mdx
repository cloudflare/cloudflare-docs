**Category:** [Limits & Quotas](/workers/platform/error-codes/#limits-quotas)

**HTTP Status:** 400 Bad Request

**Message:** `Worker name is too long to be used as a workers.dev subdomain. Names must be 63 characters or less for subdomain compatibility.`

**When this occurs:**
The Worker name is too long to work with workers.dev.

**How to fix:**
Use a shorter Worker name.

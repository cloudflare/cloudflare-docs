**Category:** [Versions & Deployments](/workers/platform/error-codes/#versions-deployments)

**HTTP Status:** 404 Not Found

**Message:** `This Worker has no versions. Deploy the Worker first using 'wrangler deploy'.`

**When this occurs:**
The Worker exists but has never been deployed.

**How to fix:**
Deploy the Worker: `wrangler deploy`

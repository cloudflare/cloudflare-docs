Reference for REST API error codes returned by the Cloudflare Workers REST API.

## Understanding Error Responses

All Workers REST API errors follow this JSON structure:

```json
{
	"success": false,
	"errors": [
		{
			"code": 10021,
			"message": "Worker validation failed: syntax error at line 5",
			"documentation_url": "https://developers.cloudflare.com/workers/platform/error-codes/10021"
		}
	],
	"result": null
}
```

**Key fields:**

- `code` - Unique identifier for the error type (10000-100999 range)
- `message` - Human-readable error description
- `documentation_url` - Link to detailed documentation (when available)

If you encounter an error not listed here or need further assistance:

3. **Report a bug** - [Create an issue](https://github.com/cloudflare/workers-sdk/issues/new)
4. **Community support** - [Cloudflare Discord](https://discord.cloudflare.com)
5. **Cloudflare support** - [Cloudflare Support](https://dash.cloudflare.com/?to=/:account/support)

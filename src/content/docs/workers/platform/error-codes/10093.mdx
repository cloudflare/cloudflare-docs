**Message:** Invalid Worker name. Names must start with a letter, be lowercase, and contain only alphanumeric characters and dashes.


**Category:** [Scripts & Workers](/workers/platform/error-codes/#scripts-workers)

**HTTP Status:** 400 Bad Request


**How to fix:**
See [10016](/workers/platform/error-codes/10016/).

**Category:** [Routing](/workers/platform/error-codes/#routing)

**HTTP Status:** 400 Bad Request

**Message:** `Cannot configure route because the Worker does not exist. Create the Worker first, then configure the route.`

**When this occurs:**
Attempting to create a route pointing to a non-existent Worker.

**How to fix:**

1. Deploy the Worker first: `wrangler deploy`
2. Then create the route
3. Verify the Worker name in your route configuration

**Message:** Text binding (name) is too large ((sizeBytes) bytes). The limit is (limitBytes) bytes. Reduce the binding size and try again.

**Category:** [Bindings - General](/workers/platform/error-codes/#bindings--general)

**HTTP Status:** 400 Bad Request

**When this occurs:**
A plain text or secret binding exceeds the [size limit](/workers/platform/limits/#environment-variables).

**How to fix:**

1. Reduce the binding value size
2. For larger data, use [KV](/kv/) or [R2](/r2/) instead
3. For configuration, consider storing JSON in KV and parsing at runtime

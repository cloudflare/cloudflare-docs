**Message:** Service binding (binding) references Worker (target) which has no deployments. Deploy the target Worker first.


**Category:** [Bindings - Service Bindings](/workers/platform/error-codes/#bindings--service-bindings)

**HTTP Status:** 400 Bad Request


**When this occurs:**
The target Worker exists but has never been deployed.

**How to fix:**
Deploy the target Worker: `wrangler deploy`

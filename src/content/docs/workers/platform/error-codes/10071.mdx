**Category:** [Scripts & Workers](/workers/platform/error-codes/#scripts-workers)

**HTTP Status:** 404 Not Found

**Message:** `Worker version not found. Verify the version ID is correct and try again.`

**When this occurs:**
The requested Worker version does not exist.

**How to fix:**

1. List available versions: `wrangler versions list`
2. Verify the version ID is correct
3. Check if the version was deleted

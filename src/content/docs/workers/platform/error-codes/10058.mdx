**Message:** Tail session has expired. Start a new tail session to continue.


**Category:** [Observability](/workers/platform/error-codes/#observability)

**HTTP Status:** 403 Forbidden


**When this occurs:**
The tail session has exceeded the maximum duration.

**How to fix:**
Start a new tail session: `wrangler tail`

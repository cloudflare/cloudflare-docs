**Category:** [Scripts & Workers](/workers/platform/error-codes/#scripts-workers)

**HTTP Status:** 404 Not Found

**Message:** `This Worker does not exist on your account. Verify the Worker name is correct and try again. To create a new Worker, use wrangler deploy or the dashboard.`

**When this occurs:**
The requested Worker service does not exist.

**How to fix:**

1. Verify you're on the correct account:

```bash
wrangler whoami
```

2. List your Workers:

```bash
wrangler deployments list
```

See [10007](/workers/platform/error-codes/10007/) for additional troubleshooting steps.

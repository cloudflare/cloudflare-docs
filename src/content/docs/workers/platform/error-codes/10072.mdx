**Message:** Cron trigger limit reached: your account allows (max) cron triggers. Delete unused triggers or upgrade your plan.

**Category:** [Routing](/workers/platform/error-codes/#routing)

**HTTP Status:** 400 Bad Request

**When this occurs:**
Your account has reached the maximum number of cron triggers. Refer to [account plan limits](/workers/platform/limits/#account-plan-limits) for current limits.

**How to fix:**

1. List existing cron triggers in your `wrangler.jsonc`:

```jsonc
{
	"triggers": {
		"crons": ["0 * * * *", "0 0 * * *"],
	},
}
```

2. Remove unused cron triggers
3. Consolidate multiple triggers into a single Worker that handles different schedules
4. [Upgrade to Workers Paid](https://dash.cloudflare.com/?to=/:account/workers/plans) for higher limits

See [Cron Triggers](/workers/configuration/cron-triggers/) for configuration details.

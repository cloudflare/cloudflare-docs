**Category:** [Scripts & Workers](/workers/platform/error-codes/#scripts-workers)

**HTTP Status:** 400 Bad Request

**Message:** `Invalid environment name. Names must start with a letter, be lowercase, and contain only alphanumeric characters and dashes.`

**Requirements:**
Same as Worker names - lowercase alphanumeric and dashes only.

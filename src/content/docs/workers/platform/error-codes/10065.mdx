**Category:** [Bindings - Durable Objects](/workers/platform/error-codes/#bindings--durable-objects)

**HTTP Status:** 400 Bad Request

**Message:** `Durable Object namespace name '{name}' already exists on this account. Choose a different name or use the existing namespace.`

**When this occurs:**
A Durable Object namespace with this name already exists on your account.

**How to fix:**
Use a different namespace name or use the existing namespace.

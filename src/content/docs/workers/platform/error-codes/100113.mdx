**Category:** [Custom Domains](/workers/platform/error-codes/#custom-domains)

**HTTP Status:** 400 Bad Request

**Message:** `Hostname '{hostname}' is invalid. Use a DNS-compliant hostname (lowercase letters, numbers, hyphens, and dots only) and try again.`

**How to fix:**
Use a properly formatted hostname.

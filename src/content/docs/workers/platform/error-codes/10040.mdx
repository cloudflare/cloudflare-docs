**Category:** [Scripts & Workers](/workers/platform/error-codes/#scripts-workers)

**HTTP Status:** 409 Conflict

**Message:** `A Worker named '{name}' already exists on this account. Choose a different name or delete the existing Worker first.`

**When this occurs:**
Attempting to create a Worker with a name that's already in use.

**How to fix:**

1. Choose a different Worker name
2. Delete the existing Worker if it's no longer needed
3. Update the existing Worker instead of creating new

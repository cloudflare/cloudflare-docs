**Category:** [Request Validation](/workers/platform/error-codes/#request-validation)

**HTTP Status:** 400 Bad Request

**Message:** `Request is missing required URL parameter 'name'. Include this parameter in your request URL and try again.`

**When this occurs:**
The Worker script name is missing from the request.

**How to fix:**
Include the script name in the URL path or query parameter.

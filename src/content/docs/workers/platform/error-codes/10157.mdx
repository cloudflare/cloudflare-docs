**Category:** [Bindings - Other](/workers/platform/error-codes/#bindings--other)

**HTTP Status:** 400 Bad Request

**Message:** `Hyperdrive configuration '{id}' not found. Verify the configuration ID is correct and try again.`

**How to fix:**

1. Create a Hyperdrive config: `wrangler hyperdrive create`
2. Verify the config ID

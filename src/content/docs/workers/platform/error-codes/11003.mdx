**Category:** [Bindings - Queues](/workers/platform/error-codes/#bindings--queues)

**HTTP Status:** 400 Bad Request

**Message:** `Queue name '{name}' is invalid: {reason}. Use a valid queue name and try again.`

**Requirements:**

- Alphanumeric, dashes, underscores
- Maximum 64 characters

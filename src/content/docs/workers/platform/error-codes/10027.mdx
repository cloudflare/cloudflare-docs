**Message:** Worker exceeds the size limit of (mib) MiB. Reduce your script size or upgrade your plan, then try again.

import { TypeScriptExample } from "~/components";

**Category:** [Scripts & Workers](/workers/platform/error-codes/#scripts-workers)

**HTTP Status:** 400 Bad Request

**When this occurs:**
The Worker script exceeds the maximum allowed size after compression. Refer to [Worker size limits](/workers/platform/limits/#worker-size) for current plan limits.

**Check your Worker's size:**

```bash
npx wrangler deploy --dry-run --outdir=dist
# Then check the size of files in ./dist
```

**How to fix:**

1. Remove unused dependencies from `package.json`
2. Use dynamic imports for code splitting:

<TypeScriptExample>

```ts
const heavyModule = await import("./heavy-module");
```

</TypeScriptExample>

3. Move large static assets to [R2](/r2/) or [KV](/kv/)
4. Use tree-shaking with your bundler (esbuild, webpack)
5. [Upgrade to Workers Paid](https://dash.cloudflare.com/?to=/:account/workers/plans) for higher limits

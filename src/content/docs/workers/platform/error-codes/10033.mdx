**Category:** [Workers.dev Subdomains](/workers/platform/error-codes/#workers.dev-subdomains)

**HTTP Status:** 400 Bad Request

**Message:** `Subdomain '{subdomain}' is invalid. Use a DNS-compliant name (lowercase letters, numbers, and hyphens only) and try again.`

**Requirements:**

- Lowercase alphanumeric and dashes
- Must start and end with alphanumeric
- Maximum 63 characters

**Message:** Cannot delete the latest version of this Worker. Upload a new version first, then delete the previous version.


**Category:** [Versions & Deployments](/workers/platform/error-codes/#versions-deployments)

**HTTP Status:** 400 Bad Request


**When this occurs:**
Attempting to delete the most recent Worker version or a currently deployed version.

**How to fix:**
Upload a new version first, then delete old versions. If deleting a deployed version, deploy a different version first.

**Category:** [Bindings - KV](/workers/platform/error-codes/#bindings--kv)

**HTTP Status:** 403 Forbidden

**Message:** `Your account does not have access to Workers KV. Enable KV from the Cloudflare dashboard or verify your API token has the required permissions.`

**When this occurs:**
Your account doesn't have access to Workers KV.

**How to fix:**
KV is included with all Workers plans. If you see this error, contact support.

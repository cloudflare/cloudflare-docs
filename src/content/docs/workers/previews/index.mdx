A **Preview** is an isolated copy of your Worker with its own [bindings](/workers/runtime-apis/bindings/), [environment variables](/workers/configuration/environment-variables/), and [secrets](/workers/configuration/secrets/). Previews let you test out changes to your Worker without impacting production data or traffic.

You create a Preview each time you:

- Run `wrangler preview` with the Wrangler CLI.
- Push to a feature branch with a connected Git repository.
- Use the Previews API or Terraform resource (needs api docs).

When you deploy a Preview, Cloudflare outputs two URLs:

- a stable **Preview URL** that always shows the latest deployed change on your Preview or branch.
- a **Deployment URL** for each pushed change or commit.

When you connect your Git repository, Cloudflare posts these URLs on your Pull Requests as a comment. By default, Cloudflare gives you a `workers.dev` domain to host your Previews, but you can also connect them your [custom domains](/workers/configuration/routing/custom-domains/).

## Getting started

<Steps>

<ol>
  <li>
    <strong>Configure your Preview settings.</strong> These settings will act as default values for all your Worker's Previews, unless overridden.

    <Tabs>
      <TabItem label="Wrangler configuration">
        Add your Preview settings to a `[previews]` block of your Wrangler configuration file.
        ```jsonc
        "previews": {
          "d1_databases": [
            {
              "binding": "MY_DB",
              "database_id": "preview-db-id"
            }
          ]
        }
        ```

        Learn more in Configuring Previews.
      </TabItem>
      <TabItem label="Dashboard">Go to your Worker's **Settings** tab and the **Bindings** tab to set up your default Preview settings. You can easily import Production values to get started quickly.  </TabItem>
    </Tabs>

  </li>
  <li>
    Check out a new branch and make your changes.
    
    ```sh
    git checkout -b my-feature
    ```
  </li>
  <li>
    Run `wrangler preview`
    <PackageManagers type="exec" pkg="wrangler" args="preview" />
  </li>
</ol>

</Steps>

## Workers Builds

Use [Workers Builds](/workers/ci-cd/builds/) when you want Cloudflare to automatically build and deploy a Preview on every commit and comment the Preview URL back on the pull request.

1. [Connect your Worker to a GitHub or GitLab repository](/workers/ci-cd/builds/#get-started)
2. Enable [Preview Builds](/workers/ci-cd/builds/build-branches/#configure-preview-builds)
3. Push a branch or open a pull request

Preview builds run `npx wrangler preview` by default. Workers Builds triggers a build, deploys the Preview, and [comments](/workers/ci-cd/builds/git-integration/github-integration/#pull-request-comment) the Preview URL and Deployment URL on the pull request. You can customize the Preview command in **Settings > Build**.

## Wrangler CLI

If you deploy from the command line, one command creates a Preview:

```sh
npx wrangler preview
```

Use `--name` to set the Preview name explicitly instead of deriving it from the branch:

```sh
npx wrangler preview --name staging
```

For machine-parseable output in scripts:

```sh
npx wrangler preview --json
```

## External CI

If GitHub Actions, GitLab CI, or another provider runs your deployments, add `npx wrangler preview` to your workflow.

```yaml title=".github/workflows/preview.yml"
name: Preview
on:
  pull_request:
    types: [opened, synchronize]

jobs:
  preview:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: cloudflare/wrangler-action@v4
        with:
          command: preview
          apiToken: ${{ secrets.CLOUDFLARE_API_TOKEN }}
          accountId: ${{ secrets.CLOUDFLARE_ACCOUNT_ID }}
```

Each push to the PR branch creates a new deployment under the same Preview. The Preview URL stays stable across commits.

For more CI examples, refer to [How-to](/workers/previews/recipes/).

## API

You can create Previews and deployments directly through the API.

{/* TODO: Link to Preview-specific API endpoints once published */}

```bash title="Create a Preview"
curl --request POST \
  "https://api.cloudflare.com/client/v4/accounts/{account_id}/workers/workers/{worker_id}/previews" \
  --header "Authorization: Bearer {api_token}" \
  --header "Content-Type: application/json" \
  --data '{ "name": "my-feature" }'
```

```bash title="Create a deployment on a Preview"
curl --request POST \
  "https://api.cloudflare.com/client/v4/accounts/{account_id}/workers/workers/{worker_id}/previews/my-feature/deployments" \
  --header "Authorization: Bearer {api_token}" \
  --header "Content-Type: multipart/form-data" \
  --form "main_module=@index.js" \
  --form 'metadata={"main_module":"index.js"}'
```

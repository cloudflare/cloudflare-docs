Use Preview commands for branch and pull request work. Use `wrangler deploy` for production.

Preview commands change either one Preview branch or Shared Preview Settings for future Preview branches. Check the target before running a command.

## Command targets

| Command                                                | Changes                 | Meaning                                                                                          |
| ------------------------------------------------------ | ----------------------- | ------------------------------------------------------------------------------------------------ |
| `wrangler preview --name <preview-name>`               | One Preview branch      | Create or update a branch Preview.                                                               |
| `wrangler preview delete --name <preview-name>`        | One Preview branch      | Delete one Preview and its deployments.                                                          |
| `wrangler preview secret put --name <preview-name>`    | One Preview branch      | Add or update a secret for one Preview branch.                                                   |
| `wrangler preview secret delete --name <preview-name>` | One Preview branch      | Delete a secret from one Preview branch.                                                         |
| `wrangler preview secret list --name <preview-name>`   | One Preview branch      | List secrets configured for one Preview branch.                                                  |
| `wrangler preview-defaults push`                       | Shared Preview Settings | Update the shared settings pool from your Wrangler `previews` block for future Preview branches. |
| `wrangler preview-defaults secret put`                 | Shared Preview Settings | Add or update a secret in the shared settings pool for future Preview branches.                  |
| `wrangler preview-defaults secret delete`              | Shared Preview Settings | Delete a secret from Shared Preview Settings.                                                    |
| `wrangler preview-defaults secret list`                | Shared Preview Settings | List secrets in Shared Preview Settings.                                                         |

## One Preview branch

Use `wrangler preview` commands when one branch or pull request needs a change.

```sh
npx wrangler preview --name feature-branch
```

Other Preview branches are not affected.

## Shared Preview Settings

Use `wrangler preview-defaults` commands when future Preview branches should receive a setting or secret.

```sh
npx wrangler preview-defaults push
```

```sh
npx wrangler preview-defaults secret put API_TOKEN
```

Existing Preview branches keep their own settings unless you also apply the change to existing Previews.

## Production deploys

`wrangler deploy` deploys production. Use Preview commands for branch and pull request Previews.

Cloudflare Workers support the following protocols and interfaces:

| Protocol               | Inbound                                                                                                                                                                                                                                                                                                                                                                        | Outbound                                                                                        |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| **HTTP / HTTPS**       | Handle incoming HTTP requests using the [`fetch()` handler](/workers/runtime-apis/handlers/fetch/).                                                                                                                                                                                                                                                                             | Make HTTP subrequests using the [`fetch()` API](/workers/runtime-apis/fetch/).                   |
| **Direct TCP sockets** | Handle TCP connections forwarded over a [service binding](/workers/runtime-apis/bindings/service-bindings/) or through a [Spectrum application](/spectrum/how-to/route-tcp-traffic-to-a-worker/) using the [`connect()` handler](/workers/runtime-apis/handlers/connect/) (public beta). | Create outbound TCP connections using the [`connect()` API](/workers/runtime-apis/tcp-sockets/). |
| **gRPC**               | Route gRPC, including bidirectional streams, through Spectrum to a Worker and [Cloudflare Container](/containers/examples/bidirectional-grpc/) (public beta).                                                                                                                                                                                                                  | —                                                                                               |
| **WebSockets**         | Accept incoming WebSocket connections using the [`WebSocket` API](/workers/runtime-apis/websockets/).                                                                                                                                                                                                                                                                           | —                                                                                               |
| **HTTP/3 (QUIC)**      | Accept inbound requests over [HTTP/3](https://www.cloudflare.com/learning/performance/what-is-http3/) by enabling it on your [zone](/fundamentals/concepts/accounts-and-zones/#zones) in **Speed** > **Settings** > **Protocol Optimization** in the [Cloudflare dashboard](https://dash.cloudflare.com/).                                                                           | —                                                                                               |
| **SMTP**               | Use [Email Workers](/email-service/api/route-emails/email-handler/) to process and forward email without managing TCP connections to SMTP email servers.                                                                                                                                                                                                                       | Use [Email Workers](/email-service/api/route-emails/email-handler/).                             |

For gRPC, the Worker receives the connection as a raw TCP byte stream. In this path, the Worker does not parse gRPC or HTTP/2 frames. It forwards the stream to a gRPC server running in a Container. Refer to [Bidirectional gRPC with Workers and Containers](/containers/examples/bidirectional-grpc/) for a complete example.

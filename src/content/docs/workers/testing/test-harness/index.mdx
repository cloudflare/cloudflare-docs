[`createTestHarness()`](/workers/wrangler/api/#createtestharness) is a Wrangler API for integration testing from any Node.js test runner. It runs one or more Workers from [Wrangler](/workers/wrangler/) projects or Vite projects that use the [Cloudflare Vite plugin](/workers/vite-plugin/).

## Features

- Runs production build output from Wrangler or the Cloudflare Vite plugin
- Dispatches requests and events to one or more Workers
- Provides access to bindings and local storage from tests
- Captures logs and diagnostic output from the Workers runtime

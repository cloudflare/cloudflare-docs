Cloudflare Email Service has the following limits to ensure optimal performance and prevent abuse. These limits apply to emails sent via both the [REST API](/email-service/api/send-emails/rest-api/) and the [Workers binding](/email-service/api/send-emails/workers-api/) unless noted otherwise.

## Email sending limits

### Per-account limits

| Account Type                                  | Daily  | Hourly | Monthly |
| --------------------------------------------- | ------ | ------ | ------- |
| **Paid account with < 2 months of age**       | 100    | 10     | 10,000  |
| **Paid account with > 2 months of age**       | 1,000  | 100    | 10,000  |
| **Paid account with production access limit** | 10,000 | 10,000 | 10,000  |

### Email content limits

| Component                    | Limit                | Notes                                |
| ---------------------------- | -------------------- | ------------------------------------ |
| **Recipients (to, cc, bcc)** | 100 per email        | Combined across all recipient fields |
| **Subject line**             | 998 characters       | RFC 5322 compliant                   |
| **Text content**             | 10MB                 | Plain text version                   |
| **HTML content**             | 10MB                 | HTML version                         |
| **Attachments**              | 10 files, 25MB total | Per email                            |
| **Header size**              | 64KB                 | All custom headers combined          |

## Workers binding limits

The following limits apply only when sending emails via the [Workers binding](/email-service/api/send-emails/workers-api/). They do not apply to the REST API.

| Limit           | Value            | Notes                          |
| --------------- | ---------------- | ------------------------------ |
| **CPU time**    | 50ms per request | Standard Workers CPU limit     |
| **Subrequests** | 50 per request   | Includes email send operations |
| **Memory**      | 128MB            | Standard Workers memory limit  |

_Need higher limits?_ Contact [Cloudflare Support](https://dash.cloudflare.com/support) or your account team.

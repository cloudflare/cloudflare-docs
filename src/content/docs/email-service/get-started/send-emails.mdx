## Send your first email

Send your first email from Workers using the Workers API.

Start by creating a new Worker project.

1.  Create a new Worker project:

    <PackageManagers
    	type="create"
    	pkg="cloudflare@latest"
    	args="email-service-tutorial"
    />

2.  Add email binding to your Wrangler configuration file:

    <WranglerConfig>

    ```toml
    [[send_email]]
    name = "EMAIL"
    ```

    </WranglerConfig>

3.  Create your Worker code in `src/index.ts`:

    ```ts
    interface Env {
    	EMAIL: EmailBinding;
    }

    export default {
    	async fetch(request: Request, env: Env): Promise<Response> {
    		// Send a welcome email
    		const response = await env.EMAIL.send({
    			to: "recipient@example.com",
    			from: "welcome@yourdomain.com", // Replace with your domain
    			subject: "Welcome to our service!",
    			html: "<h1>Welcome!</h1><p>Thanks for signing up.</p>",
    			text: "Welcome! Thanks for signing up.",
    		});

    		return new Response(`Email sent: ${response.messageId}`);
    	},
    } satisfies ExportedHandler<Env>;
    ```

4.  You can use `npx wrangler dev --remote` to develop your Worker project and send emails. This runs your code on Cloudflare's infrastructure while allowing you to step through the code.

        ```sh
        npx wrangler dev --remote
        # ⎔ Starting remote preview...
        # Total Upload: 24.96 KiB / gzip: 6.17 KiB
        # [wrangler:info] Ready on http://localhost:8787
        ```

5.  Deploy and test:

        ```sh
        npm run deploy
        # Visit your Worker URL to send the email
        ```

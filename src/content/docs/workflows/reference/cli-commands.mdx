<TabItem label="Cloudflare CLI (cf)">

Workflows commands in the [Cloudflare CLI (`cf`)](/cf/) manage deployed Workflows and their instances from the command line. Pass an explicit instance ID (from `cf workflows instances list --workflow-name <WORKFLOW_NAME>`) to instance commands. `cf workflows instances pause`, `resume`, `terminate`, and `restart` currently also require passing `--status` (for example, `--status terminate`). To inspect or manage local Workflow instances during `cf dev`, use [Local Explorer](/workflows/build/local-development/#local-explorer).

## Quick start

<AgentSteps>

1. **Install OpenCode**

   Install OpenCode. For npm, Homebrew, Bun, Scoop, or Windows options, see the [OpenCode install guide](https://opencode.ai/docs/).

   ```bash
   curl -fsSL https://opencode.ai/install | bash
   ```

2. **Install the Cloudflare Skills**

   Installs the Cloudflare Skills into `~/.config/opencode/skills/`.

   ```bash
   npx skills add https://github.com/cloudflare/skills
   ```

3. **Add the Cloudflare MCP servers**

   Add MCP servers to `.opencode.jsonc` in your project.

   ```json
   {
     "mcp": {
       "cloudflare": { "type": "remote", "url": "https://mcp.cloudflare.com/mcp" },
       "cloudflare-docs": { "type": "remote", "url": "https://docs.mcp.cloudflare.com/mcp" }
     }
   }
   ```

4. **Launch OpenCode and build**

   Start OpenCode in your project directory and try a prompt — for example, "Create an example hello world app using Cloudflare Workers."

    ```bash
    opencode
    ```

</AgentSteps>

## Tips

<TipsList>

- OpenCode supports 75+ LLMs — you can use Cloudflare Workers AI as the model provider for a fully Cloudflare-native workflow.
- The Skills plugin includes a wrangler Skill that teaches OpenCode when to reach for `npx wrangler deploy`, `wrangler d1`, and other CLI commands.
- Use OpenCode's plan agent (Tab key) to break down complex Workers projects before coding — pair it with `/cloudflare:build-agent` or `/cloudflare:build-mcp` slash commands.
- The Cloudflare API MCP server uses Code Mode — OpenCode writes JavaScript to reach any of 2,500+ endpoints in ~1,000 tokens.
- Cloudflare was one of the first sites to serve agent-friendly Markdown docs natively — OpenCode automatically requests `text/markdown` on every docs fetch.
- For more information on installing additional MCP servers, or when to use Code Mode versus traditional MCP servers, refer to the [Cloudflare MCP server repository](https://github.com/cloudflare/mcp-server-cloudflare).

</TipsList>

## FAQ

<FAQList>
	<FAQItem question="Should I use Skills, the MCP server, Wrangler CLI, or all of them?">
		All three. Skills provide persistent Cloudflare expertise so OpenCode knows
		when to reach for Durable Objects vs KV, how to structure a Workers project,
		and when to call CLI vs API. The Cloudflare API MCP server handles platform
		operations (DNS, WAF, Zero Trust, R2 buckets). Wrangler handles local dev,
		deploys, and Workers-specific commands. The bundled `wrangler` Skill teaches
		OpenCode which to use.
	</FAQItem>
	<FAQItem question="How do I connect OpenCode to Cloudflare?">
		Install the Skills plugin with `npx skills add
		https://github.com/cloudflare/skills`. The first time OpenCode calls a
		Cloudflare tool, you'll be redirected to authorize via OAuth and choose
		permissions.
	</FAQItem>
	<FAQItem question="Can I use Workers AI as the model provider in OpenCode?">
		Yes. OpenCode supports 75+ model providers, including Cloudflare Workers AI.
		Configure your model in `.opencode.jsonc`.
	</FAQItem>
	<FAQItem question="Is OpenCode open source?">
		Yes. OpenCode is fully open source and available at
		github.com/anomalyco/opencode.
	</FAQItem>
</FAQList>

## Troubleshooting

<TroubleshootingList>
	<TroubleshootingItem issue="MCP server connection fails">
		Verify the MCP configuration in `.opencode.jsonc` uses `"type": "remote"`
		with the correct URL. Run `opencode mcp list` to check connected servers.
	</TroubleshootingItem>
	<TroubleshootingItem issue="OpenCode cannot find Wrangler">
		Install Wrangler globally with `npm install -g wrangler` or ensure `npx` is
		available in your `PATH`.
	</TroubleshootingItem>
	<TroubleshootingItem issue="Skills are not loading">
		Verify skills are installed in `~/.config/opencode/skills/`. Re-run `npx
		skills add https://github.com/cloudflare/skills`.
	</TroubleshootingItem>
</TroubleshootingList>

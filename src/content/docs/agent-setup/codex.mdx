## Quick start

<AgentSteps>

1. **Install Codex**

   Install the Codex CLI. macOS and Linux are fully supported; use WSL2 on Windows. For Homebrew or other install methods, see the [Codex CLI setup guide](https://developers.openai.com/codex/cli/).

   ```bash
   npm install -g @openai/codex
   ```

2. **Install the Cloudflare Skills**

   Installs the Cloudflare Skills into `~/.codex/skills/`.

   ```bash
   npx skills add https://github.com/cloudflare/skills
   ```

3. **Add the Cloudflare MCP servers**

   Register the Cloudflare MCP servers with Codex.

   ```bash
   codex mcp add cloudflare -- npx mcp-remote https://mcp.cloudflare.com/mcp
   ```

4. **Launch Codex and build**

   Start Codex in your project directory and try a prompt — for example, "Create an example hello world app using Cloudflare Workers."

    ```bash
    codex
    ```

</AgentSteps>

## Tips

<TipsList>

- Codex runs in a sandbox — it can safely execute Wrangler commands without touching your host system, and the bundled wrangler Skill guides it on what to run.
- The Cloudflare API MCP server uses Code Mode — Codex writes JavaScript against a typed API to reach any of 2,500+ endpoints in ~1,000 tokens.
- Codex supports web browsing; pair it with the docs MCP server for the freshest Cloudflare references without leaving the agent loop.
- Try the `/cloudflare:build-agent` slash command to scaffold a complete Agents SDK project, or `/cloudflare:build-mcp` for a remote MCP server.
- For more information on installing additional MCP servers, or when to use Code Mode versus traditional MCP servers, refer to the [Cloudflare MCP server repository](https://github.com/cloudflare/mcp-server-cloudflare).

</TipsList>

## FAQ

<FAQList>
	<FAQItem question="Should I use Skills, the MCP server, Wrangler CLI, or all of them?">
		All three. Skills load Cloudflare knowledge into every Codex session (when
		to use Durable Objects, how to structure a Workers project, etc.). The
		Cloudflare API MCP server handles platform operations (DNS, WAF, Zero
		Trust). Wrangler handles local dev, deploys, and migrations. The bundled
		`wrangler` Skill teaches Codex when to run CLI commands vs. call the MCP
		API.
	</FAQItem>
	<FAQItem question="How do I connect Codex to my Cloudflare account?">
		Install the Skills plugin with `npx skills add
		https://github.com/cloudflare/skills`. The first time Codex calls a
		Cloudflare tool, you'll be redirected to authorize via OAuth and choose
		permissions.
	</FAQItem>
	<FAQItem question="Is Codex open source?">
		Yes. Codex is open source and available on GitHub at
		github.com/openai/codex.
	</FAQItem>
</FAQList>

## Troubleshooting

<TroubleshootingList>
	<TroubleshootingItem issue="Codex cannot find Wrangler">
		Ensure Wrangler is installed globally with `npm install -g wrangler` or use
		`npx wrangler` commands.
	</TroubleshootingItem>
	<TroubleshootingItem issue="MCP server authentication fails">
		Remove and re-add the MCP server. Complete the OAuth flow in your browser
		when prompted.
	</TroubleshootingItem>
	<TroubleshootingItem issue="Sandbox restrictions prevent deployment">
		Codex runs in a sandbox by default. Ensure network access is enabled for
		Cloudflare API endpoints.
	</TroubleshootingItem>
</TroubleshootingList>

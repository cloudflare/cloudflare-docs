## Quick start

<Steps>
	1. **Install Droid**

		Install the Droid CLI. For Windows, Homebrew, or npm, refer to the [Droid quickstart guide](https://docs.factory.ai/cli/getting-started/quickstart).

		```bash
		curl -fsSL https://app.factory.ai/cli | sh
		```

	2. **Install the Cloudflare plugin**

		From your shell, register the Cloudflare marketplace and install the plugin. This installs Cloudflare Skills and registers the Cloudflare MCP servers in one step.

		```bash
		droid plugin marketplace add https://github.com/cloudflare/skills
		droid plugin install cloudflare@skills
		```

	3. **Launch Droid in your project**

		Start Droid from the root of your project, where `wrangler.jsonc` lives (if it already exists).

		```bash
		droid
		```

	4. **Try a prompt**

		For example:

		<RandomPrompt />
</Steps>

## Tips

<TipsList>

- The Skills plugin includes a wrangler Skill — Droid knows when to reach for `npx wrangler deploy`, `wrangler d1 migrations apply`, and other CLI commands automatically.
- Try the `/build-agent` slash command to scaffold a complete Agents SDK project, or `/build-mcp` for a remote MCP server.
- The Cloudflare API MCP server uses Code Mode — Droid writes JavaScript against a TypeScript API to hit any of 2,500+ endpoints in ~1,000 tokens.
- Run `/mcp` inside Droid to check the connection status of the Cloudflare servers and complete OAuth authentication.
- Droid is model-agnostic — pick Claude, GPT, or Gemini per task with `/model`, or bring your own API keys.
- Use `droid exec` in CI/CD to run Cloudflare deploys and maintenance tasks headlessly. For more information, refer to the [Droid Exec documentation](https://docs.factory.ai/cli/droid-exec/overview).
- For more information on installing additional MCP servers, or when to use Code Mode versus traditional MCP servers, refer to the [Cloudflare MCP server repository](https://github.com/cloudflare/mcp-server-cloudflare).

</TipsList>

## FAQ

<FAQList>
	<FAQItem question="Should I use Skills, the MCP server, Wrangler CLI, or all of them?">
		All three — and the Cloudflare plugin configures them together. Skills give
		Droid persistent Cloudflare knowledge (when to use Durable Objects vs KV,
		what a good Workers project layout looks like). The Cloudflare API MCP
		server handles platform operations (DNS, WAF, R2 buckets, Zero Trust).
		Wrangler runs local dev and Workers-specific commands. The `wrangler` Skill
		teaches Droid when to reach for which.
	</FAQItem>
	<FAQItem question="How do I give Droid access to my Cloudflare account?">
		The first time Droid calls a Cloudflare tool, it redirects you to authorize
		via OAuth and choose what permissions to grant. You can also manage
		authentication from the `/mcp` manager inside Droid.
	</FAQItem>
	<FAQItem question="Can Droid deploy to existing Workers projects?">
		Yes. Run Droid from your existing project directory where `wrangler.jsonc`
		is located, and it will understand your project configuration and deploy
		accordingly.
	</FAQItem>
	<FAQItem question="Can I use Droid outside the terminal?">
		Yes. The [Factory desktop and web
		apps](https://docs.factory.ai/web/getting-started/overview) run the same
		agent with a graphical interface. Desktop sessions run on your local or
		remote machine and share the CLI's configuration, so the Cloudflare plugin
		from the Quick start is available there too. You can also run cloud sessions
		on Factory-managed machines, or use Droid inside VS Code, JetBrains IDEs,
		and Zed.
	</FAQItem>
	<FAQItem question="Which AI models does Droid support?">
		Droid is model-agnostic. It ships with frontier models from Anthropic,
		OpenAI, and Google, and supports bring-your-own-key (BYOK) providers and
		local models. Switch models mid-session with the `/model` command.
	</FAQItem>
</FAQList>

## Troubleshooting

<TroubleshootingList>
	<TroubleshootingItem issue="MCP server connection fails or times out">
		Run `droid mcp list` from your shell to verify the Cloudflare servers are
		registered, or use the `/mcp` manager inside Droid to inspect connection
		status. If a server is stuck, remove and re-add it: `droid mcp remove cloudflare-api`
		then `droid mcp add cloudflare-api https://mcp.cloudflare.com/mcp --type http`.
	</TroubleshootingItem>
	<TroubleshootingItem issue="Droid cannot authenticate with Cloudflare">
		The MCP servers use OAuth. Open the `/mcp` manager inside Droid, select the
		Cloudflare server, and complete the authorization flow in your browser.
	</TroubleshootingItem>
	<TroubleshootingItem issue="Getting outdated information about Cloudflare products">
		Enable the <a href="https://github.com/cloudflare/mcp-server-cloudflare" target="_blank" rel="noopener noreferrer">Cloudflare docs MCP server</a> so the agent can fetch
		current documentation at runtime. If you prefer not to use the MCP server, point
		the agent directly at <a href="/llms.txt">developers.cloudflare.com/llms.txt</a> for
		a directory of every product, or <code>developers.cloudflare.com/&lt;product&gt;/llms.txt</code>
		for a product-specific index.
	</TroubleshootingItem>
</TroubleshootingList>

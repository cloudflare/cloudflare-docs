Use the evaluation API when you cannot use the [Workers binding](/flagship/binding/). The API accepts query parameters or a JSON request body.

## Send scalar query context

The [`GET` endpoint](/api/resources/flagship/subresources/apps/subresources/evaluate/methods/get/) accepts context attributes as query parameters. Use it for scalar context values.

Flagship coerces unambiguous number and boolean query values. For example, `42` becomes a number and `true` becomes a boolean. Other values remain strings.

JSON-looking query values remain strings. A value such as `{"plan":"enterprise"}` does not create a nested object.

## Send structured JSON context

Use `POST` to send nested objects, arrays, or `null`. The following request evaluates `new-checkout` with structured context:

<APIRequest
	path="/accounts/{account_id}/flagship/apps/{app_id}/evaluate"
	method="POST"
	json={{
		flagKey: "new-checkout",
		context: {
			targetingKey: "user-42",
			profile: { plan: "enterprise" },
			tags: ["beta"],
		},
	}}
/>

The `POST` response contains the same fields as `GET`:

```json
{
	"flagKey": "new-checkout",
	"value": true,
	"variant": "on",
	"reason": "TARGETING_MATCH"
}
```

Invalid context returns a `400` response. Refer to [Limits](/flagship/reference/limits/) and [evaluation error codes](/flagship/reference/evaluation-reasons/#error-codes) for details.

Flagship enforces the following limits.

## Platform limits

| Feature                         | Limit     |
| ------------------------------- | --------- |
| Apps per account                | 10,000    |
| Flags per app                   | 5,000     |
| Flag, app, and variant keys     | 64 chars  |
| Condition attribute names       | 64 chars  |
| Condition string values         | 256 chars |
| Variant value size              | 10 KB     |
| Condition grouping depth        | 5 levels  |
| Flag description                | 512 chars |
| Flag configuration size per app | 25 MB     |

:::note
The apps-per-account and flags-per-app limits are soft limits. If your use case requires higher limits, contact Cloudflare support.
:::

## Evaluation context limits

The following limits apply to each evaluation context:

| Feature                         | Limit         | Scope                                    |
| ------------------------------- | ------------- | ---------------------------------------- |
| Top-level attributes            | 100           | All evaluation paths                     |
| Top-level key length            | 1–256 chars   | All evaluation paths                     |
| Value nesting depth             | 10 levels     | All evaluation paths                     |
| Serialized UTF-8 JSON size      | 32 KiB        | All evaluation paths                     |
| Values visited during traversal | 10,000 values | Data-plane HTTP and Workers binding only |

Flagship control-plane `POST` endpoints do not apply the 10,000-value traversal limit. Other context limits still apply.

## Notes

- Condition grouping depth counts from the top-level condition group. A flat list of conditions has a depth of one.
- Context value nesting and attribute path traversal use separate limits. Targeting attribute paths can contain up to five segments.
- Flag keys, app names, condition set names, and variant keys can contain letters, numbers, hyphens, and underscores.
- All variants on a flag must use the same value type: boolean, string, number, or JSON.
- Flag configuration size refers to the total serialized size of all flags within a single app, including their variants and rules.

The following example uses [MotherDuck](https://motherduck.com/) to connect to R2 Data Catalog. MotherDuck is a managed cloud analytics platform built on [DuckDB](https://duckdb.org/). You can attach R2 Data Catalog as a MotherDuck database to read and write Iceberg tables server-side. For more information, refer to the [MotherDuck Apache Iceberg documentation](https://motherduck.com/docs/integrations/file-formats/apache-iceberg/).

## Prerequisites

- Sign up for a [Cloudflare account](https://dash.cloudflare.com/sign-up/workers-and-pages).
- [Create an R2 bucket](/r2/buckets/create-buckets/) and [enable the data catalog](/r2/data-catalog/manage-catalogs/#enable-r2-data-catalog-on-a-bucket).
- [Create an R2 API token](/r2/api/tokens/) with both [R2 and data catalog permissions](/r2/api/tokens/#permissions).
- Sign up for a [MotherDuck account](https://app.motherduck.com/).
- Connect to MotherDuck using the [MotherDuck SQL editor](https://app.motherduck.com/) or a [supported DuckDB client](https://motherduck.com/docs/getting-started/interfaces/connect-query-from-duckdb-cli/#installation).
  - Note: If you use a DuckDB client, [DuckDB 1.5.2](https://github.com/duckdb/duckdb/releases/tag/v1.5.2) or greater is required to attach and write to [Iceberg REST catalogs](https://motherduck.com/docs/integrations/file-formats/apache-iceberg/#persisted-iceberg-catalogs) using MotherDuck.
- Ensure your R2 Data Catalog has at least one namespace. MotherDuck cannot create a namespace in R2 Data Catalog, so seed a new catalog from another Iceberg engine, such as [PyIceberg](/r2/data-catalog/config-examples/pyiceberg/), before you attach it.

## Example usage

In the [MotherDuck SQL editor](https://app.motherduck.com/), or a DuckDB client connected to MotherDuck, run the following commands:

```sql
-- In a DuckDB client, load the iceberg extension and connect to MotherDuck.
-- (Skip these three statements in the MotherDuck SQL editor.)
INSTALL iceberg;
LOAD iceberg;
ATTACH 'md:';

-- Store your R2 Data Catalog credentials in a MotherDuck secret.
CREATE SECRET r2_secret IN MOTHERDUCK (
    TYPE ICEBERG,
    TOKEN '<token>'
);

-- Register R2 Data Catalog as a MotherDuck database.
-- `warehouse` is required for R2 Data Catalog; omitting it returns a 403.
-- `default_schema` must reference a namespace that already exists in the catalog.
CREATE DATABASE my_r2_catalog (
    TYPE ICEBERG,
    "secret" r2_secret,
    endpoint '<catalog_uri>',
    warehouse '<warehouse_name>',
    default_schema '<namespace>'
);

-- Set the attached catalog and namespace as the active context.
USE my_r2_catalog.<namespace>;

-- Show all available tables.
SHOW ALL TABLES;

-- Query an existing Iceberg table.
SELECT * FROM my_iceberg_table;

-- MotherDuck supports writes: create and populate a new Iceberg table.
CREATE TABLE my_new_iceberg_table AS SELECT a FROM range(4) t(a);
```

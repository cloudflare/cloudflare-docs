## Webhook test failed with status code 400 Bad Request

This error can occur when you try to configure a webhook that is not currently supported, such as setting up a PagerDuty webhook. PagerDuty needs to be configured under [connected services](/notifications/get-started/configure-pagerduty/), not as a webhook.

## Deleted users are still receiving alerts

When you remove a user from your account via **Manage Account** > **Members** in the Cloudflare dashboard, their email address is not removed from existing alerts. You need to remove their email address by [editing the alert](/notifications/get-started/#manage-alerts).

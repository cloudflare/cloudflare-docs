Use this guide to connect AI coding assistants and LLMs to Cloudflare documentation, APIs, and platform tools.

## Quick start

- **AI coding agents**: Set up [Claude Code](/agent-setup/claude-code/), [Cursor](/agent-setup/cursor/), [Codex](/agent-setup/codex/), [GitHub Copilot](/agent-setup/github-copilot/), [OpenCode](/agent-setup/opencode/), or [Windsurf](/agent-setup/windsurf/) with Cloudflare [Skills](#skills) and [MCP servers](#mcp-servers).
- **Chat interfaces (ChatGPT, Claude.ai)**: Append `/index.md` to any docs page URL and paste the Markdown into your conversation.
- **Project rules and custom instructions**: Add a product-level [`llms.txt`](#per-product-endpoints) URL to your AI tool's rules file for an index of relevant pages.
- **API-aware coding**: Add the [OpenAPI specification](#openapi-specification) to your AI tool's context for full Cloudflare API coverage.

## Skills

[Agent skills](https://agentskills.io/home) are structured, task-specific instructions that AI tools load on demand. Cloudflare publishes a skill bundle in the [Cloudflare Skills repository](https://github.com/cloudflare/skills) covering Workers, storage, AI, networking, security, and more.

To install skills in any compatible agent, run:

```sh
npx skills add https://developers.cloudflare.com
```

For agent-specific installation (plugins, slash commands, or marketplace), refer to the setup guide for your agent.

## MCP servers

Cloudflare runs a catalog of managed remote [MCP](https://modelcontextprotocol.io/) servers. MCP servers give your agent typed tools to search documentation, call the Cloudflare API, and query observability data at runtime.

There are two approaches:

- **[Code Mode](/agents/api-reference/codemode/)**: A single MCP server covering the entire Cloudflare API.
- **Domain-specific servers**: Focused servers for docs, observability, DNS analytics, and more. The full catalog is in the [cloudflare/mcp-server-cloudflare](https://github.com/cloudflare/mcp-server-cloudflare) repository.

### Documentation MCP server

The [Documentation MCP Server](https://github.com/cloudflare/mcp-server-cloudflare/tree/main/apps/docs-vectorize) gives your agent direct access to up-to-date Cloudflare documentation.

## Markdown documentation for LLMs

Every documentation page is available as lightweight Markdown using any of the following methods, powered by [Markdown for Agents](/fundamentals/reference/markdown-for-agents/).

### Copy from the current page

On any documentation page, select **Copy as Markdown** to copy the current page as Markdown.

### Append `/index.md` to the URL

Add `/index.md` to the end of any page URL. For example:

```txt
https://developers.cloudflare.com/workers/get-started/index.md
```

### Send an `Accept: text/markdown` header

Request any page with the `Accept: text/markdown` header:

```sh
curl "https://developers.cloudflare.com/workers/get-started/" \
  --header "Accept: text/markdown"
```

The response includes an `x-markdown-tokens` header with the estimated token count, useful for context window planning.

### Site-wide endpoints

These endpoints follow the [llms.txt standard](https://llmstxt.org/) and provide documentation content in Markdown format:

| Endpoint                           | Description                                                                                                           |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| [`/llms.txt`](/llms.txt)           | Page index grouped by product category, with links to each product's own `llms.txt`                                   |
| [`/llms-full.txt`](/llms-full.txt) | Full content of all documentation in a single file, for offline indexing, bulk vectorization, or large-context models |

### Per-product endpoints

Each product has its own scoped `llms.txt` and `llms-full.txt`. Use these when you only need documentation for a specific product.

| Endpoint                                           | Description                                     |
| -------------------------------------------------- | ----------------------------------------------- |
| [`/workers/llms.txt`](/workers/llms.txt)           | Page index for Workers documentation            |
| [`/workers/llms-full.txt`](/workers/llms-full.txt) | Full content of all Workers documentation pages |

Replace `/workers/` with any product path. For the full list of available products, refer to [`/llms.txt`](/llms.txt).

## Contribute to Cloudflare documentation with AI

The `cloudflare-docs` repository includes an [`AGENTS.md`](https://github.com/cloudflare/cloudflare-docs/blob/production/AGENTS.md) file that helps AI coding agents understand the structure, tooling, and conventions of the repository so they can make correct, buildable changes when contributing to documentation.

[AGENTS.md](https://agents.md/) is a simple, open format for guiding coding agents.

The repository also includes configuration for the following AI tools:

- [OpenCode](https://opencode.ai/)
- [Windsurf](https://windsurf.com/)

To set up other AI tools (Claude Code, Cursor, or GitHub Copilot) for documentation contributions, use [`rulesync`](https://github.com/dyoshikawa/rulesync) to synchronize AI tool configurations:

```sh
# Configure Claude Code
npm run ai-setup:claudecode

# Configure Cursor
npm run ai-setup:cursor

# Configure GitHub Copilot
npm run ai-setup:copilot
```

Each script imports AI tool components (commands and subagents) from the OpenCode configuration committed to the repository and generates configuration files in the expected locations for your selected AI tool.

## Concepts

### Agent skills

Skills are reusable prompt packages that teach an agent about a specific domain. They act as plugins made of instructions and slash commands that the agent loads on demand.

### Model Context Protocol (MCP)

The [Model Context Protocol](https://modelcontextprotocol.io/) (MCP) is an open standard that lets agents call external tools and APIs. Connect an MCP server and your agent can search docs, create DNS records, deploy Workers, and more.

### Model flexibility

How many foundation models you can use depends on the agent:

- **Locked**: Only the vendor's own models are supported.
- **BYOK** (Bring Your Own Key): You supply your own API key.
- **Multi-provider**: Several providers supported out of the box.

### Context approaches

How the agent retains information about your project varies:

- **Session**: Only remembers the current conversation.
- **Project memory**: Persists across sessions.
- **Indexed codebase**: Builds a searchable index of your repository.

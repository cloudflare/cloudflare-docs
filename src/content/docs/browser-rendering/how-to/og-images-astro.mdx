Open Graph (OG) images are the preview images that appear when you share a link on social media. Instead of manually creating these images for every blog post, you can use Cloudflare Browser Rendering to automatically generate branded social preview images from an Astro template.

In this tutorial, you will:

1. Create an Astro page that renders your OG image design.
2. Use Browser Rendering to screenshot that page as a PNG.
3. Serve the generated images to social media crawlers.

This tutorial covers two approaches:

| Approach                | Best for                        | Trade-offs                       |
| ----------------------- | ------------------------------- | -------------------------------- |
| On-demand (Worker + R2) | Large sites, frequent updates   | ~2s cold start on first request  |
| Build-time (Static)     | Small sites, infrequent updates | Longer build times as site grows |

## Prerequisites

- A Cloudflare account with [Browser Rendering enabled](/browser-rendering/get-started/)
- An Astro site deployed on [Cloudflare Pages](/pages/)
- Basic familiarity with Astro and Cloudflare Workers

## 1. Create the OG image template

Create a hidden Astro route that renders your OG image design. This page serves as the source of truth for your image layout.

Create `src/pages/_internal/og.astro`:

```astro
---
export const prerender = false;

const title = Astro.url.searchParams.get("title") || "Untitled";
const image = Astro.url.searchParams.get("image");
const author = Astro.url.searchParams.get("author");
---

<html>
	<head>
		<meta charset="utf-8" />
		<style>
			* {
				margin: 0;
				padding: 0;
				box-sizing: border-box;
			}
			body {
				width: 1200px;
				height: 630px;
				display: flex;

				background: linear-gradient(135deg, #f38020 0%, #f9a825 100%);
				color: white;
			}
			.title {
				font-size: 64px;
				font-weight: bold;
				line-height: 1.1;
				margin-bottom: 24px;
			}
			.author {
				font-size: 24px;
				opacity: 0.9;
			}

				position: absolute;
				top: 60px;

			}
		</style>
```

Test locally by visiting `http://localhost:4321/_internal/og?title=My%20Blog%20Post&author=Omar`.

## 2. Set up Browser Rendering

### Option A: Generate on demand with a Worker

This approach generates images on first request and caches them in R2.

Create a Worker that:

1. Receives requests for OG images
2. Checks R2 for a cached version
3. If not cached, uses Browser Rendering to screenshot the template
4. Saves the result to R2 and returns it

Create `og-worker/src/index.ts`:

```ts
import puppeteer from "@cloudflare/puppeteer";

interface Env {
	BROWSER: Fetcher;
	OG_IMAGES: R2Bucket;
}

export default {
	async fetch(request: Request, env: Env): Promise<Response> {
		const url = new URL(request.url);
		const slug = url.searchParams.get("slug");
		const title = url.searchParams.get("title");

		if (!slug || !title) {
			return new Response("Missing slug or title parameter", { status: 400 });
		}

		// Check R2 cache first
		const cacheKey = `og/${slug}.png`;
		const cached = await env.OG_IMAGES.get(cacheKey);

		if (cached) {
			return new Response(cached.body, {
				headers: {
					"Content-Type": "image/png",
					"Cache-Control": "public, max-age=86400",
				},
			});
		}

		// Generate image using Browser Rendering
		const browser = await puppeteer.launch(env.BROWSER);
		const page = await browser.newPage();

		await page.setViewport({ width: 1200, height: 630 });

		// Navigate to your OG template, forwarding the title as a query param
		const templateParams = new URLSearchParams({ title });
		const author = url.searchParams.get("author");
		if (author) templateParams.set("author", author);

		const templateUrl = `https://your-blog.pages.dev/_internal/og?${templateParams}`;
		await page.goto(templateUrl, { waitUntil: "networkidle0" });

		const screenshot = await page.screenshot({ type: "png" });
		await browser.close();

		// Cache in R2
		await env.OG_IMAGES.put(cacheKey, screenshot, {
			httpMetadata: { contentType: "image/png" },
		});

		return new Response(screenshot, {
			headers: {
				"Content-Type": "image/png",
				"Cache-Control": "public, max-age=86400",
			},
		});
	},
};
```

### Option B: Generate at build time

Generate all OG images during the Astro build process. This script runs locally (or in your CI environment) using Puppeteer, not inside a Worker.

Create `scripts/generate-og-images.ts`:

```ts
import puppeteer from "puppeteer";
import { mkdir, writeFile } from "fs/promises";
import { join } from "path";

interface Post {
	slug: string;
	title: string;
	author?: string;
}

async function generateOGImages() {
	// Replace this with your own data-fetching logic
	const posts: Post[] = await getPosts();

	const browser = await puppeteer.launch();
	const page = await browser.newPage();
	await page.setViewport({ width: 1200, height: 630 });

	await mkdir("dist/og", { recursive: true });

	for (const post of posts) {
		const params = new URLSearchParams({
			title: post.title,
			author: post.author || "",
		});

		await page.goto(`http://localhost:4321/_internal/og?${params}`, {
			waitUntil: "networkidle0",
		});

		const screenshot = await page.screenshot({ type: "png" });
		await writeFile(join("dist/og", `${post.slug}.png`), screenshot);

		console.log(`Generated OG image for: ${post.slug}`);
	}

	await browser.close();
}

generateOGImages();
```

Add to your build script in `package.json`:

```json
{
	"scripts": {
		"build": "astro build && tsx scripts/generate-og-images.ts"
	}
}
```

## 3. Add OG meta tags to your pages

Update your blog post layout to reference the generated images:

```astro
---
// src/layouts/BlogPost.astro
const { title, slug, author } = Astro.props;
const siteUrl = Astro.site || "https://your-blog.pages.dev";

// Option A: Worker URL
const ogParams = new URLSearchParams({ slug, title });
if (author) ogParams.set("author", author);
const ogImageUrl = `https://og.your-domain.workers.dev/?${ogParams}`;

// Option B: Static path
// const ogImageUrl = new URL(`/og/${slug}.png`, siteUrl).href;
---

<html>
	<head>
		<meta property="og:title" content={title} />
		<meta property="og:image" content={ogImageUrl} />
		<meta property="og:image:width" content="1200" />
		<meta property="og:image:height" content="630" />
		<meta name="twitter:card" content="summary_large_image" />
		<meta name="twitter:image" content={ogImageUrl} />
	</head>
	<body>
		<slot />
	</body>
</html>
```

```astro
const title = Astro.url.searchParams.get("title") || "Untitled";

<body style={image ? `background-image: url(${image})` : undefined}>
```

```astro
</body>
```

## Performance considerations

### Cold start optimization

Browser Rendering has a ~2 second cold start. To minimize impact:

- Use R2 caching (Option A) to serve repeat requests instantly
- Pre-warm the Worker by generating images for new posts immediately after publish

### Image optimization

Consider running generated images through Cloudflare Images or Image Resizing for additional optimization:

```ts
// In your Worker
const optimizedUrl = `https://your-domain.com/cdn-cgi/image/width=1200,format=auto/${cacheKey}`;
```

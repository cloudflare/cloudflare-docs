Wrap your HTTP transport with a signing [`RoundTripper`](https://pkg.go.dev/net/http#RoundTripper). Use it with a reusable `http.Client`.

Requires Go 1.22 or later. The example uses the standard library. Complete the [shared setup](/bots/reference/bot-verification/web-bot-auth/sign-requests/#before-you-start) first.

## Add the transport

<Steps>
1. Save [wba.go](/web-bot-auth/wba.go) in a `wba` folder inside your Go module.

2. Create a client. Replace `example.com/mybot` with your module path and replace the signature-agent origin with your own.

   ```go title="main.go"
   package main

   import (
       "fmt"
       "io"
       "net/http"
       "os"
       "time"

       "example.com/mybot/wba"
   )

   func run() error {
       key, err := os.ReadFile("private-key.pem")
       if err != nil { return err }
       transport, err := wba.NewTransport(
           key,
           "https://bot.example.com",
           []string{"https://example.com", "https://crawltest.com"},
           nil, // Use http.DefaultTransport.
       )
       if err != nil { return err }
       defer transport.CloseIdleConnections()

       client := &http.Client{Transport: transport, Timeout: 30 * time.Second}
       response, err := client.Get("https://crawltest.com/cdn-cgi/web-bot-auth")
       if err != nil { return err }
       defer response.Body.Close()
       fmt.Println(response.StatusCode)
       _, err = io.Copy(os.Stdout, response.Body)
       return err
   }

   func main() {
       if err := run(); err != nil {
           fmt.Fprintln(os.Stderr, err)
           os.Exit(1)
       }
   }
   ```

3. Run `go run .` and [check the response](#verify-the-request).
</Steps>

## Redirects and retries

- The HTTP client sends each redirect through `RoundTrip`. Each hop gets a new signature for its destination and method.
- The transport clones the request before editing headers. Requests outside the allowed origins continue unsigned.
- Retry through `client.Do` with a new request and a fresh body. An underlying transport may retry internally; keep attempts within the signature's 60-second lifetime.
- To configure proxies or TLS, clone `http.DefaultTransport` and pass it as the final argument to `NewTransport`.
- Leave `Request.Host` unchanged. Use ASCII or punycode destination hostnames.
- Use `transport.KeyID()` to compare the selected key with your registered directory.

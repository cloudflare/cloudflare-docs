:::caution[Deprecated classification]
As of [Content Independence Day](https://blog.cloudflare.com/content-independence-day-no-ai-crawl-without-compensation/) (July 1, 2026), **signed agent** is no longer an official Cloudflare classification.

Agents that self-identify with [Web Bot Auth](/bots/reference/bot-verification/web-bot-auth/) and behave well are now classified as [verified bots](/bots/concepts/bot/verified-bots/). What used to be called a "signed agent" is now a verified bot or agent labeled **Intermediary**.
:::

## What changed

Previously, Cloudflare drew a hard line between a *verified bot* and a *signed agent*, and a bot could not be both. The new taxonomy removes that line. Every recognized bot or agent that is honest about its identity and does not abuse access is **verified**, and is then labeled by how it is operated:

| Legacy term | New equivalent | Meaning |
| --- | --- | --- |
| Verified bot | Verified bot, labeled **Direct** | Operated by a single, narrow operator, usually on its own infrastructure. |
| Signed agent | Verified bot, labeled **Intermediary** | An agentic service that many different end users can operate. |

For details, refer to [Direct and intermediary bots and agents](/bots/concepts/bot/verified-bots/#direct-and-intermediary-bots-and-agents).

## What you need to do

- **Bot and agent operators:** There is no separate signed agent application anymore. Submit your bot or agent through the [verified bots application](https://dash.cloudflare.com/?to=/:account/configurations/verified-bots) and continue to authenticate with [Web Bot Auth](/bots/reference/bot-verification/web-bot-auth/). Agents that many end users can operate are labeled **Intermediary**.
- **Website owners:** Rules and analytics that previously referred to signed agents now refer to verified bots and agents. Review [Verified bots](/bots/concepts/bot/verified-bots/) to understand how the new labels map to your configuration.

:::caution[Deprecated policy]
As of [Content Independence Day](https://blog.cloudflare.com/content-independence-day-no-ai-crawl-without-compensation/) (July 1, 2026), **signed agent** is no longer a separate classification, so there is no longer a separate signed agents policy.

Agents are now evaluated against the [verified bots policy](/bots/concepts/bot/verified-bots/policy/). An agent that many end users can operate is recognized as a verified bot or agent labeled **Intermediary**.
:::

## Where requirements moved

The requirements that previously lived here are now covered by the [verified bots policy](/bots/concepts/bot/verified-bots/policy/), which applies to all bots and agents:

- **Honest self-identification** — authenticate with [Web Bot Auth](/bots/reference/bot-verification/web-bot-auth/) (or another supported [verification method](/bots/concepts/bot/verified-bots/#verification-methods)).
- **Benign or helpful purpose** — the service must not perform abusive activity such as credential stuffing, scalping, or excessive scraping.
- **Public documentation** — the bot or agent must have a publicly documented purpose and expected behavior.

For the full, current list of requirements, refer to the [verified bots policy](/bots/concepts/bot/verified-bots/policy/).

This section is the planning layer of the style guide. It tells you what kind of page to write, where it lives, what parts it is built from, and how to write it so the page reads like the rest of the site. The four areas follow the order you meet them when you plan a page.

## What to write

[Content types](/style-guide/documentation-content-strategy/content-types/) catalog the defined page shapes and help you choose the right one. Every type documents how it is structured, scaffolded, and maintained.

## How to structure it

[Information architecture](/style-guide/documentation-content-strategy/information-architecture/) governs on-page section order and the folder shape a reader navigates. [File conventions](/style-guide/documentation-content-strategy/file-conventions/) governs the repo file, folder, and image naming a builder works with.

## The parts a page is built from

[Component attributes](/style-guide/documentation-content-strategy/component-attributes/) covers the content-strategy parts of a page, such as introductions, prerequisites, and next steps. Formatting and component mechanics live in their own sibling sections, linked from each part.

## How to write it well

[Writing guidelines](/style-guide/documentation-content-strategy/writing-guidelines/) covers the house voice and tone. [Accessibility](/style-guide/documentation-content-strategy/accessibility/) covers writing so every reader can use the page.

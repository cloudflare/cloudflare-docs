Component attributes are the content-strategy parts a page is built from. Each page here covers one part: what it is, when to use it, and how to structure it. Formatting and component mechanics live in their own sections, linked from each part.

## Moved pages

- Tables are now in [Tables](/style-guide/formatting/structure/tables/).

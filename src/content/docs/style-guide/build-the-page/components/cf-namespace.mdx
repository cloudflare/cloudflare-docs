The `CfNamespace` component documents every visible command in a Cloudflare CLI namespace using metadata from the version of `cf` installed in the [`cloudflare-docs` repository](https://github.com/cloudflare/cloudflare-docs/blob/production/package.json).

## Import

```mdx
import { CfNamespace } from "~/components";
```

## Usage

```mdx
import { CfNamespace } from "~/components";

<CfNamespace namespace="hyperdrive" />
```

## Arguments

- `namespace` <Type text="string" /> <MetaInfo text="required" />
  - The namespace without the `cf` prefix, such as `hyperdrive`.
- `headingLevel` <Type text="number" /> <MetaInfo text="(default: 2) optional" />
  - The heading level for each command name.

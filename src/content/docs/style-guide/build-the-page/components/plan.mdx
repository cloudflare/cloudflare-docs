The plan component lets you define what type of plan your product needs. Use it in the main [Overview page](/style-guide/documentation-content-strategy/content-types/overview/) of your product, or in a page where you need to talk about a specific feature with additional requirements.

Use `<Plan type="<PLAN_TYPE>" />`, choosing the type that matches your product's availability.

Refer to the examples below for more information.


```mdx
import { Plan } from "~/components"

<Plan type="all" />
<Plan type="paid" />
<Plan type="pro" />
<Plan type="business" />
<Plan type="add-on" />
<Plan type="ent-add-on" />
<Plan type="workers-all" />
<Plan type="workers-paid" />
<Plan type="beta" />
```

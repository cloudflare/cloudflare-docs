With Classic CNI you can receive alerts whenever there is routine maintenance happening to the system that may impact your service. Create an alert in the Cloudflare dashboard to receive an alert about this type of event.

1. Log in to the [Cloudflare dashboard](https://dash.cloudflare.com/login), and select your account.
2. Go to **Notifications** > **Add**.
3. From the dropdown menu select _Cloudflare Network Interconnect_.
4. Select **Connection Maintenance Alert**.
5. Add a name to the notification, and choose if you want to be alerted by webhook or email.
6. Select **Save**.

You will now be alerted when there are routine maintenance events that impact Classic CNI.

The following facilities offer Cloudflare Network Interconnect (CNI) for private connectivity to Cloudflare's global network. For public peering and best-effort interconnection at additional locations, refer to [Cloudflare on PeeringDB](https://www.peeringdb.com/net/4224).

## Dataplane versions

Each site supports one or more CNI dataplane versions:

| Dataplane | MTU | Routing | Peering |
| --- | --- | --- | --- |
| v1 | Unidirectional 1500B | Static routes | Yes |
| v2 | Bidirectional 1500B | Static routes. Overlay BGP is closed beta. | No |

For more information, refer to [Cloudflare Network Interconnect](/network-interconnect/#dataplane-versions).

## Available locations

On this page, **diversity** means that a site has two Cloudflare connectivity devices of the same type for the listed dataplane version, providing separate paths into Cloudflare's network. This reduces exposure to a single device or upstream-path failure.

### Diverse CNI available

Values show whether a dataplane is available through one or two connectivity devices. `—` means the dataplane is not offered.

\* Site has diversity being built out. Contact your account team.

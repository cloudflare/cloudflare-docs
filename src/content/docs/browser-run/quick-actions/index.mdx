Quick Actions provide simple interfaces for common browser tasks like capturing screenshots, extracting HTML content, generating PDFs, and more. You can use Quick Actions in two ways:

- **REST API**: HTTP endpoints for one-off requests or external integration.
- **Workers Bindings**: Call Quick Actions directly from a [Cloudflare Worker](/workers/) using `env.BROWSER.quickAction()`.

The following are the available options:

<DirectoryListing />

[`/crawl`](/browser-run/quick-actions/crawl-endpoint/) is available via the REST API only.

Use Quick Actions when you need a fast, simple way to perform common browser tasks such as capturing screenshots, extracting HTML, or generating PDFs without writing complex scripts. For more advanced automation, custom workflows, or persistent browser sessions, use [Puppeteer](/browser-run/puppeteer/), [Playwright](/browser-run/playwright/), or [CDP](/browser-run/cdp/).

## Before you begin

### REST API

To use Quick Actions via the REST API, [create a custom API Token](/fundamentals/api/get-started/create-token/) with the following permissions:

- `Browser Run - Edit`

### Workers binding

To use Quick Actions from a [Worker](/workers/), configure a [browser binding](/browser-run/reference/wrangler/#bindings) in your `wrangler.json`. No API token is needed when using the Workers binding.

```jsonc
{
  "browser": {
    "binding": "BROWSER"
  }
}
```

:::caution

The `.quickAction()` method requires a compatibility date of `2026-03-24` or later.

```jsonc
{
  "compatibility_date": "2026-03-24",
  "browser": {
    "binding": "BROWSER"
  }
}
```

:::

### Test Quick Actions locally

Under `npx wrangler dev`, `.quickAction()` uses a Chrome instance on your machine. It returns the same responses and errors as Browser Run, with two exceptions:

- The `json` action returns placeholder data, because [Workers AI](/workers-ai/) is not available locally. If a field in `response_format.json_schema` sets `const`, `enum`, or `default`, it gets that value, or the first `enum` entry. Other fields get an empty value, such as `""`, `0`, `false`, or `[]`. Wrangler also logs a warning.
- The [Kitesurf](/browser-run/kitesurf/) browser is not available. If you pass `browser: "kitesurf"`, `.quickAction()` throws an error.

To get real `json` results or use Kitesurf during local development, set `"remote": true` in your browser binding configuration:

```jsonc
{
  "browser": {
    "binding": "BROWSER",
    "remote": true
  }
}
```

:::note[Note]

You can monitor Browser Run (formerly Browser Rendering) usage in two ways:

- In the Cloudflare dashboard, go to the **Browser Run** page to view aggregate metrics, including total Quick Actions requests and total browser hours used.
  <DashButton url="/?to=/:account/workers/browser-run" />
- `X-Browser-Ms-Used` header: Returned in every Quick Actions response, reporting browser time used for that request (in milliseconds).

:::

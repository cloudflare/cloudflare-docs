Configure data residency for individual Cloudflare products. Each guide covers the settings that product supports: a processing region, which controls where traffic is decrypted and processed, and a log region, which controls where logs and analytics are stored.

## Verify your processing region

To verify that your processing region is applied, run one of the following `curl` commands against a regionalized hostname:

```bash
curl -X GET -I https://<HOSTNAME>/ 2>&1 | grep cf-ray
```

```bash
curl -s https://<HOSTNAME>/cdn-cgi/trace | grep "colo="
```

The first command returns a three-letter IATA code (an airport identifier that corresponds to the nearest Cloudflare data center) in the [Cf-Ray](/fundamentals/reference/http-headers/#cf-ray) header. This code identifies the data center where processing and TLS termination (traffic decryption) took place. The second command returns the three-letter IATA code directly.

For example, when a hostname uses the European Union (EU) processing region, the three-letter IATA code always identifies a data center inside the EU.

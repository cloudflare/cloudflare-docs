Set a processing region to control where cached content is stored and served from. Set a log region to control where Cache analytics are stored.

## Processing region

To set a processing region for hostnames [proxied](/dns/proxy-status/) (meaning traffic routes through Cloudflare) through Cloudflare, and ensure that [eligible assets](/cache/concepts/default-cache-behavior/) are cached only in-region, follow these steps for the dashboard or API configuration:

<Tabs syncKey="dashPlusAPI"> <TabItem label="Dashboard">

1. In the Cloudflare dashboard, go to the **Records** page.

   <DashButton url="/?to=/:account/:zone/dns/records" />

2. Follow these steps to [create a DNS record](/dns/manage-dns-records/how-to/create-dns-records/).
3. From the **Region** dropdown, select the region you would like to use on your domain.
4. Select **Save**.

</TabItem>

<TabItem label="API">

1. To create records with the API, use the [API POST](/api/resources/dns/subresources/records/methods/create/) command.
2. Run the [API POST](/data-localization/processing-region/regional-hostnames/#configure-a-processing-region-via-api) command on the hostname to create a `regional_hostnames` with a specific region.

</TabItem> </Tabs>

:::note

Only [Generic Global Tiered Cache](/cache/how-to/tiered-cache/#generic-global-tiered-cache) and [Custom Tiered Cache](/cache/how-to/tiered-cache/#custom-tiered-cache) respect your processing region. [Smart Tiered Cache](/cache/how-to/tiered-cache/#smart-tiered-cache) is incompatible with processing regions.

:::

### Egress to origin

Your processing region controls where user traffic is decrypted and processed within Cloudflare's network. It does not by itself guarantee the geolocation of the egress IPs used by the Cloudflare CDN when connecting to your origin server. Egress IPs to your origin are site-local IPs from the in-region data center where the request was processed.

If you need guaranteed egress IP geolocation, for example to allowlist Cloudflare IPs on your origin from a specific country, use [Dedicated CDN Egress IPs](/smart-shield/configuration/dedicated-egress-ips/) in combination with a processing region.

## Log region

[Cache Analytics](/cache/performance-review/cache-analytics/), Generic Global Tiered Cache, and Custom Tiered Cache are compatible with log regions. With an EU log region, the **Caching** > **Tiered Cache** tab in the zone dashboard is not populated.

For more information on CDN and caching, refer to the [Cache documentation](/cache/).

Cloudflare One provides separate controls for where Cloudflare processes supported traffic and where Cloudflare stores supported logs. These controls have different settings and supported regions.

| Control | What it controls | Current availability |
| - | - | - |
| [Regional Services for Gateway](#regional-services-for-gateway) | Where Gateway decrypts and inspects supported HTTPS traffic | Available for supported on-ramps and Cloudflare One regions |
| [Cloudflare Tunnel region](/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/run-parameters/#region) | Where `cloudflared` establishes its tunnel connections | Global or United States |
| [Customer Metadata Boundary (CMB)](#customer-metadata-boundary) | Where Cloudflare stores supported Customer Logs | European Union and United States |
| [Access with Regional Services](#access) | Where Cloudflare processes reverse proxy requests for Access-protected applications | FedRAMP Moderate Compliant (Domestic) only |
| [Browser Isolation for FedRAMP accounts](#browser-isolation) | Where Cloudflare processes supported Browser Isolation traffic | US FedRAMP region only |
| [Email Security regional processing](/cloudflare-one/email-security/reference/regional-processing/) | Where Email Security examines messages for supported deployment types | Refer to the Email Security documentation |

This guide describes the current scope of Cloudflare One data localization controls.

## Regional Services for Gateway

Regional Services controls where Cloudflare Gateway performs HTTP and Transport Layer Security (TLS) inspection. Gateway decrypts and inspects supported HTTPS traffic only within the selected region.

Regional Services for Gateway is configured at the Cloudflare One account level. The selected region applies to supported Gateway traffic for the account. Contact your account team to configure the region.

Cloudflare One supports this behavior for traffic sent to Gateway through these on-ramps:

- [Cloudflare One Client](/cloudflare-one/team-and-resources/devices/cloudflare-one-client/) in [Traffic and DNS mode](/cloudflare-one/team-and-resources/devices/cloudflare-one-client/configure/modes/#traffic-and-dns-mode-default)
- [Cloudflare Mesh](/cloudflare-one/networks/connectors/cloudflare-mesh/)
- [Cloudflare WAN](/cloudflare-one/networks/connectors/cloudflare-wan/) using IPsec

Connections from these on-ramps may terminate at a Cloudflare data center outside the selected region. For supported HTTPS traffic, Gateway forwards the still-encrypted HTTPS request to the selected region before TLS decryption and inspection.

Regional Services for Gateway is available in these regions:

- European Union
- Exclusive of Hong Kong and Macau
- Exclusive of Russia and Belarus
- FedRAMP Moderate Compliant (Domestic)
- FedRAMP Moderate Compliant (International)
- IRAP Protected
- NATO
- United States of America

Refer to [Region support](/data-localization/region-support/) for region definitions. Contact your account team to inquire about the availability of other regions.

### Egress traffic

Regional Services controls where Gateway decrypts and inspects supported HTTPS traffic. Dedicated egress IPs provide predictable, account-specific source IP addresses. Customers can use them for origin allowlisting or to associate Gateway traffic with a selected IP geolocation.

Use [dedicated egress IPs](/cloudflare-one/traffic-policies/egress-policies/dedicated-egress-ips/) and [Gateway egress policies](/cloudflare-one/traffic-policies/egress-policies/) to select these source IP addresses for Gateway traffic.

## Access

Cloudflare Access uses two HTTPS connections:

1. The user connects to the [Access team domain](/cloudflare-one/faq/getting-started-faq/#what-is-a-team-domainteam-name), such as `<team>.cloudflareaccess.com`, to authenticate.
2. The user connects to the protected application hostname, such as `app.example.com`, to access the application.

### Regional Services

Regional Services controls where Cloudflare decrypts and processes supported HTTPS requests. Access supports Regional Services in the FedRAMP Moderate Compliant (Domestic) region.

Both Access connections require configuration:

1. Contact your account team to configure the Access team domain.
2. Assign the FedRAMP Moderate Compliant (Domestic) region to the protected application hostname using [Regional Services](/data-localization/regional-services/regional-hostnames/).

When both are configured, Regional Services restricts supported reverse proxy request processing to FedRAMP-compliant data centers. For supported Access log storage, refer to [Customer Metadata Boundary](/data-localization/metadata-boundary/).

### Geo Key Manager

If the protected application hostname uses a supported custom certificate, [configure Geo Key Manager](/ssl/edge-certificates/geokey-manager/setup/) to restrict where Cloudflare stores the private TLS key for that hostname.

## Browser Isolation

Browser Isolation supports Regional Services in the US FedRAMP region. Contact your account team to set up a FedRAMP account.

## Customer Metadata Boundary

[Customer Metadata Boundary](/data-localization/metadata-boundary/) is an account-level setting that stores supported Customer Logs in the European Union or United States. It is configured independently from Regional Services.

Support varies by dataset. Refer to the current lists of [CMB-supported Logpush datasets](/data-localization/metadata-boundary/logpush-datasets/) and [CMB-supported GraphQL datasets](/data-localization/metadata-boundary/graphql-datasets/).

Some Cloudflare One dashboards and APIs cannot retrieve data stored with EU CMB. For supported datasets, use [Logpush](/logs/logpush/) to send a copy of the logs to a destination you control.

## Additional log controls

Some Cloudflare One products provide additional product-specific controls for reducing or protecting logged data.

### Gateway logs

Use Gateway logging controls to [exclude supported personally identifiable information fields](/cloudflare-one/insights/logs/dashboard-logs/gateway-logs/manage-pii/) or [select which events appear in Cloudflare One activity logs](/cloudflare-one/insights/logs/dashboard-logs/gateway-logs/#selective-logging).

### DLP payload and AI prompt logging

[Configure DLP payload and AI prompt logging](/cloudflare-one/data-loss-prevention/dlp-policies/logging-options/) to encrypt matched content with a customer-provided public key. Only the customer holds the private key required to decrypt the protected content.

### SSH command logs

[SSH command logs](/cloudflare-one/insights/logs/dashboard-logs/ssh-command-logs/) can encrypt downloadable logs with a customer-provided public key for local decryption. This encryption only applies to downloadable SSH logs, not to logs exported through Logpush.

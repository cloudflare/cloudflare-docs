You can configure your log region to select where your logs and analytics are stored. This setting controls where Cloudflare stores traffic metadata that could identify your end users. It does not control where stored files and objects are kept; those are controlled separately by a [storage region](/data-localization/storage-region/). You can configure your log region via API or the dashboard.

Currently, this can only be applied at the account level. If you only want the log region to apply to a portion of zones beneath the same account, you will have to [move the rest of the zones to a new account](/fundamentals/manage-domains/move-domain/).

## Configure your log region in the dashboard

To configure your log region in the dashboard:

1. In the Cloudflare dashboard, go to the **Settings** page.

   <DashButton url="/?to=/:account/configurations" />

2. In **Customer Metadata Boundary**, select the region you want to use: `eu` or `us`. Selecting `Global` applies no log region, which is the default, meaning your logs may be stored in Cloudflare's core data centers globally.

## Configure your log region via API

You can also configure your log region via API.

Currently, only SuperAdmins and Admin roles can edit data residency configurations. Use the **Account-level Logs:Read/Write** API permissions for the `/logs/control/cmb` endpoint to read and write log region configurations.

These are some examples of API requests.

<Details header="Get current regions">

Here is an example request using cURL to get current regions (if any):

<APIRequest
	path="/accounts/{account_id}/logs/control/cmb/config"
	method="GET"
/>

</Details>

<Details header="Setting regions">

Here is an example request using cURL to set regions:

<APIRequest
	path="/accounts/{account_id}/logs/control/cmb/config"
	method="POST"
	json={{
		regions: "eu",
		allow_out_of_region_access: false,
	}}
/>

This will overwrite any previous regions.
Change will be in effect after several minutes.

</Details>

<Details header="Delete regions">

Here is an example request using cURL to delete regions:

<APIRequest
	path="/accounts/{account_id}/logs/control/cmb/config"
	method="DELETE"
/>

</Details>

## View or change settings

To view or change your log region:

1. In the Cloudflare dashboard, go to the **Settings** page.

   <DashButton url="/?to=/:account/configurations" />

2. Go to **Preferences**.
3. Locate the **Customer Metadata Boundary** section.

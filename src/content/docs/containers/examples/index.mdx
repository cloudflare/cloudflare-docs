Build with Containers using the `durable_object` scheduling policy. Each example configures a named image and starts it from a Durable Object with the [Container API](/containers/api/durable-object-container/).

Start with [Stateless instances](/containers/examples/stateless/) for HTTP routing, or [Cron container](/containers/examples/cron/) for a scheduled task.

To run commands against an agent's durable files, follow [Use Cloudflare Computer's container backend](/agents/tools/code-execution/persistent-files/). Its experimental container backend synchronizes a mounted workspace with Durable Object storage.

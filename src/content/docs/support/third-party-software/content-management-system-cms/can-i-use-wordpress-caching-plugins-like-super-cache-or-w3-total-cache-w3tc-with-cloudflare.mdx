title: Can I use WordPress caching plugins like Super Cache or W3 Total Cache
  (W3TC) with Cloudflare
---

It is possible to cache the HTML of a WordPress site at Cloudflare's edge using a feature known as "Bypass Cache on Cookie". This can dramatically improve the speed of your website and reduce server load; in cases where the HTML is cached, Cloudflare will not need to make a roundtrip to your web server. For more information about this feature, refer to the [Bypass Cache on Cookie](/cache/how-to/cache-rules/examples/bypass-cache-on-cookie/) cache rule example.

Cloudflare is able to proxy HTTP traffic of any website, including WordPress sites with third-party performance plugins installed. However, these plugins are installed at your own risk.

You notice that stale data - for example, an IP address that you had removed from an A record - is returned even after the corresponding [Time to Live (TTL)](/dns/manage-dns-records/reference/ttl/).

## Cause

In the event that an upstream DNS server takes too long to respond, or the upstream returned a SERVFAIL, Cloudflare will use the expired DNS response from the cache and then attempt to update that cache async.
